# D-GEC 候选 C 的统计含义、可估计性与最小检查

2026-10-24。独立阅读 D-GEC、OAMP-MMV 原文及历史残差报告；仅形成研究建议，未训练、未运行接收机、未修改冻结资产。

## 1. 先定义 C：它是网络 query 的工作噪声协方差

设 H 为物理信道，接收机使用固定归一化尺度 `s=0.2647966452702405`，有效目标为 `x=aH/s`；观测与测量噪声方差相应使用 `Y/s`、`σ_physical²/s²`。送入先验模块的原坐标 query 为 u，本文所有消息 covariance 均在此归一化坐标中，物理 covariance 需乘回 s²。依据 `src/algorithm/STMP/iterations.py:47–48`、`src/configs/final/STMP.json`。有色 Gaussian 条件训练希望近似的是

\[
u\mid x,C\sim\mathcal{CN}(x,C),
\]

其中还包含适当复数、零条件均值及单位信号增益的假设。若采用实坐标，应改用对应实 Gaussian 模型。这里的 **C 应当指向 query 误差**，不能与以下对象混为一谈：

| 对象 | 定义或作用 | 与 query C 的区别 |
|---|---|---|
| 活跃信道先验协方差 | `R_H=Cov(H/s\mid a=1)` | 描述归一化信号分布；不能当噪声标签 |
| 模块后验协方差 | `Cov(x\mid u,C)`，或其分组投影 | 描述估计后的不确定性；GEC 中对应后验精度 η 的逆 |
| Gaussian site / 外信息参数 | 两个消息交换的精度 γ 与均值参数 r | 是算法工作参数，不自动等于某个实际随机误差的协方差 |
| 网络 query 的工作协方差 | 固定变换下 `C_work=TᴴDiag(γ₂⁻¹)T` | D-GEC 给网络的噪声模型；需检验其统计解释 |
| 真实 query 误差中心协方差 | `Cov(u−x\mid 已声明的条件)` | 依赖误差真实分布；模拟真值只能离线评价 |
| 未中心化误差二阶矩 | `E[(u−x)(u−x)ᴴ\mid 条件]` | 等于中心协方差加条件偏差外积；不能称为已去除偏差的噪声协方差 |

因此，“C 是 query 协方差还是 site 参数”不是必须二选一：**γ₂ 是送到去噪模块的 Gaussian 外信息精度，其逆经过坐标变换后被解释为 query 噪声协方差。后半句是需要验证的统计模型，前半句是算法定义。**

依据：Saurav K. Shastri, Rizwan Ahmad, Christopher A. Metzler, Philip Schniter，*Denoising Generalized Expectation-Consistent Approximation for MR Image Recovery*，作者稿 v2，2022-09-07，[PDF](../../../literature/shastri2022_dgec.pdf)，§II-D p.8 式(22)–(23)、§III-A pp.13–15 Algorithm 3、式(35)–(38)。[在线原文](https://arxiv.org/pdf/2206.05049v2)。

## 2. 固定基、固定分组后，GEC 递推本身就给出 C

取固定酉变换 `T`，令 `c=Tx`、`B=ATᴴ`。将系数索引分成固定组 `G_ℓ`，每组使用一个精度 `γ_{i,ℓ}`，在组内重复。原文使用实正交小波变换 Ψ，其图像信号也可以是复数；下文改用酉变换 T 是候选坐标推广，不代表已证明本项目的统计性质。复数网络灵敏度还须按相应 Wirtinger 或实增广坐标约定实现。

在线性模块，定义

\[
Q_1=(\gamma_wB^HB+\Gamma_1)^{-1},\quad
\widehat c_1=Q_1(\gamma_wB^Hy+\Gamma_1r_1),\quad
J_1=Q_1\Gamma_1,
\]

\[
\alpha_{1,\ell}=|G_\ell|^{-1}\operatorname{tr}(J_{1,\ell\ell}),\quad
\eta_{1,\ell}=\gamma_{1,\ell}/\alpha_{1,\ell},\quad
\gamma_{2,\ell}=\eta_{1,\ell}-\gamma_{1,\ell},
\]

\[
r_2=\Gamma_2^{-1}(\Eta_1\widehat c_1-\Gamma_1r_1),\qquad
u=T^Hr_2,\qquad C_{\rm work}=T^H\Gamma_2^{-1}T.
\]

因为 Γ₁ 在组内恒定，`α₁,ℓ=γ₁,ℓ tr(Q₁,ℓℓ)/|Gℓ|`，故 η₁ 的逆就是线性工作后验协方差的组内平均对角元。这是从线性估计器及其灵敏度计算出来的，不需要先计算 `Y−A xhat` 的经验 covariance。

非线性模块使用完整映射 `F(u,C)=p(u,C)μ(u,C)`；系数坐标估计器是 `f₂(r₂,γ₂)=T F(Tᴴr₂,C_work)`。对应递推为

\[
\alpha_{2,\ell}=|G_\ell|^{-1}\operatorname{tr}(\nabla f_{2,\ell\ell}),\quad
\eta_{2,\ell}=\gamma_{2,\ell}/\alpha_{2,\ell},\quad
\gamma_{1,\ell}^{next}=\eta_{2,\ell}-\gamma_{2,\ell},
\]

再按 Algorithm 3 line 12 更新 `r₁`。原文式(31)给 `gdiag`，式(33)给分组随机探针近似，式(34)给分组精度结构；定位 pp.13–14。

**这回答了可估计性问题的一半：** A、测量噪声参数、当前 Γ₁ 和完整模块灵敏度可用时，C_work 可以无真值递推。剩下一半是 `r₂−c` 是否真服从 `N(0,Γ₂⁻¹)`。原文 p.14 式(36)将其作为实验观察，并明确表示严格分析仍待研究；不能因 γ₂ 可算就宣布 C 已被统计识别。

还需注意：

- 对一般学习映射，分组 `α₂` 不自动落在正精度所需范围；负精度、近零分母和网络支持超界必须报告。任意 clipping 是额外工程近似，不能默认为原算法保证。
- 旧第二网络的一个条件 MSE 标量不能直接替代一组 Jacobian 部分迹，也不能自动生成矩阵后验协方差。若用 MMSE–Jacobian 关系代替，需要同一条件 Gaussian 模型和匹配的完整后验均值。
- corr+corr 的附加噪声应在给定 γ₂ 下独立生成。计算一次 Jacobian 的基准/扰动前向时应固定 γ₂，并复用同一附加噪声实现，避免独立重采样差分除以小步长制造伪灵敏度。这是对原文式(33)、(39)–(41)组合后的实现推断。
- `γ_w` 的噪声估计误差与 Γ₁ 的初始化仍会影响 C_work，精度递推没有消除这些输入误差。

## 3. 不能把历史残差失败直接当成 GEC 递推失败

[20261015 公开残差报告](../../../../archive/result_legacy_20261023/layout_20261021/before/docs/history/results/proposed_memory_requirements_20261015/REPORT.md) 检查的是 `Z_i=Y−AF_i=N−Ae_i` 的残差二阶矩估计反馈误差 covariance。其误差包含反馈与同一观测噪声的交叉项、A 的投影误差和有限样本噪声功率偏差。26 个三轮窗口的残差融合有 14 个真实 MSE 上升，最大增加 4.1703 dB。

这足以反对“从测量残差减掉热噪声就得到了 query C”的默认做法，但**没有直接检验以上 GEC 的分组灵敏度/精度递推**。两条路径必须区分：

1. C_work 由 GEC 消息参数递推；这是候选算法的组成部分。
2. C_true 由独立开发模拟中的真值误差离线测量；这是校验标签是否有正确统计含义，不能输入正式推断。

不建议再以第 2 条的 oracle 矩阵替代第 1 条并报告候选的可部署改善，也不建议未经条件核验又用旧残差公式校准 γ。

## 4. 新 mode Gram 结果要求撤回“天线-only 优先”的建议

本项目 `MMVLinear.pack` 把 `[K,M,N,P]` 排成 `[KP,MN]`；当前为 640×256，M=16 是物理天线数，256=MN。用户信道块有 MNP=4096 个复数坐标。

早先因现有线性模块支持共同空间 covariance，而提出固定空间酉基 `U_M`、至多 M=16 个模式方差的低维子族：

\[
C_{sp,t}=U_M\operatorname{diag}(\tau_{g(1),t},\ldots,\tau_{g(M),t})U_M^H,
\]

\[
C_{k,t}^{work}=C_{sp,t}\otimes I_{NP},\qquad
C_{all,t}^{work}=I_K\otimes C_{k,t}^{work}
\]

（Kronecker 次序随具体向量化排列改变。）项目实际是 **UPA 4×4**，不是 ULA；如使用空间 DFT，对应 `U_M=F_4⊗F_4`，具体次序与 `m=n_z+4n_y` 一致，见 `src/system/core/upa.py:24–47`。这只是固定物理基候选，不能称真实误差特征基。

**根据主任务新完成的 48 条件×3 阶段离线 mode Gram 摘要，应撤回把该子族作为目前优先充分表示的建议。** 在 uniform、−4 dB、final 中，active/inactive 的归一化非对角平方和占比分别为：

| 展开轴/基 | active 中位数 | inactive 中位数 |
|---|---:|---:|
| 天线原基 | 0.0847 | 0.0902 |
| 输出行原基 | 0.0973 | 0.0971 |
| 输入列原基 | 0.4715 | 0.4914 |
| 输入列普通 DFT | 0.4444 | 0.4622 |

相同口径白噪声参考约 0.055。首轮天线统计约 0.51，空间 DFT 降至约 0.34，但末轮无改善。以上数字来自主任务离线摘要，本笔记未重新计算，也不据此形成新训练分布。mode Gram 是边缘二阶统计；若未中心化，其中可能包含均值/信号偏差，不能只把数值称作零均值噪声 covariance。不同轴的统计也没有唯一确定完整高维 covariance。

**这些证据支持：当前天线-only 模型不能被视为充分，输入列方向应成为优先解释和检查的对象。它们尚未证明输入列 covariance 是唯一缺失因素。** 输入普通 DFT 仍留下大量非对角成分，因此不能简单把“空间 DFT”改成“输入 DFT”后就认为问题得到解决。随后主任务对公开 A_k Gram 基完成了下述事后诊断，该基现在已有明确的探索支持。

`src/algorithm/STMP/linear.py:49–77` 支持共同空间 covariance，这只是旧子族的实现便利，不是选择统计模型的证据。当前 `denoiser.py` 也只消费 isotropic cavity；任何新的有色接口仍需配套局部模块。

旧空间子族另有两项一般限制：

**第一，纯空间基变换不会增加 A 的混合性。** 观测算子在物理空间维重复 A0，固定天线 U_M 只重新组合等价的 MMV 列，等价于与重复观测作用交换。D-GEC 原文 pp.11–12 的动机是 Fourier–wavelet 各子带的近似解耦和子带内随机化；我们不能把这个 MRI 论证移植到天线 DFT。固定基这里只表达 covariance 形状。

**第二，真实误差方向未必有固定特征基。** 多用户不同角度的低秩信道、用户条件和每轮剩余干扰可能产生非对角模式 covariance。增加每模式方差数量仍表达不了跨模式项。若独立开发检查显示这种缺失主导活动证据，这个子族应被否决，再决定是否需要用户条件 covariance、低秩项或更一般矩阵；不能事先称它充分。

共同 C 避免每用户单独估矩阵的统计负担，但忽略用户异方差；即使全局 MSE 标签准确，也可能不适合弱用户判决。

### 4.1 公开 A_k 的特征基已有强探索支持，完整统计模型仍未验证

当前 `src/system/scenario/generate.py:209–213` 调用的是全局 `PartialDFTPilot`，再由用户跨帧相位构造 A；不是历史候选 `PerUserDFTPilot`。因此不能误用历史逐用户正交设计而断言当前 `A_kᴴA_k=I`。当前各用户 `A_k∈C^{16×16}` 的 Gram 一般有非平凡谱，其特征向量可仅由公开 A 计算。

可以明确写出、然后在独立开发数据上检查的输入列子族是

\[
A_k^HA_k=U_k\Lambda_kU_k^H,\qquad
C_{in,k,t}^{work}=U_k\operatorname{diag}(\tau_{k,g,t})U_k^H,\qquad
C_{k,t}^{work}=I_{MN}\otimes C_{in,k,t}^{work}.
\]

这允许每用户输入列颜色，在其余两个轴暂作白近似；不包括跨用户误差相关，也不保证表达首轮空间相关。U_k 是**给定公开算子后在该条件内固定**的基，通常随用户和导频场景改变，不是所有样本共享的同一个固定 Fourier 基。退化/近退化特征空间内的基不唯一，训练接口若只消费噪声样本需与实际采用的 covariance 一致，不能将不稳定的单个特征向量视为已识别物理方向。

主任务在同一 48 条件的后续事后诊断中，用 `V_k=eig(A_kᴴA_k)` 变换输入列 mode Gram，得到以下非对角能量占比（本笔记引用探索摘要，未重算）：

| uniform 工况/阶段 | active 中位数 | inactive 中位数 |
|---|---:|---:|
| −4 dB，首轮 | 0.0530 | 0.0626 |
| −4 dB，第 20 轮 | 0.0711 | 0.0732 |
| −4 dB，final | 0.0285 | 0.0274 |
| 0 dB，首轮 | 0.1106 | 0.1274 |
| 0 dB，final | 0.0291 | 0.0276 |

−4 dB final 从原输入列基的 0.4715/0.4914 降到 0.0285/0.0274，明显强于普通 DFT。这给出**优先验证公开算子确定的输入基**的实证依据；不再仅仅是根据 A 的形状提出的候选。它仍是同组场景上的探索，既未验证全程条件 Gaussian 模型，也未解决首轮空间结构或所有跨坐标项。

不能把 0.028 小于白噪声参考约 0.055 解读为“比白噪声更白”。若模式方差的变异系数约 0.9，对角项能量增大，即便残差来自完全正确的有色对角 Gaussian 模型，该比值也会降低。作为**有限样本代数参照**，对 n 个独立 proper Gaussian 样本、d 维对角 covariance D，样本 Gram 的非对角能量期望与总能量期望之比是

\[
\frac{(\operatorname{tr}D)^2-\operatorname{tr}(D^2)}
 {n\operatorname{tr}(D^2)+(\operatorname{tr}D)^2}.
\]

这不是随机比值本身期望的精确公式。取 `n=256,d=16,CV=0.9` 得约 0.0296；白噪声为约 0.0551。它说明应使用**相同非均匀模式方差、相同样本数的有色 Gaussian 参考**，而非把所有结果与白参考硬比。真实坐标存在依赖时，有效样本数和统计波动也可能不同；该参照并未证明实际误差条件独立。

不能自动成立的关键一步是：`A_kᴴA_k` 的特征向量并不普遍对角化实际 query 误差。线性查询的误差恒等式为

\[
e_r=(I-LA)e_{in}+Ln,\qquad e_{in}=x_p-x.
\]

若记 `B_0=I−LA`，其中心 covariance 包含

\[
C_r=B_0C_{in}B_0^H+\sigma_n^2LL^H
 +B_0C_{in,n}L^H+LC_{n,in}B_0^H.
\]

此外还要单独处理条件均值。即使假设 `C_in=γI` 且交叉项为零，当前 L 也含 `Aᴴ(σ_n²I+γAAᴴ)⁻¹` 和迹归一化，用户块 covariance 一般涉及 `A_kᴴW A_j`，而不只是自身 Gram。用户相位和非正交块使 `AAᴴ` 未必为标量 I；随 γ 改变的 W 会改变用户块的方向。再加上真实结构反馈 covariance 和噪声交叉项，固定 U_k 没有普遍对角化保证。

这也给出一条可核查的近似机制，而非仅凭相关性猜基：若在理想工作模型下 `A_0A_0ᴴ=cI`、`C_in=γI` 且反馈误差与测量噪声不相关，那么迹归一化线性滤波器为 `L=ℓA_0ᴴ`，利用 `(A_0ᴴA_0)²=cA_0ᴴA_0` 可得

\[
C_r=\gamma I+\beta A_0^HA_0,\quad
\beta=-2\gamma\ell+(\gamma c+\sigma_n^2)\ell^2.
\]

其第 k 个用户的输入列边缘 covariance 恰为 `γI+βA_kᴴA_k`，所以由 U_k 对角化。当前实验不保证这些条件，但如果公开 `A_0A_0ᴴ` 接近标量矩阵，就有具体理由预期这个基有用。上述代数不把实际反馈的信号依赖、交叉噪声项或早期空间相关消除；它应作为后续公开算子诊断和独立验证的解释假设。

因此更准确的优先级是：**优先在独立开发数据上验证公开 A_k 特征基及其输入列模式方差表示；当前探索结果支持这一顺序，但不能代替完整 C 族和条件噪声分布的检验。** 如果固定 U_k 投影后，相对匹配的有色 Gaussian 参照仍存在显著非对角误差或条件偏差，就应调整或否决它；不能用同一 48 条件继续挑一个最好基、学习训练 p_Γ，训练后又用同组条件证明成功。也不应未经检验改成每轮由真值误差 PCA 产生 U_k，那是 oracle 模型。

输入列 covariance 不在当前共同天线 `SpatialLinear` 的直接接口内，不能只替换一个 16×16 矩阵的作用轴。对应公开线性工作模型可用 `S_1=blockdiag(S_{1,k})`，并通过 `σ_n²I_Q+A_0S_1A_0ᴴ` 的 Q×Q 逆计算 Gaussian 更新；Q=16，线性代数规模可控，但分组投影、外信息和非线性接口都需一致改写。这个可实现性判断不代表统计模型已经通过。

## 5. 仅 C 模型表达不了什么，以及哪些相关性不必被误判

**均值或增益。** 若真实 query 可写成 `u=Gx+b+ε`，只匹配 `Cov(ε)` 不会修正 G 或 b。将 `u−x` 的二阶矩直接当 C 会把偏差混入噪声，但这不等于学习到了正确的活动似然。OAMP-MMV 使用 `Xhat=XΘ+Z`，同时记录 Θ 与 Σ，而不是只有 Σ；见 Cheng 等 2023 v1 [PDF](../../../literature/cheng2023_oamp_mmv.pdf) p.5 式(15)–(18)、p.6 式(28)–(34)。单次真值投影系数也不是已经识别的条件增益矩阵，尤其每用户信道低秩时不能从一份样本估任意 G。

**跨用户相关。** `I_K⊗C_k` 省略用户间误差相关。跨用户相关本身不必破坏单个用户的正确边际 Gaussian 似然，但会影响联合推断、活动耦合以及线性反馈的有效 covariance。不能以“每用户边际近似正确”证明完整闭环近似正确，也不能以存在任何跨用户相关就直接断言局部分类器模型无效。

**跨轮相关。** D-GEC 每轮 query 的 Gaussian 边际模型不要求不同轮误差彼此独立。仅发现时间相关不能否定当前轮的 C 模型。但若额外做历史平均或双向阻尼，混合后的 covariance 需要交叉项；不能继续把原未阻尼 γ₂⁻¹ 原样解释为混合 query 的 covariance。Takeuchi 的长记忆公式提供的是这方面的条件核对，不能叫当前参数阻尼 bug。

**复数伪协方差。** 对非 circular 复数误差，仅 `C=E[eeᴴ]` 不足以定义 Gaussian 分布，还需要 `P=E[eeᵀ]`。直接使用 proper `CN(0,C)` 生成噪声等于假设 P=0；要检验它。若 P 的影响不可忽略，可以用实部/虚部联合实坐标模型表达，而不是只增加 Hermitian C 的秩。原文 corr+corr 本来在实向量/多输入通道下定义，不能把“可用于复数图像”解释为 P 可忽略的证明。

**条件依赖。** 实际 γ₂ 可经前几轮 Jacobian 依赖 y、信道和活动；线性本轮的 Jacobian不依赖 r，并不意味着整段 γ 历史与活动独立。独立条件训练使用的是 `p(a,H)p_Γ(γ)p(u\mid aH/s,γ)`；部署可能具有不同的 `p(a,H\mid γ)` 和不同的 `p(u\mid aH/s,γ)`。两者不必一致。这不是“内生 γ 必然无效”的结论，而是必须检验的条件校准问题。corr+corr 的额外噪声只编码给定 covariance，不会恢复被遗漏的活动条件先验或均值偏差。

## 6. 最小的可证伪检查，不在本轮启动实验

后续只有在用户另行授权实验时执行。设计上先固定基、分组、精度递推、初始化、网络条件模型和评价方案，再查看独立确认结果。

1. **算法内参数资格。** 检查两模块 α、η、γ 的可行性和数值支持，完整 pμ 链式项与分组坐标一致性；C_work 始终由公开输入和递推参数产生。真值不可回流。先用可解析 Gaussian 先验核对分组线性/外信息代数；这只能证明实现，不能证明物理统计模型。
2. **预测方差对实际误差。** 在独立开发场景，按组比较 `E||P_g T(u−x)||²/|G_g|` 与 `τ_g`，同时分别记录中心化 covariance、均值项与信号投影。全局平均接近 1 不能代替活跃/非活跃、弱/强用户分层校准；阈值应按场景抽样不确定度规定，不把 KNP 坐标当完全独立样本。
3. **固定基是否足够。** 评价变换域组间 covariance、组内异方差、伪协方差以及用户差异，与相同维度/样本数的模型 Gaussian 对照比较；不能因为高维样本矩阵偏离单位阵就宣布失配。若方向性遗漏显著影响局部活动概率，这个 C 子族失败，应调整表示而不是只调一个总体方差倍率。
4. **条件分布是否正确。** 比较均值/增益校准、条件 Gaussian 尾部和活动概率可靠性。可以用已声明的 oracle Gaussian 替换作机制对照，但需要分开保留/重置增益和均值；替换多个因素所得收益不能唯一归因于 covariance 形状。
5. **闭环与局部资格分开。** 局部合成有色 Gaussian 去噪/分类正确只是必要检查。闭环仍须验证 γ 的校准、支持范围、固定门限漏检/虚警和弱用户表现。已存在 256×256 Onsager、FIRE 和残差历史融合负结果，不能只凭局部矩匹配宣称闭环改善。

## 7. 训练 C 分布与已有 48 场景的边界

D-GEC 原文 p.16 式(41)通过独立抽取 `γ∼p_Γ` 及条件噪声训练，p.17 的实验采用预先指定的子带标准差范围。p.15 式(37)允许用**训练集**估初始误差的平均分组精度，并讨论以额外初始噪声保证早期匹配的代价；不是用测试失败样本拟合训练分布。

**不能使用当前 48 份冻结诊断回放学习 p_Γ、选择 C 的特征基/秩/分组，或调整条件噪声训练区间后，再把同一 48 份当独立效果证据。** 它们已用于机制诊断，且 48 份不等于 48 个独立场景。可以据其发现一般问题、提出可检验假设；训练 covariance 族及覆盖范围应来自物理设计、预先规定的合成参数范围、独立训练/开发数据。若某些旧场景实际参与模型选择，必须明确降为开发用途，之后另留未参与选择的确认场景。

即使以独立训练数据生成了合理 p_Γ，也应在独立开发闭环上检验 `p(a,H\mid γ)` 与 `p(u\mid aH/s,γ)` 的匹配；这种资格检查不同于通过整段十层反传训练。独立 covariance 条件模块可以保留模块化路线，但其输入统计承诺必须被真实 query 支持。

## 结论

更新后的建议是：**撤回天线-only 作为优先充分表示的提议；公开 A_k Gram 特征基已明显降低输入列 mode Gram 的非对角项，应优先做独立开发验证。** 目前支持的是这一输入基的探索方向，完整 covariance 族及全程条件噪声分布仍未验证，尤其早期空间相关尚未解决。基与分组经独立开发确定后，可由 GEC 分组精度递推生成 C_work；“它是否描述真实 query”仍是可否证假设。还需分别处理均值增益、跨用户/跨轮依赖和复数伪协方差。无需将旧公开残差 covariance 估计重新包装成必需步骤，也不能用这 48 条件学习训练 covariance 分布后继续宣称独立验证。
