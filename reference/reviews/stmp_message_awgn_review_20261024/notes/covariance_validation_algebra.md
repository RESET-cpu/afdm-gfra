## 1. 定义与第一步恒等式

对每个用户 `A_k∈C^(Q×Nin)`，取公开局部右奇异基 `V_k`，令

\[
B=[A_1V_1,\ldots,A_KV_K],\quad N=K N_{in},\quad
S=\sigma^2 I_Q+\nu B B^H,
\]

其中初始 Gaussian 输入 covariance 为 `νI`、均值为 0。记 `b_i` 为 `B` 第 `i=(k,j)` 列，定义

\[
K_0=\nu B^HS^{-1}B,\quad h_i=(K_0)_{ii},\quad
\phi=N^{-1}\sum_i h_i.
\]

只要 `σ²>0,ν>0,b_i≠0`，有 `0<h_i<1`。若 `b_i=0`，该模式没有观测信息，正确外信息精度为 0，不能用除以 `h_i` 的公式产生有限 query；第 8 节详述数值秩亏及接口含义。另有 `sum h_i<Q`，当前 `Q=16,N=640` 时 `φ<0.025`。

细分模式组的第一步输出为

\[
r_{2,i}=\frac{\nu b_i^HS^{-1}y}{h_i},\qquad
\tau_{2,i}=\nu\frac{1-h_i}{h_i}.
\]

原公共归一化在同一输入基中为

\[
r_{old,z,i}=\frac{\nu b_i^HS^{-1}y}{\phi},\qquad
v_{old}=\nu\frac{1-\phi}{\phi}.
\]

因此

\[
\boxed{r_{2,i}=\frac{\phi}{h_i}r_{old,z,i}.}
\]

在这一步它首先是一项可完全检查的、逐模式增益重标定，不是凭 covariance 标签本身创造了额外观测。所有 `(m,r)` 共用同一 `h_i` 和线性算子。

## 2. Jensen 关系：细组平均方差不能免费降低

当全部 `h_i>0` 时，由 `1/h` 的凸性，

\[
\bar\tau_2=\nu\left(\frac1N\sum_i\frac1{h_i}-1\right)
\ge\nu\left(\frac1\phi-1\right)=v_{old}.
\]

比例为

\[
R_{var}=\frac{\bar\tau_2}{v_{old}}
=\frac{\phi\,\overline{h^{-1}}-\phi}{1-\phi}\ge1.
\]

更有解释力的精确分解为

\[
\bar\tau_2-v_{old}
=\frac{\nu}{\phi^2}\,
\overline{\frac{(h_i-\phi)^2}{h_i}},\qquad
R_{var}=1+
\frac{\overline{(h_i-\phi)^2/h_i}}{\phi(1-\phi)}.
\]

只在全部 `h_i` 相同时取等。小 `h_i` 不仅带来大增益 `φ/h_i`，还以 `1/h_i` 权重主导均值，所以仅报告中位数会漏掉主要风险。

这个不等式针对**全部 N 个模式、相同权重**的平均；对任意活跃用户子集，不一定仍有 `mean τ_active ≥ v_old`，因为该子集平均 `h` 不一定等于全局 `φ`。可对该子集用其自身平均 `h` 写 Jensen 下界，但不要把全局保证逐用户套用。

对固定嵌套分组，设组均值 `h_g=mean_{i∈g}h_i`，组标签 `τ_g=ν(1/h_g−1)`。按组维度加权，进一步细分会使平均标签不下降。这提供了可检查的“分组精细度—噪声放大”取舍，不表示应任意挑一个有利分组。

### 2.1 它何时也是实际 MSE 关系

在严格工作模型 `z∼CN(0,νI)`、`w∼CN(0,σ²I)` 独立下，令 `D_h=diag(h)`，细组估计矩阵

\[
F_2=\nu D_h^{-1}B^HS^{-1},\qquad G_2=F_2 B=D_h^{-1}K_0.
\]

误差为 `(G_2−I)z+F_2w`，故

\[
C_{e,2}=\nu\left[
D_h^{-1}K_0D_h^{-1}-D_h^{-1}K_0-K_0D_h^{-1}+I
\right].
\]

其对角恰等于 `τ2_i`。原公共输出的误差 covariance 为

\[
C_{e,old}=\nu\left[I+(\phi^{-2}-2\phi^{-1})K_0\right],
\quad N^{-1}\operatorname{tr}C_{e,old}=v_{old}.
\]

因此在该 iid Gaussian 工作模型下，Jensen 也是**第一步线性 query 平均 MSE**的比较。本项目真实物理信道不满足这个完整先验；该关系不能替代实际误差检查，也不能推出后续非线性估计或活动检测一定更差。较大 query 噪声与较小信号偏差可能有不同检测效果，需实测。

## 3. 何时会退化为逐用户直接逆

考虑当前 `Q=Nin` 且 `A_k` 满秩。写

\[
A_k=U_k D_k V_k^H,\qquad B_k=A_kV_k=U_kD_k,
\]

`D_k=diag(s_kj)>0`。若 `S=tI`，则

\[
h_{kj}=\nu s_{kj}^2/t,\quad
r_{2,kj}=u_{kj}^Hy/s_{kj},\quad
\tau_{2,kj}=t/s_{kj}^2-\nu.
\]

变回物理输入坐标即

\[
\boxed{r_{2,k}=V_kD_k^{-1}U_k^Hy=A_k^{-1}y.}
\]

此时还没有其他用户的非零反馈均值可用于干扰消除；直接逆把其他活跃用户和观测噪声都带入本用户 query。仅 thermal 部分的输入模式方差就是 `σ²/s_kj²`。

严格等号并不要求 `S` 为标量：只要 `W_k=U_k^HS^{-1}U_k` 对角，也得到同一结果。一般情形令

\[
E_k=\operatorname{diag}(W_k)^{-1}
[W_k-\operatorname{diag}(W_k)],
\]

则细组 query 的物理线性算子恰为

\[
L_{2,k}=V_kD_k^{-1}(I+E_k)U_k^H,
\qquad
L_{2,k}-A_k^{-1}=V_kD_k^{-1}E_kU_k^H.
\]

这给出了直接可计算的接近程度，不必凭“低 SNR”口头推断。特别地

\[
\frac{\|L_{2,k}-A_k^{-1}\|_F}{\|A_k^{-1}\|_F}
\le\|E_k\|_2.
\]

当 `σ²I` 主导 `νBBᴴ`，或 `BBᴴ` 近标量时，`S` 接近标量，故此退化有明确根据。还应区分算子接近直接逆与本用户响应接近单位阵：在 `V_k` 坐标中

\[
V_k^H L_{2,k}A_kV_k
=I+D_k^{-1}E_kD_k,
\]

后者会受奇异值比影响。即使 `E_k` 小，病态 `A_k` 的 cross-mode 响应偏差也可能被放大。

**不能用调小初始 `ν` 自动消除这一问题。** 在噪声主导极限，分子和归一化中的 `ν` 抵消，仍趋向 `A_k^{-1}y`。机械扩大新网络的方差训练范围也不会恢复小奇异值方向已经不足的观测信息。

## 4. 为什么第一次 query 的完整独立轴模型尚不成立

候选声明

\[
C_k=I_M\otimes I_{Nout}\otimes
V_k\operatorname{diag}(\tau_k)V_k^H.
\]

这同时声明了：输入模式在 `V_k` 基中不相关；不同天线/输出行独立且使用相同输入谱；噪声 proper Gaussian；其条件均值为零，且对本用户信道没有未建模依赖。mode-Gram 近对角只检验其中一个二阶性质。

第一次物理查询满足

\[
R_2=L_2(AH+W),\quad E_2=(L_2A-I)H+L_2W.
\]

实际 `H` 有共同用户活动、共享路径、空间 steering 和 AFDM 行列结构。第一项会把这些结构直接传给误差。相同 `A`/`L` 重复用于所有天线与输出行，并不会把这些物理坐标变成独立样本。

即使在 `S=tI` 的直接逆特例，本用户信号项可以完整保留，但剩余项仍为

\[
E_{2,k}=A_k^{-1}\left(\sum_{j\ne k}A_jH_j+W\right).
\]

其他用户若只有少数活跃、具有强空间/AFDM 结构，则其干扰一般既非组内白也非 Gaussian。thermal 部分确实沿天线/输出行独立；只有当它足够主导时，完整候选才可能接近实际。这与早期空间相关仍显著的离线发现相容。

工作模型也不证明完整误差与完整未知信号独立：

\[
\operatorname{Cov}(e_2,z)=\nu(D_h^{-1}K_0-I).
\]

该矩阵对角为零，但通常有非零交叉项。由于 `rank(L_2B)≤Q<N`，有限系统中不可能让全向量响应等于 `I_N`。不过不能把此事实误用为“每用户 own-signal independence 永远不可能”：在直接逆特例且各用户独立时，本用户误差可与本用户信道独立，仍然受其他用户造成的有色、非 Gaussian 干扰。验证应明确独立性是指哪个层次。

给定固定真实 `H` 时，误差条件均值为 `(L_2A−I)H`，条件 covariance 的 thermal 部分为 `σ²L_2L_2ᴴ`。把单次误差 `E Eᴴ` 当成中心 covariance，会混入条件偏差；其数值适合描述二阶误差能量，却不能单独证明零均值 Gaussian 模型。

## 5. 本轮最小正确验证指标

本轮是第一步线性检查与旧 query 的有色参照，不是完整新接收机验证。至少应分别覆盖以下项目。

### 5.1 代数与尾部代价

- 用公开 `A,ν,σ²` 核对 `h,φ`、`r2_z=(φ/h) r_old_z`、`τ2` 及 Jensen 等式；保留零/近零模式，不只分析成功样本。
- 每 case 报告 `h` 与 `τ2` 的最小值、中位数、高分位和最大值，以及 `mean τ2/vold`。再按用户报告极端条件，避免总体中位数掩盖少数高放大模式。
- 报告 `A_k` 奇异值/条件数、`||L2_k||_F²` 或 thermal 输出功率 `σ²||L2_k||_F²/Nin`。通过 `||L2_k−Ak^{-1}||_F/||Ak^{-1}||_F` 或 `||E_k||` 检查直接逆解释。
- 核对完整用户 self-response `L2_k Ak`，不能只检查其变换基对角为 1。后者由公式构造，不能证明所有信号方向都已无偏。

### 5.2 真实第一步 query 的配对统计

- 相同 scene/noise/公开算子下比较新旧 query 的实际全信道 MSE、active/inactive MSE，及新旧 query 总功率；第一步 MSE 与最终检测性能分开表述。
- 在每用户 input pack `E_k∈C^(Nin×(M Nout))` 上使用 `E_z=V_kᴴE_k`，避免行向量 covariance 的共轭约定误用。比较每模式经验误差功率与 `τ2_kj`，同时报告整用户 trace 校准；只拟合 trace 不充分。
- 用声明 `τ` 标准化后检查输入模式之间、天线之间和输出行之间的残余相关；至少保留幅度分布尾部与 signal-projection/响应偏差指标。匹配 covariance 不代表 Gaussian 或独立性。
- 上述 empirical second moments 来自非独立物理坐标，有限样本参考应采用相同谱、相同轴和一致处理。不能继续用各向同性 0.055 作为任意有色谱的通用阈值。

### 5.3 有色参照能回答什么

对已保存旧 query 构造 `H+CN(0,C)`，可检验独立 Gaussian 噪声在给定 covariance 下如何影响冻结模块。但它同时移除了原误差的条件偏差、信号依赖和非 Gaussian 性。原 query 与该参照的差不能全部归因于 covariance。

同 trace 的 scalar Gaussian 参照与 input-spectrum Gaussian 参照之间的比较，才较直接地隔离**Gaussian 模型内部**的 covariance 形状影响。没有训练新两网络、也没有运行其闭环时，参照结果不能宣称新候选已经降低漏检。

## 6. 何时需要修正最小候选

1. **若细组带来严重尾部噪声放大，先拒绝“保留表示就必须逐模式完全去偏”的假设。** 输入基仍可作为诊断/训练条件，但其最细 `gdiag` 未必是合适更新。
2. 可以考察更粗、事先定义的输入模式分组，按组平均响应作标准 GEC 投影。Jensen 保证它降低或维持平均工作标签；但会保留组内增益差异，实际 query 模型需重新检查，不能保证检测更好。
3. 直接把 `h` 截断、把 `τ` 封顶或略去病态用户，会改变 self-response 或 Gaussian quotient。若采用，必须同步说明新均值/噪声模型；不能沿用原单位增益标签再把失败隐藏在裁剪后。
4. 若保留受控偏置的 LMMSE 输出而不做单位增益恢复，应显式让非线性模块处理信号增益与 covariance。那是更一般的消息模型，不再是本轮仅以 `H+CN(0,C)` 定义的最小候选。
5. 若主要缺口是初轮空间/输出行相关，应评估扩展 covariance 族；但更大 covariance 不能挽回由小奇异值直接逆造成的信息损失。需要先分清是哪一种问题。

## 7. 短小确定性核验结果

取 `Q=Nin=2,K=2,ν=.2,σ²=1`，令 `V` 为归一化 2 点 Hadamard 矩阵，

\[
A_1=\operatorname{diag}(.1,\sqrt{1.99})V^T,\qquad
A_2=\operatorname{diag}(\sqrt{1.99},.1)V^T.
\]

每个 `A_k` 的两列均为单位范数，`AA^H=2I`。因此 `S=1.4I`，严格属于上一节可检查的特例，而非从真实 AFDM 中挑选样本。

- `h=[.00142857,.28428571,.28428571,.00142857]`，`φ=.14285714`。
- `τ2=[139.8,.50351759,.50351759,139.8]`，`vold=1.2`。
- 平均方差比 `mean τ2/vold=58.4598`。
- 完整 Gaussian 工作模型误差 covariance 的对角与 `τ2` 最大误差 `2.84e−14`；旧 query 平均误差与 `vold` 差 `4.44e−16`。
- 新物理线性算子与逐用户 `Ak^{-1}` 最大 Frobenius 差 `2.83e−15`。
- Jensen 精确分解误差 `1.42e−14`。

这说明“方差标签精确、模式归一化正确、基完全合适”可以同时伴随很大的噪声放大。它不是当前 AFDM 的性能结论，但足以要求真实第一步检查优先报告上述代价。

## 8. 数值秩亏补充：零精度不是一个需要 floor 的普通小数

### 8.1 验证状态与数值来源

父任务在 1000 scenes × 两档 SNR 的第一步检查中发现部分 `A_k` 数值秩亏，并观察到某些模式的响应约为 `10^−30`。这一现象要求先判别 null space，而不能直接把其倒数报告成正常有效方差。

**第一版批量检查使用了 legacy noise 字段，未通过 48 个旧 first-query 的复算，已保留为 rejected；父任务正在用冻结 `estimate_spatial_noise(y)` 重算。** 本笔记不使用该首版的 MSE、方差放大、场景比例或噪声统计得出实验结论。以下 null 方向结论是代数事实，不依赖那一版噪声数值；最终出现数量与验证结果以修正输入且通过复算后的记录为准。

### 8.2 正确消息是零精度、零自然参数

若 `v_ki` 是 `A_k` 的右 null 方向，则 `b_i=A_k v_ki=0`，所以

\[
h_i=0,\quad p_i=\nu,\quad\eta_i=1/\nu,\quad
\gamma_{out,i}=\eta_i-1/\nu=0.
\]

Gaussian 外信息最好用精度与自然参数表示。令 `βout=γout rout`，初始均值为 0 时，对非零模式可直接写成

\[
\gamma_{out,i}=\frac{h_i}{\nu(1-h_i)},\qquad
\beta_{out,i}=\frac{b_i^HS^{-1}y}{1-h_i}.
\]

null 方向的连续含义为

\[
\boxed{\gamma_{out,i}=0,\qquad\beta_{out,i}=0.}
\]

该 Gaussian **因子**沿该方向是常数，表示线性观测没有提供信息。它本身在该方向不可归一化，但可与 proper 信道先验结合形成 proper 后验。此时 `rout=βout/γout` 没有定义；写 `τout=∞` 是“零观测精度”的极限记号，不是已经取得了一次数值无限大的 Gaussian 噪声样本。

这也适用于非零输入均值：null 方向的线性 posterior 等于输入消息，quotient 恰好将它除掉，外信息仍为零。不能把输入均值的保留误认为获得了新的观测。

### 8.3 严格正有限 16 个 τ 的 covariance 族不覆盖 null

原初候选 `V_k diag(τ_k) V_kᴴ` 规定每个 `τ_ki` 严格正且有限，因而每个对应精度都为正。它不能精确表达上述 null 方向。可在数学上把**精度域**扩展为半正定、允许零特征值，但网络接口随之需要明确哪些方向没有观测信息。

不能直接把 `∞` 方差送入当前有限噪声 corr+corr 生成器；也不能用巨大的有限随机数近似而不评估数值与统计后果。若采用零精度，非线性模块需要受训/定义明确的 mask 或半正定精度条件，并由信道先验及其他可观测坐标推断 null 成分。null 成分可以因物理先验相关性被估计，这与线性模块凭空给它一个正精度是两回事。

### 8.4 为什么“仅设 floor”不是等价修复

若把 `h_i` 换成 `hbar_i=max(h_i,ε)` 并继续沿用原公式，则它相当于人为给出

\[
\gamma_{floor,i}=\frac{\bar h_i}{\nu(1-\bar h_i)}>0.
\]

对真实 null 方向，原分子为零，因而 `r_floor=0`。这产生的是一个**以零为中心、有正精度的人工消息**，会约束该方向信道接近零；而原观测在此没有信息。对近 null 方向，其 own-mode response 变为 `h_i/hbar_i`，一般不等于 1，故仍把它标为单位增益 `H+CN(0,C)` 也不正确。

因此 floor 可以被设计成一个新的正则化操作，但必须说明引入的偏置/人工信息和相应训练条件；它不是原 GEC quotient 的数值等价实现。只 cap `τ`、只 clip query 或在统计中删去病态模式，同样不能同时保留原均值、精度和信息解释。

将 null 与非 null 模式放在较粗的 trace 组内，可使该组平均响应为正，是另一种 GEC 投影；但它仍没有创造 null 方向的观测信息。组内 finite-variance query 是近似消息，需要重新检查其方向响应及误差，不能宣称每个坐标都获得了有效有限精度。

### 8.5 应怎样判别和报告

1. **区分数值 null 与统计上很弱的有限模式。** 用 `A_k` 的奇异值、相对残差 `||A_k v||`、矩阵尺度和浮点精度做数值秩判断，记录明确容差。仅看 `h` 很小不够，因为高噪声也会使非零模式的 `h` 很小。对 `A_kᴴA_k` 求特征值会平方条件数，秩诊断宜回到原 `A_k` 的 SVD，而非将 Gram 的浮点小正特征值全部当作可观测模式。
2. 数值秩容差应与运算精度、矩阵尺度有关，并与任何为了统计稳定而设的“最小可用精度”阈值分开报告。若真实弱模式并非数值 null，应保留其大但有限的代价，不把它随意归为零。
3. 报告 null 用户/模式计数、每个用户有效秩及是否发生整条 finite-τ 接口失效。可以另报可观测子空间的方差分位数，但必须注明分母；不得将排除 null 后的有限均值冒充完整候选的平均性能。
4. 一旦存在确切 null，原全模式平均 `τ2` 在扩展实数意义下为 `∞`，Jensen 下界仍成立，但不应把 floating-point `1/h≈10^30` 当成有物理意义的有限估计。完整的“16 个有限正方差”候选在该输入上没有定义，属于接口覆盖问题，而非仅需优化某个方差数值。
5. null 归类与 noise 字段修正分别验证：前者主要由公开算子决定，后者关系到所有非零模式的 `S,h,τ` 和旧 query 复算。未通过冻结输入复算的首版结果不能用于性能结论。

当前可做的最小正确判断是：**先保留零精度及失败覆盖记录，再决定扩展非线性接口或改变分组/增益模型；不能用一个未披露的 floor 把未定义候选变成表面全部成功。** 本笔记只补充该边界，没有修改运行代码或实施上述新方案。
