## 1. 被检验的模型和可识别范围

固定公开算子决定的基 `A_k^H A_k = V_k Λ_k V_k^H`，对每个用户的误差张量按输入列变换

`e_z[k,m,r,j] = sum_n conj(V_k[n,j]) e[k,m,r,n]`。

候选是给定公开算子与方差标签后，误差在 `(m,r,j)` 上为零均值 proper 复 Gaussian，沿 `(m,r)` 重复的 covariance 为 `diag(τ_k)`。本次 oracle 拟合为

`τhat_kj = mean_mr |e_z[k,m,r,j]|²`，`w_kmrj = e_z[k,m,r,j] / sqrt(τhat_kj)`。

这里的 `τhat` 是**单次真值误差的未中心化功率**，既包括随机部分也包括均值/信号方向偏差，不是已识别的条件中心 covariance。其用途是回答“即使允许逐模式 oracle 能量适配，该固定基族是否仍遗漏明显结构”，不能证明公开递推能得到这些 τ。

已有 C 表示分析曾比较不同基，本轮即使预先固定 `V_k`，也仍是已使用场景上的探索性资格检查。将正式 1000 场景扩展到首轮只增加描述覆盖面，不把这批数据变成独立确认集。

## 2. Gaussian 参考必须复现拟合过程

每个保存 query 的 16 份参考可以按 `e_z^(b)=sqrt(τhat) ξ^(b)`、`ξ^(b)~CN(0,I)` 生成，但**每一份都要重新计算自己的 `τhat^(b)` 和 `w^(b)`**。所有中心化、范数归一化、尾部阈值、投影分母、零信号处理均应重复相同操作。固定 `V_k`；不从参考或真实误差重新选择基、秩、分组或特征向量。

必要注意事项：

1. `mean_mr |w_kmrj|² = 1` 是拟合恒等式，不能作为方差校准成功的指标。原始 `τhat/public τ` 才提供公开标签的校准信息。
2. 同一模式有 `n=M Nout=256` 个坐标。在 iid proper Gaussian 原假设下，拟合后四阶比 `mean |w|⁴ / 2` 的期望是 `n/(n+1)`，而不是恰好 1；阈值 `|w|² > -log(.01)` 的概率也不是恰好 1%。这是归一化的有限样本代数效应，应以同流程参考为主。该公式仅作代码核对，不把真实坐标当独立样本。
3. 16 份参考适合显示模型参考均值和离散程度，不能把其 min/max 或 5%/95%经验分位数称为 95%置信区间。即便满足交换性，逐 query 单侧秩检验的最小 p 值也是 `1/17≈0.0588`；一般带拟合谱及投影分母的参考又是代入估计后的模拟，并非自动具有精确交换性。本轮不宜发布逐 query 的 5%显著性判决。
4. 若 τ 极小、为零或非有限，应保留原值、数量及原因；不能只删除难以归一化的模式。数值保护值必须公开，同时原值和使用值分开。16 份参考足够本次描述目的，不要求扩大模拟数量。

## 3. 必要指标及其解释

### 三个轴的未中心化二阶矩

对 `w` 分别按天线、输出行、输入列展开为 `W_a`，计算 `G_a=W_a W_a^H/n_a` 及

`sum_(i≠j) |G_a[i,j]|² / sum_(i,j) |G_a[i,j]|²`。

每个轴都与对应参考比较，不能把理论目标设为数值零。额外保留对角项的范围/变异以及未中心化均值能量，有助于区分轴向异方差和非对角结构。三个边缘展开都接近参考仍不能证明全张量 covariance 可分、所有坐标独立或跨用户误差独立；它们只是本次选定的必要检查。

### 输入列伪协方差和均值

输入展开的 `P=W W^T/n` 中**不取共轭**，且应包括对角项；只看非对角项会漏掉各模式自身的非圆对称。保留 `||P||_F²/||G||_F²`，并按相同方法给出样本中心化版本及被减去的样本均值能量。proper 定义涉及中心化伪协方差，原始伪 Gram 非零也可能来自均值。沿 `(m,r)` 的样本均值不等于已识别的条件期望，所以这两种统计都只与同处理的参考比较。

### 四阶与尾部

报告归一化四阶比及 `|w|² > -log(.01)` 的坐标比例，并保留按模式分布，防止一个总体平均掩盖局部重尾。不要把 4096 个相关坐标当 4096 次独立试验来计算二项置信区间；坐标统计先变成用户/场景的描述量。

### 信号方向投影

对活跃、信号能量非零的用户，可保留原坐标等价的复投影与对应 colored Gaussian 尺度：

`Z = sum_mrj conj(x_z[m,r,j]) e_z[m,r,j] / sqrt(sum_mrj τhat_j |x_z[m,r,j]|²)`。

在 x 和真实 C 固定且误差确为独立 `CN(0,C)` 时，该分母给出 `Z~CN(0,1)`；当前 τ 为拟合值，因此仍使用每份参考重新拟合后的 Z 作比较。至少同时报告 `Re Z`、`Im Z` 和 `|Z|²`；仅报告绝对相关性不能区分衰减方向与增强方向。再保留容易解释的实投影系数 `1 + Re<x,e>/||x||²`。这些是单次投影统计，不是已经估计出的条件增益函数。

非活跃用户 x=0 时投影无定义，应记为不适用并报告数量，不能记 0 后参与活跃投影平均。全局复均值接近 0 也不能排除 `e≈−a x`：随机信道相位可以让这种系统性衰减的复均值相消。

## 4. 分层、配对与统计单位

- uniform 和 failure_enriched 始终分开；SNR、stage、活动真值分层保留。final_miss 仅作条件个案描述，因为选择最终失败会使噪声、信道能量与投影相关，换噪声后的改善有回归均值成分。0 dB 的增强组也继承按 −4 dB 筛选的条件。
- 同一场景的 −4/0 dB、1/20/final、40 用户和 16 模拟重复不是独立场景。每个用户先形成“实际统计 − 16 份参考统计均值”，然后按场景汇总。模拟重复增加的是参考精度，不增加真实场景样本量。
- 对活跃或弱用户等不等规模分层，应说明采用每场景等权还是所有用户等权。若报告全用户平均，可在场景层面重抽样，再重新计算分子/分母之比；不要把无活跃用户场景的缺失值改成 0。报告场景数、用户数及无有效用户的场景数。
- uniform 只有 12 个场景；范围、方向一致性、场景配对差应先于精确总体效应表述。若给 bootstrap 区间，应保持场景为重抽样块，并明确小样本探索性质。
- 多轴、多个阶段和多个分层全部展示，避免只挑一个通过或一个失败的指标。当前以描述性资格检查为宜，不必扩大为大量逐项显著性检验。

## 5. 正式 1000 场景首轮线性对照

此部分只使用同一输入、同一噪声估计、同一初始化方差和同一归一化，分别计算旧 scalar 投影与固定输入模式分组 GEC 的首轮。真值仅用于计算误差，不进入候选的 `V_k`、τ、滤波器或保护参数。它可以检验候选的公开方差和线性代价，不能说明新网络或闭环性能。

记输入先验方差为 c，`Ã=[A_1 V_1,...,A_K V_K]`，`S=σhat² I+c ÃÃ^H`，第 i 个模式的列为 `ã_i`。首轮均值为零时，候选标量组的外信息可写为

`d_i=ã_i^H S^(-1) ã_i`，`F_i=ã_i^H S^(-1)/d_i`，`r_i=F_i y`，`τout_i=1/d_i−c`。

以下量必须共同解释：

1. **公开 τ 的完整分布。** 按场景/用户/模式保留最小值、常用分位数、最大值及非正/非有限数量；不能只汇报均值。弱观测模式可能使 `d_i` 很小、τ和噪声放大很大。保留相应 `λ_i(A_k^H A_k)`，避免把数值条件差误归为噪声分布问题。
2. **噪声放大。** 对给定滤波器，`σhat² ||F_i||²` 是公开工作模型中的纯观测噪声贡献；它与 `τout_i` 的总工作误差不是同一个量。与旧首轮用同一单位和同一输入配对比较。若用于物理真实噪声参考，真实 σ² 只能明确标记为 oracle 评价。
3. **单位响应的范围。** `F_i ã_i=1` 是可直接检验的代数关系，但不等于整个用户块 `F_k Ã_k=I`。应同时记录自身用户块的非对角响应和最大偏离；跨用户干扰仍然存在。把该代数关系称为“模式自身的单位响应”，不能直接写成“实际误差条件零均值”。
4. **经验方差校准。** 保留 `mean_mr |r_i−x_i|² / τout_i`，按活跃/非活跃和预先定义的信号能量层展示。区分模式比值平均、总误差/总τ之比：后者可被少数高τ模式主导。所有统计的不确定度仍以场景为单位。
5. **均值与信号依赖。** 在上述投影统计外，可用已算出的 `F` 与真实 x 评价 `(F Ã−I)x` 的能量/方向，明确这是 oracle 评价的线性响应项，不是新推断。若噪声估计 `σhat²(y)` 来自同一观测，F 也依赖 y；`σ² F F^H` 是冻结 F 的代数尺度，不能无条件宣称它等于实际噪声项的条件 covariance 或保证 `E[F(y)w]=0`。

不必新增网络实验或更多场景来完成这些检查。现有 1000 场景只覆盖这两个 SNR 和首轮；即使候选首轮校准改善，也不能外推至第20轮/final或活动检测。

## 6. 可接受与不可接受的结论

可以支持：

- “在这批已复用场景中，允许逐模式 oracle 功率后，某些轴向二阶结构/非圆对称/尾部/信号投影仍明显超出同处理 Gaussian 参考；因此仅有该对角谱不足以描述这些保存查询。”
- “本次统计未发现某类明显偏离；固定公开基的表示值得保留为候选，但公开τ、联合分布与新闭环仍未验证。”
- “候选首轮有明确的模式自身单位响应，同时存在某一数量级的噪声放大；公开τ与真值误差之间的偏差按分层记录如下。”

不能支持：已证明 Gaussian/独立性、已得到真实条件 covariance、oracle C 已可部署、失败恢复证明反馈是原因、所有阶段都匹配、已降低低SNR活动检测误差、或这批结果来自新的 held-out 检验。任一遗漏维度明显失败可否定当前简化模型在对应范围的充分性；有限统计全部接近参考则只能提供有限支持，不能证明模型完备。
