## 1. D-GEC：要同时改变精度表示、线性更新和非线性外信息

**原文。** p.13 式(31)的 `gdiag` 不是取逐元素对角，而是每组的平均 Jacobian 迹，再把该数重复到组内坐标。Algorithm 2 两端都使用这一操作；p.14 式(35)的线性估计使用相应对角精度矩阵。p.14 式(36)的 Gaussian 行为来自实验，严格分析未成立；p.15 区分了用于验证每轮误差模型的较强初始化/较准确 CG，与追求最终恢复精度的实际设置。

**按原文公式重排。** 设第 ℓ 组有 `d_ℓ` 个实坐标，模块输出 `z_i=f_i(r_i,γ_i)`，则

\[
\alpha_{i,\ell}=\frac{1}{d_\ell}\operatorname{tr}J_{f_i,\ell\ell},\quad
\eta_{i,\ell}=\frac{\gamma_{i,\ell}}{\alpha_{i,\ell}},\quad
\gamma_{j,\ell}=\eta_{i,\ell}-\gamma_{i,\ell},
\]
\[
r_{j,\ell}=\frac{z_{i,\ell}-\alpha_{i,\ell}r_{i,\ell}}
{1-\alpha_{i,\ell}}.
\]

这与论文精度加权表达等价；不能只把一个全局方差换成向量而保持其他步骤不变。

**项目改写。** 当前接口的限制相互关联：

- `denoiser.py:75–89` 强制 `cov=vI`；`moments.py:27` 把二阶输出在所有实分量/天线/二维坐标上平均；`denoiser.py:119` 又把各用户风险平均成一个 τ。
- `iterations.py:73–75` 先平均用户空间矩，再按当前 isotropic 配置做 trace 投影；`gaussian.py:26–36` 使用这些矩的 Gaussian 除法构造外信息，而不是对实际联合映射计算分组散度。
- `linear.py:62–76` 支持一个共享天线协方差的特征模 LMMSE，但它不是任意分组精度的通用求解器。引入跨用户或用户内异方差后，必须重新检查线性模块表达与复杂度。

若借鉴 D-GEC，分组应由实际误差/算子的结构支持。MRI 小波分组依赖 Fourier–小波列块近似解耦；当前 AFDM 的重复 MMV 算子没有自动继承这一性质。按用户分组只能区分用户间的平均功率，不能描述用户内天线方向相关。用协方差自适应特征基时，还要记录该基与信号/观测的依赖。

当前非线性均值在无投影且 site 接受时是 `F_k(r)=p_k(r)μ_k(r)`。应求导完整 F；其 Jacobian 包含 `μ_k∇p_kᵀ`，不能只求第一网络 μ 的导数。site 回退或可选 rank-one 均值投影启用时，映射又不同，须固定状态与分支定义。现有源码包含这些选项，不表示所有选项都用于最新冻结实验。

## 2. corr+corr：怎样借鉴到活动检测，哪些部分没有论文保证

**原文。** D-GEC pp.15–16 式(38)–(41)在原图像坐标中处理有色 Gaussian 噪声。除 `x+n` 外，网络再接收 K 个同协方差、相互独立且独立于输入噪声的样本；噪声协方差在训练中抽取。原文用 clean/noisy MSE 训练去噪器，未训练活动分类器。D-VDAMP p.3 §2.3 使用另一接口：把每子带标准差作为各层额外通道；D-GEC 的 corr+corr 则让辅助噪声样本也携带方向信息。

**项目建议，非原算法。** 若接受单独训练有色噪声模块，可把 `auxiliary.py:63–81` 的标量 AWGN 生成扩展为下面的条件训练任务：

\[
 C\sim q(C),\quad r_+=H+n_+,\quad r_-=n_-,\quad
 n_+,n_-,n_{\rm aux}\mid C\stackrel{\rm ind}{\sim}\mathcal{CN}(0,C).
\]

正负类使用相同 C 分布，辅助噪声独立抽样；C 的表达可以先限于可识别的低维空间参数，而不是直接训练一个任意 4096×4096 复协方差接口。复数实现以实部/虚部打包，必须保持 `CN(0,C)` 对应的实协方差与当前 v/2 约定一致。

第一网络可用 MSE 训练 `μ_C(r,n_aux)`；活动网络用 BCE 训练 `(r,μ_C,n_aux)`。训练类先验若仍为 1/2，部署仍可按当前 `denoiser.py:171–172` 只修正一次先验 log-odds。当前 `activity.py:42,63–105` 只条件于标量 v，不能直接把不同方向的 C 全压成 trace 后称为 corr+corr。

这里有四项边界：

1. 这训练的是参数化有色 Gaussian 下的模块，不需要把十层回路展开，也不要求一定收集实际迭代轨迹；但现有 AWGN 权重不能当作已具备这一能力。
2. C 若在线由 query/活动证据估计，可能与 H、a 相关；独立采样 q(C) 的训练模型未自动匹配真实联合分布。必须检查条件校准和错误协方差输入下的稳健性。
3. 有色条件模型仍无法自动表示非零条件均值、信号方向收缩及高阶非 Gaussian 干扰；准确预测 C 不是全部目标。
4. 当前二阶网络是固定第一网络的标量条件风险估计器，不能直接充当各组 posterior covariance 或实际 F 的分组散度。可选择按实际映射计算 Jacobian；若另训风险网络，应明确其目标而不偷换为中心后验协方差。

## 3. VDAMP / D-VDAMP：分组修正有依据，但密度补偿不是低 SNR 的免费改善

**原文。** VDAMP p.4 §II-A 的归一化是对随机采样集合取期望后单位响应：`E_Ω[ΨFᴴP⁻¹M_ΩFΨᴴ]=I`。p.4 式(15)结合采样概率与残差估计误差谱；pp.4–5 式(13)、(22)–(24)逐组修正散度。D-VDAMP p.2 Algorithm 1 实现对应修正并在预测误差功率增大时停止；p.4 Table 2 明确显示其低 SNR 不总领先，原文归因于密度补偿放大测量噪声。

该表使用 256×256 MRI、1/8 可变密度 Fourier 采样：25 dB 测量 SNR 时 Proposed D-VDAMP 的 PSNR 为 34.8 dB，P&P ADMM (BM3D) 为 30.9 dB；5 dB 时分别为 25.0 与 27.8 dB。这里比较的是原论文特定实现及参数，不证明所有密度补偿方法都会在所有低 SNR 场景失败；但足以否定“把消息推向易描述的 Gaussian 分布就自然提高低 SNR 性能”的一般化判断。

**项目判断。** 不能把 `P⁻¹` 套在任意 AFDM 矩阵上：原文 P 是 Bernoulli Fourier 采样概率，当前固定 A₀ 没有相同采样模型。可借鉴的是“用方向/组别协方差检查输入，再在相同分组上计算完整映射散度”，而不是照抄 Fourier 残差方差公式。

D-VDAMP p.2 §2.1 的复数散度分别对实、虚扰动求导再平均。这能指导项目归一化审计，但本项目复通道/活动概率映射与其主要实值 MRI 去噪实验不同。不能把其低 SNR 数字当成本系统预测，也不能以输入更白为唯一性能标准。

## 4. D-Turbo-CS：外信息缩放可以独立于 MMSE 方差公式，但前提仍是 Gaussian query

**原文。** pp.3–5 §III 先指出通用去噪器不能直接沿用 MMSE 外信息公式，再构造 `D_ext=c[D−αr]`，`α=div(D)/n`，以 SURE 选 c，见式(13)、(18)–(26)。相关图像在普通 partial DCT 下仍不符合其 MSE evolution；pp.8–9 §V-C 改变实际测量为 `SWΘ` 后才看到 Gaussian 误差与预测改善。

**项目推导。** 对实坐标完整联合映射 F，固定本次 α 后令 `d=F(r)−αr`，式(26)对应

\[
c=\frac{r^\top d}{\|d\|^2}.
\]

采用复数且限制 c 为实数时，相应最小二乘表达为 `Re(rᴴd)/||d||²`。它是一个可以单独比较的外信息缩放选择，并非 `1/(1−α)` 的别名。但 SURE 无偏性仍依赖独立 Gaussian query；当前信号相关误差下，不能把该准则的最小值当作真实 MSE 最优。经验 α 的输入依赖也意味着有限维时不能按常数求导就宣布严格 divergence-free。

**原文显示核验。** 下载 v1 的 p.5 Algorithm 2 line 6 写加号，而 pp.4–5 式(13)、(19)–(20)、(26)均为减号；已渲染页面确认，不能当成文本抽取造成。实现若参考此文应依据推导式核对，不能机械复制算法框。未检查后续排版或作者代码是否已修正。

## 5. DD-VAMP：可借鉴初始化一致性，现有失败不是一个未试过的新建议

**原文。** p.3 Algorithm 1 对均值作算术阻尼，对精度作逆平方根域阻尼，并对平均灵敏度的平方根阻尼。§3.2 要求初始化均值和精度相互匹配，用 PnP-ADMM-PR 先运行再放开精度更新。p.4 的 MRI 实验用现成 DnCNN 并调初始精度/切换轮次，未证明任意结构化算子产生 AWGN。

**项目判断。** 当前 `iterations.py:18–25` 是均值和协方差分别算术平均，与原文标准差域阻尼不同。但旧 `proposed_uniform_inference_20261014/REPORT.md` 已试两种 DD-VAMP 阻尼，并出现支持超界；不能将换成标准差阻尼重新包装成未尝试的修复。旧试验同时改变了 query 阻尼和回退等设置，且权重不同，故也不能据此否定最终网络下所有 DD-VAMP 配置。

可参考的是先检查平均灵敏度、方差代理与初始化精度是否一致，再决定是否值得做独立对照。当前低 SNR 多数已收敛，“稳定了”不能替代活动漏检改善。

**原文显示核验。** 下载版 p.3 Algorithm 1 line 9 的 Monte Carlo 表达未显示 `/N`；同页正文明确灵敏度为 `tr(∇f)/N`，且 line 4 有 `/N`。页面渲染确认该显示不一致。本项目应按实坐标 2d 维的平均 Jacobian 迹定义核对，不照抄未归一化量；这不是发现当前代码存在该错误。

## 6. FIRE：补噪加在 posterior 上，与现有 STMP 的 extrinsic query 不是同一个对象

**原文。** 下载版 p.5 式(10)由各向同性误差且与观测噪声独立的模型估计 ν。式(11)是 Gaussian posterior 均值，式(14)为其工作协方差 C；再按式(15)添加 `σ²I−C`。p.6 Algorithm 1 **line 6** 使用 `max{σ²/ρ,ν}` 保证半正定（HTML 行编号不同）。p.6 Theorem 1 和 pp.20–21 证明要求理想 AWGN 初值，以及每次去噪输出误差白 Gaussian、已知 ν、独立于观测噪声；不是任意初值、任意网络的结论。

**项目代数比较。** 将线性模型写成复数形式，设

\[
K=\nu A^H(\nu AA^H+\sigma_y^2I)^{-1},\quad
\phi=\operatorname{tr}(KA)/d.
\]

FIRE 线性输出与补噪查询是

\[
\hat x=\bar x+K(y-A\bar x),\qquad r_{\rm FIRE}=\hat x+c.
\]

当前 STMP 的 isotropic 情形对应 `linear.py:62–72`：

\[
r_{\rm STMP}=\bar x+\frac K\phi(y-A\bar x).
\]

因此它们既使用不同的线性响应，也对应不同的误差协方差。FIRE 的 C 不能直接当作现有 STMP query 的 C 来补噪。`tr(KA)/640≤16/640` 只界定平均线性响应；不界定某个结构信道的单次投影，而且一般的 x̄ 自己含信号信息，不能笼统说 FIRE 的“信号增益只有 0.025”。仅在 `x̄=0` 的特例，条件均值为 `KAx`，零均值补噪仍不会改变它。

若实际 prior 误差 `e_p=x̄−x` 协方差为 P，且与热噪声交叉协方差为 T，则 posterior 误差是

\[
e_{\rm post}=(I-KA)e_p+Kn.
\]

除两个平方项外，真实协方差还含 `(I−KA)TKᴴ` 及其共轭转置。FIRE 的简式 C 依赖 `P=νI,T=0`。同一个 y 在多轮反复使用，不能未经检验删除 T；活动混合后的均值也可能有明显信号相关偏差。

**与旧失败的实质比较。** 项目已试过完整 FIRE 回路适配，并非只试过一次 oracle 补噪：

- `proposed_uniform_inference_20261014/PROTOCOL.md` 有 residual-direct、residual-annealed 和二阶风险替代三种；独立结果中二阶替代输出近零，残差版本还会超网络支持范围。
- 同目录 `REPORT.md` 的一个开发条件初轮 `MSE/v≈0.991`、空间二阶矩最大特征值占比约 0.068，却有误差对信号归一化投影约 −0.971；这说明平均功率与空间二阶矩接近各向同性仍不足。它是旧权重小样本证据，不能外推为最终版的统一因果结论。
- `proposed_uniform_spatial_20261015/PROTOCOL.md` 是 residual 空间矩、原 EP feedback、支持范围内部分补齐的混合方案，明确不是原 FIRE；其后 `ORDERED_PROTOCOL.md` 已修正独立补噪被算术阻尼稀释的问题。

这次细读并未发现一个能直接绕过这些失败的 FIRE 新环节。新候选若仍叫 FIRE，应明确解决哪一项不同：可实现的初值、P/T 模型、posterior 与 extrinsic 的选用、ν 估计，或分类器输入。仅改名称、再加相同协方差噪声，没有新的研究依据。

## 结论与优先级

六篇中最值得进一步设计的是 **D-GEC 的成套分组接口** 和 **corr+corr 的独立有色 Gaussian 条件训练**；它们可以保持“统计模型驱动、模块化训练”而不退化为十层端到端展开。是否采用，首先取决于能否找到实际误差适合的低维协方差表示，并检查信号方向偏差。

冻结现有 AWGN 网络的约束下，D-Turbo/DD-VAMP/FIRE 提供的是候选外信息、稳定性或补噪机制；本项目已有相关失败，尚没有文献支持它们可直接解决当前低 SNR 漏检。下一步应以假设、输入分布、完整联合映射和配对性能验证来区分候选，而不是按算法名称重复试验。
