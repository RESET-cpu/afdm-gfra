# 已预补偿卫星有授权随机接入前导码检测调研

调研截止：2026-11-05。用户要求不评估学生基础、工作量或研究周期，只判断已有研究覆盖程度和研究价值。

- RQ1：在终端已作时间和频率预补偿的卫星有授权随机接入中，接收机仍面对什么残余不同步和多用户检测问题？哪些参数有规范或论文依据？
- RQ2：普通 NR PRACH/Zadoff–Chu 前导码的传统检测、学习检测、碰撞检测及后续接入处理已做到什么程度？哪些工作直接覆盖所考虑场景？
- RQ3：保持已有前导码和预补偿机制时，哪些可检验的接收机改进仍值得研究，哪些想法已明显重复？

主要范围：NR 四步竞争随机接入的 Msg1 检测；以现有 ZC 前导码和 UE 预补偿为默认，不预设需要修改波形。NB-IoT NPRACH、地面 NR/LTE、GNSS-independent 同步、连接态跟踪仅作为明确标记的相邻证据。AFDM/OTFS/HFM 波形创新不列为拟议主线。

检索视角：规范与残余误差；传统和模型驱动多用户检测；学习与碰撞处理及反证检索；原始研究版本和实际验证范围。

方法：并行独立检索后串行综合；优先原始规范、出版社、arXiv 作者稿和机构库；核对标题/作者/年份/版本与支撑段落；摘要证据不用于宣称全文遗漏。报告区分检测到前导码、估计定时/频偏、估计碰撞人数、识别具体 UE 和成功接入。采用最后可取得版本，尤其防止将早期稿未包含的实验当作研究空白。

不会启动实验、训练或修改现有研究主线。
