## 1. 实际结构与 1025→64 压缩

代码定位：

- `src/training/colored_score_20261024/noise.py:50`：条件是 `[log(v)/5, Re(Ra-I), Im(Ra-I), Re(Rc-I), Im(Rc-I)]`，共 1025 个实数。
- `src/training/colored_score_20261024/model.py:17`：第一层改为 `Linear(1025,64)`；新增矩阵条件权重初始为零。
- `src/networks/score.py:47`：之后为 SiLU、`Linear(64,64)`、SiLU。
- `src/networks/score.py:53`、`normalization.py:193`：同一个 64 维向量经各层线性投影产生通道尺度、通道均值项系数和偏置。
- `model.py:31`：协方差进入 score 的唯一路径是该条件；最终另有已知标量 `1/sqrt(v/2)`。完整协方差也用于网络之外的均值重构。

1025 个数包含 Hermitian 冗余，不能把它当成 1025 个独立物理自由度。一个 16×16 Hermitian 矩阵有 256 个实自由度，固定 trace 后为 255；固定 v、两个因子合计 510。首层线性映射最多保留 64 个线性组合。

**一般正定因子的严格反例。** 固定 v、Ra=I，只改变 Rc。在 Hermitian 零迹矩阵的 255 维空间中，首层对 Rc 的映射必有非零核方向 D。缩放到谱范数 1 后，取 `Rc±=I±0.4D`，两者均正定、trace=16，却给出完全相同的首层激活。因此对于同一观测 y，两者给出相同网络 score。

令信号恒为零、噪声为 proper complex Gaussian，则精确实打包 score 为 `pack(-2 C^-1 y)`。不同正定 C 的逆算子不同，存在同一 y 使两个目标不同；该网络不能同时精确满足二者。若不希望用退化的零信号先验，取信号 `CN(0,pI), p>0`，目标改为 `pack(-2(pI+C)^-1 y)`，同样成立。

观测 y 的确可以帮助统计估计协方差；但在不同正定 C 下，同一 y 的密度均为正，不能以“网络可从 y 推断 C”消除这个要求精确条件映射时的反例。网络外部重构 `y+Σs` 会再次使用 C，因此两个条件的最终均值未必相同；这不修复 score 条件中已丢失的信息。

## 2. 全局条件是否足够处理任意输入列混合

`model.py:32` 把实/虚和 16 天线合并为 32 个特征通道，输出/输入坐标留在 16×16 空间轴。`ncsn_channel_diffusion.py:20` 起使用固定 3×3 卷积、多尺度分支和 dilation=2/4；协方差不直接生成逐列混合矩阵。

`normalization.py:201–207` 的 gamma/alpha/beta 对空间位置共享。因此 Ra 对应的天线变化发生在可直接混合的通道维，任意 Rc 的绝对列方向则需由共享卷积、边界和多个条件调制间接表达；这为列方向适配提供了较弱的结构先验。随机稠密 Rc 通常没有局部、平移不变的列结构。**“这会增加学习难度”是合理推断，尚非当前性能主因的实验证明。**

不能据此声称“条件仿射只能调幅，不能改变混合”。条件调制、固定卷积与非线性复合后能够改变有效混合算子；多尺度分支和归一化使有效依赖范围也不局限于单个 3×3 邻域。

一个可说明限制但不能冒充本实现定理的理想化例子是：若空间算子严格循环平移等变、条件又全局共享，固定 Rc 下的网络算子必须与循环移位交换；一般 Rc 的逆并不交换，不能精确表达其作用。然而当前实现使用零填充、下采样、插值和全局归一化，严格平移等变前提不成立，不能把该理想化反例直接用于宣判当前网络不可能。

## 3. 归一化与 legacy_image

### 归一化：有表达约束，但不是“所有幅度都丢失”

`normalization.py:184,194–203` 对每个通道去空间均值、除空间标准差；另将各通道空间均值在通道维标准化后加回。原始空间方差没有作为独立数值传给后续层。`layers.py:383–398` 仍有未归一化 shortcut；非线性和多通道特征也可把幅度转为相对形状。因此不能仅凭 InstanceNorm 宣称整网对输入缩放严格不变。

末端 `ncsn_channel_diffusion.py:93–95` 仍是 conditional normalizer→ELU→卷积，没有绕过末端归一化的原始输入 score 分支。对固定有限 C 和权重，归一化后的每通道空间向量范数有界；标准化后的通道均值向量同样有界，因而最终 score 关于输入幅度有界。精确 Gaussian score 则随输入线性无界。因此该架构不能在整个无界输入空间精确表达 Gaussian score。

这也是原白噪声网络共有的限制，而且通常只要求有限概率区间的近似；它不是新网络失败的特有证据。可通过固定方向的幅度扫描检查当前工作范围是否已经出现明显响应饱和，而不是据理论极端输入立即更换归一化。

### legacy_image：可疑的习惯设置，但不是不可逆信息损失

实际读取的 checkpoint 配置为 `input_transform='legacy_image'`。`score.py:74–79` 设置 `logit_transform=False,rescaled=False`，故 `ncsn_channel_diffusion.py:75–79` 使用 `h=2x−1`。没有剪裁、sigmoid 或限幅；该仿射映射可逆，不能解释为把复信道截断到图像范围。

它对零均值复信道引入偏移，配合零填充形成固定边界图案，可能影响学习效率；但旧白噪声与当前有色噪声使用同一映射，旧模型已表现出较好去噪。因此这不是已查明的新旧差距来源。对已训练权重直接切换为 identity 会改变输入分布，不能当作等价修复。

## 4. 训练曲线到底说明什么

相同 epoch 17：旧模型验证 DSM 0.101455；新模型 0.393517。两者噪声分布和矩阵加权目标不同，不能把比值直接当作相同任务的性能比或归因于结构。新模型从 epoch 5 到 19，验证 DSM 0.498878→0.384698，整体 NMSE 7.851→6.707 dB；epoch 19 训练 DSM 0.386906 接近验证 0.384698。目前没有明显的大训练/验证差距，但它们的采样和 EMA 状态不同，不构成“没有过拟合”的检验；也未见可据此宣布已收敛的证据。

新模型 epoch 19 保存的区间 NMSE：

| 输入 SNR 区间 | 验证 NMSE (dB) |
|---|---:|
| −20 到 −15 | 15.157790 |
| −15 到 −10 | 10.291241 |
| −10 到 −5 | 5.308006 |
| −5 到 0 | 0.352597 |
| 0 到 5 | −4.502837 |

恒零信道估计的 NMSE 恒为 0 dB，所以前四个区间在当前验证样本上都还不如恒零估计。这个比较不需要旧网络，也不受新旧噪声分布不同的混淆。它不表示检测性能已经下降；当前网络还没有在接收机中完成配对评估。

令实打包观测 `y=h+n`、`Cov(n)=Σ`、`μhat=y+Σsθ`，则当前 DSM 每样本目标满足

`L = ||Σ^(1/2)sθ + Σ^(-1/2)(y−h)||² / d`

`  = ||Σ^(-1/2)(μhat−h)||² / d`。

代码依据为 `formal_batches.py:65–85` 及 `noise.py:46–48`。正式 batch 保留直接采样 epsilon，故与通过浮点 noisy−clean 重建的式子可能有舍入级差别。

普通均值误差是 `||μhat−h||²`，不是上面的逆协方差加权量。给定残差向量，两者满足 `λmin(Σ)L ≤ MSE_per_real_coordinate ≤ λmax(Σ)L`。低 SNR 的大 v 以及相关噪声大特征值方向会放大普通 MSE。因此 loss 下降和很差的低 SNR NMSE可以同时发生；这本身不表示 DSM 或 Tweedie 公式写错，也不代表已知协方差使任务本质更难到当前程度。

## 5. 最小的后续冻结权重诊断（本次未执行）

建议预先固定一个很小的已有验证场景子集、一个 checkpoint 和同一组 h/v/epsilon，保存全部结果。只作内部机制检查，不称新 held-out 或正式 1000 MC 比较。按场景配对汇总；不要把 4096 个复坐标当独立样本。

| 检查 | 保持固定与操作 | 能判别什么 | 不能判别什么 |
|---|---|---|---|
| 条件配对/打乱 | 同一 noisy、v；只替换传给 score 的 Ra/Rc，在近似强度匹配的样本之间置换；**DSM 权重、均值重构始终用真实 Σ** | 条件是否被利用，以及正确条件是否比错误条件有益 | 无差异不证明理论上不能用条件；可能尚未学会、敏感性弱或样本不足 |
| 各向同性/弱/强相关 | 同一 h/v/epsilon，原固定方向形状改变 alpha；先只改 Ra，再只改 Rc，再同时改；保持 trace | 失败是否集中在列轴、强相关或联合相关；需同时报告普通 MSE 与加权 loss | 不是只比较纯架构，改变了噪声难度；alpha=0 是当前连续训练族的边界，没有点质量 |
| 零信号 Gaussian 参考 | 合成 h=0；目标 score 为 `−Σ^-1 y`，目标均值为0；先检查同一协方差若干方向 | 逆协方差方向和幅度响应是否正确；无信道先验不确定性 | h=0 不等于真实训练信道先验；异常只提供局部能力证据 |
| 已知非退化 Gaussian 参考 | 仅用解析 `CN(0,pI)` score `−(pI_real+Σ)^-1 y` 和相应均值作标尺，明确实/复的1/2 | 检查坐标、方向、尺度和幅度趋势 | 当前网络没有按该 Gaussian 信号先验训练，不能把不匹配直接判为实现 bug |
| 幅度扫描 | 固定 v/Ra/Rc、输入方向，对幅度取少量覆盖正常范围的倍数，比较网络与零信号 Gaussian 的线性响应 | 工作范围内是否近似饱和、增益错误 | 一般真实信道 posterior score 不必对幅度线性；极端范围失败不等于实际分布失败 |

此外，在上述同一批样本中用 Ra/Rc 的特征向量分解均值误差，检查普通误差是否集中于噪声大特征值方向；不必再增加网络调用。对实际信道，`s0=−Σ^-1 y` 只是产生恒零估计的解析参考，**不是实际信道边缘分布的真 score**。

若条件打乱几乎无影响，先查条件分支敏感性/训练进度；若正确条件有益但只在强 Rc 下失败，再考虑直接使用已知 Rc 做列轴作用的最小结构；若主要是幅度或低 SNR 残差，可考虑保留解析 Gaussian 线性项并学习修正。它们都是待验证设计方向，不是本次获准的实现改动。直接白化后套用旧网络也不是自动正确：白化同时改变信号先验，需要保留这个条件。
