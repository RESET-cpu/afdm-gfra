## 段落与句法

每段围绕一个数学操作或结论：对象与目的 → 条件/定义 → 公式 → 必要的解释。无需每段机械凑齐四句。用 define、condition、substitute、average、obtain 等具体动词；仅在确有因果或推导关系时使用 hence/therefore。方法描述使用现在时。条件概率与近似高斯表达均写出条件和所用分布。

概念首次出现时给一个明确边界：物理模型/工作先验、实际查询/高斯近似、有限网络条件误差/理想条件方差分别在II-D、III-B、IV-B集中交代；后文直接使用相应定义。技术归因紧接借用操作，不堆积与操作无关的引用。

## 本稿长度与布局

II四个小节完成信号链和后验；III三个小节完成消息更新；IV四个小节完成学习目标；V三个小节完成执行。减少实现日志、参数历史、重复风险提示和泛泛的“显著提升”句。公式数量由闭合推导决定，正文不以语料论文的页数作为已满足投稿版面限制的证据。实验性结论保留到VI。
