# C 候选验证：输入列基的解释能力与逐模式外信息代价

2026-10-24。接续 [C 表示分析](STMP_COVARIANCE_REPRESENTATION_20261024.md)。

**结论：保留公开输入列基作为误差分析工具，但不建议直接按“每用户16个独立模式精度”的方案构造新训练集或替换接收机。** 旧查询的末轮输入方向结构可被该基描述；首轮和中间轮仍遗漏明显天线相关及信号方向偏移。配套的逐模式 GEC 归一化在正式1000场景的首轮产生约27倍的查询 MSE 中位数。这个代价不是少数异常用户造成的，也没有被“归一化误差功率接近1”消除。

这不是完整 D-GEC 的最终性能否定。本轮没有训练、调用网络或运行完整候选接收机，不能宣称最终活动检测变差。应先重新比较分组和消息增益，再决定训练条件。

## 1. 旧查询：即使允许 oracle 方差，输入列 C 仍不充分

候选为

\[
C_k=I_M\otimes I_{N_{\rm out}}\otimes
V_k\operatorname{Diag}(\tau_{k,1},\ldots,\tau_{k,16})V_k^H,
\qquad A_k^HA_k=V_k\Lambda_kV_k^H.
\]

V 仅由公开 A 决定。对旧查询误差按输入列变换后，使用真值拟合

\[
\widehat\tau_{k,j}=\frac1{256}\sum_{m,r}|e_{k,j,m,r}|^2,\qquad
w_{k,j,m,r}=e_{k,j,m,r}/\sqrt{\widehat\tau_{k,j}}.
\]

这是 oracle 的未中心化误差功率，不是可部署方差估计。归一化功率为1由拟合保证，不能据此说方差校准成功。每份实际查询生成16份同谱 proper complex Gaussian 参考；每份参考重新拟合自己的方差。三个轴展开后均计算 Gram 的非对角平方能量占比。

下表是均匀组活跃用户的场景等权平均。Gaussian参考约0.055，有限尺寸下本来就不应为零。

| SNR | 轮次 | 输入模式非对角占比 | 天线非对角占比 | 输出行非对角占比 | 实信号投影系数 |
|---|---|---:|---:|---:|---:|
| −4 dB | 1 | 0.1361 | 0.6416 | 0.1676 | 0.9867 |
| −4 dB | 20 | 0.1261 | 0.3709 | 0.1282 | 0.6768 |
| −4 dB | 最终 | 0.0587 | 0.0906 | 0.0708 | 0.9763 |
| 0 dB | 1 | 0.2234 | 0.7938 | 0.2406 | 0.9888 |
| 0 dB | 20 | 0.1674 | 0.4814 | 0.1602 | 0.6374 |
| 0 dB | 最终 | 0.0594 | 0.1002 | 0.0749 | 0.9848 |

实信号投影系数为 \(1+\operatorname{Re}\langle x,e\rangle/\|x\|^2\)，是单次投影统计，不能当作已识别的条件增益函数。第20轮投影差的场景配对bootstrap区间为：−4 dB [−0.3578,−0.2845]，0 dB [−0.3875,−0.3331]；这是12场景、固定模拟参考下的探索性逐项区间，不作多重检验结论。

三点解释：

1. 末轮输入模式占比接近匹配参考，支持保留 V；但天线和输出行仍有剩余结构。
2. 首轮与第20轮，即使用 oracle 逐模式功率，天线相关仍很强。只扩展输入列的16个方差不足以描述这些旧消息。
3. 第20轮存在明显信号方向衰减，最终大幅恢复。均匀组38名活跃用户在两档SNR最终全部检出，不能把这组衰减直接解释为最终漏检原因。失败富集组的最终漏检分层仅作条件性描述。

全部分层与指标见 [SAVED_SUMMARY.json](../../../result/snr_comparison/data/stmp_covariance_validation_20261024/SAVED_SUMMARY.json)。四阶比接近Gaussian参考没有抵消上述失配。原始互补二阶矩未中心化，不据此宣布存在中心化伪协方差；有限几个统计量接近参考更不证明完整联合Gaussian性。16份参考的分位范围不是置信区间，也不发布逐query的5%显著性判决。

**这部分检验既有 STMP 查询，不能据此断言尚未运行的新闭环一定产生相同的中间轮误差。**

## 2. 新首轮：逐模式归一化产生大幅噪声与查询误差放大

以 \(B=[A_1V_1,\ldots,A_KV_K]\) 表示公开基中的算子。两支使用同一零初始均值、\(\nu=\rho\times1.0004404181394917\)，以及正式入口从观测估计的噪声：

\[
S=\widehat\sigma^2I+\nu BB^H,\quad
h_i=\nu b_i^HS^{-1}b_i,\quad \phi=\frac1{640}\sum_i h_i,\quad
f=\nu B^HS^{-1}Y.
\]

当前标量首轮与逐模式候选分别为

\[
r_i^{\rm scalar}=f_i/\phi,\quad v=\nu(1-\phi)/\phi;
\qquad
r_i^{\rm mode}=f_i/h_i,\quad \tau_i=\nu(1-h_i)/h_i.
\]

候选来自组内对角投影、精度相减及均值外信息操作，见 [GEC §II-A/B，式(6)–(12)、Algorithm 1](https://arxiv.org/pdf/1602.07795v2)，以及 [D-GEC §III-A，Algorithm 2、式(31)](https://arxiv.org/html/2206.05049v2#S3.SS1)。本项目将每用户每输入模式设成一组，天线和输出行共256坐标共享精度；这不是论文已验证的 AFDM 分组。

表中“实际MSE比”是逐用户 \(\|r^{\rm mode}-x\|^2/\|r^{\rm scalar}-x\|^2\)，不是两支总体MSE分别平均后的比值。

| 指标 | −4 dB | 0 dB |
|---|---:|---:|
| 全用户实际MSE比，中位数 | **27.0005** | **26.7507** |
| 活跃用户实际MSE比，中位数（4079用户/SNR） | 25.9310 | 24.5542 |
| 全用户实际MSE比，1%分位 | 6.979 | 6.808 |
| 全用户实际MSE比，90%分位 | 144.5242 | 143.1775 |
| 全用户实际MSE比，99%分位 | 1500.0985 | 1534.6481 |
| 公开用户平均方差比，中位数 | 27.0635 | 26.9305 |
| 固定滤波系数的测量噪声放大比，中位数 | 27.2911 | 27.2739 |
| 剩余976场景的实际MSE比，中位数 | 27.0082 | 26.7544 |

“测量噪声放大比”比较两支滤波器的平方范数。正式噪声估计依赖同一观测，因此这是固定公开系数下的工作模型量，不能直接称为真实噪声项的无条件协方差。

公开 \(\tau\) 归一化后的平均误差功率，全用户中位数仍为0.9661/0.9556。这与大幅MSE增加并不矛盾：**把很大的误差正确标成很大的方差，也不等于获得有利于检测的消息。** 而且候选首轮在该归一化下，活跃用户天线非对角占比中位数仍为0.4369/0.7139，不能把功率接近1解释为已经得到独立Gaussian误差。

代价是当前细分方式的性质，不只是方差标签写错。所有 \(0<h_i<1\) 时，由凸函数 \(1/h\) 直接得到

\[
\overline{\tau}=\nu(\overline{1/h}-1)\geq\nu(1/\phi-1)=v,
\qquad
\overline{\tau}-v=\frac{\nu}{\phi^2}\overline{\frac{(h-\phi)^2}{h}}.
\]

这里平均覆盖全部640模式，不能任意换成某个用户子集后仍声称同一不等式。弱观测方向的 h 很小，逐模式恢复自身单位响应就会放大它。且“每个模式自身响应为1”不等于完整用户响应矩阵为单位阵：候选 \(\|R_{kk}-I\|_F/4\) 的中位数为0.2375/0.3959。

因此，C 的表示能力和外信息投影必须一起评价。仅因为旧误差在某基中较接近对角，就把每个方向独立归一化，依据不够。

## 3. 数值极端与复现检查

按 \(16\epsilon s_{\max}\) 的 SVD 阈值，所有公开 \(A_k\) 块均判满秩；**本次没有证实精确零空间**。但场景22有8个用户块的条件数超过 \(10^{12}\)，最大约 \(1.94\times10^{14}\)。两档SNR共享这些块。

这些近奇异方向产生极端大的有限浮点方差，原始最大值约 \(10^{29}\)。保留全部记录，但不把极端均值和最大值当作可靠物理量级。附加 SVD 形成 \(B=U\Sigma\) 的比较仍显示巨大放大；普通场景0的方差比与 Gram 特征分解相对差不超过 \(1.16\times10^{-14}\)。

不含这8条数值敏感记录的补充中位数为26.9941/26.7435，与全量27.0005/26.7507基本相同。主体结论不依赖异常尾部；全量始终作为主表，见 [数值审计](../../../result/snr_comparison/data/stmp_covariance_validation_20261024/NUMERICAL_AUDIT.json)。

若未来确有 \(h=0\) 的精确零空间，外信息应为零精度、零自然参数，查询均值未定义；有限正方差族不能完整覆盖它。这是理论边界，不是当前样本已发现的秩亏。直接给 h 设置下界会改变消息，不能作为算法等价修补。

执行中发现并纠正一处错误：首版首轮脚本读取输入文件的旧 noise 字段，而正式 STMP 会重新执行 observation-only 的 MDL 噪声估计。首版未通过旧查询复现，已拒绝并保留，不能引用其结果；旧查询的 oracle Gaussian 对照不受影响。修正后：

- 48份旧首轮查询与方差全部复现；最大相对误差分别为 \(2.56\times10^{-15}\)、\(8.59\times10^{-16}\)。
- 640维 Gaussian 工作模型中，直接计算误差协方差对角与 \(\tau\) 公式的最大相对差为 \(7.11\times10^{-16}\)。这只证明代数，不证明真实信道符合该先验。
- 全部2000个首轮条件及48个旧查询条件留存，完成文件校验。
- 54个受保护的主线绑定、STMP代码与配置文件哈希未变；未修改权重，未训练或运行新闭环。

## 4. 下一步设计约束

当前不应立即重建整套训练数据。先保留干净信道数据与现有网络，完成消息族选择：

1. 保留公开 V 用于检查输入方向；将“每模式独立精度”降为待比较候选。优先比较更粗的固定分组，量化方差代价和剩余相关性。分组规则及导数投影须配套；这属于 GEC 允许的对角化选择，但具体哪种适合本项目尚未确定。
2. 同时记录实际消息增益与误差结构，避免把信号方向偏移吞进 C。若强制单位响应代价仍高，应重新考虑含增益的工作模型，不能只把标量方差换成矩阵就认为问题解决。
3. 天线相关必须纳入验证，但不据此立即增大到完整4096维 C。先在少量参数化候选中明确需要保留的相关性及噪声代价，再确定训练条件。

这是负结果支持的研究顺序，不是已经验证的修复。完整新闭环、两个网络的条件训练及最终活动检测性能均待后续验证。
