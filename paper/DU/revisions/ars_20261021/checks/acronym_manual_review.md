# 缩写人工复核

ARS 原始报告保留了工具的实际覆盖状态。以下定义均已在英文引言首次出现时核对；摘要独立定义其所使用的缩写。中文引言独立核对，不依赖英文中的定义。

| 报告项目 | 首次定义 | 核对结果 |
|---|---|---|
| GFRA，英文引言 | grant-free random access (GFRA) | 定义完整；grant-free 的两个词首字母均计入 GFRA，人工核对无误。 |
| IoT，英文引言 | Internet-of-Things (IoT) | 定义完整；工具未确认该全称，人工核对无误。 |
| OTFS，英文引言 | Orthogonal time-frequency space (OTFS) | 定义完整；time-frequency 为两个词的首字母。 |
| MIMO，英文引言 | multiple-input multiple-output (MIMO) | 定义完整；两个连字符组合共对应四个词。 |
| MP，英文摘要 | message-passing (MP) | 定义完整；正文另在首次出现时用 message passing (MP) 定义。 |
| NR、NTN，中英文引言 | new radio non-terrestrial network (NR-NTN)；新空口非地面网络（NR-NTN） | 稿件定义完整的 NR-NTN；检查器将其拆成两个未单独定义的缩写。 |

无需为这些识别限制改写标准专业术语，也未添加隐藏上述告警的忽略规则。其余被检查的缩写未报告问题。
