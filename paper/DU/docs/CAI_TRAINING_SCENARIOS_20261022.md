# Cai 训练方案与十层微调的场景选择

2026-10-22。来源：academic-research-suite，论文与公开代码核对；不是已完成微调的结果报告。当前两档 SNR 试跑已中断，日志保留，没有保存微调最终权重或生成测试结果。冻结版本保持。

## 核实的原文与代码

依据 Cai 等论文 §IV-B 式(47)–(49)、§IV-C 式(54)后说明，以及 §VI-A1–3（正式版印刷 p.3585）：

| 项目 | Cai 的设置 | 本项目不能混淆的单位或范围 |
|---|---|---|
| 数据 | 50,000 个训练信道、5,000 个评估信道 | 单用户信道样本，不是 50,000 个多用户接收场景 |
| 信道分布 | CDL-C；训练时随机路径角度、时延和复增益 | 同一信道模型内部有随机变化，不要求同时混合许多系统工况 |
| 加噪水平 | −10～30 dB，每整数 dB 一个水平，共 41 个 | 单信道去噪的加噪水平，不是十层接收机必须扫描的接收 SNR |
| 优化 | Adam，学习率 1e-4，批量 400，400 epochs，EMA 0.999 | 先验网络训练参数，不能直接用作展开接收机的微调参数 |
| 分阶段安排 | 先训练一阶，再固定它训练二阶；也可禁止二阶损失向一阶反传 | 不是“固定活动分类器、只微调一阶”的验证证据 |
| 接收机评估 | NMSE 每点 500 次，活动错误每点 5,000 次 Monte Carlo | 评估次数；不能作为训练集规模照抄 |

原文链接：[§IV-B/C](https://arxiv.org/html/2506.00581v2#S4.SS2)、[§VI-A](https://arxiv.org/html/2506.00581v2#S6.SS1)。本地正式版为 `reference/literature/cai2026.pdf`，已有文字抽取为 `reference/reviews/section_structure_20261009/cai.txt`。

作者仓库当前 main 仍指向 `0c75680c966dcb8e46250de146f4c27e9294c283`。完整目录和全部 Python 源码已核对：主要提供推断入口、网络定义、配置和下载链接，没有完整训练循环或信道数据生成程序。`configs/unet_channel.yml` 能核对 41 个水平、学习率、批量和 EMA；其 `max_epochs: 1000` 与论文的 400 不同，因此不能声称已逐行复现作者的完整训练流程。`model/__init__.py` 的 `get_sigmas_channel` 使用几何间隔的噪声标准差，对应均匀 dB 间隔。仓库存在 `classifier_model.py`，但不能据文件名推断论文使用了可训练活动分类器。

代码证据与清单保存在 [来源记录](../../../reference/reviews/cai_training_review_20261022/PROVENANCE.json)。

## 与现有一阶预训练的关系

现有旧 STMP 所绑定一阶权重的训练记录是 50,000 个训练信道、5,000 个验证信道，使用 Cai DSM 目标，固定总体坐标尺度，连续加噪范围 −20～30 dB；记录显示完成 200 epochs。权重 SHA 与 `src/configs/final/STMP.json` 的一阶绑定一致。依据为 `result/runs/proposed_50000_cuda_graph_20261018/training.json`、`model/first/complete.json`，目标与采样代码在 `src/training/scores/direct_objectives.py`、`score_matching.py`。

所以不能把“本次只用两档接收 SNR 微调”说成“原一阶网络只见过两种噪声”。基础去噪训练已经覆盖广泛噪声。十层任务微调会改变这些权重，是否保留原有去噪能力与接收性能必须另行评估。

Cai 训练的是人工 Gaussian 扰动下的信道先验。我们的层内查询由多用户线性模块和先前消息共同决定，其方差标签不等于接收 SNR 的简单倒数，误差也未必是独立 Gaussian。因此，多噪声先验训练提供的是分布覆盖思路，不保证十层任务微调的稳定性。

## 建议采用的场景原则

固定当前主系统：40 个候选用户、16 个导频帧、16 根接收天线、名义活动概率 0.1、当前 off-grid TDL-D 信道和 DFT 导频方案。这里的 D 是项目 TDL-D，不能因参考 Cai 就改成其 OFDM CDL-C。

增加数据时，增加同一系统内独立的用户位置、路径、复增益、活动集合、导频随机抽样和噪声实现。沿用当前非空活动场景约定及其条件活动先验，不把平均约 4 个活跃用户改为每个场景固定 4 人。

主实验 SNR 配置确认为 −4、−2、0、2、4、6 dB。若目标是判断整条主曲线上的微调增益，建议训练 SNR 在 −4～6 dB 内均匀随机取样；不同访问重新抽噪声，三次训练使用相同的预定输入抽样表，仅改变顺序。连续取样是本项目对连续噪声条件网络的设计，不是 Cai 公开代码已证实的训练细节。只用 2、6 dB 仍可作为局部诊断，但不能支持全范围结论。

保留整百预算：400 个训练物理场景、100 个验证物理场景、200 个独立测试物理场景。按物理种子划分三个集合；同一物理信道的不同 SNR、噪声版本不得跨集合。验证和测试分别把自己的同一批场景用于六个固定 SNR 点，所以分别有 600、1,200 个评估输入，不能把它们误记成 1,800 个独立物理场景。此规模是初始化已有预训练权重后的有限微调预算，没有理论保证它已足够。

只在全部训练结束后评估最终第十层输出；保留固定预算下三次运行，不挑最好的一次。分类器、alpha/beta/gamma 和反馈公式继续冻结；不因参考 Cai 自动增加二阶训练、活动 BCE、EMA、功率归一化或其他候选。既定相位/噪声口径须在新运行计划中单独明示，不能借文献引用默默改变。

两档 SNR 试跑留下 170 条正式更新日志，未完成第一轮，没有测试结果，不能判断增益。见 [中断记录](../../../result/candidates/score_only_finetune_20261022/INTERRUPTED.json)。该目录原计划和日志保留；新分布若采用，须使用独立运行目录从冻结权重重新开始，不能混合续跑。

结论边界：Cai 支持“固定主要信道分布、覆盖多种去噪难度”的安排，没有证明本项目冻结分类器微调一定稳定。200 个测试物理场景可以先比较明显的 NMSE 变化；在 AER 很低时，少量错误事件不足以支撑很强的稳定性或总体优势结论。当前尚无这轮微调的验证或测试结论。
