## 确认的问题及处理

| 问题 | 修改前的具体表现 | 处理 |
|---|---|---|
| 合并句子后，修饰对象不够准确 | I贡献3写成每个新增层由预训练得分网络初始化；V用“from which”接在噪声、相位和估计程序之后 | 明确只有新增层的得分网络加载预训练权重；直接写出由估计相位构造矩阵 `A(beta_hat)`。 |
| 连接词没有准确反映条件或必要性 | “Since ... need not lie on this grid”把可能的离网情况接成一般因果；II说欠定系统“requires”同时采用两类结构；V从顺序执行直接推出存储量 | 离网泄漏改用“When ... fall between grid points”；将两类先验表述为本稿选择；存储量明确为算子、SVD及一层所需消息的存储，不据顺序执行断言实现必然复用内存。 |
| 同一个动机反复出现，章节之间推进不足 | 引言、III局部混合均值之后、III末尾和IV重复强调两类估计影响下一层 | 引言说明为什么联合训练；III由积分目标引出去噪器和分类器；IV具体解释层内和跨层梯度路径。保留公式后必要的解释，删除重复的动机和预告句。 |
| 同一简称指向不同变量 | AFDM有效信道 `H_k` 与 `X_k=alpha_k H_k` 均简称effective channel，V还有“conditional channels” | 保留Huang的AFDM有效信道用语；定义X时直接描述乘以活动指示量的操作，III/V使用X的符号明确估计对象；改为conditional channel estimates。 |
| 训练描述的主语和对象不够精确 | “objectives propagate”以及“while ... retaining independent parameters” | 明确传播的是损失梯度；活动损失作用于所有用户，信道损失作用于活跃用户；新层接收先前层消息与拥有独立参数分别陈述。 |
| 抽象概括替代具体操作 | “two distinct training tasks”“adapting the complete ... procedure to a prescribed depth”“We summarize ... requirements” | 直接陈述预训练学先验、接收机训练适配消息、新层得分网络初始化及逐层联合微调；删去无新增内容的章节预告。 |
