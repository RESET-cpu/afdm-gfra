## 5. 压缩时必须保留的三项贡献依据

1. **多帧 AFDM 模型：** 长 CPP 的相位及分数时延／Doppler 路径算子；跨帧相位分离的推导和假设；观测增加而共同信道维度不变的结果。基础定义可紧凑呈现，模型推导不能整体移除。
2. **基于得分的生成式信道先验：** 学习对象确为多天线 AFDM 有效信道；连续物理参数如何体现在样本中；整用户张量的依赖关系；score、Tweedie 条件均值和 DSM 目标的联系。网络通道数不是这一创新的主要论据。
3. **深度展开及联合训练：** 两模块来自后验分解；条件信道均值与活动概率共同形成估计；两类损失的统计目标及其通过层间消息的联系；渐进训练的实际顺序。不能用“联合优化可以提高性能”代替这些解释。
