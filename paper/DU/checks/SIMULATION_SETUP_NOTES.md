# TWC仿真设置准备记录

本文件记录实际绑定的第三版训练设计，不表示训练完成或性能已验证。
依据：第三版协议与 cloud/review_20261021/MANIFEST.json。

| 项目 | 设计值 |
|---|---|
| 场景 | 已知相位、已知噪声的条件接收机 |
| 主干 | DirectCai RefineNet，一阶score；每层独立参数 |
| 先验初始化 | 同一50,000信道AWGN预训练权重，逐层独立加载 |
| 主训练条件 | 四条单变量扫描的19个去重条件 |
| 数据 | 每条件250训练、100开发场景，共4,750/1,900 |
| 默认条件 | K=40，Q=16，活动抽样概率0.1，SNR=0 dB |
| SNR | −4、−2、0、2、4、6 dB |
| 用户数 | 20、40、60、80、100，其余默认 |
| 导频帧数 | 8、16、24、32、40、48，其余默认 |
| 活动抽样概率 | 0.05、0.10、0.15、0.20、0.25，其余默认 |
| 深度与阶段 | 规划1至10层，每深度新增层适配1轮、联合微调2轮 |
| 层权重 | 前层0.2，末层1；除以权重总和 |
| 损失 | 固定平均场景能量归一化的条件信道平方误差＋固定平均用户数归一化的BCE |
| 适配学习率 | score 2e−5，活动头1e−4，校准1e−3 |
| 联合学习率 | 各组乘0.1 |
| 优化 | Adam，betas=(0.9,0.999)，eps=1e−8，weight decay=0；全局梯度范数上限1 |
| 校准初值 | 三个对数标量为0；活动头末层为0，使初始概率等于公开先验 |
| 消息常数 | eta=0.02，epsilon_s=epsilon_r=1e−6，q_max=0.95 |
| 预训练复方差支持 | [0.001,100] |
| 归一化 | RMS=0.2647966452702405；预训练二阶矩=1.0004404181394917 |
| 检查点选择 | 每深度epoch0及3轮中，全开发集末层两项损失之和最低；同值取早 |
| 最终活动门限 | 所有条件0.5 |

独立测试的场景数、结果、统计区间和硬件耗时尚不填写。
估计相位/噪声接收机需单独评价；不得混用信息条件或将已用于研究设计的场景称作独立测试。
监督对象与梯度消融须固定数据、初始化、深度、预算和选模规则的形式，不能直接把不同历史运行当作单因素对照。
