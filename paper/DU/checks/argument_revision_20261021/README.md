# TWC 第二至五章论证修订

本轮在作者指定的 `paper/TWC/main.tex` 及其实际引入章节上修改。
目标是让每个设计选择接在它要解决的问题之后，并让推导结果自然进入下一步。
修订前文件及哈希保存在 `../../history/before_argument_revision_20261021/`。

## 具体修改

1. **第二章：把共享信道的推导写完整。** 明确公共块定时与公共时延补偿的模型起点，
   说明终端位置用于信道生成。由 useful-window 起点和共同 Doppler 推出
   `G_k^(q)=exp(j q beta_k) G_k`，再将相位移入导频。随后解释增加帧数增加
   观测行，但不增加待估信道维度，以及对应的观测时间代价。
2. **第三章：解释公式之间的联系。** 从 Gaussian 乘积均值推导方差变化时的均值更新；
   从条件信道均值和活动概率得到有效信道估计；从残差能量关系引出共享方差，
   再依次说明正值映射、Gaussian 相除和自然参数阻尼。区分相除前的输出
   与真正返回下一层的消息。新增一张双栏消息传递图。
3. **第四章：使网络与训练可复核。** 补充实际 conditional RefineNet 和活动头的
   张量尺寸、卷积、噪声条件、归一化及激活。解释两类监督分别对应的统计目标，
   标签为何用于选择活跃信道项，以及梯度如何跨模块和跨层传播。说明增加
   新层后为何训练上一层此前未使用的反馈参数。
4. **第五章：从实际执行顺序说明代价。** 区分训练给定参数与完整接收机估计参数；
   解释相位拟合的主导路径近似与完整多径去噪的分工。说明相位为何使一般
   矩阵计算仍然必要，并将网络运算、前端固定开销和独立层参数存储联系起来。

术语来源、原文位置与本文适配范围写入 `docs/TERMINOLOGY.md`。
没有给普通操作新增名称或缩写。摘要、引言、附录、文献表以及研究实现未改动。

## 核验

- `revision_validation.json`：II–V 原有 50 个编号公式保持一致；只新增一个跨帧关系。
  加上附录共 58 个编号公式。跨帧关系在含分数时延、长于有用块的时延和正负
  Doppler 的确定性样例中，最大相对误差约 `4.65e-14`。
- `../VALIDATION.json`：现有一般矩阵 LMMSE/SVD、均值方差联动、残差展开、
  Gaussian 相除、自然参数阻尼和损失归一化检查通过；13 个旧稿文件与原快照一致。
  引用键和交叉引用均可解析。脚本的编译字段已改为“本脚本未运行”，避免每次
  核验重新写入早期资源包下载失败的过时状态。
- `acronyms.json`：正文缩写检查为 advisory、partial；处理本次范围内的重复
  定义和 FFT/SVD 首次定义。工具未识别部分带连字符的定义；NR-NTN 已在引言
  以复合名称展开，L-BFGS-B 在附录作为所引论文的算法名称使用。保留原始报告，
  不把工具的部分覆盖写成全面通过。
- 编译和最终 PDF 版面检查见 `compile_result.json`。最终阅读稿为
  `output/pdf/TWC_chapters_II_V_revised_20261021.pdf`。
