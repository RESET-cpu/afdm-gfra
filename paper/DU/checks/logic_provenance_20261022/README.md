## 本稿自己的代数与量级计算

1. **跨帧分离。** 将 `g_q=N_CPP+q(N+N_CPP)` 代入 `eq:path-operator`。共同用户多普勒使所有路径共享 `exp(j q beta_k)`，从而得到共享信道及有效导频。其条件是本稿已有的充分前缀、块内固定参数和每用户共同多普勒。
2. **有效导频的行内积。** 对 q≠q'，`(A A^H)_{q,q'}=sum_{k,n} P_{qkn} conj(P_{q'kn}) exp(j(q-q') beta_k)`。原导频的行内积为零，不意味着带用户相关相位后的加权和仍为零。所有用户beta相同时仍可保持行正交，因此正文使用“generally”。数值检查仅核对这一恒等式和一个非零示例。
3. **块内几何变化。** 令 r=||g-s||，u=(g-s)/r。固定地面点时 `u_dot=-(I-u u^T)v/r`。对本稿 `nu=-(fc/c0)u^T v` 求导，得 `nu_dot=(fc/c0)[v^T(I-u u^T)v/r-u^T a]`。圆轨道满足 r≥h、||a||=v²/(R_E+h)，由此得到正文的 B_nu 上界。固定tau_c和路径超额时延时，`tau_dot=nu/fc`；积分给出时延变化界。对多普勒变化积分给出相位误差界 `pi B_nu T_B²`。
4. **采用项目自身参数。** 来源为 `src/system/config.py`、`src/system/scenario/geometry.py`、`src/system/scenario/scene_generator.py`：N=16，Δf=30 kHz，N_CPP=336，fc=2 GHz，轨道高度600 km，地球半径6371 km，初始|nu|≤41 kHz。速度由圆轨道计算。正文展示Q=16；`model_scale_check.json`同时记录Q=8至48，未筛除较长块的结果。上界不是接收机性能结果，也不验证路径增益的块内恒定性。尤其Q=48的相位误差上界约2.69 rad，不能用Q=16的数值宣称所有块长下变化都可忽略。
5. **训练依赖。** `src/algorithm/proposed/receiver.py:73–89` 中的 conditional、probability、estimate、residual、feedback 保留梯度联系。新增文字据此说明活动损失可训练条件去噪器，后续信道损失可训练前序分类器与消息参数。这是设计动机和实现关系，不是联合训练必然改善性能的证明。

量级与恒等式核验可运行本目录 `verify_model_scales.py`。它不启动训练、Monte Carlo性能实验或冻结实验计划。
