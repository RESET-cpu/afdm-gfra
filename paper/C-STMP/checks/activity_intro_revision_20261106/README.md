## 句级依据与含义

1. Cai 作者稿 `reference/literature/cai2026_stmp_v2.pdf`，§III-B，PDF pp.6–7：式 (17) 及其后说明给出匹配一、二阶矩的 Gaussian projection；式 (24)–(27) 为 Gaussian extrinsic messages；式 (28)–(30) 为活动后验概率。当前句是这些具体操作的概述，不声称逐字引用。
2. 非高斯后验的矩匹配一般不保留边缘似然，是本稿对近似的分析，不归为 Cai 原文给出的不足或性能结论。这里指单次局部更新中的后验矩与归一化常数，不断言完整得分函数无法恢复密度，也不声称已证明所有高斯近似都会造成明显检测误差。
3. Menon–Ong，ICML 2016，§3 式 (6)–(8)、§4.2 式 (16)–(17)，pp.305–306，提供密度比与类别概率的关系；用于本稿活动更新的具体构造见第三章与第四章。原文：https://proceedings.mlr.press/v48/menon16.html 。本句是该关系的应用说明。

“this Gaussian approximation”仅指活动更新采用的信道后验高斯投影；等效 AWGN 模型和模块间高斯消息仍保留。不新增方法名、模型定义、实验或参考文献条目。
