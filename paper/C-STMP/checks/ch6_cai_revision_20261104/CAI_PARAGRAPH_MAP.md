# Cai 原段组织与本稿适配

来源为 [Cai 期刊 PDF](../../../../reference/literature/cai2026.pdf)，不是混用作者稿页码。原页文本和图片保存于[上轮对照目录](../ch6_cai_presentation_review_20261104/)。本表登记段落任务和分析角度的对应，不宣称逐句翻写或所有段落一一对应。

| 本稿位置 | Cai 原位置 | 采用的组织/角度 | 本稿差异与保留范围 |
|---|---|---|---|
| VI-A1 数据与系统参数 | VI-A1，PDF p.11／印刷 p.3585 | 先数据和系统，再训练与评估 | 采用本文 NTN-TDL-D、AFDM、条件化活动采样和逐场景 SNR；不移植 OFDM/CDL 条件。 |
| VI-A2 网络与训练 | VI-A2、Table III，PDF p.11／p.3585 | 网络层配置表；正文解释输入、条件注入和训练 | 本文去噪器与分类器结构不同，按网络分组；表格来自既有实现核验，不套用 Cai 两个 score 网络参数。 |
| VI-A3 比较接收机 | VI-C 开头，PDF p.12／p.3586 | 圆点列表、加粗算法名、核心方法与关键预算 | 本文五种基线；GP-MP 是本文的 AFDM 适配；GAMP-SBL 的多天线共享精度说明属于本项目实现。 |
| VI-A4 评估设置 | VI-A3，PDF p.11／p.3585 | 默认条件与统计设置集中说明 | 保留本文停止规则、阻尼、样本数、NMSE 与 AER 统计定义；不复制 Cai 的评估参数。 |
| VI-B 去噪 | VI-B，PDF pp.11–12／pp.3585–3586 | 先独立去噪任务与参考方法，再比较学习方法、解析先验、稀疏方法及 genie | 本文采用 AWGN 下两种训练网络与条件 MMSE 参考；不把低 SNR 的有色训练收益扩展至全范围，也不移植复杂度结论。 |
| VI-C 密度比比较 | 无直接同类消融段 | 本文新增的独立实验任务 | 保留 AER 与迭代上限两项结果，删除正文内错误类别的具体计数和拆解。 |
| VI-D 收敛 | VI-C Fig.5 分析，PDF p.12／p.3586 | 观察迭代趋势及最终精度 | 本文只是一例配对场景；60 为规定的最小停止轮数，不能写成全样本平均或严格收敛速度保证。 |
| VI-D SNR | VI-C Figs.6–7 分析，PDF pp.12–13／pp.3586–3587 | NMSE、活动检测分别说明；比较基线及差距随 SNR 的变化 | 本文保留整体 AER；不拆漏检/误警，不照搬 Cai 的先验改善因果归因。 |
| VI-D 设备数 | VI-C Fig.8 分析，PDF p.13／p.3587 | 负载改变及相对表现 | 本文固定活动概率、增加候选设备数；没有复制 Cai 的四倍容量结果。现有曲线相关的 C1 仍按既有决定待定稿处理。 |
| VI-D 活动概率 | VI-C Fig.9 分析，PDF p.13／p.3587 | 固定候选集合，活动负载增加 | 保留总体恶化及两种学习接收机的差距，不重复设备数段的总结；不宣称本文具有 Cai 曲线相同斜率。 |

| VI-E 跨信道 | VI-C Fig.11 分析，PDF pp.13–14／pp.3587–3588 | 训练与测试信道不同、无需重训练 | 本文 D→A/B/C；与四种稀疏基线的优势和与 GP-MP 的较小、随条件变化的差异分开写，不作所有条件均优于 GP-MP 的断言。 |
