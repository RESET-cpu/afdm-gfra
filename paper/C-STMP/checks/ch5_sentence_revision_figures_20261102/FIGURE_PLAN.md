## 判断

最值得补的是两幅解释方法的图：**第二章的系统与多帧传输图，以及第五章的学习接收机总图**。它们分别回答“观测是怎样形成的”和“学到的量怎样共同完成推断”。现有第三章框图继续回答通用的消息交换关系。这样可以保持第二至第五章由模型、框架、学习到算法的论证次序。

实验部分已有 SNR、帧数、设备数、活动概率和跨信道等比较。后续如补实验图，优先考虑分离有色训练和密度比估计贡献的消融，而不是继续增加相似的参数扫描。

## 优先补图一：系统与多帧 AFDM 传输

**拟放位置：第二章多帧观测模型形成处；一张双栏图，左右两部分。**

左图呈现 LEO 卫星、UPA、活动/非活动地面设备，以及公共时延补偿后的差分时延。只标与模型有关的量，例如设备活动状态、差分时延和设备 Doppler；无需把全部几何参数挤进场景。

右图画同一设备的 Q 个连续 AFDM 帧，每帧由 CPP 与有效符号部分组成，标出导频 P、帧序号 q 和帧时长。各帧下方依次标示相位因子 1、exp(j beta_k)、…、exp(j(Q−1) beta_k)，并用同一个信道块 H_k 与活动变量 alpha_k 贯穿 Q 帧。图底以正文的关系连接到观测矩阵：

`H_k^(q) = exp(j q beta_k) H_k → A_qkn = P_qkn exp(j q beta_k) → Y = A X + W`。

这张图的论证落点是：**各帧共享同一组待估信道，跨帧相位进入观测矩阵，增加帧数提供更多观测。** 它能把第二章的物理模型与后续线性估计直接连起来。

- 现有定义足够绘制，不需要实验数据。
- CPP 画为结构示意；正文允许 N_CPP 大于 N，不能用明显短于有效符号的比例暗示相反设定。
- 不把不同帧画成独立信道，也不把补偿后的差分时延画成设备已预补偿的时延。
- 英文图题建议：*System model and multi-frame AFDM pilot transmission.*

## 优先补图二：学习接收机与联合去噪展开图

**拟放位置：第五章 A，Algorithm 1 附近；一张双栏图，上部概括训练，下部展开在线迭代。**

上部只画与第四章贡献直接有关的两条训练关系：

1. 信道样本 H 与有色 Gaussian 扰动、协方差 C 一起生成均值去噪器的训练输入，经第四章损失学习 F_theta。
2. 固定去噪器后，活动/非活动两类白噪声观测及去噪特征用于训练密度比分类器 z_phi。

下部画在线主干 `Y, A_hat, sigma_hat² → MFLE ↔ GPJD → channel estimates / activity decisions`。在 GPJD 内展开同一个输入 `(R_k, v)` 的三个计算去向：

| 去向 | 图中需显示的关系 | 汇合后的作用 |
|---|---|---|
| 条件均值 | `F_theta(R_k, vI) → F_k` | 与方差合成 Gaussian site，再与当前输入得到条件矩 |
| 条件方差 | 对同一均值映射作中央有限差分，得到 tau_hat_k，再汇总为 tau | 给出上述条件矩所需的方差 |
| 活动概率 | `(R_k, v, F_k) → z_phi → density ratio → Bayes correction with rho → p_k` | 与条件信道矩合成联合后验均值与协方差 |

联合矩经过外信息计算返回 MFLE，并给出当前信道与活动估计。图中的参数连线表明已训练网络用于在线推断；在线网络输入明确为 C=vI。方差尺度更新可画为返回下一轮输入 v 的一条辅助箭头，详细数值分支仍由 Algorithm 1 表达。

这张图的论证落点是：**第四章得到的均值、方差和活动概率在第五章汇合，形成可迭代的联合估计。** 与第三章通用框图相比，它增加的是这些量的来源和用途。

- 现有算法足够绘制，不需要训练或新实验。
- 方差支路连接同一 F_theta，不能画成另一张独立训练的方差网络。
- 必须保留 F_k 到分类器的输入连线；活动先验 rho 接在 Bayes 修正处。
- 不把有色训练分布画成在线使用的一般有色消息；密度比训练的两类噪声仍为白噪声。
- 训练部分采用浅色分组，在线部分采用实线箭头；版面不足时缩减训练细节，不增加层数、卷积尺寸等架构清单。
- 英文图题建议：*Training and message passing in the proposed receiver.*

## 下一幅实验图：接收机消融

若后续增加实验，建议让一张双子图分别报告 NMSE 和 AER，以有色/白色训练、学习密度比/Gaussian 活动证据构成 2×2 比较。各组采用相同物理场景、观测、相位/噪声估计和迭代设置；每个均值去噪器须配套训练其冻结特征下的分类器，不能直接交叉复用另一去噪器的分类器。

该图回答两个具体问题：有色训练对完整接收机有什么作用，密度比活动估计又带来多少变化。均值导数方差在四组中保持，避免把多个变化混在一个差值里。

当前独立去噪图已比较两种训练扰动，但测试噪声均为 AWGN，尚不能替代上述完整接收机消融。`result/density_ratio_ablation/data/README.md` 将相关历史记录标为暂缓或不完整，当前不能直接据此生成正式消融图。本轮仅提出问题和对照关系，未启动实验或训练。
