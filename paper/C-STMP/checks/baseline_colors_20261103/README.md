# 基线曲线配色调整

按作者 2026-11-03 的要求，Off-grid SBL 使用原 STMP 的蓝色，另外三个稀疏恢复基线提高颜色饱和度：

| 方法 | 颜色 | 色值 |
|---|---|---|
| Off-grid SBL | 蓝色 | `#2878b5` |
| GNN-ASPL | 紫色 | `#7b2cbf` |
| GAMP-SBL | 橙色 | `#e68600` |
| SOMP | 绿色 | `#159447` |

GP-MP、GP-MP-CCD、GP-MP-CCD-EP 仍为原定红色，分别使用虚线圆点、实线方块、虚线三角。所有方法的名称、线型、标记、线宽和数据均保持，仅上述四种基线的颜色变化。

更新用户数、活动概率、跨信道、导频帧数和 SNR 五幅图。收敛图无上述四种基线，正式文件保持；独立去噪图和三幅方法图也保持。重绘读取上一轮相同的保存数据，未启动推断或训练。逐项比较上一轮绘图记录，505 个点及除指定颜色外的曲线设置完全相同，见 `COLOR_VALIDATION.json`。

当前绘图入口为 `render_five_figures.py` 与 `render_snr.py`；修改前文件和哈希保存在 `before/`、`BEFORE_HASHES.json`。最终编译与排版检查见 `VALIDATION.json`，预览见 `previews/`。
