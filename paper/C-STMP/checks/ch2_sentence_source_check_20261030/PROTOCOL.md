# 第二章当前版本逐句来源核查

本轮按作者最新要求，检查每一句是否来自参考论文原句，仅有必要术语/符号替换，或属于可逐分句定位且保持原义的合理组合。旧审查结论不复用为本轮证据。只写本目录核查产物，不修改正文、PDF、参考文献、实验或模型。

核查对象为 manifest.json 绑定的当前英文第二章；中文译文不是另一份论文改写。每个段落按完整英文语法句切分，包括显示公式前后相连的 where/Here 从句。每句完整 draft_tex 必须逐字取自 Pxx.input.txt，所有句子依次拼接后仅忽略空白即覆盖该段，无遗漏、无重复。公式纳入相应语句，另说明数学适配。

分类：EXACT（排版规范化后原句一致）；TERM_ONLY（完整原句只替换必要技术对象、符号或维度，其他英文关系保留）；REASONABLE_COMBINATION（能定位所组合的具体原句/分句，连接后含义和假设不变，仅有必要语法调整）；SUPPORTED_PARAPHRASE（内容有依据但句子经过自行改写，不能称只作术语替换或原句组合）；AUTHOR_DEFINED_OR_DERIVED（本稿定义、符号重排、建模假设、公式推导或内部章节指引，无对应参考原句，不等于错误）；SOURCE_GAP（现有来源不能支持具体内容或存在归属/假设缺口）；UNVERIFIED（材料不能读取或无法消歧）。不得用词汇相同、普通学术模板或技术合理性代替原句对应。

每句记录 id、draft_tex、source_refs（key/page/section/eq/quote或locator）、category、changes、reason、technical_status、formula_adaptation、action。来源优先本轮 SOURCES.json 中的原始PDF及其逐页提取；遇到公式或抽取歧义回看PDF页面，记录实际查看。NO_SOURCE类结论须限定检索语料，不宣称所有文献都没有。

Shen、Cai正式版与v2、Ding、Huang为项目中用户提供的原始PDF，可以为本次比对引用必要原句。Li与Bemani是此前公开检索补入的资料，每篇在本轮交付物中原文引语合计不超过25英文词，其余提供精确页码、公式和释义；Li由P01–P03审查员使用，Bemani由P04–P08审查员使用，其他审查员仅提供定位。

每段另外给出段落来源顺序、是否跨来源组合，以及结构是否改变论述条件。综合报告分别统计原句适配、支持性改写、本稿定义/推导和来源缺口，不能用总PASS掩盖后几类。覆盖检查通过仅表示没有漏句，不表示每句都满足作者要求。
