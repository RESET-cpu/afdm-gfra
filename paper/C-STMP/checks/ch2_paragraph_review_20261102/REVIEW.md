## 总体判断

1. **大结构成立。** 物理信道及阵列 → 导频与 AFDM 波形 → 有效信道及跨帧关系 → 接收观测 → 联合估计目标，前后依赖基本顺畅。没有必要推倒重排整章。
2. **重点还不够集中。** 主要缺口是多帧方案的具体操作与用途仍要读者从几个公式中自行拼接；连续时间波形的必要性，以及训练信道先验在接收机推断中的作用，也没有用简短文字交代清楚。
3. **细粒度总体合理。** 阵列、标量与矩阵调制式、CPP、实数时间波形、紧凑路径矩阵、观测索引及后验因子都有正文用途。主要应调整解释的分配和位置，而非笼统删公式或搬回附录。
4. **此前的问题部分仍在。** 生硬的特定词组、异质变量集中报名称、活动概率和 DRE 过度展开等问题没有复现；“列性质但没讲用途”“列定义但没把方案说明白”仍局部存在。
5. **不能再确认整章都是参考论文原段原句的最小替换。** 部分句子确有直接母句；另一些只有句式或术语依据；还有本文自己的假设、定义和推导。旧来源记录对这三类的区分仍不够严格。来源记录失准与正文数学错误是两件事。

在本轮逐元素、维度及公式依赖核对的范围内，未发现必须改变当前模型才能修复的确证代数错误。该结论不等于完成了新的物理模型验证或恢复性能实验。

## 最值得修的几处及原因

### 1. 把多帧方案的操作与观测关系接起来

当前 §II-B 先连续定义 N、Q、导频符号、向量和矩阵，然后经过调制、CPP、波形及路径矩阵，才得到跨帧关系。该关系末尾只说相位累积而 H_k 近似不变。再到 §II-C，矩阵式又主要被介绍为更紧凑的表达。

这些公式已经具备所需模型，但读者必须自行完成下面的连接：

> 连续 AFDM 帧发送导频 → 每帧去 CPP 并进行 DAFT → 将设备的跨帧相位计入相应导频系数 → 多帧观测共同关联同一个参考信道/活动加权信道 → 增加帧数增加观测，而非增加待估计信道矩阵的尺寸。

这里的“计入”是建立接收模型，不意味着未知相位已经通过真值获得。若写入正文，应沿用已有术语并与实际前端接口一致。

Shen §II-B（PDF pp.4–5）先交代具体传输过程，再从准静态性质接到增加观测的作用。值得借鉴的是这一顺序；其数据扩频与 OTFS 特有步骤不应移植。

**最小修正方向：** P04 增加极短的过程总览；P10/P13 根据承接集中说明作用。可在 P10 交代相位进入导频，在 P13 用矩阵尺寸落实共同未知量，不能在三处重复完整的“更多观测”论述。

维度依据是：Y、W 为 Q×MN，A 为 Q×KN，而 X 为 KN×MN。固定 K、M、N 且既有跨帧模型成立时，增加 Q 增加前者的行数，不改变 X 的尺寸。这一结论不附带恢复误差必然单调下降或可任意增大 Q 的保证。

### 2. 实数时间波形既要说明用途，也要准确标明引用支持范围

P08 目前在 `can be written as` 后引用 Bemani，再给出含 w_ξ 和取整函数 ζ_n 的完整波形。重新读取本地 30 页版本可确认：Bemani p.7 式(14)给周期关系，p.8 式(18)、(19)给离散调制基函数及 CPP；这些位置未给当前完整实数时间式。

本轮核对了整数样值与 IDAFT 一致、波形满足 CPP 相位关系，二者均成立。但这两个性质本身不能唯一确定所有非整数样值，故不能说当前整式只是 Bemani 的符号替换。

本段真正的用途是让下一段能够定义 `[B_d]_{tn}=φ_n(t−d)`，特别是 d 非整数时。应将该用途与“本文采用这一实数时间定义”的归属简洁写清，并把文献引用限定到实际支持的离散 AFDM/CPP 依据。**这不是要求改公式，也不是已证明当前物理波形错误。**

### 3. 活动段修连接顺序即可

P11 当前顺序是 i.i.d. → `As a result` 少数设备活跃 → 定义活动指示 → ρ≪1。i.i.d. 本身不蕴含少数活跃，例如同为 i.i.d. 的 Bernoulli 模型可以有很高的活动概率。

Cai 引用版本 p.4 原文确实有这个简写，所以不能把“有原句”当成逻辑自动正确。最小处理是把少数活跃的句子移到 ρ≪1 之后。全段已有正确的低活动率条件，无需重建模型或增加概率推导。

### 4. 后验段准确说明 q_tr 的推断角色

P14 把 q_tr(H_k) 仅描述成 `for training`，后面却直接把它放入后验分解。读者需要明确：这是与训练信道样本对应、并在接收机推断中采用的完整联合信道先验；不逐元素分解意味着保留系数间的统计依赖。

应在同一处把这个角色说明完整，把训练损失和网络实现留给后文。现有 `We assume` 与 `With ... fixed` 已经标明独立性和固定前端输入；可与先验角色一起收束其推断范围，**不另加物理生成模型与计算模型差异的长免责声明**。

末句的 MMSE estimate 可直接点名 X_k，因为公式给的是 E[X_k|Y]。这属于文字对象精确化，目标公式本身没有写错。

### 5. 将泄漏理由放到其直接服务的判断旁边

P09 末句讨论分数时延和 Doppler 导致泄漏、削弱信道稀疏性，下一段却马上返回绝对采样起点 g_q 与跨帧推导。该句技术内容有 Huang 依据，但此处轻微打断主线。

它与 P14 的“估计完整 H_k、不强加信道稀疏性”关系更直接。将两者相邻即可建立理由到处理方式的联系，不需要再补一段分数效应教程，也不应把该理由牵强接到设备活动的块稀疏性上。
