# P03：阵列响应与块内参数恒定

## 段落任务与结论

基线：`snapshot/02_system_model.tex` 第46–59行，独立段落 `paragraphs/P03.tex`。本段先把上一段物理信道中的空间因子 a_k 写明，再给出物理参数在传输块内不变的近似。

**结论：阵列公式、术语和定义顺序基本清楚；不能将整段认定为某一参考论文原段的最小替换。** 引出句与 Li 的相同技术任务原句高度对应；公式后解释结合了 Li 的阵元间距定义与 Shen 的坐标/方向余弦定义；末句是本文全体物理参数的块内恒定假设，尚未核得技术条件相同的完整原句。它不是 Cai 原文“所有信道块内准静态”的直接同义替换。

本文阵列表达采用 Shen 的正指数、未归一化空间相位约定，并把半波长间距展开为 d_y、d_z 与波长 λ；Li 提供阵元间距定义和 array response vector 名称。不能因此把当前整个阵列公式标为 Li 的原式，Li 的向量采用负指数并含归一化因子。当前表达本身未因此发现错误。

## 确证问题与最小修正方向

### P03-F1：全体参数恒定不能按 Cai 原句直接通过（中）

- **位置：** 第58–59行。
- **证据：** Cai 原句对象是 all the channels；本句对象是 path gains、delays、Doppler shifts、angles of arrival。本文式(1)含显式时间相位，因此该替换改变了假设所约束的层次。Li 的块衰落结论又依赖其已做多普勒和时延补偿的前文条件。
- **影响：** 不影响本句作为本文假设的可读性，但直接影响“原句最小替换”及技术来源的真实性。不能用 Cai 的普通块衰落句证明本文多帧高多普勒条件已成立。
- **最小方向：** 在核验记录明确列为本文假设，保留其真实含义；若用户后续要求进一步改写，优先找同样约束物理参数的原句。未找到前不能仅替换 `approximately constant`/`quasi-static` 就宣布满足要求。此项不要求正文新增免责声明。

### P03-F2：全局物理假设挂在阵列定义末尾，作用层级略不清（低）

- **位置：** 第58–59行及与上段的连接。
- **证据：** 前两部分只解释 a_k 与空间坐标，末句突然覆盖增益、时延、多普勒和AoA；其实际后果直到后文跨帧 H_k 的近似恒定才出现。Cai 将块内恒定放在系统总体假设组，Shen 将跨帧恒定放在有效信道与多帧观测的关系处，而非单独挂在阵列定义上。
- **影响：** 读者能理解该句，但容易把它当作又一项阵列附属定义，而未意识到它是多帧共同信道模型的前提。这是轻微的层次问题，不是逻辑矛盾。
- **最小方向：** 若后续修改，只需考虑把该句放入前段物理信道假设组，或在物理模型结尾独立收束，并与后文 Q 帧的作用范围保持一致；无需再展开一段动机或照抄 Shen 的数值论证。

## 保留的优点

1. `array response vector` 和 `spacing between adjacent antennas` 都有技术对象一致的直接出处；旧 `UPA response` 问题没有复发。
2. 先引出阵列公式、再解释索引/几何参数，顺序服务阅读；没有把时间变量、Dirac函数和阵列向量拼成一个 `The notations...` 句。
3. `directional cosines` 与本文正指数空间相位一致；轴序 z,y 与所列变量逐一对应，没有将 AoA 角值误称为方向余弦。
4. `can be written as` 表示给出模型表达，`We assume` 明确标出假设；`approximately` 没有把近似写成严格物理恒定。
5. 不需要为每个普通定义补充动机；本段没有为应对假想质疑而增添防御性文字。

## 相对参考文献的细粒度

- **与 Shen 比：** Shen 在物理信道式(1)内直接放入两个空间指数，并用一个句子同时定义方向余弦与角度关系。本稿把空间因子独立成式(2)，多列一般间距和波长，删去不参与后续公式的角度转换。这个详略变化合理：它解释多天线物理信道的空间因子，并未扩张成阵列建模专题。没有依据将式(2)整段移到附录。
- **与 Li 比：** Li 的相近段还定义归一化一维向量、Kronecker积、相同路径AoA、空间角、天底角及其可行域，然后说明角度缓变和已知性。本稿明显更简洁，未不加区分地移植 Li 的角度已知或预补偿条件，这是优点。无需为“完整照原段”恢复本文不用的这些细节。
- **块内恒定：** Cai 在系统配置中用一句约束整体，Shen在有效信道后的跨帧讨论给出定量适用范围。本稿保留一句参数假设的细粒度本身可以接受；更有价值的调整是位置和与后文范围的对应，而不是增加四类参数逐项解释。
