## 当前修改

| 原算法框的问题 | 当前处理 |

| 普通 enumerate 长段落充当伪代码，循环体和条件没有层次 | 使用逐行伪代码环境；循环、条件及结束行自动缩进和编号 |
| 标题整体加粗、编号后加冒号，缺少标题下横线 | 算法编号加粗、名称常规字重，标题上下横线；独立算法计数及交叉引用 |

| MFLE/GPJD 内容混成长句 | 使用模块注释，按计算对象拆成短句，通过既有公式号定位 |

| 训练区间外的兜底被突出成算法主分支 | 根据作者纠正，从伪代码移除训练区间判断及 Gaussian evidence 分支，明确算法框概括主迭代流程 |

## 作者决定及实现边界

**伪代码用于说明主算法，不机械展开代码里的范围检查和兜底分支。** 此次 Gaussian evidence 指输入方差超出网络训练区间时，利用保留的 Gaussian site 计算活动概率的既有实现；不把它包装成方法贡献，也不因代码含有这一步，就要求在算法框中强调。

本轮只移除该分支在算法框中的呈现。第 VI-A3 节既有实现说明和式 (43) 本轮未改，不能把此次修改说成已从全文删除，也不能说实现取消了这一步。后续若作者要求进一步精简正文，再沿此呈现原则处理，不重开此前的 M2/M3 争论。

原有正精度条件、首次消息不阻尼、下一轮 κ 更新、输出尺度和停止规则保持。未更新的 site 自然沿用已有值。对照依据包括原算法框、`src/algorithm/C_STMP_variance_em_20261025/iterations.py` 与 `src/algorithm/STMP/denoiser.py`；实现和数值参数未修改，没有启动实验或训练。
