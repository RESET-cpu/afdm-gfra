## 具体建议（均未实施）

### R1 / MINOR / 优先：V-A 的 Gaussian site 细节占据整体算法说明的中心

位置：`sections/05_overall_algorithm.tex:22–54`。

原文先写 “the denoiser provides the channel mean”，随后 “the channel prior is approximated by a Gaussian site”，再写 “The product of this site and the current Gaussian likelihood determines the channel variance and mean”。

读者刚在第四章理解如何得到均值与方差，进入整体算法后又经历后验除似然、site 乘似然的完整过程，容易暂时失去对接收机整体信息流的把握。在本轮 site 接受更新且使用同一输入时，式 site-update/site-mean 代入 conditional-moments/conditional-channel-mean，代数上还原当前 F_k 和 tau^post；site 保留条件及跨轮使用才使这个实现结构有独立作用。Algorithm 1 已有接受条件，因此不能据此删掉 site 或擅自把所有分支都改为 Hpost=F。

建议：V-A 保留 MFLE → 去噪均值/方差与分类活动概率 → 联合矩 → 外信息回传的完整主流程和算法框；site 构造与条件矩重组的细节归入 V-B 的迭代实现部分，以简短正面说明交代其作用。保留现有接受/保留规则与公式，不恢复此前删除的冗长失败防御。若后续实施移动，图 3 和算法交叉引用需同步。

### R2 / MINOR：III-B3 的开头可以更清楚地呈现活动推断与消息近似的顺序

位置：`sections/03_bayesian_receiver_design.tex:124–158`。

原文以 “Approximating the active-channel posterior by a Gaussian ... gives a Bernoulli–Gaussian approximation” 开头。前一节已经定义活动概率，第四章又给出密度比估计，数学顺序并没有倒置；但此处重新以高斯近似为段落主语，使读者需要自己辨别它与引言讨论的 Gaussian 活动概率近似有何不同。

建议：用已获得的 p_k 与活跃条件下的信道均值/方差如何形成联合估计作为开头，再说明以高斯消息回传。只调整解释重心和句序，不改变混合分布或协方差公式。让计算顺序体现差异，无需增加“我们并没有……”或“不同于 Cai……”式防御段。

### R3 / MINOR / 优先：V-B 在预处理与迭代内更新之间往返

位置：`sections/05_overall_algorithm.tex:131–230`。

当前顺序为噪声估计 → 相位估计 → “Minimizing ... over the input variance v” 的迭代方差更新 → “The channel and observation quantities ... are normalized” 的归一化 → 递归阻尼。

归一化属于进入迭代前的尺度处理，却放在迭代方差目标之后；这一跳转让相邻段落更像并列实现条目。各段内部推导本身基本清楚，不必重新扩充每项背景。

建议：先连续完成噪声/相位估计与归一化，再展开迭代中的方差调整、site 和阻尼。一次性参数估计与迭代内更新各自连续展开即可，不必拆出大量短小小节。具体搜索范围、步长和停止阈值仍放在现有实验设置中，不重新搬回正文。

原文为 “These moments are obtained using the learned denoiser as described in Section ...”，目标为 V-A。V-A 确实负责 site 后的实际条件矩，因此不是错引；但学习估计的来源在第四章，这一指引跳过了紧接着的学习章节。
