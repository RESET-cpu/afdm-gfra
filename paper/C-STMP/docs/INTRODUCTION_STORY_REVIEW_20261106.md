## 总体判断

现有顺序具备完整骨架：LEO IoT 与 GFRA → 不依赖终端预补偿 → OTFS／AFDM → 稀疏先验局限 → 生成式先验与采样代价 → STMP → 三项贡献。没有发现需要另造研究问题才能连接这些内容的矛盾。

建议的总问题是：在终端不进行时频预补偿的条件下，如何组织多帧观测，并把学到的复杂有效信道统计用于卫星端的联合活动检测与信道估计。该句是对本稿的归纳，不是引用文献的原句或新术语。

## 优先修改的三处论证

### R1：AFDM 表示与先验学习之间缺少实际作用说明（MAJOR，写作）

原文：`This compact representation motivates learning the effective-channel prior directly for GFRA.`（50–51 行）。

紧凑表示说明学习对象容易组织，不足以单独解释为何需要学习先验；后者的直接动机是下一段的离网泄漏与稀疏表示局限。两者应各司其职：先说明跨帧相位分离后，多帧观测作用于固定的有效信道；再说明该信道不宜依赖过强的稀疏／网格假设，因此直接学习其统计。

另一个衔接问题是，39–42 行从 OTFS 的“three-dimensional tensor”转到 AFDM 的“one-dimensional chirp modulation”，比较对象从信道表示换成调制方式。二者各自正确，但不能凭“三维／一维”直接推出信道维数或计算收益。宜直接连接后文已有的有效信道表示比较。

证据：本稿 §II-B 跨帧关系与匹配带宽、时长下的表示比较；§II-C 观测式及固定未知量说明。Shen §II-B 为所比较 OTFS 表示的原始来源。现有共同设备多普勒条件保留，不新增普遍波形优越性主张。

### R2：第二项说明了方差如何得到，但其在接收机中的必要性不够突出（MAJOR，写作）

原文：`estimate the average posterior variance required for message passing`；随后两行半强调二阶训练依赖和存储（115–119 行）。

“required”目前代替了解释。应在动机段先简短说明：去噪器给出信道估计后，接收机还需要其不确定性来形成传回线性模块的消息。随后保留已经确认的 Tweedie → 条件均值导数／协方差关系。这样，同一去噪器提供推断所需统计量是主要作用，无额外二阶训练是落实该作用的设计收益。

证据：本稿 §III-B 的联合均值、平均方差及外信息更新同时使用信道均值、条件方差与活动概率；§IV-C 用已有恒等式和数值导数估计平均方差。Cai §I-A、§III-B、§IV-A明确均值与方差在消息传递中的作用；Manor–Michaeli §3.2 式(11)支持由去噪器导数获得协方差。

本项不建议删去此前确认的数学链，也不将平均方差计算包装成新的恒等式或已证明的校准、稳定性结论。

### R3：第三项的主要动机仍小于正文实际解决的问题（MAJOR，写作）

原文：`To reduce errors associated with a Gaussian approximation of the channel posterior`（125–126 行）。动机段90–95行也仅从 Cai 的 Gaussian 活动更新切入。

应先说明：score 学习直接提供对数密度梯度；活动概率计算还需要似然比。对本稿，活动状态下的似然涉及对未知信道积分。由此引出直接学习所需密度比，让有效信道统计参与活动概率计算，绕过显式似然求值。随后再说明现有 Gaussian 投影给出一种解析近似，其矩匹配不保证保留一般非高斯模型的边缘似然；这是本文选择学习密度比的具体比较依据。

顺序建议：活动判决所需量 → score 的直接输出与该量不同 → 现有 Gaussian 解析近似 → 密度比学习提供所需比值。不要写成所有解析计算都不可用，也不写成 score 在数学上不包含任何密度信息。

证据：本稿 §III-B2 的活动／不活动似然与 Bayes 活动概率，§IV-D 分类训练与 log density ratio；Menon–Ong §1、§3 式(6)–(8)、§4.2 式(16)–(17)。Cai §III-B1 式(17)、(24)–(27)及 §III-B2 式(28)–(30)为 Gaussian 投影和解析活动更新的依据。Menon–Ong支持估计构造；AFDM 推断动机是本稿模型的应用分析。§VI-C已有活动更新替换实验支持该选择的实用效果。
