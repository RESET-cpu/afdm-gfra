# 更粗的 GEC 分组：首轮误差、模式响应与天线相关

2026-10-24。承接 [C 候选验证](STMP_COVARIANCE_VALIDATION_20261024.md)。

**结论：粗分组确实降低了逐模式归一化的首轮误差代价，但没有得到“单位信号响应＋可由当前 C 描述的Gaussian误差”。** 每用户1组和对折4组的原始查询MSE接近现状，模式响应差异却基本保留；连续细分逐步接近模式自身单位响应，误差代价随之增加。全部分支仍有明显天线相关。当前不采用某个分组作为新主线，不据此开始重训。

上一轮约27倍的结果还需补充一个重要解释：它是原始query MSE比。在保留公开缩放元数据时，各首轮query之间可逆，因此不能把27倍说成信息量损失或最终检测性能下降。本轮把这种等价关系与代价一并验证。

## 1. 比较了哪些分组

基仍由公开 \(A_k^HA_k=V_k\Lambda_kV_k^H\) 决定，模式按特征值升序排列。每用户分别采用1、2、4、8、16个连续等长组，另保留当前全局标量作为对照。还预先固定一个4组成员对照，按零起始编号分为：

\[
\{0,7,8,15\},\quad\{1,6,9,14\},\quad
\{2,5,10,13\},\quad\{3,4,11,12\}.
\]

这里简称“对折4组”，只描述编号分组操作，不是新具名算法。相同组的模式在天线×输出行的256坐标上重复同一精度。特征值排序不保证等于实际响应 \(h_i\) 排序；对折也不保证实际灵敏度完全均衡。

分组操作对应 [GEC §II-A式(6)–(9)、Algorithm 1](https://arxiv.org/pdf/1602.07795v2) 的 block uniform diagonalization，以及 [D-GEC §III-A式(31)、(34)、Algorithm 2](https://arxiv.org/html/2206.05049v2#S3.SS1) 的组迹投影。当前AFDM分组是项目候选，不是上述论文已验证的选择。

所有分支使用相同公开观测、冻结的观测噪声估计、零初始均值及初始方差 \(\nu=\rho\times1.0004404181394917\)。未使用输入文件的旧噪声字段。

## 3. 为什么粗组能降误差，却不能免费获得单位响应

令 \(B=[A_1V_1,\ldots,A_KV_K]\)，在固定参数工作模型下定义

\[
S=\widehat\sigma^2I+\nu BB^H,\qquad
J=\nu B^HS^{-1}B,\qquad h_i=J_{ii},\qquad
f=\nu B^HS^{-1}Y.
\]

组 \(g\) 的平均 \(h_g=|g|^{-1}\sum_{i\in g}h_i\)。首轮GEC外信息为

\[
r_i^{(g)}=\frac{f_i}{h_g},\qquad
\tau_g=\nu\frac{1-h_g}{h_g}.
\tag{1}
\]

它对自身输入模式的系数为

\[
a_i=\frac{h_i}{h_g}.
\tag{2}
\]

组内 \(a_i\) 平均为1，并不意味着每个模式都是1。本轮全用户连续4组在−4 dB下，每用户最小/最大 \(a_i\) 的中位数分别约0.0533/2.2871；16组才使所有自身系数为1，且其他模式和用户的耦合仍未自动消失。

在辅助模型 \(x\sim\mathcal{CN}(0,\nu I)\)、\(n\sim\mathcal{CN}(0,\widehat\sigma^2I)\) 且独立、线性系数固定时，实际误差的对角元为

\[
\mathbb E|r_i^{(g)}-x_i|^2
=\nu\left(1-\frac{2h_i}{h_g}+\frac{h_i}{h_g^2}\right).
\tag{3}
\]

组平均恰为 \(\tau_g\)，但单个模式一般不是 \(\tau_g\)。这解释了为何“每组平均功率正确”可以和严重的模式失配同时出现。真实噪声估计依赖观测，真实信道也不满足该独立各向同性先验，式(3)只作冻结系数的工作模型恒等式，不能改称真实无条件误差定律。

更直接的是，对式(1)逐模式恢复自身单位系数：

\[
\frac{r_i^{(g)}}{a_i}
=\frac{f_i/h_g}{h_i/h_g}
=\frac{f_i}{h_i}
=r_i^{(16)}.
\tag{4}
\]

这在实际计算的全部2000条件、7分支中，最大相对误差为 **\(3.39\times10^{-16}\)**。因此，先粗分组再做这种单位响应校正，会精确回到细分消息，噪声放大也回来。式(4)依然不保证完整自身用户响应矩阵为单位阵。

保持同一 \(\nu,S,h\)，对**嵌套**分区按模式数加权，由 \(1/h\) 的凸性可知平均 \(\tau\) 随细化不降。当前全局→每用户1→2→4→8→16组符合该条件；对折4组与连续4组不满足嵌套关系，不能套用排序。

另有 \(r^{(g)}=D_g^{-1}D_{\rm scalar}r^{\rm scalar}\)。保留正缩放矩阵及公开坐标元数据时，首轮query可相互恢复。因而原始MSE代价不等于信息损失；同样，信息等价也不保证冻结网络、有限容量网络或未完整提供元数据的网络具有相同表现。

独立推导与原文定位见 [代数复核](../../../reference/reviews/stmp_message_awgn_review_20261024/notes/covariance_grouping_algebra.md)。

## 5. 当前研究决策

**不把“改成2组或4组”直接作为修复方案，也不把对折4组当作胜出者。** 这些分组展示的是原始误差和模式响应之间的交换关系，天线结构则几乎没有被解决。

下一步应先把增益与误差协方差分开建模。可从公开可计算的完整自身用户响应 \(G_{kk}=D_k^{-1}J_{kk}\) 出发，分析

\[
r_k=G_{kk}x_k+\xi_k,
\]

其中 \(\xi_k\) 含其他用户贡献和测量噪声。不能只使用式(2)的对角系数替代完整 \(G_{kk}\)，也不能未经检验就假定 \(\xi_k\) 是与信号独立的Gaussian。天线方向协方差需要同步检查。含矩阵增益的消息表达可参考既有OAMP-MMV文献的Gram–Schmidt模型，但这是当前AFDM问题的新适配，不直接获得其理论保证。

这意味着暂时应把研究对象写成**消息增益与 C 的联合描述**，而不是只扩展 C 的维度。如果仍坚持训练输入严格为“真实信道＋Gaussian噪声”，必须先找到能在实际迭代中实现这一近似、且不产生过大噪声代价的完整消息更新；本轮七种首轮分组还未给出这样的证据。现有干净信道数据继续保留，新训练噪声及网络条件接口暂不冻结。
