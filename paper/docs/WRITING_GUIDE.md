## 出处应当核到什么程度

| 要确认的内容 | 需要的证据 | 不能据此推出什么 |
|---|---|---|
| 单词或词形有先例 | 参考论文或已确认摘要、引言中的实际用例 | 不能推出任意组合后的短语或句子也有先例。 |
| 专业术语有出处 | 完整名称、对应技术含义、章节或公式位置 | 同时找到 UPA 和 response，不能证明 UPA response 是原文名称。 |
| 完整搭配有出处 | 连续表达及其原语境；必要时注明单复数、连字符变化 | 不能把从几篇文章各取一段短语的拼接登记为完整原句。 |
| 句子依据原文修改 | 原句及相邻语句、本文改后句、必要替换、条件对应 | 只有 denote 或 can be expressed 相同，不足以认定整句是最小替换。 |
| 段落依据原文修改 | 原段的任务、句序及各句之间的关系 | 一串分别有出处的句子，不一定保留了任何一篇原文的段落组织。 |
| 技术陈述有依据 | 同一建模对象下的假设、公式、推导或实验 | 原句描述消息独立，不能证明本文的信道与活动变量独立。 |

出处记录应明确写成“原句仅作必要替换”“采用原搭配”“借用句式，技术条件为本文假设”或“本文推导，相关术语有出处”。这些是写作记录中的说明，不是需要加入正文的技术名称。

本文自己的波形、跨帧关系、矩阵排列和估计条件应保留真实归属。参考论文提供了句式或相关技术依据时，应准确记录所支持的部分；不得为了满足形式上的逐句对应，把本文公式说成参考论文的原式，也不据此自动认定本文公式具有原创性。

## 第二章已经暴露的具体问题

### 把分散的词拼成一个未经核实的名称

旧稿使用 UPA response，却没有核得该完整搭配。上一轮词形检查能够匹配 UPA 和 response，但无法证明组合成立。修正后的 array response vector 有 Li §II-B、PDF p.3 式(2)后的直接依据；p.4 的阵列响应段也提供了相应的公式引出句。

后续章节遇到复合名称时，应核对完整搭配和含义。已经批准的本文模块名称依批准记录使用；不要因普通词各有出处，就把新组合登记为已有方法名称。

### 把不同性质的定义硬并在一起

旧句把 a_k、t_c、δ(·) 放进同一个 The notations … denote … respectively 句，分别解释阵列向量、时间和函数。这个完整句子是拼接结果；Shen 的运算符说明不能为整个改后句提供原句依据。

修正时，将物理信道式中的路径数、增益和 Dirac 函数放到式后的解释中，将时间原点作为本文约定说明，再在阵列段引出 a_k。判断依据是读者需要在何处理解哪个对象，不是句子中有几个符号。相关参数本来就共同解释一个公式时，where 从句中的并列定义仍然合适。

### 保留单句表面却丢失段落关系

旧稿连续重复 time-domain signal，却没有说清第二个式子是前一式的矩阵形式。Ding §II、PDF p.2 的原段从时域信号及其参数自然过渡到矩阵形式，关键衔接是：

> The signal in (1) can be represented in matrix form as

代入本文式号即可说明下一式与上一式的关系。不能只从两篇文献各选一句“信号给定为”，再认为两句都合格就完成了段落修订。

### 用通用句型掩盖对应关系过弱

旧对照曾以运算符定义句为母本，替代阵元间距定义；也曾用消息关于列索引的独立性句，解释本文关于设备的先验独立性。这些至多提供部分句式依据，不能登记为同一技术陈述。

后续核对时，应比较句子的主语、操作、对象、条件与结论。大部分实质内容都被替换后，即使保留了几个功能词，也不能继续称为原句的最小合理替换。优先寻找技术任务更接近的原段；本文特有定义则如实登记必要适配。

已实施修改见[定义句与衔接修正](https://github.com/RESET-cpu/afdm-gfra/blob/9ac940e477d9f2a81ff687c85ba488f5a106f88b/paper/checks/ch2_natural_expression_20261101/REVISION_NOTES.md)和逐行差异（仅本地历史资料：`paper/checks/ch2_natural_expression_20261101/CHANGES.diff`）。早期逐句对照保留为历史证据，其中被撤回的出处归类不能继续用作通过依据。

## 术语和语法表达分别怎样检查

**术语保持一致。** 同一技术对象采用已确认的名称。不要为了变化，在 array response vector、steering vector 和其他名称之间轮换；是否可替换取决于本文定义和原文含义。新增缩写、方法名和复合修饰语必须核实完整表达，必要时用现有术语和公式直接说明操作。

**动词必须与对象和作用相符。** 定义符号、给出等价形式、由条件推导结果、通过实验观察现象，是不同的句子任务。选用原文的动词时，要连同它连接的对象和证据一起核对。不得为了避免重复，把 denotes、represents、defines 随意轮换，也不得把观察或近似改写成证明或精确等价。

**形容词和程度词保留原有论断强度。** approximate、significant、severe 等词应具有适用于本文的条件或证据。删改其中一个词可能改变结论，不能仅按语言偏好处理。原文形容某一设置的结果，并不自动授权将相同修饰语用于本稿其他设置。

**连接词承担实际关系。** 因果、转折、补充、特例和步骤推进应与前后内容对应。来自原文的连接词，移到新段落后也要重新检查。不要通过给每句话加 Then、Moreover 或 Specifically 来制造连贯感；也不要把这些词一律删除。有用的承接应保留。

**定义放在首次需要它的位置。** 辅助变量通常紧跟其解释的公式；重要未知量应在读者需要理解目标时出现；推断中的固定条件应与相应推断表达关联。避免提前集中报完所有变量，然后在后文再次解释同一对象。

**重复是否有问题取决于上下文。** 数学论文中反复使用 where、let、denote 很常见。检查的是重复是否造成停顿、冗余、对象混淆或逻辑中断，不设置词频上限，不把换词数量当成改进指标。

## 每一轮修订的执行顺序

1. **确定段落任务。** 用一句中文说明这一段要让读者理解什么，以及它怎样接到下一段。先锁定符号、维度、假设、条件、估计目标和论断强度。
2. **找任务相近的母本。** 优先查 Shen、Cai，结合内容使用 Xu、Ding、Wei；已有参考文献中更贴切的阵列、波形等专业说明也可采用。按适用性选取，不要求每篇文章分配固定份额。
3. **读完整原段及相邻内容。** 核对版本、章节、页码和公式。来源只有短语时，不能补写成“原文整句”；未读到的原段不作为依据。
4. **只作必要适配。** 先替换符号、维度和技术对象，再逐项检查条件。OFDM→AFDM、CP→CPP、DFT→DAFT 等替换必须与本文公式相符；不能顺带带入母本的同步、整数时延、块衰落或逐元素先验假设。
5. **连续读改后段落。** 检查相邻句是否重复启动，代词能否唯一对应，长定义是否打断主线，连接词是否仍然成立。暂时略过公式读文字，应当仍能看出定义、变换和推导的顺序。
6. **分别核对出处与技术含义。** 逐句记录真实对应；对本文假设、本文推导和文献原结论分别归类。核对“完整信道先验”和“设备活动稀疏”等不同层次，避免在改词时混淆。
7. **检查真实差异并交付。** 保存修改前文本，只改授权范围。检查公式、条件、引用和排版；说明改了哪些内容及仍待解决的问题。旧对照在正文变化后应标为历史版本或补充更正，不能继续声称对应当前正文。

原文中的笔误、不适用于本文的条件或不自然语法，不应因“原句最小替换”而机械复制。修正这些问题需要记录具体原因。对本文必要的数学条件，保留其作用；对没有影响模型、结论或读者理解的潜在质疑，不添加防御性解释。
