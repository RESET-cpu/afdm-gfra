# 新边缘似然初始化之后的相位更新：分析与待验证方案

状态：仅分析和推导；未改算法，未运行新的接收机推断，未恢复1000场景实验。

## 已有证据及其边界

依据 `result/candidates/c_stmp_phase_init_marginal_20261104/INTERPRETATION.md`、`DIAGNOSTICS.json` 与当前源代码：

- 20个已观察诊断输入全部零活动错误；10个旧漏检用户均在第一次相位更新前恢复。
- 这10个用户从新初始化到最终输出的相位RMSE：4个降低、5个升高、1个不变。例如235/6 dB的用户28为0.035458→0.300683 rad；235/4 dB同一用户为0.078981→0.191177 rad；397/4 dB用户35为0.100580→0.181456 rad。这是使用真值的事后诊断，不是可用于运行时选择输出的指标，也不等于整体AER或NMSE退化。
- 当前候选已无固定周期。固定相位运行原接收机至其条件停止检查通过，才提出共同斜率更新；消息历史连续。
- 当前相位步已经使用固定Gaussian外信息重新条件化得到的完整跨用户投影协方差，不是只用信道点估计消干扰。
- 当前每个用户通过多项式驻点比较求解整个相位周期内的单坐标目标；停止量是预期预测变化相对信号与噪声总能量的平方根，容差0.01。

证据尚不能区分后续更新的收益与初始化收益。首要对照应为：同一新初始化、同一已知相位接收机和停止规则，固定初始化相位至结束。不能拿旧初始化的前端结果替代此消融。

## 概率模型不能混同

初始化采用每用户一条物理路径和零均值随机增益；后续相位步采用有效信道的非零均值Gaussian外信息。两者都积分掉声明模型中的未知信道/增益，但不是同一个先验或同一个全程目标。

后续固定Gaussian消息为x~CN(m,V)，线性观测为y=A(beta)x+n时，可写其局部边缘目标

`L_t(beta)=log det C_t(beta)+r_t(beta)^H C_t(beta)^(-1) r_t(beta)`，

`C_t=Sigma_n+A(beta)V_t A(beta)^H`，`r_t=y-A(beta)m_t`。

固定消息、在旧beta下计算条件后验，再降低该后验的期望残差目标，可使这个固定消息模型的边缘目标不增。下一轮神经消息改变m,V后，目标也随之改变；不能据此声称全程物理似然、AER或NMSE单调。

不建议把初始化的增益方差直接当成后续信道方差或相位正则强度。参数所在空间、维度和模型不同；从同一Y得到的相位初值也不是独立先验。

## 可测试的最小修改：当前条件矩下局部降低相位目标

保留每用户一个共同斜率 `phi[q,k]=exp(j*q*beta[k])`，参考帧q=0固定。固定当前Gaussian条件矩后，沿用现有

`F(beta)=sum_q [phi_q^H G_q phi_q-2 Re(phi_q^H b_q)]`。

G包含用户间条件协方差。逐用户更新、其余beta固定，定义

`c[q,k]=b[q,k]-sum_{j!=k} G[q,k,j]*phi[q,j]`，

`f_k(beta_k)=-2 Re sum_q c[q,k]*exp(-j*q*beta_k)`。

其导数及全局曲率上界为

`g_k=-2 sum_q q*Im(c[q,k]*exp(-j*q*beta_k))`，

`f_k''(beta_k)=2 sum_q q^2*Re(c[q,k]*exp(-j*q*beta_k))`，

`L_k=2 sum_q q^2*abs(c[q,k]) >= abs(f_k''(beta_k))`。

若L_k>0，取 `delta_k=-g_k/L_k`，然后将beta_k+delta_k按2π折回；L_k=0时保持旧值。由二次上界：

`f_k(beta_k+delta_k) <= f_k(beta_k)+g_k*delta_k+L_k*delta_k^2/2 = f_k(beta_k)-g_k^2/(2L_k)`。

因此逐坐标更新可保证固定条件期望不增，不用全周期求根，也不需要给相位步指定一个固定阻尼系数。原接收机消息阻尼仍保留。实际实现仍应核对目标差，防止舍入问题。

这个局部步不是新命名算法，是二次上界最小化对本项目相位目标的适配；与 `PHASE_EM_20261103.md` §3 的曲率上界思想相关，但这里是逐坐标、使用当前完整Gaussian条件矩。早先零初始化和独立用户工作分布下的失败不构成该组合的实验结果。

局部更新可能较保守；更便宜的单步不等于更低总运行时间。局部步也可能停在不良驻点，不能保证修复坏初始化或阻止模型偏差造成的相位漂移。只有对同一输入比较AER、NMSE和总时间后才能判断其价值。

## 调度及停止

保留当前外层相位、内层条件推断的结构，不恢复“每N轮”或“神经消息每轮必更新相位”。先按已知相位算法的既有规则稳定条件推断，再固定其工作分布做局部相位优化，最后以连续消息继续推断。

当前停止量平方为 `eta^2=E||[A(beta_new)-A(beta)]x||^2/(E||A(beta)x||^2+E||n||^2)`。因此固定eta容差对应的相位扰动/噪声能量比上限随信号能量增加。可另考察

`rho=E||[A(beta_new)-A(beta)]x||^2/E||n||^2`。

rho表示本次候选更新引起的预期观测变化相对估计噪声能量，不是真实剩余相位误差，也不是置信区间。可用它解释精度要求，但不能只因单个保守局部步的rho很小就停止；需同时检查固定目标的归一化梯度和优化进展。阈值仍是预先指定的数值精度要求，不存在由上述公式自动推得的普适最优常数。更严格停止不能消除工作模型偏差。

建议依次比较：A新初始化后固定相位，B新初始化加当前更新，C新初始化加局部更新。先隔离更新器影响，再单独对照停止尺度；不要同时改变初始化、条件矩、调度、停止和网络。历史失败输入只作诊断，推广结论还需独立场景及完整SNR范围。此处仅建议，未启动这些实验。
