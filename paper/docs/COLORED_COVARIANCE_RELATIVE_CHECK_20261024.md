# 有色协方差是否比标量白噪声更合理

## Material Passport

- origin_skill：academic-research-suite / experiment-agent。
- origin_mode：validate；Verification Status：ANALYZED。数值实现检查为 PASS。
- 材料：24个已有场景、48个−4/0 dB查询条件；12个均匀抽样与12个失败富集场景分开。检查第1、20及最终轮，共5760条用户阶段记录。
- 本次只重新分析已保存查询，没有生成新的物理MC场景、运行网络、训练或接收机。因此不是新的正式1000场景性能实验。

## 决策

**按用户要求的“比当前白噪声近似更合理，而非精确匹配误差分布”标准，现有 C=v R_a⊗I⊗R_c 已有足够的探索性依据继续做独立去噪试验。保留 rank=4、强度上限0.5，不为了追求零剩余相关继续扩张模型。**

这次检查支持的是该族在明确拟合规则下对实际误差的相对描述能力；没有检验训练后的去噪效果或活动检测性能，也没有证明随机采样协方差的频率与实际迭代完全匹配。

## 对照如何避免只在拟合数据上变好

每用户误差张量为 e=r−x，形状16天线×16输出行×16输入列。分别用偶数输出行估计，奇数行评分，再交换；两折先在用户内平均，再对每个场景内用户平均，最后场景等权汇总。

三个对照为：

1. 当前保存的标量方差，C=τI。
2. 仅在拟合行重新估计功率的标量模型，C=vI。
3. 同样使用拟合行功率v，加上当前候选的归一化协方差因子。

**主对照为3相对2**：两者都用真值误差拟合功率，避免把标签功率校准误当作协方差形状改善。当前标签结果也完整保存，但不把它与oracle条件混为一谈。两个模型都保持零均值，不另拟合高维均值。

因子估计直接使用拟合行的天线和输入列二阶矩，trace归一到16；保留最大4个特征值，将剩余12个替换为均值；需要时整体向单位阵收缩，使最小特征值至少0.5。这样得到的因子属于当前rank4加单位矩阵、alpha≤0.5的族。这个简单规则不是最优联合拟合，也不称为已识别的中心条件协方差。

评分使用未参与拟合行的复Gaussian负对数密度，略去所有模型共有的logπ，每个复坐标归一：

\[
\ell=\log v+\frac{\log\det R_a+\log\det R_c}{16}
+\frac{1}{d}\,e^H(vR_a\otimes I\otimes R_c)^{-1}e.
\]

这只是检验工作协方差的评分，不宣称实际误差服从Gaussian。输出行共享结构，不是独立实验样本；偶奇行划分属于同一消息内部的预测检查，不能冒充新场景测试。对真值的使用仅限离线诊断，当前还没有新增可部署的C估计器。

## 结果

以下为均匀抽样组的活跃用户，先按场景平均。Δ为有色模型减去同样重新拟合功率的白噪声模型，负数表示更好，单位为每复坐标自然对数。

| 测量SNR | 阶段 | 平均Δ | 分数改善的场景 |
|---|---|---:|---:|
| −4 dB | 第1轮 | −0.2970 | 12/12 |
| −4 dB | 第20轮 | −0.1989 | 12/12 |
| −4 dB | 最终轮 | −0.1379 | 12/12 |
| 0 dB | 第1轮 | −0.5504 | 12/12 |
| 0 dB | 第20轮 | −0.2816 | 12/12 |
| 0 dB | 最终轮 | −0.1385 | 12/12 |

失败富集组以及非活跃用户也全部保留；在组别×SNR×阶段×活动的24个分层中，每层均为12/12个场景的平均评分改善。各分层重复使用相同场景，不能当作288个独立成功试验，也不据此给总体成功率或显著性结论。

相同评分行上的白化后二阶矩非对角能量占比也有变化。均匀组活跃用户的首轮天线指标，−4 dB从0.5266降到0.2096，0 dB从0.7531降到0.2069；输入列分别从0.5079降到0.4308、0.5449降到0.4377。

**不利结果没有省略：** −4 dB最终轮的天线指标从0.1649升到0.2031，0 dB也从0.1656升到0.2032。中间轮若干天线指标同样略升。输入列指标在这些阶段仍下降，整体评分仍改善。因此只能说整体工作近似更贴近这些误差，不能说所有轴、所有指标都改善，或误差已经白化。

alpha上限在不少查询上会触及：均匀组活跃用户首轮天线与输入列拟合分别约50%、85%的折次达到0.5。此处只记录限制，不因为这点立即扩大范围；当前受限族已达到本轮的相对改善目标。实际训练采样频率的选择仍是后续开发问题。

## 数值与解释核查

- 256维非实协方差的密集矩阵计算与张量计算的二次型、归一化logdet一致，误差小于1e-12。
- 独立合成检查使用每种256个噪声张量，不是物理MC场景：纯白噪声上，有色拟合相对标量拟合的平均Δ=+0.06522；来自当前有色族的噪声上，平均Δ=−0.13060。说明评分流程并不会因多拟合了参数就必然偏向有色模型。这些合成参考未用于改变原始查询结果或采样配置。
- 全部5760条用户阶段记录有限、保留完整；48条件均完成，主检查约9.7秒，仅CPU。
- 主线绑定、接收机、训练候选代码与配置哈希均保持不变。本轮不以“近似要完美”为理由阻塞后续去噪试验，也不将这一诊断直接写成网络性能提升。
