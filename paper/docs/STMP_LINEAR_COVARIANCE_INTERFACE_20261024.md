## 判断

**已有线性模块可以给出一个无需真值、保留输入列相关性的 C 起点。现有接口没有返回它，但计算所需的 SVD 已经缓存。** 可以保持现有查询 r 完全不变，只增加协方差输出；无需再次采用此前会显著放大查询误差的逐模式归一化。

当前冻结配置的反馈是各向同性。按它现有的辅助高斯误差模型，未阻尼原查询的每用户协方差恰可写为 `I_antenna ⊗ I_output ⊗ E_k`。因此可取 `v_k=tr(E_k)/16`、`Ra=I`、`Rc=E_k/v_k`。它提供了输入列结构，但不会凭空生成实际查询中存在的天线相关性。

原始 Rc 不属于当前训练的 rank-4 加单位阵、强度≤0.5 族。简单保留最大四个特征值、合并剩余特征值并在需要时向单位阵收缩后，可得到合法的训练条件。48 个已有首轮条件的矩阵近似检查支持进一步测试这个做法；它不是实际误差校准或检测改善的证据。

## 未阻尼查询的协方差推导

以下为对项目现有公式的独立代数展开。L=用户数×输入列数，当前 L=640。固定 A、噪声方差 σ² 和传入协方差 P。对 P 的一天线特征方向，其特征值为 c>0，令

```
W = c A^H (σ²I + c A A^H)^(-1)
G = W A = V diag(d) V^H
d_l = c s_l² / (σ² + c s_l²)
α = tr(G)/L
r = m + W(y-Am)/α
```

这正是当前 `SpatialLinear.update` 的查询，未改变其全局平均响应归一化。令 `η=m-x`，假设 `Cov(η)=cI`、`Cov(n)=σ²I`、二者不相关，并将所有线性系数视为固定。则

```
r-x = (I-G/α)η + Wn/α
E = c(I-G/α)(I-G/α)^H + σ² W W^H/α²
  = c[I + (α^(-2)-2α^(-1))G]
```

最后一步使用 `cG²+σ²WW^H=cG`。每用户所需的输入列块为

```
E_k = c[I_16 + (α^(-2)-2α^(-1)) V_k diag(d) V_k^H]
```

`V_k` 是全局 V 中属于用户 k 的 16 行，因此无需构造 640×640 完整矩阵。全局平均恰好满足

```
mean_k tr(E_k)/16 = c(1-α)/α
```

右边就是旧代码的标量 cavity。**旧方差是该辅助模型下的平均量，不代表每个输入方向都具有相同误差方差。** 也不能把线性后验协方差 `c(I-G)` 或单独的 `σ²WW^H/α²` 当作当前查询的完整误差协方差。

若 P 为非各向同性矩阵 `U diag(c_j) U^H`，还假设不同用户、输入列及输出行的误差天线向量之间不相关，各天线向量的协方差均为 P，观测噪声跨这些坐标独立。于是天线特征模间也无误差互协方差。同理对每个 j 算 `E_k,j`，得到

```
C_k = sum_j (u_j u_j^H) ⊗ I_output ⊗ E_k,j
```

这是多个 Kronecker 乘积的和，通常不等于单一 `v Ra⊗I⊗Rc`。但当前各向同性配置使所有 `E_k,j` 相同，所以确实退化为 `I⊗I⊗E_k`。实际协方差计算复杂度主要是小矩阵乘法，不需新的高维求逆；本次没有测量完整接收机运行开销。

## 与当前训练族的匹配检查

从保存的 48 个公开观测重新计算原有 observation-only 噪声估计，按原初始化与尺度计算首轮。首轮没有旧查询参与阻尼，因此可以直接核对原查询。

- 原查询最大相对复现误差：`1.96e-15`。
- 小尺寸、非各向同性 P、复数 A 的独立稠密误差传播与每用户谱公式，最大块协方差相对误差：`8.54e-16`。
- 对新协方差求平均与现有 cavity 一致；各用户平均功率与旧 pooled 方差的比值约在 `0.984–1.019`，主要新增的是方向信息。
- 全部 1920 个用户条件的原始 Rc 均不属于当前训练族。其最小特征值中位数为 `0.0106/0.0160`，训练族要求至少 0.5。这里不能忽略谱失配。

采用明确的简单投影：Rc 特征值排序后，保留最大四个，其余十二个用均值 b 代替，保持 trace=16；若 b<0.5，再将矩阵沿 `I+t(R-I)` 收缩到 b=0.5。这样得到 `(1-a)I + rank-4 PSD`、a≤0.5，可用当前网络接收，不需为表示这个投影另改网络。

| 已有条件 SNR | 单位阵近似 Rc 的相对 Frobenius 误差中位数 | 上述训练族投影误差中位数 | 合并十二个方向后的所需 a 中位数 |
|---|---:|---:|---:|
| −4 dB | 0.6869 | 0.3016 | 0.4675 |
| 0 dB | 0.6841 | 0.3014 | 0.4637 |

这些数字仅比较**对辅助模型矩阵本身的近似**，不是真实信道 NMSE、误差分布拟合分数或活跃检测结果。1920 个用户条件也不是1920个独立场景。数据包括先前均匀与失败富集组，未依据活动标签筛选；脚本未读取真值。原始用户记录和分组标记完整保留于 `RECORDS.json`。

## 尚不能由线性模块单独解决的部分

1. **阻尼。** 当前实际去噪输入为 `r_t=(1-δ)r_old+δr_new`。其误差协方差为 `(1-δ)²C_old+δ²C_new+δ(1-δ)(C_cross+C_cross^H)`，跨轮项未知。代码对协方差使用线性插值，这是 Gaussian 消息参数的阻尼规则，不是上述误差传播恒等式。可以先沿用相同插值形成工作条件，但必须标明近似；不能假设重复使用观测的两轮误差独立。
2. **真实信号结构和独立性。** 当前 P=cI 的辅助模型忽略实际天线及信道结构。即使首轮 x 本身满足独立 Gaussian 先验，也一般有 `Cov(r-x,x)=c(G/α-I)`，全局 trace 为零并不使该矩阵为零。因此这个 C 不能把现有查询自动变成“真信道加独立高斯噪声”。更后面的 m、噪声估计和相位都依赖观测，固定系数假设也是近似。
3. **闭环配套。** 本次只解决当前线性模块能否提供 C 的来源。新均值对应的反馈方差、活动网络与其条件，以及模型验证仍需独立完成。

## 建议的最小下一步

保留现有线性求解、查询均值和全局归一化，先为其增加每用户输入列协方差输出；使用 `Ra=I`，将 Rc 投影到既有训练族。对于阻尼先明确采用与原消息参数一致的插值近似，并用已有查询做分阶段诊断，再决定是否需要更复杂的空间反馈或跨轮处理。当前结果没有要求立即修改正在运行的训练，也没有完成接收机接入。
