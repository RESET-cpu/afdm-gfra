## 相位与高斯反馈

完成线性更新、三网络去噪、活动混合矩及外信息阻尼后，取实际反馈均值 `out` 和公共各向同性协方差 `out_v`。
设归一化尺度为 s，物理消息均值为 s·out，方差为 s²·tr(out_v)/M。活动概率已进入联合信道矩，
不再重复乘权或按当前活动判决排除用户。

普通细化复用十层展开的固定高斯消息相位求解器，保留完整跨用户投影条件协方差，并降低其条件期望二次型。
推导与出处见[相位公式](PHASE_MESSAGE_GEM.md)及[术语依据](TERMINOLOGY.md)：
GPML §2.1.1 式(2.6)–(2.8)、Shen §III-C 式(48)–(53)、Dempster等 §3、印刷p.7。

对固定消息 X∼CN(μ,γI)，模型 Y=A(β)R(θ)X+N 可写为 Y=A(β)H+N，H∼CN(R(θ)μ,γI)。
因此，返回的常数旋转只吸收入**实际反馈消息**均值，标量方差保持不变，首帧物理相位仍为1。
旧线性查询由旧观测算子和消息共同计算，不能依据这一等价关系同时旋转并继续沿用原方差混合。
当前实现重建相位算子，下一轮重新生成配套查询均值和方差，跳过一次旧查询阻尼，随后恢复0.2新消息权重。
反馈阻尼保留；停止窗口重置；最后一次更新后至少进行10轮条件更新，保证返回的信道与相位对应。

同状态对照已证实旧缓存处理的问题：相同相位解之后的20轮，旧处理最多31/40个检测错误，
仅旋转反馈最多1个，再重新生成匹配查询后0个。公式、能量核对和原始数据见
[查询失配诊断](../../archive/result_legacy_20261023/candidates/stmp_phase_refresh_20261023/METHOD.md)。
这是一例受控对照，不代替全部场景的性能验证。

## 活动概率与相位候选

为使当前漏检用户仍有恢复机会，检查全部用户。固定其他用户实际高斯反馈，在归一化单位下构造

    z_k = Y - sum_{j != k} A_j u_j
    C_-k = n I + c sum_{j != k} A_j A_j^H.

训练二阶矩产生相位方向函数的正值驻点，与当前相位共同组成候选。使用训练平均功率 gamma，逐候选计算

    C = C_-k + gamma A_k A_k^H
    f = gamma tr(A_k^H C^-1 A_k) / N
    r = gamma A_k^H C^-1 z_k / f
    v = gamma (1-f) / f.

高斯条件均值精确，协方差的标量迹投影近似。原有三个网络使用同一查询(r,v)，活动分类器经训练先验修正得到对数密度比ell。
候选须达到已有0.5活动判决阈值，且概率增量超过已有0.001容差；跨用户按log(1−rho+rho·exp(ell))增量排序，
每次最多替换一个用户相位。筛选的是**候选相位的概率**，没有用当前判决提前排除用户。

这一操作是局部分类器证据近似，不是完整观测似然或已证明的广义EM步，记录中与普通高斯细化分开。
候选替换后至少完成一次普通细化，才允许满足停止条件。
详细操作、公式核对与开发失败依据见[候选说明](../../archive/result_legacy_20261023/candidates/stmp_phase_supported_hypotheses_20261023/METHOD.md)。

## 调度、停止与模式

从第20轮起每20轮检查一次；当前条件输出、活动决策及有效神经矩的窗口稳定后才更新相位。
这是检查时刻，不保证第20轮必然更新，也没有固定延迟到第60轮的规则。
停止仅比较满足更新条件的实际边界，检查物理信道和接收信号预测跨完整相位周期的变化，容差0.05，
要求一个稳定周期、10轮稳定活动决策和有效当前矩，并完成当次全部用户候选检查。
存在合格候选或最近候选尚未普通细化时，不允许停止。

两项周期变化量的精确定义为：

    delta_H = ||H_t - H_prev||_F / max(||H_t||_F, ||H_prev||_F, 1e-12)
    delta_Y = ||Yhat_t - Yhat_prev||_F / max(||Yhat_t||_F, ||Yhat_prev||_F, sqrt(E_noise), 1e-12).

E_noise为估计噪声方差乘观测的复数元素个数，使用与预测信号相同的归一化单位；prev是上一个实际合格更新边界。
两项均须严格小于0.05。当前条件窗口沿用信道/查询协方差0.005、活动概率0.001、连续5轮及10轮判决稳定要求，
不使用真值决定更新或停止。

未知相位最少80、最多600轮，不是强制在100轮返回。软概率、查询方差和消息残差继续记录；
不能把条件子迭代暂时稳定误当作整个相位循环收敛。已知相位绕过相位拟合和候选搜索，保留原条件接收机及最少150轮。
给定/估计噪声独立选择；估计模式忽略传入占位值。四种模式均由实际登记入口核验，见
[逐数组模式检查](../../archive/result_legacy_20261023/stmp_phase_integration_update_20261023/REGISTERED_MODES.json)。

## 已验证结果与限制

28个开发及不利输入的四种分组通过原定准确度条件。此后固定实现、权重和参数，
在20个未用于开发的物理场景、−6/0/6 dB下完成180次配对推断及4条600轮续算。
全部保存预测重新评分，逐轮活动错误、普通相位目标下降及实际停止条件均检查。

| 独立验证 | 原相位流程 | 当前修正 | 已知相位 |
|---|---:|---:|---:|
| 合并NMSE / dB | −8.718 | −9.242 | −9.951 |
| AER | 0.917% | 0.708% | 0.375% |
| 平均迭代 | 181.4 | 132.3 | 150.2 |
| 含初始化平均耗时 / s | 41.4 | 37.5 | 18.2 |

整体、分SNR、最差输入和检测错误数四项预设条件均通过。6 dB仍退化0.135 dB；
20个独立场景的配对区间不能证明总体NMSE或AER显著改善。计时包括各自实际初始化和全部额外候选查询，但GPU未隔离。

全部实际运行中，更新后10轮最大NMSE反弹由24.64降为1.50 dB。仍有低SNR反例，不能宣称反弹消失或活动检测逐轮单调。
场景1032/−6 dB更新后错误6→13，最终比原版多1个错误，600轮仍未收敛。
开发集严格“原六例100轮以后始终零错误”检查也保留为失败；允许独立测量的修订发生于新输入生成前。
四条预选续算在正常停止后无新增判错用户，最大NMSE回升0.1271 dB；它们不能覆盖全部困难输入。

固定高斯目标下降不能推出真实相位、NMSE或AER改善，也不能推出三个学习网络组成的整套迭代全局收敛。
采用判断和这些限制同时成立。全部不利输入、统计区间、完整曲线和计时分解见
[独立验证报告](../../archive/result_legacy_20261023/candidates/stmp_phase_supported_hypotheses_holdout_20261023/REPORT.md)。
本次没有重新训练；正式500场景仍停止，正式2000场景计划只准备与检查，没有执行。
