# 有色噪声一阶网络：结构是否需要更换

日期：2026-10-24。定向文献核读、作者代码核对与已有权重机制诊断；不是系统综述，也不是正式接收机性能实验。当前 200 轮训练继续作为原结构对照，本次未修改其代码、配置、权重或进程。

## 1. 结论

**建议修改现有网络对协方差的处理和输出参数化；现阶段没有充分依据直接更换整个 NCSN/RefineNet 主干，更没有依据指定 Transformer。**

先前的检查支持“这个 C 族比标量白噪声更能近似已有消息误差”，不等于证明“把 C 展平后压成 64 维条件，原 score 主干就能高效学会”。这是两个不同问题。当前有两个具体不足值得优先处理：协方差信息在进入 score 主干前被大幅压缩；低 SNR 下，通过 score 和较大的协方差恢复均值，对误差及相消精度比较敏感。

最有依据的第一候选是：**保留现有主干，用已知 C 显式完成矩阵输入预处理和线性均值分支，让网络预测剩余的非线性修正，输出条件均值；需要 score 时再按正确公式转换。** 这是一项待验证的项目设计，不是已完成训练的改进结果。

## 2. 当前结果实际说明了什么

同为第17轮，白噪声网络验证 DSM 为 0.101455，新网络为 0.393517。二者的采样分布和方向加权不同，不能把比值当作同任务的性能比，也不能单凭曲线归因于网络结构。

本次另外读取第20轮保存权重，使用64个不同开发场景，每个噪声区间16个信道，保持观测、噪声强度、真实协方差读出和评分不变，只改变送给 score 网络的矩阵条件。噪声强度是训练所用参考 SNR，不是接收机测量 SNR。各区间用总误差/总信号能量计算 NMSE：

| 参考噪声 SNR 区间 | 正确 C 条件 | 打乱 C 条件 | 单位矩阵条件 | 使用真实 C 的简单线性估计 |
|---|---:|---:|---:|---:|
| −20 到 −10 dB | 13.953 dB | 14.252 dB | 14.466 dB | −0.194 dB |
| −10 到 0 dB | 3.329 dB | 3.439 dB | 3.649 dB | −1.914 dB |
| 0 到 10 dB | −5.488 dB | −5.288 dB | −5.007 dB | −5.595 dB |
| 10 到 30 dB | −19.496 dB | −19.298 dB | −19.176 dB | −18.039 dB |

最后一列是 `(I+C)^−1 r`，假设归一化复信道协方差为 I。它使用了合成任务中已知的真实噪声 C，但 I **只是代理先验**，不是实际信道分布，也不是实际先验 MMSE 或性能下界。矩阵分解实现与256维密集求解的相对误差为 1.32e−15。

因此已有证据支持以下有限结论：

- 网络已经利用 C；不能说条件分支完全无效。正确条件的四档汇总误差都较小。
- 当前低 SNR 去噪仍有很大改进空间；不仅比简单线性估计差，也比恒零估计的0 dB差。不能把现状解释成有色噪声必然带来的不可消除误差。
- 高 SNR 区间网络好于这个代理线性参考，说明当前主干在这批输入上仍有有效去噪能力；收益可能来自更合适的二阶统计、线性滤波或非线性先验，尚不能由此区分。
- 只有每档16场景、一次固定置换，无显著性检验；打乱同时改变强度和方向。不能据此定位唯一原因、证明新结构优越，或声称活跃检测改善。

## 4. 我们现有结构的两个具体问题

### 4.1 条件入口确实存在信息压缩上限

当前 C 条件是 `log(v)/5` 与两个16×16 Hermitian因子的实、虚部，共1025个数，经过 `1025→64→64` 后共享给全部条件归一化层。其参数在空间位置上广播，完整矩阵没有直接作用于 score 主干的输入或特征。

1025包括冗余，不是1025个独立自由度。当前每个 rank4 PSD 矩阵的实维数为 `2×16×4−4²=112`；固定trace减一，再加入alpha增一，所以两因子在一般内部区域、固定v下共有224个自由度。一个连续64维条件不能在整个族上保持无损一一表示。**只扩大后端主干，无法自动恢复条件分支已丢失的信息。**

这一存在性限制不等于64维不能形成有用近似，也没有给出当前分布下的误差下界；观测本身还可提供统计信息。独立核查使用一般正定因子构造了相同条件、不同精确Gaussian score的数值反例，明确该具体反例不一定属于当前rank4采样族。见[结构核查](../../reference/reviews/colored_architecture_review_20261024/architecture_audit.md)。

现有RefineNet已含多尺度、扩张卷积和全局归一化，因此不能将它描述成只能看局部邻域、必然无法处理相关噪声。随机稠密输入列相关缺乏平移不变结构，交给共享卷积和全局调制间接学习可能不高效，这是尚待验证的判断。

### 4.2 输出参数化及误差权重值得优先处理

以下全部使用实打包变量，维数 `d=8192`，协方差 `Σ=real_embedding(C)/2`。当前

\[
\widehat h=r+\Sigma s_\theta,
\qquad
\mathcal L=\frac1d\|\Sigma^{1/2}s_\theta+\Sigma^{-1/2}(r-h)\|^2
=\frac1d\|\Sigma^{-1/2}(\widehat h-h)\|^2.
\]

因此DSM下降不等于普通均值MSE同比例下降。在高噪声或较大特征值方向上，同样的加权残差对应更大的均值误差。噪声主导、先验均值接近零时，score还需要近似实现 `−Σ⁻¹r`，才能抵消观测中的大噪声项。当前模型仅在网络外显式乘Σ，相关方向的逆作用仍主要交给网络学习。

这与EDM讨论的尺度和相消问题相吻合，是设计动机而非当前因果归因的证明。InstanceNorm++及`2x−1`输入映射的影响也核对过：前者有多条shortcut，不能说整网丢掉全部幅度；后者可逆且旧网络同样使用，不能直接认定为新旧差距原因。

## 5. 推荐的最小结构候选及正确训练目标

令 `τ²=1/2` 表示归一化复单位功率对应的实坐标代理方差。它是预条件的参考尺度，不把信道真实先验改成独立Gaussian。构造

\[
K=\tau^2(\tau^2I+\Sigma)^{-1},\quad
B=(\tau^2I+\Sigma)^{-1/2},\quad
O=\tau\,\Sigma^{1/2}(\tau^2I+\Sigma)^{-1/2}.
\]

用现有主干作为修正网络：

\[
\widehat h_\theta=Kr+O F_\theta(Br,\text{协方差条件}),\qquad
s_\theta=\Sigma^{-1}(\widehat h_\theta-r).
\]

K、B、O由已知C计算，不训练，也不经过64维条件压缩。即使网络输出零，仍保留一个明确的线性估计；低噪声时K趋近I，高噪声时K趋近0。网络负责信道先验超出这个代理线性估计的部分。与单纯加宽条件MLP相比，它直接处理了已知矩阵的作用；仍需检查剩余非线性修正是否需要更丰富的条件输入。

本项目的两个16×16因子可分别分解，然后对256个特征值乘积施加这些标量函数，并在16个输出行上复用。不需形成8192×8192实矩阵。`τ²I+Σ`一般不再是单个Kronecker积，但与Σ共享特征向量，不能错误地把它拆成两个相加的因子逆。

为了先判断参数化本身是否有益，第一项对照仍保留原目标 `||Σ^−1/2(hhat−h)||²/d`。设 `t=O^−1(h−Kr)`，其等价raw-network损失是 `(F−t)ᵀK(F−t)/d`，不是无权平方误差。若后来换用EDM风格的无权 `||F−t||²`，均值空间权重会变为 `Σ⁻¹+τ⁻²I`，需单列为损失变化。给定C的无限容量最优条件均值一致，不代表有限网络训练轨迹相同。

直接白化后套用原冻结白噪声网络不是等价修复，因为白化也改变了信道先验。把covariance矩阵随意当作与信道两个空间轴一一对应的图像通道也不成立。若使用corr+corr辅助噪声，它必须与实际污染噪声条件独立，不能把本次加到输入的epsilon直接提供给网络。

如果后续接收机利用去噪器的Jacobian推算不确定性，固定Σ时应对完整映射求导：`J_D=K+O J_F B`，不能只用主干的导数。这里仍未证明有限网络的Jacobian对应合法后验协方差，接收机适配须独立核查。

## 6. 决策顺序与当前工作状态

1. 保留本次200轮训练作原结构对照，并保存各SNR区间结果；不因看到低loss或当前曲线慢就切换冻结模型。
2. 下一项优先验证上述显式矩阵处理与均值参数化，继续使用同一5万干净信道、同一噪声族。结构改变后不能声称所有权重初始化仍逐位等同，应记录可复制的主干初始化与新分支初始化。
3. 若仍不能有效利用C，再对比更充分的确定性矩阵条件接口。corr+corr可作替代接口参照，但不是无损传递C的定理。
4. 在接口和参数化明确后，若原主干仍有可重复的差距，再比较DRUNet类残差U-Net；Transformer不作为默认首选。比较必须保持数据、目标及训练预算可解释，并报告推理成本。
5. 正式取舍依据同一噪声上的1000场景配对去噪、低SNR分层及最终接收机检测结果，不能靠跨噪声分布的训练loss直接决定。
