## 构建与核验

### Mac下载后检查

在已有仓库中更新 `main` 后，从仓库根目录运行：

```sh
python3 paper/TWC/checks/validate_manuscript.py
cd paper/TWC
latexmk -pdf main.tex
```

核验脚本需要NumPy；编译需要包含IEEEtran的LaTeX环境和latexmk，也可使用
`tectonic main.tex`。核验会读取同仓库的原稿及DCN快照，不需要下载训练权重或数据。
