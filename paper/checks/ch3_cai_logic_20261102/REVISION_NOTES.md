# 第三章：先落实与 Cai 对应的推导顺序

## 作者要求与本轮范围

作者要求以 Cai 第三章为参照，先落实论述逻辑，语言润色后置；随后明确指出密度比估计活跃概率应在后文出现。本轮仅重排与改写第三章，更新阅读 PDF、术语记录和稿件索引。摘要没有重新生成；第四、第五章的正文和公式没有修改。

本轮依据是 Cai et al., *Joint Activity Detection and Channel Estimation for Massive Connectivity: Where Message Passing Meets Score-Based Generative Priors*, arXiv:2506.00581v2（2026-02-07），第三章，PDF pp.5–8。已阅读该章及第二章末尾、第四章开头的衔接；原文与当前稿分别位于 `reference/literature/cai2026_stmp_v2.pdf` 和本轮 `before/`。在线核对：https://arxiv.org/html/2506.00581v2 。

沿用的是适用的推导顺序与标准数学关系。正文采用自有表述，开篇明确引用 Cai，不将新正文登记为蔡文原句的最小替换。

## 哪些内容不能只替换变量

1. Cai 的信道为 N×M，本文每设备为 M×N×N；相应总维数、观测矩阵和跨帧相位沿用本稿第二章。
2. Cai 的线性公式使用部分正交导频条件，本文保留原来的完整矩阵和迹平均。
3. Cai 在 III-B1 式(24)–(27)构造高斯信道外信息，并在 III-B2 用它计算近似活动概率。本文第三章继续用完整先验定义贝叶斯目标；第五章现有的高斯 site 表示服务具体迭代实现。本轮没有把 Cai 的高斯活动似然移入当前理论目标，也没有改变接收机算法。
4. 本文标量方差、空间协方差和裁剪规则保持现有定义；不移植 Cai 的逐天线方差或状态演化结论。

这些是模型和计算方式的对应范围，不是新增贡献主张。第四章的有色噪声训练、由均值导数获得方差、密度比学习均保留在原位置，本轮不改写。
