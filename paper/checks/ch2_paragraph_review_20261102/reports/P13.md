# P13 单段审查：多帧矩阵观测与设备块稀疏性

## 段落任务与结论

本段应把上一段的逐帧、逐天线与接收符号观测，组织成后续联合活动检测与信道估计使用的矩阵模型，并说明设备活动带来的块稀疏性及所考虑条件下的欠定性。

**矩阵维度、四个索引关系和设备块稀疏性均成立，未发现代数错误。** Cai 正式发表版 PDF p.4 的原段直接支持“紧凑矩阵观测→设备块稀疏→非活动设备对应零块”的组织，但不能作为本文 `Q×MN` 排列的原式出处。主要可改进处是：文字目前只把跨帧收集说成一种“更紧凑”的表示，没有明确点出各帧共同观测同一个 `X`，以及在跨帧模型成立、K/M/N 固定时，增加 Q 会增加观测行数而不增加 `X` 的尺寸。这个作用已在引言贡献中提出，第二章这里适合用一句数学对象明确的说明将其落实。

`Q<KN` 足以使把 `X` 视为自由矩阵的线性观测方程欠定，但它是本段新引入的参数范围，不能从前文导频行正交直接推出严格不等式。当前写法可被理解为在此规定工作条件，不构成已证实的错误；改为条件式或明确所考虑范围会更清楚。无需增加活动概率解释，也无需在本段引入接收算法或新实验。

## 数学、索引和条件的具体核验

1. 对 `q=0,…,Q−1`、`m=0,…,M−1`、`r=0,…,N−1`，复合列索引 `mN+r` 覆盖 `0,…,MN−1`；因此 Y 和 W 都为 Q×MN。对 `k=1,…,K`、`n=0,…,N−1`，复合行/导频列索引 `(k−1)N+n` 覆盖 `0,…,KN−1`；因此 A 为 Q×KN，X 为 KN×MN。
2. 矩阵乘积的 `(q,mN+r)` 元素为 `Σ_k Σ_n A_{qkn} X_{kmrn}`，与第 215 行相同。n 是被求和的发射符号索引，r 是保留在输出列的接收符号索引，没有错把 n/r 交换；不需要共轭。
3. X 中每个设备对应连续 N 行、全部 MN 列的块。其条目由同一个标量 α_k 乘 H_k 的全部 M N² 个条目得到。α_k=0 使整个块为零；这不要求 α_k=1 时 H_k 的内部条目稀疏，也不声称活动块必然处处非零。
4. 若 A 给定且 `Q<KN`，`rank(A)≤Q<KN`；每列线性方程的观测数少于其 KN 个自由坐标，因此通常意义的线性系统欠定。MN 列不能消除针对任意自由 X 的空空间，但块结构或信道先验可以限制解集。这与下一段采用贝叶斯先验不矛盾。
5. 前文 `PP^H=KE_p I_Q` 在非零导频能量下要求 `Q≤KN`，不能推出严格 `Q<KN`。本句应读作额外选定的范围，而非前文正交式的推论；也不需要从该范围进一步推导活动设备数阈值。
6. 前文 `H_k^(q)=exp(jqβ_k)H_k`、`A_{qkn}=P_{qkn}exp(jqβ_k)` 与块内活动不变共同使 X 不带 q 下标。保持 K/M/N 和该跨帧假设时，增添一帧会为 A、Y、W 各增添一行，X 的 KN×MN 尺寸不变。这里只是观测模型的尺寸/共享关系，不能据此无条件保证误差单调下降或允许任意增大 Q。

## 确证问题与最小修正方向

### P13-F1：多帧性质到估计用途的关系留在公式中，没有在本段说透

- 位置：221–240 行，连同前文 180–181 行的跨帧近似不变说明。
- 证据：本段先写 compact form，再列四个尺寸、四条索引，随后转到设备稀疏性与欠定性。未明确说明 Q 帧共同观测同一个 X。引言贡献第一点已经承诺“准静态性质提供更多 JADCE 观测”；Shen §II-B PDF pp.4–5 在有效信道近似不变之后立即交代更多观测的用途，§II-C p.5 式(15)后又将多帧收集与观测数连接。
- 影响：读者可以自行从 q 下标及维度推出来，但文字容易把多帧收集理解为记号压缩，错过本方案最应强调的结构。它是解释不足，不是缺少共享模型或需要重建公式。
- 严重性：中，写作与重点组织。
- 最小方向：在矩阵模型后补一句，或把当前 compact 引出句改得更有信息量，明确“这些帧共同用于估计同一个 X；在既有跨帧假设下，Q 增加的是观测行数，X 尺寸不变”。保留现有公式，不把 Shen 的 OTFS 数据检测、角域稀疏性或性能提升保证一并搬入。无需加新实验，也无需复述全部物理前提。

### P13-F2：严格不等式是新工作条件，应与已知维度区分

- 位置：245 行。
- 证据：第二章此前定义 Q、K、N 并要求导频行正交，未先声明 `Q<KN`；Wei 原文先明确 `M≪N_r` 的观测设置，再在问题段据此论述欠定性。
- 影响：当前 Since 句本身能够承担条件声明，因此不判为数学错误；但读者可能误认为严格不等式由前文导频约束自动得到。严格不等式的来源和作用可以更直接。
- 严重性：低，条件交代。
- 最小方向：将该句写成“对于 `Q<KN`，该线性观测问题欠定”的条件式，或在同句明确这是本文考虑的范围。无需另加“防御性”解释，也无需扩写对结构化信道的可辨识性讨论。

- 本段紧接单帧式，矩阵乘法又自然接到下一段按列写似然、按设备写先验的后验分解，位置合理。
- Cai 的两句块稀疏解释在本文保留了原有因果关系和句序，`Due to` 与 `Specifically` 都有实际作用；没有机械堆叠同义连接词。
- “X 的设备块稀疏”与下一段“对完整 H_k 不施加信道稀疏假设”已经分清。本段给出 α_kH_k，下一段直接指明 H_k，足以表达两种不同层级的稀疏性。无需再增加一整段免责声明，也不应删掉正确的 block-sparsity structure 来制造表面一致。
- Cai p.4 在式(4)前后用堆叠定义压缩排列说明，本文用元素式展开。**本文比 Cai 更细有实际理由**：H_k 有天线、接收符号、发射符号三维，n 与 r 的排列影响 AX 的正确性。至少 Y 与 X 的映射宜保留；W 同 Y，A 的排列又与前文 P 对应，可在版面紧张时压缩文字，但没有证据表明四行式本身应该移入附录。
- Shen p.5 式(14)后的元素、块矩阵和相位说明比本文更长，仍以服务后面的联合处理为目的；据此不能用“公式多”判本文过细。本文需要补的是一句用途，而非再加一种矩阵定义、MMV 名称解释或观测比名称。`eq:mmv` 只是内部标签，本轮未把它当成正文新增专业术语。
- Wei p.2 把“恢复对象→观测比/条件→欠定性→先验需要”连在一起。本文将先验任务放在下一段是合理分工；保留欠定性收尾即可，无需为了复制原段再加入 measurement consistency 等算法要求。
- Xu §II-C 式(16)在多接收天线、多时隙下以块矩阵写 `Y=H_eff X+N`，其中 X 是活动加权的发射数据。它可作“矩阵化服务后续检测”的对照，但未知量与本文信道 X 不同，不能作为本文 Q×MN 排列或共同信道维度的直接依据。
