# P04：多帧导频与矩阵（源稿第 63–74 行）

## 段落任务与结论

本段在 §II-B “Transmission Scheme” 开头定义导频资源、帧数、逐符号导频、每帧导频向量以及全局导频矩阵。下一段立即使用全局矩阵 P 给出约束，再下一段使用 p_qk 给出 IDAFT。因此，符号定义有实际后续用途，不能简单认定为多余罗列。

**逐句出处结论：6 个句子中 A=4、B=1、C=1、D=0。** 前三句主要对应 Cai 期刊版 §II-A 的资源与导频段；第五句对应 Wei v1 的已知导频句。第四句将 Cai 的对角导频矩阵构造改成本文向量构造，只能确认近似句式和相关术语；第六句是本文的全局矩阵排列定义。不能据此声称整段来自某一原段的最小替换，也没有发现必须改变这些数学定义的理由。

**论述结论：作为导频定义段，条理基本清楚、详略并不过量；作为本文新传输方案的小节起首，仍缺一个简短的实际操作总览。** 这一问题与此前引言中“尚未说清方案如何工作”的问题相通，但这里已经具体说明了谁、在哪一帧、哪个子载波上传导频，不能说完全没有说明传输方式。

分类 A/B/C/D 只对应下表明确划分的句子，不代表自然程度、原创度或学术质量分数。

## 确证问题与最小处理方向

### P04-F01：整段“原段原句最小替换”归类不能通过（中）

- **位置：**第 68–70、72–74 行；尤其第四、六句。
- **证据：**Cai 原文定义的是作用于 OFDM 频域信道的 diagonal pilot matrix；本文定义的是 IDAFT 输入向量。本文 Q×KN 的 P 又是自行规定的联合排列。此前将两者只标为“代入本文向量／矩阵”会掩盖实质性技术对象变化。
- **影响：**这不是模型错误，但会使“每一句只作必要术语替换”的来源承诺失真。
- **最小处理方向：**来源记录分别写清 B、C 级支持；如仍要满足更严格的完整原句要求，需另找作用于调制输入的导频向量构造原句与同类矩阵排列句。不能把 `Let`、`construct` 等通用词当作原句证明，也不能改动本文维度来迁就来源。

### P04-F02：新方案小节起首仍以定义代替操作总览（中，段落功能问题）

- **位置：**本段整体，结合 §II-B 第 63–184 行与 §II-C 第 210–245 行。
- **证据：**Shen，PDF p.4，§II-B 起首在定义 spreading code 前，先按“设备分配码字→符号跨 Q 个连续帧发送→各帧独立调制解调→接收端收集并处理”的顺序介绍方案。Cai 的对应段则为已知 OFDM 系统直接定义导频、CP 与接收信号。本文以蔡文的定义段开启自己声称提出的多帧传输方案，读者直到 P10 才读到 consecutive frames 和公共 H_k，到 P13 才看到多帧共同观测。
- **影响：**读者能理解 P_qkn 的含义，却需要自行跨过后续波形及有效信道公式，拼出导频如何形成多帧共同观测。引言贡献中“多帧方案”与本节实际流程之间的对应没有在起首建立。
- **最小处理方向：**在本段起首用很短的操作性总览交代设备在连续 AFDM 帧发送导频、接收端使用这些帧的观测；跨帧相位及共同 H_k 的理由留在其现有公式位置。总览须核对技术相近母本再定稿，不能直接移入 Shen 的 spreading code／data-symbol spreading，也不宜在这里提前展开分数时延、CPP 相位、MMSE 或活动检测器。本轮仅指出方向，不擅自改写。

## 逻辑、动词、形容词与连接方式

- **局部顺序成立：**资源 N → 帧数 Q → 标量导频 → 每帧向量 → 接收端已知性 → 全局排列。向量与矩阵层次没有混淆，P_qkn 的设备／帧／子载波索引均能从文字和向量端点读出。
- **`shared`、`allocated`、`transmitted`：**均保留 Cai 同类导频句的主谓和用途，含义合适。
- **`construct`：**是集合标量成向量的合理动词，但“动词合理”不等于完整母句通过；这里不需要为了换词而换词。
- **`known`：**清楚陈述接收端所知导频，不等于相位调整后的 A 也已知，后文估计 A 的流程不会被本句否定。不能把 S5 擅自扩展成 A 已知。
- **`Let … denote`：**仅用于一个同类对象的定义，不是旧版把时间、向量和 Dirac 函数硬拼在一个 notations 句里的问题。
- 本段没有程度形容词、因果连接词或性能承诺；没有发现因果强度超过数学依据的表述。
- 不应要求每个普通符号定义都交代“原因”。缺少的是小节起首的流程关系，并非 N、Q、p、P 每一项都要另加动机句。

## 细粒度与参考段比较

1. **与 Cai 的局部导频段相比：**Cai 用三句交代时域资源数量、逐符号导频和对角矩阵，接着进入 CP 和接收模型。本文同一局部区域有六句，多出的内容主要是共享资源句、已知导频句以及全局 P。篇幅没有明显失控；P 与 p 是不同对象，不能按“两个导频名称”删掉一个。
2. **与 Shen 的新方案起首相比：**Shen 起首的重点是具体发送／接收过程，然后才落实 spreading code、调制和波形。本段重点停在定义集合，作为“新方案介绍”的层级比 Shen 少一层流程说明，作为“符号准备”的层级则足够。
3. **P 是否定义过早：**P 下一段就用于 P P^H=K E_p I_Q，所以局部不存在无后续用途的提前定义。但把全局矩阵及约束放在 IDAFT 之前，确实使读者先处理了代数设计条件再看到实际发送波形。这是可讨论的组织顺序，不是确证错误；不建议只移动 P 而把 P05 留在原地。若全章改序，P 与约束应一起考虑。
4. **是否移入附录：**本段六句均是理解后续模型所需的短定义，没有必须移入附录的推导。优先改善开头关系，不以增加解释篇幅解决所有问题。

## 保留的优点

- Cai 的两句“时间资源分配→符号在设备／时间／子载波上的定位”在当前稿中保持相邻，适配程度高，读者容易核对。
- 没有移入 Cai 的同步假设或 Wei 的恒模、单位功率与可直接消去导频的条件。
- 向量 p_qk 与矩阵 P 的维度和索引可互相核对，并分别服务调制与矩阵约束。
- 多余的 `a total of` 已删除；本段没有过度谈活动概率、DRE 或算法细节。
