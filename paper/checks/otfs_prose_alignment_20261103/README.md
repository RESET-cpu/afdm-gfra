对照表逐字移入附录 B-B，轴含义和 M=N=16、L=7 的数值例子移至相应索引计数段。共同多普勒、分数时延、稠密表示与物理自由度的区别以及优化 OTFS 的调制成本分析均保留。没有把条件性比较改成普遍优势。
