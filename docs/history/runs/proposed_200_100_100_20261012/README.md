## 核验结果

- 50,000 个训练信道来自 12,500 个物理场景；5,000 个验证信道来自 1,250 个物理场景，每场景均匀选 4 个候选用户。训练、验证及既有测试场景种子互不重叠。
- 全部信道有限且非零，训练与验证集合内部及跨集合均无完全重复信道；身份、文件 SHA 与保存的矩统计均通过核验。抽查重建 24 个信道，与存储的 complex64 数据逐元素相同。
- 独立构造损失核对一阶 DSM 和二阶样本平均风险回归；复噪声方差为 v，每个实分量方差 v/2。独立 AWGN 测试符合采样定义。
- 原始断点对应源码已找到，SHA 匹配。迁移前后网络、目标、采样、验证及一阶更新函数相同；共用 trainer 仅移除了当前流程不使用的方法。
- 25 项相关测试通过，包括三阶段训练与绑定、各阶段中途恢复，以及导入断点后与连续训练的参数、EMA、Adam 和随机状态逐项比较。
- 在真实 MPS 断点上以零次参数更新验证导入，原始与导入状态的所有参数、优化器张量、随机流、历史、轮内位置完全相同。

物理信道重建时，当前数值库在矩阵乘法处报告了 288 次运行时警告。所有输出均有限；对 24 个重建信道改用显式元素求和独立核对，最大相对误差为 4.01e-16 以下。原始警告保留在审计记录中，没有删除样本或修改信道。

## 本次配置与保存

完整配方见 [recipe.json](recipe.json)，文件身份见 [MANIFEST.json](MANIFEST.json)。
`preserved/` 保存旧三份网络、原教师记录、原始一阶断点和数据副本；`runtime/` 保存运行所用源码。
原目录中的模型和默认推断配置保持原样。

一阶恢复原学习率 8.857950124856526e-6，从第 82 轮平滑下降到第 200 轮的 1e-6；未按新总轮数重新计算原来的余弦曲线，否则在第 82 轮会出现学习率上跳。
跨运行导入的来源明确记录在 [CONTINUATION.json](training/first/CONTINUATION.json)，没有把新规格冒充为原始实验。

任务每约 120 秒保存断点，并在每轮结束时保存。后台运行使用系统的防空闲睡眠功能；进程退出后自动释放。
全部阶段完成后，任务自动核验 200/100/100 轮、教师绑定以及原资产 SHA，生成 `COMPLETION_VERIFICATION.json`、`COMPLETION.md` 和 `training/receiver.json`。

若进程因重启或异常退出，查看状态和日志后，用同一命令恢复；重复同时启动会被文件锁阻止：

```sh
.venv/bin/python -B runs/proposed_200_100_100_20261012/driver.py
```

暂停当前阶段可在其目录创建 `pause.request`，任务会保存当前状态并结束串行任务；移除后按上面的命令恢复。

## 结论边界

本次核查支持数据身份、划分、训练公式和状态恢复正确，并不证明独立 AWGN 与接收机实际迭代查询分布相同。此前诊断指出的查询分布差异仍然存在。
本任务尚不能给出新权重的 AUD/NMSE，也不能断言延长训练后必然优于 off-grid SBL。新权重完成后需要另行进行接收机性能评价。
