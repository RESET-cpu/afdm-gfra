# 弱用户漏检的修复选择与论文依据

2026-10-16。academic-research-suite；针对现有诊断的定向文献核对，非系统综述。
本轮完成原文、既有失败试验和候选公式核对；仅运行小尺寸合成代数检查，没有新训练、接收机成绩或主线切换。

**建议保留当前酉导频，继续检验双向空间矩阵消息，但先修复它尚未通过的局部网络接口。优先处理均值与协方差的训练耦合、协方差病态和同一查询下的消息定义，再检验是否减少强用户反馈对弱用户的抵消。**

这是一条有文献依据、可以具体实施的候选路线。没有找到能保证“原三张权重完全不动、换一个反馈公式，就解决当前19次漏检”的现成定理。现有证据也不支持“矩阵化必然有效”或“标量方法必然无效”。

## 1. 修复目标应从“总噪声是否白”转到有效输入是否保留弱用户

[固定30场景诊断](../proposed_feedback_uncertainty_20261016/REPORT.md)中，−4 dB共有149个活动、1051个不活动用户，原结果19 MD / 0 FA。19个漏检都在各场景较弱的一半。

- 原漏检组的查询误差功率/方差标签中位数为0.984，但沿真实信道的输入增益中位数只有0.682。
- 固定R，仅替换成真值辅助的逐用户误差功率，仍为19 MD / 0 FA。
- 固定原历史，把较强用户反馈替换成真值后，局部结果为4 MD / 34 FA；再使用实现误差功率标签为4 MD / 10 FA。它说明反馈内容值得修，但不是已经得到一个可部署的改善。
- 第30轮14 MD / 7 FA，末态19 MD / 0 FA；后期新漏的5人随R而非这两个时点的v发生判决变化。不能据此选最优轮次或只恢复旧v。

一个无需统计近似的反例说明区别。设两个用户块均为酉矩阵，

\[
y=A_1h_1+A_2h_2+n,\qquad
e_2=h_2+\lambda A_2^HA_1h_1.
\]

则第一用户的排除自身反馈查询为

\[
r_1=A_1^H(y-A_2e_2)=(1-\lambda)h_1+A_1^Hn.
\]

热噪声严格白，显式自身旧反馈已经不存在，目标信号仍被抵消。该式是本项目为解释机制构造的反例，不是对实际反馈形式的拟合。把v改成矩阵V，本身不会自动补回被减掉的信号；必须通过改进去噪均值及反馈更新，使e₂改变。

## 2. 论文实际支持到哪里

| 来源与原文定位 | 可以采用的依据 | 不能据此宣称 |
|---|---|---|
| [Ma–Ping, Orthogonal AMP](https://arxiv.org/html/1602.06509v3)，§III-A(12)–(14)、§III-E Assumptions 1–2；[Cheng等 OAMP-MMV](https://arxiv.org/html/2304.08038v1)，§III-D Assumption 18、§III-F(31)–(34) | 反馈需处理误差相关；MMV可以保留矩阵交叉相关，而非只匹配平均迹 | 酉用户块拼接就具有全局Haar性质；做一次迹或矩阵校正后，有限AFDM的查询就独立AWGN |
| [Minka, EP](https://tminka.github.io/papers/ep/minka-ep-uai.pdf)，§2(4)–(6)、§3(8)–(10)；[Fletcher等, GEC v2](https://arxiv.org/pdf/1602.07795v2)，§II-B(12)、§III-D Theorem 3 | 用同一cavity形成局部后验矩，再除去同一输入；精确MMSE映射的导数与中心协方差相关 | 独立训练的三个有限网络已经来自同一后验；任意风险读数可以替代Jacobian/中心协方差 |
| [Shastri等, D-GEC, JSAIT 2022](https://arxiv.org/html/2206.05049v2)，§III-A Algorithm 3、(31)、(35)–(37)，§III-B(38)–(40) | 将消息统计的表达与去噪器训练联合设计；去噪器需要看到实际保留的有色噪声统计 | MRI小波分组就是AFDM天线分组；其Gaussian误差经验结果是我们的收敛保证。作者在(36)后明确留下严格分析问题 |
| [Stirn等, Faithful Heteroscedastic Regression, AISTATS 2023](https://proceedings.mlr.press/v206/stirn23a/stirn23a.pdf)，§2 Proposals 1–2、(5)、Theorem 1，PDF pp.3–4 | 均值采用平方误差梯度，隔离协方差损失到均值/共享特征的梯度，保护均值优化过程 | 获得真实中心后验协方差、消除反馈偏差或保证检测改善；原文没有为本AFDM提供这些结论 |
| [Takeuchi, LM-OAMP](https://arxiv.org/html/2111.05522v2)，§III-C(27)–(28)、§III-D(44)–(45) | 跨轮组合必须保留误差交叉项；阻尼需和外信息更新保持一致 | 直接用当前工作v构造历史误差Gram就正确；任意小阻尼都能修复错误固定点 |

文献的共同支持是“均值、二阶量、输入统计和反馈更新必须配套”。把这些文献拼接并不构成一个已经被证明的AFDM算法。直接的多用户EP/软干扰抵消证据及条件见[线性侧核验](LINEAR_SOURCES.md)，中心协方差与有限网络的区别见[非线性侧核验](NONLINEAR_SOURCES.md)。

## 3. 第一项可具体修复的故障：矩阵局部训练

[已有空间矩阵候选](../proposed_spatial_messages_20261016/REPORT.md)在第44次更新前失败：正常输入V条件数约9.03，输出C条件数约1.08×10²²，损失二次型约3.05×10¹⁹；协方差、first和second分支都出现巨大梯度。这是该新候选的训练故障，不能倒过来解释旧接收机的19次漏检。

### 3.1 协方差输出要有真正的谱约束

旧表示C=TTᴴ仅约束T的对角为正，不能控制T的最小奇异值。候选可改成以下明确的受限族，例如

\[
C=s\left[I+(\kappa_{\max}-1)
\frac{BB^H}{1+\|B\|_F^2}\right],\qquad
s=s_{\min}+\operatorname{softplus}(a),\quad s_{\min}>0.
\]

取κ_max≥1，它满足sI≼C≼sκ_max I，因而κ(C)≤κ_max。整体尺度仍可学习。此式是本项目直接给出的参数化，不冒称上述论文原算法，也不是事后截断失败的输出。它限制可表达的协方差族，κ_max与s_min必须在新训练协议中预先固定、单独验证，不能凭漏检结果调到有利值。

**不要额外强制后验C≼输入V。** 对非Gaussian先验，逐点后验协方差不必满足这个限制；活动混合后的U尤其可能大于V。数值正定、统计校准和site精度可行是三件不同的事。

### 3.2 保护均值训练，隔离协方差梯度

按Stirn等(5)的原则，在独立候选中用

\[
\mathcal L=\mathcal L_{\rm MSE}(\mu,H)
+\mathcal L_{\rm NLL}(H;\operatorname{sg}(\mu),C)
+\mathcal L_{\rm BCE}(\ell,a).
\]

这里sg表示停止梯度；C所用的均值特征及共享first特征也必须停止梯度。各分支的梯度范数记录与裁剪分开，避免协方差的巨大梯度通过全模型裁剪再次缩小均值更新。只在NLL显式残差里detach均值并不足够。

代码核对发现：当前activity.inputs已经对mean执行detach，因此BCE经mean回传first并不是这次已存在的故障。应保留这一隔离。待修改的是NLL直接路径、cov_features中的均值路径及全模型梯度裁剪耦合。

原文的保证是与相同训练条件下mean-only模型的优化相符；它不是“比旧预训练first更好”的保证。若要声称优化轨迹相同，还必须匹配批次、初始化、优化器状态和裁剪等条件。

### 3.3 仍需区分误差风险和中心协方差

给定输入R,V及活跃状态，令m*=E[H|R,V,a=1]。有限均值μ满足

\[
\frac1L E[(H-\mu)(H-\mu)^H\mid R,V,a=1]
=C_*+\frac1L(m_*-\mu)(m_*-\mu)^H.
\]

因此，固定有限μ后训练Gaussian NLL，最优矩阵仍包含均值偏差项。隔离梯度、保证正定都不会删除它；不能从旧second中减去一个可观测的简单项就得到C_*。

该偏差项是非负的，不能用它单独解释目前实际风险被低估；有限拟合误差、查询分布失配、池化和活动混合还需分别检验。[Cai §IV-C(52)–(54)](https://arxiv.org/html/2506.00581v2#S4.SS3)同样将有限first代入second训练目标，因此这项解释边界也适用于Cai的有限网络实现。不能将我们实测的不一致程度外推给作者权重。

允许把训练出的C明确定义为近似局部分布qθ自身的协方差，用其形成工作消息，同时分别验证均值误差、风险校准和导数一致性；不能把它写成真实物理后验协方差。若要让新输出继续称为有色Gaussian模型的score，还必须按对应协方差的Tweedie恒等式重新定义读出；旧代码的trace(V)标量乘score只是一种均值参数化，不能直接借用该恒等式。

## 4. 接回完整迭代时必须一同修改的关系

令H_k为16×256，每用户保留空间Gaussian site的均值E_k、协方差S_k。沿用当前酉导频，在该工作模型内有

\[
R_k=A_k^H\!\left(Y-\sum_{j\ne k}A_jE_j\right),\qquad
V_k=\sigma^2I_{16}+\sum_{j\ne k}S_j.
\]

A_k及其共轭转置均作用于AFDM坐标，S_k/V_k作用于天线坐标；式子是算子记号，不是将16×16天线矩阵与AFDM块混乘。用户site因子独立、全部256个AFDM坐标列独立且共用同一个S_k，以及Gaussian site仍是工作近似；不同用户的S_k无需相互交换。

三个局部职责基于同一(R_k,V_k)输出p_k、μ_k、C_k，形成

\[
m_k=p_k\mu_k,\qquad
U_k=p_kC_k+p_k(1-p_k)\mu_k\mu_k^H/256.
\]

然后从同一cavity作相除：

\[
\Lambda_k^{\rm new}=U_k^{-1}-V_k^{-1},\qquad
B_k^{\rm new}=U_k^{-1}m_k-V_k^{-1}R_k.
\]

在自然参数上做预先规定的阻尼，并记录不可行site、矩残差和未收敛。不能把强用户p≈1解释成其信道已确定；不能先跨用户平均C再处理活动混合。该16×16表示只保留空间二阶矩，并未表达全部4096维结构、用户间相关和跨轮相关。

这些消息关系已有候选实现和代数控制；本次新工作重点是使局部接口能够被可靠训练和检验，而不是把旧joint-EP再跑一遍。若局部资格通过而完整循环仍有方向衰减，应据此重新检查均值模型和用户间/跨轮依赖，不能继续只加大矩阵或调阻尼。

## 6. 执行顺序与判断标准

1. **局部实现。** 新目录实现谱约束、梯度隔离和明确的均值/score读出。先核对故障微批的有限前后向、矩阵界和梯度路径，不运行完整训练来碰运气。
2. **独立局部训练与资格。** 使用训练场景和独立抽样V，保持物理信道先验；与同架构均值MSE对照、旧trace接口比较均值MSE、活动BCE、方向风险、NLL、有限性和支持范围。现有30场景不得变成训练集。方向NLL改善不能替代均值或活动性能。
3. **固定闭环开发对照。** 先用既定6例，再完整30例，对照同导频原接收机；合格时再看新物理场景及多SNR。统一ρ、0.5阈值、噪声和相位条件，报告全部MD、FA、完整NMSE、未收敛、运行成本。30例已经反复诊断，只能算开发/回归证据。
4. **机制判断。** 保存预测后再用真值诊断方向增益、较强用户反馈负投影、风险校准与后期新增漏检；同时检查所有用户，不能只展示原19个漏检者。若候选只使协方差更白、却未改善方向损失或检测，就没有达到修复目标。

当前证据仍留下独立的相位前端误差；准确其他反馈和真实相位下仍有3个极弱用户被原网络漏掉。不能承诺单改反馈消除全部漏检，也不能把这3人称为物理不可检测。

## 7. 本轮实际完成的验证与边界

[合成代数检查](ALGEBRA_CHECK.json)验证了酉块下仍可能产生信号抵消的反例、风险/中心协方差恒等式、20个谱约束案例和一次隔离梯度的反向传播。恒等式误差不超过2.11×10⁻¹⁵，隔离后的均值梯度与MSE梯度差为0。它们没有使用项目场景或网络，不能折算成漏检改善。

首次NumPy复数矩阵乘法输出有限且代数检查通过，但出现算术警告；已保留初始脚本/输出及[记录](NUMERICAL_NOTE.json)。相同种子和案例改用显式求和，并将算术警告设为错误后通过。没有删除实际接收机失败或重新挑样本。

论文间的条件核对：OAMP的渐近正交性与D-GEC的结构算子经验结果不构成矛盾；精确MMSE的导数恒等式与有限均值的风险偏差也不构成矛盾；Stirn的均值优化保护不等于EP后验一致性。以上是选定文献对的定向核对，不声称完整覆盖。scholar_confirmation: pending，仅表示研究者尚未审阅这份综合判断，不是执行授权门槛。

**改动范围判断：以非线性局部接口和消息迭代的联合修复为主，线性模块配套传递矩阵；物理信道模型和当前酉导频可保持。三个网络的职责及骨干可以保留，但矩阵条件输入、二阶输出和训练需要独立适配，不能继续承诺旧结构及权重完全不用改。**
