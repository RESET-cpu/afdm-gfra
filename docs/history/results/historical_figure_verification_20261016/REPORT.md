原图各方法样本量不一致，且仅部分场景重叠，属于描述性对比。它与后来 `baselines_1000_20261015` 的四 baseline × 1000 场景结果是两批实验；后者采用估计相位和估计噪声，不能混为同一张图的来源。

## 原图 Proposed 的准确统计

每档 100 个物理场景，合计 4000 个候选用户判决、426 个活跃用户。AER 分母是所有候选用户判决数，不是活跃用户数。

| SNR / dB | 漏检 | 虚警 | AER / % | 完整信道 NMSE / dB |
|---:|---:|---:|---:|---:|
| −4 | 32 | 0 | 0.800 | −7.830 |
| −2 | 14 | 0 | 0.350 | −9.794 |
| 0 | 7 | 0 | 0.175 | −11.350 |
| 2 | 1 | 0 | 0.025 | −12.932 |
| 4 | 1 | 0 | 0.025 | −14.235 |
| 6 | 0 | 0 | 0.000 | −15.424 |

因此原图的 2、4 dB 并非零漏检，只是 0.025% 在图中很接近零；原图没有 8、10 dB 的结果。

当前十场景八点实验中，Proposed 在八档的完整信道 NMSE 均低于四个 baseline，2、4、6、8 dB 无活动检测错误；−4、−2、0、10 dB 各有一次漏检，全部八档无虚警。当前 10 dB 的漏检也已通过完整接收入口逐元素重放，必须保留。这不与原图 6 dB 零漏检相矛盾，但说明当前实验不能直接沿用历史图的检测优势结论。详见 [当前八点结果](../proposed_original_snr8_10_20261016/FINDINGS.md)。

本次验证支持历史数据完整及两个关键推断条件可精确复现；未进行相位与阻尼的因果消融，也不据不同场景数量的两批实验判断某项改动必然改善或恶化性能。
