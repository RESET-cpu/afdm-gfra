## 1. 数据完整性与物理正确性分开判断

前轮已逐数组核对55000个小矩阵与完整信道第一天线的切片一致；没有非有限数、全零样本、精确重复矩阵或训练/验证场景交叉。48个样本由种子重建后逐元素吻合。这说明文件和管线没有明显损坏，但同一个生成器重建自己不能验证物理模型。

本轮增加独立计算：显式构造时域发送样本及336点前缀后执行整数延迟；用手稿式(10)的逐元素求和计算分数时延矩阵；用几何距离的有限差分验证 Doppler；用天线到地面用户的真实距离差验证阵列相位。分数时延检查仍以项目所选连续波形为前提，不能等同于实测硬件验证。

## 2. 长时延、跨周期和相位实现

| 检查 | 范围 | 最大误差 |
|---|---|---:|
| 显式时域前缀、延迟、Doppler、DAFT 与生成器比较 | 整数时延0至336，337种 | 相对误差1.55×10⁻¹¹ |
| 独立展开求和与矩阵实现比较 | 8个时延×3个Doppler，包含边界两侧及335.51点长时延 | 相对误差3.39×10⁻¹¹ |
| 第15帧直接生成与公共相位旋转比较 | 同上24组 | 相对误差1.48×10⁻¹³ |
| 完整时延与折叠时延加解析相位比较 | 同上24组 | 相对误差1.55×10⁻¹¹ |
| 单路径Frobenius能量应为N=16 | 同上24组 | 绝对误差2.49×10⁻¹⁴ |

数值误差与长时延二次相位求值的浮点精度相符。故意把延迟改错一格，参考测试的最小相对误差为1.66，说明比较能识别实质错误。

对于当前整数 `2Nc1=7`，令 `d0=d mod N`，直接得到并验证

\[
G(d,\nu)=e^{j2\pi c_1(d^2-d_0^2)}G(d_0,\nu).
\]

因此，**长时延并不自动增加几百个独立自由度**。很多跨周期差异可并入路径复增益。真正需要比较的是折叠后的时延、Doppler及其联合分布，不能仅凭699微秒比几十纳秒大就断言学习困难增加了相同倍数。

本参数下整数采样处的广义前缀相位恰好为1，所以将普通CP作为反例无法有效检验跨周期相位；本轮使用显式时域构造、分数时延展开和错延迟反例。

依据：冻结的 [连续路径矩阵](../oracle_direction_small_20261013/runtime/src/afdm_jadcedd/system/afdm/continuous.py)，项目[手稿](../../paper/history/phase4_sections_20261008/draft.md)式(7)、(10)、(11)。这些检查没有发现矩阵下标、Doppler正负号或跨帧相位漏乘问题。

## 3. 分数时延矩阵存在真实跳变

当前波形使用

\[
w=(t-d)\bmod N,\quad \rho=\lfloor2c_1w+n/N\rfloor,
\quad \varphi\propto e^{j2\pi[c_1(t-d)^2+nw/N-\rho w]}.
\]

当整数分支 `rho` 改变时，复包络一般不连续。实际检查如下；比较的是 `d−10⁻⁹` 与 `d+10⁻⁹`，并额外消除两个矩阵之间最佳公共相位，防止把整体相位变化误认成结构变化。

| 中心时延d，单位采样点 | 相位对齐后相对矩阵变化 |
|---|---:|
| 1/7 | 0.2112 |
| 2/7 | 0.3857 |
| 1 | 2.34×10⁻⁸ |
| 16+1/7 | 0.2112 |
| 144+1/7 | 0.2112 |
| 0.2，非边界 | 2.16×10⁻⁸ |

逐级缩小扰动 `10⁻³→10⁻⁵→10⁻⁷→10⁻⁹`，前两项趋向非零常数，非边界趋向零。不是所有 `k/7` 处都有非零跳变，整数位置的相位变化可抵消。结果见CHECKS完整表。

这是当前模型中原有的性质，仓库 `test_delay_refinement_intervals_respect_physical_jumps` 也明确测试它，不能包装成刚发现的代码错误。Cao–Shao 2026预印本 *Resolving the Discontinuity of Continuous-Time AFDM Waveforms*，§II-A式(1)–(3)、Proposition 1，也分析了这种频率折叠和相位修正构造的连续性问题。该文指出，整数IDAFT采样相同并不能唯一决定采样点之间的连续波形。[作者稿](https://arxiv.org/html/2609.07480v1)

对本项目的含义：当前标签严格对应一种指定的连续波形，不能直接当作任意脉冲成形AFDM系统的通用标签。跳变可能增加时延参数到矩阵的分段复杂性；**尚未证明它导致当前score训练缓慢或NMSE差距**。Huang式(5)也含分段折叠项，不能推断Huang采用了完全光滑的替代模型。任何换波形实验必须同步更换训练数据、测试数据和物理基线，另立实验版本。

## 4. 与 Huang 的数据分布并不相同

Huang §II式(3)、Table I，p.2950；§IV，pp.2951–2952：路径时延为归一化TDL时延乘30–50 ns。最大表中局部延迟为 `7.334×50 ns=366.7 ns`，在480 kHz采样率下为0.176016点；论文另给最大归一化时延支持 `lmax=1`。公式中没有本项目的公共参考下用户宏观差分时延。

本项目为 `tau_p=tau_macro+d_p*tau_spread`，使用600 km轨道、30度最低仰角、128 km波束内用户几何；Huang是500 km、25度。相同N=16和TDL表格不足以构成同分布复现。

本轮从训练、验证各等间隔选200个独立场景，按实际选样规则各取800个候选用户；另生成200个独立新场景、8000个候选用户。不把同场景内用户当作独立场景做显著性检验。

| 指标 | 训练800用户 | 验证800用户 | 新场景8000用户 |
|---|---:|---:|---:|
| 宏观时延均值，采样点 | 124.362 | 123.966 | 125.014 |
| 折叠宏观时延均值，采样点 | 7.862 | 7.966 | 8.070 |
| 折叠宏观时延最小–最大 | 0.018–15.986 | 0.005–15.999 | 0.007–15.993 |
| Doppler标准差，kHz | 21.427 | 20.644 | 21.449 |
| 最大局部路径时延均值，采样点 | 0.14108 | 0.14067 | 0.14079 |

结果与同一生成法相容，但描述性统计不能排除所有高维差异。**与Huang相比，主要改变的是宏观时延折叠后的覆盖区域及几何联合分布，而不是局部TDL表格写错了。** 随机公共LOS相位也是本项目明确的生成约定，作者代码缺失时不能声称逐项一致。

小网络当前学习的是此分布下的边缘先验。判断Huang效果能否复现，需要单独构造其论文设置的对照；不能拿当前小矩阵直接称为Huang数据。

## 5. TDL增益与全局功率没有发现异常

600个场景、24000个候选用户的四分量平均功率：

| 分量 | 理论功率 | 实测功率 |
|---|---:|---:|
| 零时延LOS | 0.936699 | 0.936699 |
| 同一零时延Rayleigh | 0.063227 | 0.062033 |
| 归一化时延0.5596 | 0.102636 | 0.101491 |
| 归一化时延7.3340 | 0.021033 | 0.021099 |

前两项合起来是一个Rician tap，其功率比恰为11.707 dB；之后两个Rayleigh tap。因此“四个分量”与“三个tap”没有矛盾。当前标准生成器没有再次给LOS分量加一份Rician散射；旧 `legacy_gain` 不是当前训练标签采用的字段。

各分量归一化复均值的模小于0.009，分量间归一化交叉二阶矩的模最大0.00795，与当前独立圆对称生成约定相容。独立分量及单位路径范数给出理论每个G元素平均功率

\[
\mathbb E\|G\|_F^2/N^2=\sum_pP_p/N=0.07022466.
\]

实际全局归一化尺度平方为0.07011726，相差约0.153%。没有发现漏乘天线数、把LOS散射重复计入或错误单位功率归一化的迹象。

## 6. 几何审查：一项小缺陷，一项重要的未利用信息

**Doppler、阵列相位、支持范围。** 24000个候选用户的几何核算中，距离有限差分得到的Doppler与实现最大差0.000112 Hz；有限距离天线相位与远场阵列近似最大复数差3.54×10⁻⁶。最低仰角30.157度，最长路径332.910点，小于336点前缀。这些是本次抽样范围，不是总体极值证明。载波、Doppler和阵列符号与项目[系统模型](../../docs/SYSTEM_MODEL.md)的RF约定一致。

**已确认的几何边界缺陷。** 波束按切平面圆盘径向投影到球面构造。若波束中心地心角为gamma，判断星下点是否在波束内应使用 `R*tan(gamma)<=r_beam`；`_closest_ground_in_beam` 使用了 `R*sin(gamma)<=r_beam`。

错误分支只可能出现在

\[
\arctan(r_b/R)<\gamma\leq\arcsin(r_b/R),
\]

即本参数下0.02008833–0.02009239 rad的极窄环带。构造中点可复现：所返回星下点需要切平面半径128012.92 m，超出128000 m。整个错误区间的参考距离偏差上界约0.0006084 m，即约2.03 ps、9.74×10⁻⁷采样点。

扫描实际训练、验证的全部13750个场景种子，命中数为0。**所以它是应修复的边界公式问题，但不能解释现有训练loss或NMSE差距。** 此轮保留冻结生成器，避免混淆历史数据版本；后续修复应把场景版本及回归检查一并记录。

**方向决定Doppler，但网络未显式利用。** 当前速度沿全局X，UPA的z轴也沿X。因此

\[
\nu=-\frac{f_c}{c}\|v_{sat}\|\mu_z.
\]

数值检查最大残差7.28×10⁻¹² Hz。这里不是笼统的“方向可能与Doppler相关”，而是给定方向余弦即可确定Doppler。

当前实验仅以真实方向做 `aᴴR/16` 投影，再调用学习边缘 `p(G)` 的网络；没有将方向或由它确定的Doppler作为网络条件，因而不能视为充分利用真实方向的条件估计器。这是算法建模的可改进点，不是标签损坏。已知跨帧相位也构成条件信息；边缘先验与严格条件先验的区别在系统模型中已有说明。方向条件是否带来额外NMSE收益，仍须实验。

## 7. 训练与实际评估链路

核对保存的36个闭环案例，共12个物理场景、58个不同活动用户信道，三个SNR重复使用相同物理真值：

- 活动信道与冻结训练生成器重建值完全一致，非活动真值严格为零。
- 用显式用户求和重建无噪接收量，接收SNR与记录最大差1.78×10⁻¹⁵ dB。
- 标准化接收噪声的平均复功率为0.99687；三个SNR复用同一噪声实现，不能当作36个独立噪声场景。
- 由真实Doppler计算跨帧相位斜率，与保存值最大差1.74×10⁻¹⁴ rad。

训练候选样本在活动掩码之前生成，评估的非空活动条件只改变独立活动流；没有证据表明它改变活动用户的边缘物理信道分布。但36个评估案例并不足以排除所有统计偏差，且当前小网络/完整网络与物理基线的信息条件仍需按既有oracle说明区分。

## 8. 对“数据是否有问题”的最终判断

| 命题 | 当前证据判断 |
|---|---|
| 数据损坏、切片错、加噪方差错、路径矩阵或跨帧相位明显算错 | 本轮及前轮检查未发现 |
| 小网络数据就是Huang的16×16数据 | 不成立，分布和几何设置有实质差异 |
| 当前分数时延生成法可代表任意实际AFDM波形 | 不成立，必须声明连续波形及接收模型 |
| 真实方向已经被小网络充分利用 | 不成立，目前只用来投影 |
| 几何生成器完全没有实现缺陷 | 不成立，发现一项未命中当前库的微小边界缺陷 |
| 已经证明训练慢主要由数据而不是网络/优化造成 | 未证明，需要受控对照 |

建议优先做两个互相分开的对照：一是在当前数据上比较原小网络与单天线输入的RefineNet，固定噪声分布和验证集、披露计算预算；二是用Huang论文的局部时延设置另建数据，固定同一网络与训练方式，检查分布改变后的学习曲线。随后比较显式Doppler/方向条件。改变连续波形属于系统模型实验，应单独编号，并同步更新物理基线。不能一次同时改数据、网络和损失后把收益归给其中一个因素。

当前实际小网络约47.9万参数，而完整网络约3257.5万参数，且结构家族不同。继续称“小网络就是Huang网络”会掩盖这个混杂因素；loss数值也必须先统一单位，不能用0.3与0.03的原始数值判定数据坏了。

## 9. 限制与复现

本轮为仿真物理和分布审查，没有实测波形、接收滤波、硬件、时变几何或信道数据。Huang没有可核实的作者代码供逐样本对照，其未披露设置保留为未知。新波形连续性来源是2026预印本，其结论在本项目中的使用限于所列公式和独立数值检查。

运行中捕获到NumPy矩阵乘法的浮点告警，详细位置保存在CHECKS；路径矩阵及报告全部数值显式检查为有限，独立残差检查通过。不能把告警删除后声称运行没有告警。全部训练和评估输出保持原样；此目录只新增审查材料。
