# 输入维滤波与空间处理：八个新物理场景的确认

通过全部预定确认点门槛，保留为独立候选。本阶段不修改原Proposed及其28个受保护文件或备份。
独立单位为8个物理场景，每场景配对−4/0/4 dB，共24个条件、48条接收机运行。
源代码、0.1 dB预算、三个网络、原反馈、双向0.2阻尼与600轮上限在生成数据前冻结。
