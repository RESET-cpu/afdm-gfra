## 为什么更换统一回路仍未奏效

**FIRE 的模型协方差补加成立，不等于实际查询成为独立 AWGN。** 开发scene000/−4 dB的残差方差、标签初值10版本，初轮误差功率/标签为0.991、空间二阶矩最大特征值占比为0.068，表面上接近各向同性；但误差在信号上的归一化实投影为−0.971。最终功率/标签仍为1.007，投影为−0.993，输出却为零、所有活跃用户漏检。空间指标为未中心化二阶矩，不是噪声独立性的检验。

零均值补噪不消除信号方向偏差；若模型误差协方差与真实误差不符，补噪会保留两者差异。这与 [FIRE §3.1、Theorem 1](https://arxiv.org/html/2501.17468v4#S3.SS1) 的适用条件有关。当前实现没有满足其理想 AWGN 初值及理想去噪误差条件的保证。直接残差版还会越过旧网络的方差支持上限100；二阶替代版虽能运行，却走向近零输出。

**旧联合去噪映射的散度与二阶方差代理明显不一致。** 对完整 D(r)=p(r)F(r)，在相同初始查询处用3条独立复高斯探针、3个中心差分步长（0.005、0.01、0.02乘以√v）估计归一化实 Jacobian 迹，得到：

| 开发条件 | 归一化散度估计范围 | 二阶网络方差代理 / 查询标签 |
|---|---:|---:|
| scene000 / -4 dB | -0.3757 ～ -0.3744 | 0.00240 |
| scene008 / +0 dB | -0.1277 ～ -0.1260 | 0.01020 |
| scene016 / +4 dB | -0.6392 ～ -0.6361 | 0.00398 |
| scene024 / -4 dB | -0.0434 ～ -0.0421 | 0.00953 |

36次估计均为负，排除了所试单一探针、单一步长造成符号异常的解释；这是有限差分估计，未计算完整Jacobian。二阶代理与原接收机首轮使用的标量方差比一致。理想 AWGN 后验均值在实坐标满足 J_D=Cov(X|r)/(v/2)，应为正半定；见 [Dytso–Poor–Shamai，Proposition 1式(17)](https://doi.org/10.1109/TIT.2022.3216012)。因此不能直接把当前有限网络的正方差输出当作真实散度。这项诊断没有真值输入。

![初始查询的散度与方差代理](derivative_consistency.png)

这一不一致与 DD-VAMP 依赖的灵敏度/外信息交换接口直接相关，但**本实验没有把它单独确认为所有失稳的唯一原因**：DD-VAMP 同时取消了原查询阻尼和站点回退，并采用标准差域反馈阻尼；有限AFDM算子、查询失配及活动分类也可能参与。新场景没有用于调整散度截断或阻尼。实测散度与原二阶代理差异的原因，应进一步在非线性接口中区分，而不能只归结为线性模块算错。

PnP-ADMM 避开散度/精度相除，也没有整体改善，说明仅删掉这类外信息操作不够。本次不能声称通过任何候选已将实际多用户误差变成独立白噪声；原接收机β=0.2只是当前保留旧网络约束下更合适的受测设置。

## 代码、核查与边界

- 候选实现位于 [candidate.py](../../experiments/proposed_uniform_inference_20261014/candidate.py) 与 [pnp.py](../../experiments/proposed_uniform_inference_20261014/pnp.py)，没有修改主线网络、接收机源码或默认配置。主线、生成器、权重和推断源码的哈希核验通过。
- DD-VAMP 的均值与标准差阻尼按 [Sarkar等 §3.1、Algorithm 1](https://arxiv.org/abs/2010.11321)；PnP-ADMM 按该文§2.1式(3)、§2.2。FIRE 的复数协方差采样式见 [此前推导](../../references/uniform_receiver_literature_20261014/REPORT.md)。完整活动映射、初始化、方差估计和预算是明确记录的项目选择。
- 确定性检查包括小矩阵后验/协方差补加恒等式、与原去相关线性查询的等价、实/复差分归一化、活动先验只修正一次；Gaussian去噪器的ADMM结果与闭式解相对误差为1.20×10⁻¹⁵。旧网络适配器的均值和二阶输出与原实现最大差均为0。
- [保存结果核查](INTEGRITY_CHECK.json)独立重算 45 个完整输出的误差与活动决策，完整误差能量最大相对差 4.02e-16；保留 21 个推断失败。新场景跨SNR的标准化噪声最大重构差 9.16e-16。
- 新场景首次准备时，生成器内存返回的额外方向元数据被严格输入接口拒绝，接收机尚未执行。已保留 [准备失败记录](setup_failure_01/NOTE.json) 与原始生成文件，只投影到 observation/operator/noise_variance/activity_prior 四项；种子、公开数组和参数均未改变，见 [输入投影记录](PUBLIC_INPUT_PROJECTION.json)。方向元数据未进入推断。
- 日志保留了NumPy矩阵乘法的浮点警告；完整输出与重新计算的主要指标均为有限值。这些警告没有被删除或当成算法失败的替代解释；候选失败依据明确的查询支持超界。空间二阶矩诊断只作辅助，不承担独立AWGN证明。
- 新场景仅2个物理实现、3个SNR，没有给出总体置信区间或高SNR结论；随机候选均未通过质量条件，因此没有按协议进入额外两种种子复核。未测试D-GEC重训练版或Memory AMP，不能称它们已经被本次排除。
