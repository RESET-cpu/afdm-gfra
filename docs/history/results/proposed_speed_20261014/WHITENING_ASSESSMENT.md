# 线性查询误差能否接近独立白噪声

2026-10-14。结论：可以通过改善多用户干扰处理与外信息更新来争取更接近AWGN的查询，但当前不能靠一次白化变换无损地实现。本轮证据将优先方向进一步收窄到**跨天线的多用户干扰结构**。旧网络在空间误差二阶矩更均匀的oracle对照中明显改善；同功率的各向同性加噪仍产生大量虚警，说明改善不能仅归因于提高噪声标签或降低信噪比。

这是四个预先选定开发条件的首轮诊断。32次新增网络查询均未反馈到完整接收机；两例超出支持区间的oracle条件如实保留。三个旧网络、接收机、数据和主线配置的69项冻结文件哈希均未改变。

## 1. 当前线性模块已经做了什么

实际查询的恒等式为

\[
r=x_p+L(y-Ax_p),\qquad
r-x=(LA-I)(x-x_p)+Ln.
\]

首轮中 \(x_p=0\)。当前一般SVD实现使用实际输入算子，按平均响应归一化；四个条件均验证 \(\operatorname{tr}(LA)/(KN)=1\)，误差在浮点精度内。该条件约束平均响应，不等于 \(LA=I\)，也不等于完整查询误差协方差为标量单位阵。

纠正本轮最初口头说明：基础全局partial-DFT导频行正交，但实际 \(A_k=D_kP_k\) 还包含用户相关跨帧相位。四例 \(\|AA^H-40I\|_F/\|40I\|_F\) 为0.1423、0.1487、0.1413、0.1518。当前SVD更新正确处理了这些实际算子，并未误用严格行正交简式；不能将这14%–15%的偏离单独认定为故障原因。数值见 [WHITENING_FEASIBILITY.json](WHITENING_FEASIBILITY.json)。

每个天线/AFDM输出索引对应的基本算子为16×640。要求一个线性变换对任意完整信道同时满足 \(LA=I_{640}\) 不可能，因为 \(\operatorname{rank}(LA)\le16\)。利用先验进行迭代仍然可能恢复信道；这个秩论证只排除不利用先验的一次完全线性分离。

## 2. 干扰为何没有成为白噪声

对用户k，首轮精确分解为

\[
R_k-X_k=(L_kA_k-I)X_k+\sum_{j\ne k}L_kA_jX_j+L_kn.
\]

本模型中各用户的多条路径共享阵列方向，\(H_k=a_kG_k\)。线性模块首轮仅沿导频/AFDM输入轴混合，故自身失真和其他用户干扰仍位于活跃用户阵列方向张成的空间。若活跃数为S，则这些项展开到天线轴后的秩至多为S。这里的每用户空间秩一不表示AFDM信道只有一条时延–Doppler路径。

用保存真值作离线分解，得到：

| 场景 / SNR | 活跃数 | 自身失真功率 | 多用户干扰功率 | 热噪声实现功率 | 去掉热噪声后空间秩 |
|---|---:|---:|---:|---:|---:|
| 0 / −4 dB | 2 | 0.0296 | 1.2831 | 3.3871 | 2 |
| 8 / 0 dB | 7 | 0.1348 | 6.3021 | 6.5573 | 7 |
| 16 / 4 dB | 3 | 0.0758 | 3.2861 | 1.4098 | 3 |
| 24 / −4 dB | 6 | 0.1756 | 6.3209 | 16.2694 | 6 |

功率采用接收机归一化单位；各项存在交叉项，不能直接将表中三列相加当作总MSE。所有交叉项已保存，完整向量重建相对误差小于 \(4\times10^{-16}\)。这些方向集中的干扰可以呈现类似真实信道的空间结构；“因此被活动网络误认为用户信号”是由下述对照支持的解释，并非已经逐项完成的分类器因果证明。

数据：[分解及全部交叉项](first_query_error_decomposition_verified/SUMMARY.json)。最初矩阵乘法版本虽得到有限结果，但出现运行库RuntimeWarning；原记录及源码保留于 `first_query_error_decomposition/`。改用显式求和重算并将RuntimeWarning升级为错误，验证版本无警告，主要数值一致。

## 3. 为什么直接白化不适配旧网络

即使已知零均值误差的正定协方差 \(C_e\)，变换也会得到

\[
C_e^{-1/2}R=C_e^{-1/2}H+C_e^{-1/2}E.
\]

因此旧网络面对的干净信号先验变成了 \(C_e^{-1/2}H\)。任意非酉白化一般不保持当前物理信道分布；去噪后再乘回矩阵不能使错误先验自动正确。只有在误差原本联合Gaussian且与信号独立、协方差正确等条件下，白化才同时得到独立Gaussian分量。对当前信号相关的误差，消除二阶相关也不能直接推出独立性。固定酉变换仅旋转协方差，保留特征值，也不会自动将不同特征值变成相等。

## 4. 保留信道坐标的加噪对照

为区分可计算的热噪声与未知干扰，先做两种固定查询构造。对每用户矩阵C，选共同 \(\tau=\max_k\lambda_{\max}(C_k)\)，固定查询后新抽取Gaussian扰动

\[
\eta_k\sim\mathcal{CN}(0,\tau I-C_k),\qquad R'_k=R_k+\eta_k.
\]

这样不对H作坐标变换，但增加误差功率。这是本项目直接线性代数构造，不冠以文献算法名称。

- **仅处理热噪声：** \(C_{n,k}=\sigma^2L_kL_k^H\) 沿AFDM输入轴，由公开A、噪声方差和配置计算，不使用真值。标签设为原标签加平均新增噪声功率，仍然只是总误差方差近似。其热噪声功率增加约5.46–5.65 dB；仍不消除跨用户相关或多用户干扰。
- **oracle空间二阶矩处理：** 取实际误差 \(E_k=R_k-X_k\)，\(C_{e,k}=E_kE_k^H/(N_{\rm out}N_{\rm in})\)，沿天线轴加扰动。此矩阵是未中心化的样本二阶矩，包含偏差，并非已知总体噪声协方差。相对于固定查询，新增扰动期望下每用户空间二阶矩变为 \(\tau I\)；这不保证全部4096个坐标独立、误差Gaussian或误差与H独立。构造依赖真值，不能用于接收机。

每个可支持条件使用4个固定种子。oracle选用共同τ的代价为平均误差功率增加7.20–11.10 dB，其中场景8、24的τ分别为118.93、119.73，超过旧网络上限100，没有截断后强行评估。这个代价属于本次具体构造，不是所有去相关方法的下界。

| 条件 | 原查询首轮虚警数 | 仅处理热噪声后的平均虚警数 | oracle空间处理后的平均虚警 / 漏检数 |
|---|---:|---:|---:|
| 0 / −4 dB | 38 | 23.50 | 0 / 0 |
| 8 / 0 dB | 33 | 33.00 | 超出训练范围 |
| 16 / 4 dB | 37 | 37.00 | 0.25 / 0.75 |
| 24 / −4 dB | 34 | 34.00 | 超出训练范围 |

结果见 [完整记录](whitening_controls/SUMMARY.json)。所有“虚警”均为首轮计数，不能与最终活动错误率曲线混用。

随后增加**逐用户新增功率及方差标签都匹配**的oracle对照：给每用户加各向同性扰动，其方差为 \(\tau-\operatorname{tr}(C_{e,k})/16\)，使用相同基础随机数。各向同性加噪和空间补齐的期望总功率相同，但前者保留空间二阶矩特征值的差异。

| 条件 | 同功率各向同性加噪：平均虚警 / 漏检 | 空间补齐：平均虚警 / 漏检 | 联合均值实际MSE：前者 → 后者 |
|---|---:|---:|---:|
| 0 / −4 dB | 14.25 / 0 | 0 / 0 | 0.12169 → 0.01214 |
| 16 / 4 dB | 31.25 / 0 | 0.25 / 0.75 | 0.63110 → 0.04044 |

同功率对照支持空间误差形状确实影响旧网络与分类器，而非仅仅“噪声更大、网络更保守”。但只有两个支持范围内的物理条件；oracle估计和加噪改变了查询分布，不能推导真实接收机一定能获得这些收益。原始数据见 [同功率对照](whitening_power_controls/SUMMARY.json)。

## 5. 实际优化的优先级

**优先检验多用户干扰的均值和空间不确定性处理。** 当前反馈最终把各用户协方差平均为一个共同标量，会丢失用户和空间方向的区别。值得测试在原始观测坐标中，根据当前其他用户的软信道估计扣除其均值，并让剩余不确定性进入线性LMMSE的矩阵权重；最终保持旧网络所估计的原H坐标。示意模型为

\[
y_{-k}=y-\sum_{j\ne k}B_j\mu_j,\qquad
\widehat\Sigma_{-k}=\sigma^2I+\sum_{j\ne k}B_j\widehat C_jB_j^H.
\]

此处 \(B_j\) 是包含天线维度的公开测量块，\(\widehat C_j\) 是用户j估计误差的协方差模型。第二式是**忽略跨用户误差相关项时的工作近似**；不能将错误的高度确信输出直接认作可靠协方差，也不能声称它保证白噪声。这条候选还须解决启动阶段不可靠活动概率、非正定估计及均值/方差一致性，尚未实现。

[OAMP §III-A–B、III-E](https://arxiv.org/html/1602.06509v3#S3)将去相关线性估计与无散度非线性估计配套使用；统计正交本身仍弱于独立。[非可分去噪器VAMP分析 §III–IV](https://arxiv.org/html/1806.10466v3#S4)还要求高维、右旋转不变随机算子和相应去噪器条件。当前重复块AFDM测量结构不自动满足这些条件。已有全映射散度替换小试验也没有消除漏检，已有逐用户标量方差反馈对照没有整体改善，故应把这些结果纳入下一轮方案，而非重复宣称补一个校正项即可解决。

**备选是显式处理有色误差。** [D-VDAMP §2.2–2.3](https://arxiv.org/html/2010.13211v1#S2)将有色有效误差模型与相应噪声条件网络联合使用，是相关设计先例；MRI的变换结构和经验状态演化不能直接移到本项目。若保留旧网络的前端改进仍不足，再评估必要的噪声条件适配，而不是立即重开多套网络训练。

**导频调整可作单独系统设计对照。** 现有 `PerUserDFTPilot` 在Q=N时可使各用户有效块为酉矩阵，用户相关跨帧相位不破坏这一性质；可消除首轮单用户块失真并使该块的热噪声协方差为标量阵。但其他用户贡献依然保留空间结构，本轮只做代数检查，没有运行新导频接收机。若开展，应对全部baseline使用相同新导频，不能与原曲线混用。

下一步候选应同时检查误差与信道的相关、空间/AFDM二阶矩、实际MSE与报告方差的匹配，以及完整接收机的漏检、虚警、NMSE、轮数和总耗时。目标是改善有效查询及完整性能，不把二阶矩看起来更均匀当作独立AWGN成立的证明。
