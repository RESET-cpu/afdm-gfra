# 当前 proposed 与 Cai 的对应核查

核查日期：2026-10-14。对象为 `configs/proposed.json` 及其绑定的 first、second、activity 三个旧网络；不修改接收机、训练目标、权重或原图配置。

**判断：当前 proposed 可以定位为基于 Cai 的 score 辅助 turbo message passing 框架、面向本项目 AFDM 观测的适配。其核心计算链条成立，但不能称为 Cai 原算法的等价复现，现有实验也没有证明达到 Cai 原文的性能、速度或理论适用范围。**

## 核查来源和范围

- Cai 等，*Joint Activity Detection and Channel Estimation for Massive Connectivity: Where Message Passing Meets Score-Based Generative Priors*，IEEE JSAC 44 (2026)，DOI [10.1109/JSAC.2026.3663274](https://doi.org/10.1109/JSAC.2026.3663274)。本地正式 PDF 为 `references/cai2026_score_based_jadce.pdf`，本目录 `cai_paper.txt` 是新提取的检索文本；公式核查同时参照 [arXiv v2](https://arxiv.org/html/2506.00581v2)。DOI 可解析到 IEEE，但网页正文受机器人验证限制，未将该页面当作全文证据。
- 作者公开仓库固定提交 `0c75680c966dcb8e46250de146f4c27e9294c283`。本轮重新读取 [main_stmp_jadce.py](https://github.com/chang-cai/score-massive-connectivity/blob/0c75680c966dcb8e46250de146f4c27e9294c283/main_stmp_jadce.py)、两个网络定义和配置；主程序 SHA 与此前留存完全相同。核查结论限定于该公开版本，不等同于确认作者生成论文全部图表时的私有运行状态。
- 当前源码、checkpoint 内嵌配置、训练完成记录，以及原图引用的 600 个 off-grid 输出的已有汇总。重新运行了 28 项现有确定性测试；没有新增 Monte Carlo 性能试验，也没有下载、运行作者权重及测试数据。

## 算法对应关系

| 项目 | 原文定位 | 当前实际实现 | 判断 |
|---|---|---|---|
| 整体框架 | §III，式(6)–(42)、Algorithm 1 | `iterations.py`：线性模块 → 外信息 → 完整信道去噪与活动概率 → 联合矩 → 外信息反馈 | 保留核心结构；不是仅在最终估计后追加一次去噪 |
| 线性模块 | §III-A，式(7)–(11) | `linear.py` 对一般已知 AFDM/MMV 算子作 SVD-LMMSE，再投影和相除 | 合理推广；在部分正交算子下与简化公式一致，已测试 |
| 一阶训练及均值 | §IV，式(44)、(48)–(49)、(55) | `direct_objectives.py` 使用 DSM；`moments.py` 实坐标噪声方差为复方差的一半 | 目标形式和 Tweedie 读出对齐；测试未发现系数或符号错误 |
| 二阶训练 | §IV-C，式(53)–(54) | 冻结 first；对全实坐标取平均后平方，学习总迹对应的读数 | 对齐全迹损失；不等同于完整 Hessian 或每坐标二阶量的监督 |
| 方差反馈 | 式(23)、(38)、(56) | 二阶读数先跨用户平均；活动混合后再投影为单一各向同性方差 | 比原文逐天线方差更强的共享近似；不能声称保留完整空间协方差 |
| 活动更新 | §III-B2，式(28)–(30) | `denoiser.py` 用第三个平衡 BCE 分类器，将 logit 加上公开活动先验的 log-odds | 实质性项目改动；不是 Cai 原文解析活动更新 |
| 阻尼 | §V-B1，式(57)–(58) | 两个方向都对均值和方差作算术阻尼，权重 0.1 | 运算类型与作者公开程序一致，取值和停止条件不同 |
| 数值处理 | 原文与公开程序中的方差近似 | 正精度 site 接受、旧 site 复用、支持区间检查、反馈方差比例裁剪、多项停止检查 | 均须单独披露；数值固定点不等于真实后验最优解 |

代码相对路径均在 `src/afdm_jadcedd/algorithm/proposed/` 下，训练损失在 `src/afdm_jadcedd/experiment/training/scores/direct_objectives.py`。完整推导见 `docs/THEORY.md`。

二阶网络的含义需要准确表述。记有限一阶网络的输出为 F，复维度为 D；目前损失的理想回归读数是

\[
\frac1D E[\|F(R,v)-H\|_F^2\mid R,v]
=\frac1D\operatorname{tr}\operatorname{Cov}(H\mid R,v)
+\frac1D\|F(R,v)-E[H\mid R,v]\|_F^2.
\]

只有一阶均值精确时，后项才为零。这是有限网络代入原训练目标后的条件期望分解，不是声称原文已经证明我们网络的实际方差校准。全迹损失也不能唯一识别每个天线的子迹；当前使用总平均方差与这种监督范围相符，但仍是近似。

## 网络和训练并非原样复制

1. **输入与骨干。** 作者程序一阶采用 `NCSNv2`、二阶采用 `NCSN`，单用户输入是实/虚两通道的天线×频率矩阵。当前两个网络都实例化条件 `NCSN` 骨干，加入连续 log-variance MLP，一阶保留 1/sigma 输出缩放；16 根天线连同实/虚打包成 32 个特征通道，卷积平面是 16×16 的 AFDM 输入/输出索引。属于同一 RefineNet 技术路线的改写，不能仅凭 1/sigma 缩放称为完整原版 NCSNv2。
2. **训练分布。** 当前独立抽取复 AWGN 方差 v∈[0.001,100]，连续 log-uniform；实际 checkpoint 的名义去噪 SNR 范围是 −20～30 dB。不能依据 Python 类默认值误写成 −10～30 dB，也不能把该去噪 SNR 等同于图中接收 SNR。
3. **功率归一化。** 原文 §V-B2 式(59)–(65)明确逐样本归一化训练及推断缩放；当前是固定总体 RMS，保留样本间的功率差异。它改变了所学先验，但训练与推断尺度一致，本轮未发现混用两套尺度的错误。若要采用另一种归一化，需要相配的训练及受控实验，不能直接把现有权重的推断入口改掉。
4. **预算与完成状态。** 当前 first 完整训练81轮并选81轮，second 39轮并选39轮；这两项按用户选定预算结束，记录未宣称优化收敛。activity 完成84轮、选82轮，达到所设验证平台期条件。原文 §VI-A2报告两套 score 各400轮。轮数差异不能单独证明我们训练不足，但当前证据也不支持声称已达到同等训练充分性。

上述 checkpoint 身份和选取信息已重新提取到 `CURRENT_EVIDENCE.json`，三文件与当前配置绑定一致。

## 论文与作者公开程序必须分开比较

该固定提交的 `main_stmp_jadce.py` 中：

- `lambda_post_gaussian`（行193–210）使用固定零均值 Gaussian 活跃先验，方差为 `var_h`；没有把同轮 score 产生的 channel extrinsic 均值、方差传入活动概率。它与原文式(28)–(30)采用 channel extrinsic message 的写法有区别。
- `module_B`（行134–166）直接查询原尺度输入，并按最近的离散噪声级选择标签；该主程序未实现原文式(60)–(65)的逐查询功率缩放。
- 主循环按给定迭代数运行，默认30轮、阻尼0.8；基于 NMSE 的停止代码已注释。传入真值用于评分，检查范围内未发现它进入 `module_B` 的估计运算。
- `result_B`（行213–226）只对真正活跃用户的估计计算 NMSE；原图主统计包括所有用户的估计误差。

因此，应分别写“与 Cai 论文的框架对应”和“与其这一公开程序版本的不同”，不能混用二者而宣称逐项完全复现。这里没有据此判定论文整体无效。

## 当前最重要的适用性差距

**独立 AWGN 是学习模块的工作假设，不是线性 LMMSE 完成之后自动成立的有限维恒等式。** 原文 §V-B1本身要求大系统与 right-rotationally invariant random measurement matrix 条件，并承认有限维、特定导频下会偏离。Cai 自身也使用近似；我们沿用该训练方法有文献依据，但其表现与适用性必须在本项目验证。

当前已知算子、有限用户数、共同用户方向和低秩 AFDM 信道不会因执行线性模块而自动满足这些条件。此前实测诊断中的一个30 dB场景首轮查询，残差空间二阶矩的最大特征值占迹约96.10%；把该查询的方差标签改为经验 MSE 仍未恢复匹配 AWGN 下的去噪表现。原始证据见 `results/implementation_audit_20261014/score_algebra_check.json`，本轮只复核该记录，没有重新执行这一查询。

这支持“差距可能涉及误差结构，不能只归因于误差大小”，但它是一个事后选择场景的首轮诊断；不能推广成全场景因果证明，也不能据此判定哪项修改会提高最终接收机性能。

Cai 的完整信道先验来自多角度、多时延的 CDL-C；当前是共同用户方向下的 AFDM 信道。两者都学习完整信道，但路径自由度、观测和导频结构不同。矩阵元素更多、大时延/多普勒或多天线，并不自动证明当前问题更难、也不自动赋予 score 相同的优势。

## 本轮验证与论文表述边界

执行：

```text
.venv/bin/python -m pytest -q tests/test_cai_derivation_audit.py tests/test_activity_classifier.py --junitxml=results/cai_alignment_20261014/TESTS.xml
```

结果：28 passed，21条 AFDM 矩阵乘法 RuntimeWarning；相关确定性数值比较全部通过。警告原样留在测试记录中，未删除样本或放宽容差。测试涵盖精确混合先验下的 Tweedie 实/复系数、全迹监督的识别范围、活动先验校正、一般 LMMSE 到部分正交公式的退化和完整活动特征。它们验证计算关系，不验证训练达到理想 MMSE，也不构成完整性能复现。

目前可以作出的表述是：**基于 Cai 的 score 辅助 turbo message passing 框架，将完整信道先验学习和外信息迭代适配到当前已知算子的 AFDM 接入问题，并采用学习型活动概率更新。**

目前不能据此作出的表述包括：完整复现 Cai 的 STMP-JADCE；已达到或超过其性能和收敛速度；AWGN 近似在当前场景严格成立；仅移植框架便已证明独立算法创新。

若要声称对 Cai 作了有效改进，关键缺项是在相同 AFDM 输入和相同 score 权重下，分开比较原文解析活动更新、作者公开程序的固定 Gaussian 活动更新、当前分类器更新，并报告误差、失败与成本。它可作为消融证据，不要求重排用户已确定的五个 baseline。归一化、骨干及训练充分性则需要各自的配对控制，不能从本轮静态核查直接断言改成原版一定更好。
