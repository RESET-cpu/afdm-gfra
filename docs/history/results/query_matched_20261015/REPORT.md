# 实际查询诊断、分类器续训与闭环验证

## 1. 做了什么

按[预定协议](../../experiments/query_matched_20261015/PROTOCOL.md)推进：

1. 历史未知相位面板前8个物理场景，SNR=−4、−2、0、6 dB，32条件全部复跑。每条件保存1、10、30轮和终态，共128快照，所有40用户均纳入，没有筛选失败用户。
2. 对1、30轮和终态作4类Gaussian控制，每类2次独立噪声重抽；原输入96份，合成输入768份。它们仍来自8个场景，不能当作864个独立物理样本。
3. 场景0–5训练、6–7验证，所有SNR及轮次按物理场景整体划分。冻结均值、风险网络和分类器特征，只续训原分类器最后128权重+1偏置，最多2000步。
4. 依据预定验证约束选出第250步，再放回原递推，在2个验证场景×4 SNR做完整闭环对照。推断公式、0.5后验阈值及停止条件在所有SNR相同。
5. 候选开发指标变差，未进入预留10新场景×6 SNR确认；未生成或读取这些测试样本。原因记录在[确认状态](CONFIRMATION_STATUS.json)。

同时完成了独立CPU小系统控制，用精确联合活动边际化检查平均干扰Gaussian近似。它与物理接收机性能严格分开。

## 2. 复跑与公式核验

32条件的连续输出与历史输出逐元素相同，最大差为0；原主线源码、配置和三个权重没有改变。全部128快照的Gaussian site均被接受，故本批即时pF与使用的条件均值相符；终态pF与原输出最大相对差2.47×10⁻¹⁶。保存特征重建原分类概率最大误差6.81×10⁻⁸。

对复数协方差采样，用确定性正交噪声验证Lz的二阶矩，误差1.88×10⁻¹⁵。[QUERY_QA](QUERY_QA.json)

首次离线特征乘法出现NumPy矩阵乘法RuntimeWarning，但输出有限且核验通过；随后改为等价显式收缩，并在警告视为错误的模式下通过。初次记录保留于[QUERY_QA_INITIAL](QUERY_QA_INITIAL.json)。该修订没有改变接收机或采集数据。

本轮说明：

- **早期方差标签失配有实际影响。** 第1轮活跃用户MSE/v的5/50/95百分位为0.679/1.147/1.602，非活跃为0.637/1.089/1.550。合成功率控制仍沿用原标签，明确检验这种失配，而不是已修正标签的网络。

## 4. 小系统证明平均干扰近似可能丢失活动信息

200个独立Gaussian场景，K=8、N=Q=4、C=64、ρ=0.1；枚举256种活动支撑，使用同一0.5判决阈值。含93个空活动场景，全部保留。各SNR复用场景，1600判决/SNR。

| 方法 | −4 dB AER | 0 dB AER | 6 dB AER |
|---|---:|---:|---:|
| 精确联合边际后验 | 0.875% | 0.313% | 0.125% |
| 公共ρ平均干扰Gaussian近似 | 13.313% | 14.688% | 17.125% |
| 已知其他用户活动oracle | 0.188% | 0.063% | 0% |

该控制验证了**在这个明确模型中，平均二阶矩近似不足以替代共同活动混合的边际化**。全部600条件和1800方法输出已重新生成并逐数组复现。K=40枚举代价不同，物理AFDM列也非本控制的独立Gaussian列；这些数值不计入Proposed成绩。[完整报告与复现](support_control/REPORT.md)

## 5. 分类器轻量续训：离线改善没有转成闭环改善

本轮是隔离实验：只动原分类器最终129参数，均值、风险及卷积特征全部冻结。用训练集特征均值和尺度标准化增量权重，采用类别平衡logistic损失与固定L2约束，最后将增量折回原线性层。保持原活动先验修正及0.5阈值，不增加SNR分支。

验证时同时看全部阶段后验BCE、各SNR终态错误数与pF NMSE；step0也作为候选。2000步的验证BCE下降，但高SNR错误开始增多，故依预定约束选择250步。250步全部阶段BCE由59.244降至53.038，终态验证−4 dB漏检仍为1。落盘float32后的判决与选择结果已核对。[训练记录](readout_training/HISTORY.json)、[选择记录](readout_training/SELECTION.json)

**放回原反馈循环后的完整结果如下。** 每档只有2个历史验证场景、80次用户判决，属于开发结果；全部16次原版/候选输出完成且收敛。

## 6. 本轮结论与剩余问题

**这轮已经把“输入不匹配”的判断细化了，也完成了一次实际查询训练和闭环验证；尚没有可替换主线的新接收机。**

早期需要关注方差标签及未建模相关；终态漏检更突出的是反馈沿弱信号方向抵消。共同活动Gaussian控制也显示，平均协方差与完整活动混合并不等价。现有证据不支持把这些问题全部交给分类器最终线性层补偿。

后续较大的模型改动应涉及与实际线性消息匹配的均值、活动及不确定性，而不是继续扩大本轮末层训练步数。需要更多独立训练场景，或先验证可实现的活动条件化/边际化近似，再决定完整网络训练；本轮没有执行三网络联合训练或端到端展开，也没有证明此类方法一定有效。原推断与原分类器权重保持选定主线。
