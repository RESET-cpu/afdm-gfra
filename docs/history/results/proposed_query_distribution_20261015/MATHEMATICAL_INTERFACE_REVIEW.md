# Gaussian 局部因子与实际查询条件分布不能混用

这是本轮训练和闭环实验完成后的数学复审，不回写实验前协议或删除失败结果。

令物理先验为p(H)，线性模块传来Gaussian因子

    q_A(H) ∝ CN(H;R,vI).

局部更新计算的是

    b(H;R,v) = p(H) q_A(H) / ∫p(H)q_A(H)dH.                 (I1)

在相同先验和归一化下，AWGN训练的精确条件均值等于(I1)的均值，对每个R、v均成立。
**这一点不要求实际算法产生的R真的等于H加独立Gaussian噪声。**
实际查询失配说明Gaussian工作因子及其标量压缩需要进一步检查，
不能仅由失配宣布Tweedie恒等式或原局部积分本身错误。
有限网络在不同查询区域的误差仍需要单独验证。

用原算法轨迹监督训练得到的另一对象是

    m_actual(R,Z)=E[H | R_actual=R,Z],
    risk(R,Z)=E[||H−F(R,Z)||²/D | R_actual=R,Z].            (I2)

通常(I2)的条件分布不同于(I1)。即使m_actual和其方差估计完全准确，
也不能直接套用(I1)所对应的Gaussian因子相除。风险还满足

    risk = tr Var(H|R,Z)/D + ||E[H|R,Z]−F(R,Z)||²/D,        (I3)

因此有限均值预测器的实际MSE并不自动等于(I1)或(I2)的后验方差。
本轮候选保留了原Gaussian相除，但把实际轨迹风险送入这一接口；
这只是一项经验性替换，缺少保持同一局部概率对象的推导。
其离线风险损失下降不能为原TMP的数学一致性背书，闭环失败也不能归因于唯一一个因素。

## 一个即使预测器完美也失败的反例

取H~CN(0,1)、R=0.5H+ε、ε~CN(0,1)，观测R=2+0.5i。
真实后验为m=0.4R、u=0.8。若错误地除去单位响应CN(R;H,1)，得到

    site_precision = 1/u−1 = 0.25,
    site_natural   = m/u−R = −0.5R.                       (I4)

它没有恢复原先验的精度1、自然均值0，反而把数据R带进了先验消息。
除去正确的响应0.5似然（精度0.25、自然均值0.5R）才恢复原先验。
用工作均值F=0.5R时，真实条件风险为0.8425，也不等于真实后验方差0.8。

上述反例和64个非特定生成来源的复数查询点已独立数值核验：
[MATHEMATICAL_INTERFACE_CHECK.json](MATHEMATICAL_INTERFACE_CHECK.json)。
后者用有限差分核对Bernoulli–Gaussian先验的逐点Tweedie均值恒等式；不是物理接收机性能实验。

## 对下一步修正的约束

下一步应先把**待近似的外部似然/消息**明确写出来，再决定保留哪些方向响应、
其他用户活动混合和相关项，并让非线性模块与该因子计算同一个(I1)类型的局部矩。
不能继续把实际查询的监督MSE当成新的Gaussian site方差直接回填，
也不能仅凭边缘四阶矩或平均功率接近Gaussian就忽略本轮发现的方向偏差。
若改用直接监督的完整接收机，则需要另立完整推断模型并验证，不沿用原TMP精确相除的解释。
