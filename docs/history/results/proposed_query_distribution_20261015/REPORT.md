# 实际查询与其他用户反馈误差：全量诊断及修正试验

## Material Passport

- Origin Skill：academic-research-suite / experiment-agent；inline validate + authorized implementation。
- 2026-10-15启动，2026-10-16汇总。本轮已完成；整体“发现问题并解决”的目标仍未完成。
- 样本：原主线8个历史开发场景、4档SNR、第1/10/30轮与终态，共128快照、5120条用户记录；全部用户保留。
- 新增：64快照的320次离线网络批查询、一个小型条件修正网络训练、2条件×2版本完整闭环。
- 原主线源码、配置、权重及只读副本保持不变。所有统计真值、oracle控制与实际推断分开。

**结果：独立标量Gaussian工作信道不能充分描述实际查询；但把其他用户误差直接去相关、
或把实际MSE回填为原消息方差，都没有解决问题。新候选已淘汰。**
另一个重要区分是：实际查询不满足AWGN，不等于原先验×Gaussian因子的局部Tweedie公式无效。
该接口区别决定了后续修正必须针对什么概率对象。

## 1. 单位响应与独立标量噪声的联合描述失配

在工作假设 `R|H,v ~ CN(H,vI)` 下，活动用户的

    z = Re⟨H,R−H⟩ / sqrt(v||H||²/2)

应具有标准正态边缘。下表每格包含36个活跃用户，来自8个相同物理场景；
用户、重复SNR及轮次不是独立样本，因此不作二项显著性检验。

| 阶段 | SNR / dB | 查询方向响应中位数 | z中位数 | 绝对z超过3的比例 |
|---|---:|---:|---:|---:|
| 第10轮 | −4 | 0.101 | −18.608 | 100% |
| 第10轮 | −2 | 0.244 | −16.965 | 100% |
| 第10轮 | 0 | 0.449 | −14.271 | 100% |
| 第10轮 | 6 | 0.768 | −9.545 | 91.7% |
| 终态 | −4 | 0.966 | −0.848 | 13.9% |
| 终态 | −2 | 0.962 | −1.081 | 8.3% |
| 终态 | 0 | 0.969 | −1.388 | 16.7% |
| 终态 | 6 | 0.974 | −2.202 | 33.3% |

这里检验的是整个条件工作模型；单个方向投影不能单独证明确定性增益是多少，
也不能把所有偏差唯一归于其他用户反馈。
进一步使用固定实际W的Gaussian颜色，并把总功率换成真实误差功率的oracle参照，
第10轮−4 dB的z中位数仍为−18.669，终态6 dB仍为−2.176。
方向偏差不能仅由标量功率标签或W引入的输入轴颜色解释。

精确分解保留了阻尼。第10轮−4 dB活跃用户的阻尼余项方向贡献中位数为−0.670，
其他用户残余为−0.223；终态分别约−0.0003、−0.0203。
不同轮次的主要项不同；这些中位数不能直接相加来重构中位总响应，也不是修改阻尼的闭环因果结论。

## 2. 边缘看起来接近Gaussian，仍然不是独立白噪声

−4 dB终态，所有320个用户的实际查询误差：

- 功率/原标量标签的中位数为1.00182。
- `E_sample|e|⁴ / (E_sample|e|²)²` 的用户平均为1.9968，接近proper complex Gaussian的2。
- AFDM输入轴二阶矩的标量偏离为0.9851；同尺寸IID Gaussian参照为0.2495，固定W Gaussian参照为0.9871。
- 天线轴对应偏离为0.3198；IID参照0.2494，固定W参照0.3457。

因此，四阶矩和总功率都可能“看起来对”，但输入轴相关仍很强。
部分天线轴样本偏离可由固定W的有限样本Gaussian参照解释，不能全算成额外非Gaussian干扰。
固定W参照也删除了W与同一观测的依赖，不能宣称是实际噪声的完整条件分布。

## 3. 其他用户误差不是39个同等、独立的小贡献

令 `Ckj=WkAj(Hj−Zj)`，保留全部j≠k分量。在−4 dB终态的活跃目标中：

- 按分量能量计算的 `(ΣE_j)²/ΣE_j²` 中位数约2.99，5–95%范围1.73–6.49。
- 最大单用户贡献的能量占比平均约38.5%。
- 全部目标的干扰总能量/各分量能量之和平均0.870，包含不能省去的交叉项。
- 第10轮该能量比平均升至4.779；反馈与热噪声的归一化实内积平均约−0.141。

初始反馈误差H−Z中88.75%的用户块为零；活动块的天线方向接近秩一。
终态原反馈误差及其他用户合成项仍有明显的轴向结构。所有零块都单独标记，
没有把零块的未定义标准化统计填成正常Gaussian数据。

这些证据不足以支持“用户多，所以反馈误差自然变成IID Gaussian”。
它们也不要求反馈本身必须Gaussian：OAMP的Assumption 2要求的是IID及与A、噪声独立，
不同于其Assumption 1对线性输出误差的Gaussian要求。
参见[Ma–Ping §III-E](https://arxiv.org/html/1602.06509v3#S3.SS5)。

## 4. 保持其他用户项的二阶矩，也不能随意打散依赖

针对全部32条件的第10轮和终态，将其他用户残余换成
`Σ ξ_j Ckj`，ξ分别取独立单位圆相位、CN(0,1)。给定全部C，两种控制有相同的完整二阶矩；
后者为Gaussian。它们删除了原分量与信号、热噪声及其他项的依赖，并不保持每次总误差功率。

−4 dB终态离线判别：

| 输入 | 漏检 | 虚警 | 判决数 | 活动错误率 |
|---|---:|---:|---:|---:|
| 原查询 | 3 | 0 | 320 | 0.938% |
| 其他用户分量独立相位重抽 | 0 | 200 | 640 | 31.250% |
| 匹配二阶矩的Gaussian系数 | 0 | 193 | 640 | 30.156% |

重抽每条件2次，因此分母加倍；不能当作物理场景翻倍。这些是oracle离线控制，
不是新接收机成绩。结果表明原相关结构也包含有益的抵消，
不支持“只要把干扰Gaussian化就会变好”；它没有唯一定位损失来自哪一类高阶关系。
全部SNR、阶段及概率保存在 [controls](controls/SUMMARY.json)。

## 5. 一次实际查询适配没有形成可用修正

新增47,394参数的条件修正网络，输入R、原反馈Z、原条件均值、v及反馈方差，
不接收SNR、轮次、用户编号或真值。原三网络固定。场景0–5训练，6–7验证，属于历史开发数据。

均值和活动共同训练600步。验证BCE由59.244降至最低46.974，但所有训练后检查点都增加了终态活动错误，
且条件均值误差未通过预定限制。因此选中的是原零修正。
随后只校准条件风险300步，验证风险损失由5.984降至0.919。
该风险修正进入原完整消息循环后，结果如下：

| 条件 | 原版漏检/虚警 | 候选漏检/虚警 | 原版NMSE / dB | 候选NMSE / dB | 候选轮数 |
|---|---:|---:|---:|---:|---:|
| scene003 / −4 dB | 2 / 0 | 7 / 0 | −5.506 | 约0 | 600 |
| scene007 / −4 dB | 1 / 0 | 0 / 32 | −6.010 | 19.937 | 600 |
| 合并 | 3 / 0 | 7 / 32 | −5.758 | 17.091 | — |

两条候选都在第4轮超过原网络v≤100的支持范围；分别有530、525轮复用旧site，
均达到最大迭代数。首轮风险从约0.22增加到约3.1后，后续轨迹大幅改变。
完整失败、所有检查点及警告保留，候选不采用；没有放宽支持范围或挑选最佳中间轮次。

## 6. 数学接口的复审：不能用错误的局部概率对象修补

AWGN条件均值是 `p(H)×CN(H;R,vI)` 这一局部分布的均值，逐点成立，
并不要求算法真实生成的R是独立AWGN观测。
从实际轨迹直接监督得到的 `E[H|R_actual,Z]` 和实际MSE通常对应另一个条件分布。
后者不能不经重新推导就代入原Gaussian因子相除。

甚至在一个一维、预测器完全准确的Gaussian例子中，响应为0.5时，
把真实后验除以单位响应似然会得到先验精度0.25，而正确先验精度是1。
此外，有限均值预测器的条件风险还含均值偏差平方，不能自动当作后验方差。
所以本轮风险修正不仅有闭环失败，还存在维持原TMP接口所需的概率解释缺口。

详见[数学复审与反例](MATHEMATICAL_INTERFACE_REVIEW.md)。64个复数查询点的逐点恒等式核对通过，
最大均值误差3.36×10⁻¹⁰。来源与局部因子规则参见
[Cai §III-B、§IV](https://arxiv.org/html/2506.00581v2)及
[Minka §2–3](https://tminka.github.io/papers/ep/minka-ep-uai.pdf)。

下一步须从明确的外部似然/消息近似出发，保留必要的方向响应和其他用户结构，
让均值、活动及协方差仍对应同一个局部因子。不能继续盲目补噪、随机化误差或回填实际MSE。
尚无通过闭环及独立确认的修正，整体目标保持进行中。
