# 实际网络输入的误差功率与相关项

2026-10-15。本阶段直接分析旧输入维/空间组合候选的实际网络输入，
不再用残差矩阵估计误差大小来代替网络输入误差。
4个已有开发条件、各首末轮，共8个完整查询；零新增接收机运行、网络调用和训练。
原Proposed及全部已有候选保持原状。

## 实际查询与间接协方差估计不同

用户平均的末轮真实误差功率/网络方差标签为0.99832、0.99998、1.01466、1.00690，均接近1。
前阶段的投影反馈协方差矩阵相对误差很大，不能据此宣称实际网络输入也有同等程度的方差失配。
当前工作矩阵、反馈传播和噪声交叉项存在抵消，不能独立“纠正”其中一项便认为整体更准确。

## 从已有公开记录重建，无须重跑网络

旧补噪路径与后续半正定平方根路径严格区分。本阶段使用原组合候选保存的查询r，
以及曾严格复现其预测的measurement_response阶段保存的补噪特征向量和特征值。
按原随机流恢复g，令r0=r−g，再由

    Z = solve(I−AW, Y−A r0),
    S = r0−W Z

恢复当时进入线性模块的平滑反馈。该恢复只用公开输入、固定W及原运行的内部记录。
四条件I−AW条件数均小于1.663；8/8公开重建通过，最大相对误差3.55e−14。
检查包括首轮S=0、残差空间矩阵及工作系数与原记录一致。
全部公开重建检查保存后，才读取真值做分解。

20组合成复数阵列验证重建与协方差展开，最大相对误差3.52e−16。
静态检查曾在实际分析前修正一个输出字段的单位，原代码及冻结记录保留于
[修订记录](PRE_ANALYSIS_REVISION.md)，未改公式、阈值或观测结果后再改规则。

展开为七项，包含反馈传播、反馈工作矩阵偏差、热噪声样本项、两类交叉项及工作补齐误差。

## 空间样本偏离不能一概解释为额外有色干扰

同一个N经当前固定W后仍是Gaussian。其天线维总体二阶矩为sigma² n_k I，
但AFDM输入坐标有相关性，空间样本矩阵因此有可观的有限样本波动。
8个查询分别与同一噪声实现的WN比较，而非把用户当作40份独立噪声。

| 条件 | 首轮实际查询空间偏离 | 末轮实际查询空间偏离 | 相同WN的空间偏离 | W引入的输入坐标总体偏离 |
|---|---:|---:|---:|---:|
| scene000 / −4 dB | 0.2547 | 0.3025 | 0.3118 | 0.7372 |
| scene008 / 0 dB | 0.2499 | 0.2730 | 0.3057 | 0.7381 |
| scene016 / 4 dB | 0.2481 | 0.2871 | 0.3164 | 0.7442 |
| scene024 / −4 dB | 0.2523 | 0.2748 | 0.3115 | 0.7445 |

前三列均为每用户样本空间矩阵用自身迹归一化后偏离标量矩阵的Frobenius度量，再取用户平均。
第四列由公开W计算，是总体输入协方差的确定性偏离，不含有限样本误差。
所有用户及活动/非活动分组数据保留；这不是Gaussian性、独立性检验。

进一步由proper complex Gaussian四阶矩展开可得，令G_k=W_k^H W_k，
以已知总体方差归一化的空间偏离D满足

    E[D_k²] = (M/R) tr(G_k²) / tr(G_k)².

推导中，不同天线行独立；每个样本空间矩阵元素的方差为
sigma⁴ tr(G_k²)/(R N²)。将M²个元素相加并除以M(sigma² tr(G_k)/N)²，
即得上式。这一总体矩关系不依赖反馈正交或AWGN查询假设。

本实验M=R=N=16，单用户IID Gaussian的RMS参照为0.25；
当前W的Gaussian参照为约0.311。用户平均共享同一N，其参照使用sum_k G_k，
RMS约0.252，不能误用独立40用户的0.0395。
这些是均方尺度而非实际查询的置信区间；图中与已知方差归一化的对应指标比较，
没有混用表中按样本迹归一化的数值。

因此，现有首末轮证据不支持把“空间样本矩阵不完全像I”全归因于未处理的多用户干扰。
更明确仍存在的是输入坐标相关：W_k W_k^H本身明显非标量。
四条件的反馈/热噪声交叉项也非零，估计反馈矩阵时必须连同它处理。
这些判断不等于实际查询已经AWGN，更不意味着所有轮次或反馈都满足目标。

## 下一步依据

不将新空间矩阵约束接入闭环。接下来优先比较每轮一致、输入维热噪声严格白化的固定W
与现有空间处理的组合，作为一个明确的噪声/性能取舍候选。
旧独立极因子试验曾造成明显性能损失，仍保留该证据；本轮没有重做该接收机或宣称克服该损失。
