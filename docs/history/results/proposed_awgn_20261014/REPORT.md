# 近似 AWGN 查询与每轮反馈：顺序实施结果

研究启动于2026-10-14，整理完成于2026-10-15。主线、配置和旧三个网络保持不变。

**本轮确实改善了部分候选的误差统计，但没有得到性能合格的新接收机。** 一般去噪器 D-OAMP、两种导频对照、每轮空间协方差处理及其与酉导频的组合均已实际实施。空间处理明显改善早期输入与反馈的相关性，却增加噪声功率，完整性能未通过。不能将“协方差更白”写成算法优化已经成功。

## 范围与材料状态

- Origin Skill: academic-research-suite，实验规划、执行与统计解释。
- 材料：已有四个开发条件、公开观测、冻结接收机与权重、[前置文献和公式调研](../../references/awgn_linear_design_20261014/REPORT.md)。
- 本轮是4个物理场景下的32次接收机运行，不是32个独立场景，也不是同一批场景上的SNR曲线。另有数学测试、诊断查询和算术等价核验。
- 推断只接收观测、有效算子、物理噪声方差、活动先验；真值在推断结束后用于统计。全部失败和预算耗尽记录保留。
- 候选预算为240个完整40用户score批次等价调用；主线每轮一阶、二阶网络各一次，D-OAMP每轮两次一阶网络。活动网络调用另行记录。诊断用AWGN查询不计入接收机推断成本。
- 质量要求为：不增加活动错误，汇总NMSE损失不超过0.1 dB，单条件不超过0.25 dB，同时有统计或计算收益。失败条件不能从汇总中剔除。
- 详细设定：[协议](../../experiments/proposed_awgn_20261014/PROTOCOL.md)、[冻结清单](PLAN.json)、[汇总](SUMMARY.json)、[逐条件数据](RESULTS.csv)。

## 1. 噪声功率准确，并没有解决旧网络失配

对第一阶段D-OAMP的首轮查询，保持同一真实信道，另生成独立AWGN。噪声功率采用原查询的声明方差；原查询实际MSE与标签之比已经为0.9993–1.0026，因此这组对照基本排除了“仅仅是噪声功率不同”的解释。

| 场景 / SNR | 真实查询的一次联合去噪NMSE | 同信道、同功率AWGN查询NMSE | 真实查询虚警 / 漏检 | AWGN查询虚警 / 漏检 |
|---|---:|---:|---:|---:|
| 000 / −4 dB | +11.808 dB | −11.991 dB | 38 / 0 | 0 / 0 |
| 008 / 0 dB | +11.853 dB | −8.611 dB | 33 / 0 | 0 / 1 |
| 016 / 4 dB | +13.361 dB | −13.309 dB | 37 / 0 | 0 / 0 |
| 024 / −4 dB | +10.463 dB | −7.669 dB | 34 / 0 | 0 / 0 |

这不是可实现接收机的性能上界；AWGN对照使用了真实信道，只用于解释误差分布的影响。第二组按实际MSE匹配功率的对照也已保存。此结果强烈支持当前输入分布失配的重要性，但不能证明它是所有振荡或全部性能损失的唯一原因。

原始证据：`current_operator/scene*_doamp.controls.json` 与对应 `trajectory.json`。使用相同冻结联合映射 pF、活动先验和归一化，未为AWGN对照换网络。

## 2. 第一阶段：一般去噪器的 D-OAMP

实现沿用实际A的迹归一化LMMSE，完整pF的有符号Monte Carlo散度，SURE反馈增益，并从公开观测残差单独估计下一轮反馈误差功率。没有用二阶网络风险代替散度，也没有把负散度截成小正数。这是[D-OAMP Algorithm 2及§3.3式(7)–(11)](https://arxiv.org/html/1610.05991v1)的项目适配；复数归一化与近似条件见前置报告。

四个条件都在第二次网络查询前失败：所需查询方差依次为1064.96、6001.11、4205.93、4409.67，超过旧网络0.001–100的支持范围。

| 场景 | 首轮散度α | 查询—反馈误差相关系数的实部 | 公开残差估计的下一轮反馈功率 | 反馈实际MSE |
|---|---:|---:|---:|---:|
| 000 | −0.1111 | 0.4270 | 27.219 | 0.8317 |
| 008 | −0.2316 | 0.5997 | 153.702 | 4.4766 |
| 016 | −0.5462 | 0.7900 | 107.809 | 2.8889 |
| 024 | −0.0999 | 0.4016 | 112.639 | 3.5561 |

残差估计高于实际反馈MSE约32–37倍。它不是任意自适应反馈下的代数恒等式；当前反馈与测量方向的相关性破坏了其统计前提。仅纠正散度和风险之间的关系，不能自动修好有色输入。该结果否定的是当前适配在这四条件下的有效性，不是对D-OAMP原论文的否定。

## 3. 第二阶段：改变导频

保持四个物理信道和标准化噪声实现，构造每用户酉导频及独立复Gaussian导频。实际噪声方差重新按各自干净接收能量设置，以匹配接收SNR；因此不是相同物理噪声方差的对照。Gaussian导频每帧能量只在期望上相同，实际波动已记录于[PILOT_INPUTS.json](PILOT_INPUTS.json)。

两种新导频的D-OAMP都仍在第二轮失败，共8/8。原接收机的结果如下：

| 导频 / 原接收机 | 四条件汇总全信道NMSE | 漏检 / 虚警总数 | 按原停止规则收敛的条件数 |
|---|---:|---:|---:|
| 当前导频 | −9.700 dB | 1 / 0 | 4 / 4 |
| 每用户酉导频 | −8.177 dB | 3 / 1 | 3 / 4 |
| 独立Gaussian导频 | −8.165 dB | 2 / 1 | 1 / 4 |

汇总NMSE为先累加误差能量与信号能量后取比值，不是平均dB。运行到预算上限仍有结果的条件保留，但不称为收敛。四个开发条件不足以证明某种导频普遍更差；足以说明这两种直接替换没有解决当前问题，不能作为无验证的主线升级。

酉导频的作用边界仍然成立：Q=N时，它消除目标用户自身反馈项，并保持该用户热噪声为白。但它不消除其他用户误差的空间协方差。独立Gaussian基础矩阵也不保证MMV误差状态是标量；一般状态可以是矩阵。[Liu–Yu §III-B式(14)–(17)](https://arxiv.org/html/1706.06438v2#S3)

## 4. 第三阶段：每轮处理空间协方差

这个候选各轮使用完全相同的规则：从公开残差二阶矩中减去热噪声，投影为正半定并作预先固定的10%收缩；据此进行共同空间协方差LMMSE和逐特征方向的迹归一化；再给低方差方向增加独立Gaussian扰动，使模型空间协方差成为vI。最后使用与第一阶段相同的实际散度及反馈增益。

它不读取真实误差，不使用旧二阶网络构造矩阵反馈。每轮补噪独立于已有历史；不复用固定随机噪声，也不挑有利噪声实现。超过旧网络支持范围时失败，不截断后假称完成白化。工作协方差正确、误差Gaussian且与信道独立等条件仍需验证，不能由这一步构造自动推出。

协方差形状指标定义为

\[
\delta_C=\frac{\|\widehat C-\frac{\operatorname{tr}\widehat C}{16}I\|_F}
{\operatorname{tr}(\widehat C)/\sqrt{16}}.
\]

按用户计算并取平均。每个16维协方差使用256个展开坐标，因此纯AWGN的有限样本值约0.25，不应要求零；其他轴相关也会改变该指标的有限样本分布。

| 场景 | 首轮空间δ_C：标量 → 空间处理 | 查询—反馈相关系数实部：标量 → 空间处理 | 模型误差功率增加 |
|---|---:|---:|---:|
| 000 | 1.095 → 0.251 | 0.427 → −0.002 | 6.42 dB |
| 008 | 1.798 → 0.250 | 0.600 → 0.004 | 8.39 dB |
| 016 | 2.662 → 0.253 | 0.790 → 0.002 | 10.01 dB |
| 024 | 0.956 → 0.255 | 0.402 → 0.010 | 5.85 dB |

上述功率增加相对空间LMMSE的补噪前工作协方差，不是相对最终NMSE。首轮声明功率与实际MSE也较接近，但协方差、相关性和功率三个指标改善，仍不等于所有坐标都已独立Gaussian。

完整接收机的代价很明显：

| 000 / −4 dB | −12.211 | −10.811 | 120轮预算耗尽，0漏检0虚警 |

## 5. 对当前机制的判断

**已验证：** 同信道同功率的独立AWGN对照使旧网络恢复明显更好的单次去噪和活动检测；正确功率标签不足以描述真实查询；每轮空间处理能显著改善早期协方差形状和查询—反馈相关性，但本次完整性能不合格。

**合理解释：** 少量活跃用户的共同阵列方向使早期干扰集中在少数空间方向；同一基础A重复作用于各天线与AFDM输出坐标，标量校正不能覆盖全部特征相关。为让各方向方差相同而抬高到最大特征值，会丢失原来低噪声方向中的信息。准确协方差条件下，这是相对于保留原始有色观测的噪声增加；这里并未证明所有白化方法都必须付出相同代价。

**仍需区分：** 原接收机收敛时MSE/v约0.995–1.011，但AFDM输入轴δ_C仍约0.982–0.996，同尺寸AWGN对照约0.25。空间δ_C约0.31–0.34的一部分可由其他轴相关造成的有限样本波动解释，不应全归为总体空间颜色。近似Gaussian的边际四阶矩也不能证明坐标独立。

正确的推断目标应是“去噪输入的条件模型可信、反馈正交性和误差功率自洽”。一般OAMP不要求非线性反馈误差本身在所有坐标上都严格IID Gaussian；要求它逐坐标AWGN会把任务定义得过强。[OAMP §III-A/B](https://arxiv.org/html/1602.06509v3#S3)

## 6. 后续应怎样做

继续无限增加噪声以保留旧AWGN接口，当前证据不支持。更有依据的下一阶段是**让线性模块输出可预测的有色误差统计，训练与该统计配套的去噪器，再建立一致的矩阵反馈**。这仍可各轮使用同一规则；不需要给第一轮特殊待遇。

[D-GEC §III-B式(41)，pp.535–536](https://phil-schniter.web.app/pdf/jsait22_dgec.pdf)提供了直接先例：网络同时接收有色噪声观测及同协方差的独立噪声样本，用干净信号监督训练。本文献是MRI中的结果，不能据此直接保证AFDM收敛或性能；它说明了协方差信息如何进入去噪器的一个可实施接口。

具体设计和先后验证条件见[NEXT_DESIGN.md](NEXT_DESIGN.md)。关键是从公开算子和预先定义的Gaussian误差模型生成训练扰动，训练整个噪声统计族；不按某几个失败接收机轨迹加入负导数惩罚。活动概率也必须匹配该噪声模型。改善有色Gaussian去噪，并不自动证明实际反馈误差已Gaussian，因此需要重新核验完整递推。

本轮尚未启动这项新训练，也没有把它描述为已实现的优化。现有主线继续保持旧三网络、原LMMSE/外信息更新、新值阻尼0.2、不加首轮处理。

## 7. 数值核验与复现

四项数学测试通过，包括小维完整Gaussian模型与SVD实现、非MMSE映射的有符号散度风险关系、酉导频自身反馈抵消、空间协方差传播及补噪恒等式。

原主线运行产生了NumPy矩阵乘法的RuntimeWarning，记录未隐藏。先核验空间乘法后仍有警告，进一步将Gaussian外信息中的矩阵乘法替换为独立显式求和，仅在核验进程生效：3042次空间乘法和338次外信息更新逐次一致；四个最终信道估计、概率与保存结果完全一致，核验路径没有未捕获警告。该证据验证本次计算结果一致，不解释系统库警告的底层原因。记录见[NATIVE_ARITHMETIC_CHECK_FULL.json](NATIVE_ARITHMETIC_CHECK_FULL.json)；先前部分核验也保留。

实验入口位于 `experiments/proposed_awgn_20261014/`。每个阶段的 `DESIGN.json` 记录当时源码哈希，`RESULTS.json`记录输入、真值、输出哈希及停止原因；失败保存堆栈，逐轮统计和配对控制单独保存。新阶段名不得覆盖已有目录。图与汇总可独立重新生成，详见[分析产物清单](ANALYSIS_MANIFEST.json)。

所有指标来自有限开发样本，不作显著性、论文最终排序或新场景泛化主张。本轮没有合格候选进入独立确认阶段。
