# 有色误差统计与去噪器配套的后续设计

日期：2026-10-15。状态：已推导的实施设计，尚未训练或验证。主线保持冻结。

当前结果表明，旧网络对匹配AWGN查询仍有能力，但每轮通过补噪获得更白的输入会明显牺牲精度。下一阶段应先验证有色Gaussian条件去噪的收益，再决定是否训练并接入完整接收机。不能先声称该路线保证AWGN或保证比当前主线更好。

## 1. 条件模型要保留原信道坐标

用实坐标书写，避免复数方差的因子二混淆：

\[
r=h+e,\qquad e\mid C\sim\mathcal N(0,C),\qquad e\perp h\mid C.
\]

这里C是在去噪时给定的误差统计模型。复数各向同性噪声每坐标功率为v时，实坐标协方差为(v/2)I。匹配条件score满足

\[
D_C(r)=r+C\nabla_r\log p_C(r),
\qquad J_{D_C}(r)=\operatorname{Cov}(h\mid r,C)C^{-1}.
\]

第二式在固定C下求导。它给出后验均值、Jacobian与后验协方差之间的一致性关系，不允许将一个独立风险网络的输出直接代替实际Jacobian。[Dytso–Poor–Shamai，Proposition 1，式(22)](https://arxiv.org/pdf/2104.01883)。有限神经网络不自动满足该关系，必须测量误差。

在线估计的C_t本身依赖观测与历史。固定C的去噪Jacobian不等于整个闭环对数据的完整导数；忽略这部分数据依赖需要单独说明近似条件。

直接对r乘C^{-1/2}会同时改变h的先验。此方案在原坐标中给网络提供C的信息；不以“白化后再乘回去”作为旧网络保持匹配的理由。

## 2. 训练噪声可以由公开线性操作生成

对于一个固定工作协方差和当前线性算子W，取独立Gaussian反馈误差Q及物理噪声N，构造

\[
E=(I-WA)Q+WN.
\]

从相同协方差、独立随机数生成另一份E′，作为网络的噪声统计侧信息。该构造可通过现有小维SVD和矩阵乘法实现，无需显式建立4096×4096协方差。

训练时的h独立于Q、N。A、W和工作协方差来自预先定义的分布，不能从验证场景真值拟合。噪声族至少应包含各向同性、少数空间方向功率集中的协方差，以及当前算子导致的AFDM输入轴颜色；还应覆盖后期接近热噪声的情形。高噪声范围由生成条件和训练预算事先规定，不用裁剪验证样本掩盖不支持的查询。

这仍是有色Gaussian的工作模型，不等于真实有限用户干扰的精确分布。实际Q可能与A、N和h相关，Gaussian近似有效性要在独立物理场景上检验。

## 3. 网络接口与训练目标

[D-GEC §III-B，pp.535–536，式(41)](https://phil-schniter.web.app/pdf/jsait22_dgec.pdf)的corr+corr接口使用有色观测及同统计的独立噪声样本。本项目可保留旧一阶网络作为初始化，新增噪声侧信息输入。一个有限噪声样本只是协方差的统计提示，不等于把精确C提供给网络；须与直接协方差参数条件化作区分。

若精确C或其可计算因子可用于训练与推断，可令Dθ(r,C)=r+Csθ(r,C)，最小化

\[
\mathbb E\|C s_\theta(h+e,C)+e\|^2.
\]

对正定C，这一损失逐条件的总体最优均值为E[h|r,C]；最优score为∇log p_C(r)。该式为直接条件期望推导，不另命名新算法。矩阵乘Csθ应使用模型协方差的隐式作用，不能按一个平均方差替代。

为了保持与旧接收机的可解释联系，先研究条件活动信道的均值F，再让活动分类器在相同有色噪声模型下训练并校准，联合均值仍为pF。只适配F而沿用旧AWGN活动分类器，可能保留早期虚警。不能使用验证标签反向校准门限。

首个实验不同时修改基础信道分布、稀疏度、导频预算、活动门限和网络规模。先解决统计适配，再研究共享特征或减少第二网络调用的效率收益。

## 4. 反馈要与矩阵状态配套

一般MMV误差状态可能是矩阵；对应Onsager校正也可能需要特征维度的Jacobian平均。[Liu–Yu §III-B](https://arxiv.org/html/1706.06438v2#S3)；[Kunde等2026预印本§III-C式(18)–(21)](https://arxiv.org/html/2604.21115v1#S3.SS3)。这些文献的基础矩阵和正则条件不能直接替当前AFDM算子背书。

不能把新去噪器简单接回原标量pF/风险交换后，就宣布所有轮次自洽。应分别检查：

1. 在已知C的合成条件中，均值MSE、活动概率校准、实际Jacobian与协方差关系。
2. 接收机可计算C的预测质量，特别是反馈后残差估计是否再次偏离真实MSE。
3. 查询误差与反馈误差的相关性、误差与信道的相关性、空间及AFDM两轴的颜色。
4. 完整接收机同观测、同预算的检测、NMSE和耗时。

若混合历史反馈，必须计入跨轮误差协方差。不能把两个方差的线性插值当作误差混合的真实方差；[Takeuchi式(27)–(28)、(44)–(45)](https://arxiv.org/abs/2111.05522v2)给出相应长记忆框架的来源，但当前算子上的统计假设仍需核查。

## 5. 最小验证顺序

先固定一个独立训练噪声族，用旧网络原样输出作为对照，验证有色Gaussian输入上的适配收益，同时保留AWGN退化情形。训练集、调参集和确认集按物理信道划分。

仅当条件去噪与活动检测同时改善，才进入统一矩阵反馈的完整接收机试验。第一轮和后续轮次使用相同规则；真值只用于诊断。若有色Gaussian条件去噪有效，而真实查询仍明显非Gaussian或信号相关，则应回到干扰模型和反馈构造，不能继续把问题统归于网络容量。

目前这一步仍待实施。旧网络、主线配置和正式baseline矩阵均不需要因这份设计而改变。
