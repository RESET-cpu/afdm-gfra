# 系统与信道建模专项核对

2026-10-14。范围仅为传播信道、几何、连续发射波形、分数时延、CPP与采样映射。不评价接收机或算法性能。该报告补充并收紧上一轮综合审计的物理结论；没有改动实际信道生成器或历史数据。

## 结论

**NTN-TDL-D的功率、延迟和Rician分解没有发现录入错误；共同卫星方向、共同Doppler及静止终端的常值随机tap有合理依据。当前最实质的物理问题，是连续分数时延和长CPP延拓尚未与声明的480kHz收发带宽、DAC及接收滤波建立一致映射。**

因此，应区别两件事：当前程序正确计算了它定义的矩阵；这个矩阵是否来自所声称的物理收发系统，仍有实质缺口。此前用代数一致性概括“物理实现未发现问题”不充分。

## 1. 当前传播信道究竟是什么

在块内固定几何近似下，代码对应

\[
h_{k,m}(t,\tau)=a_m(u_k)e^{j2\pi\nu_k t}
\sum_{i=0}^{3}g_{ki}\delta(\tau-\tau_{k,\mathrm{macro}}-d_i\mathrm{DS}_k).
\]

这里宏观时延由地球/卫星/用户几何决定，扣除公共参考时延；DS独立取30–50ns；归一化超额时延为(0,0,.5596,7.334)。所有分量使用同一用户的卫星方向和Doppler。块内gain固定，跨独立场景随机。

代码位置：`system/scenario/continuous.py:45–98,106–142`，`geometry_consistent.py:26–42,74–86`；实际观测入口为`experiment/generate.py`。

### TDL分解正确，但“四条可分辨路径”不准确

按TR38.811 §6.9.2、Table6.9.2-4，第一tap包含同延迟LOS和Rayleigh分量，另有两个Rayleigh tap。因此四行是三个不同时延tap。当前LOS固定幅值随机相位、其余圆对称复Gaussian，第一tap的Rician K1为11.707dB，正确；全信道LOS/全部散射比为7dB，二者不同。

归一后，第一tap约占总平均功率89%。总功率表之和不是1不构成错误，第一tap均值约为0dB正是表格约定。静态载频相位可以并入随机复gain；现有随机LOS相位描述独立场景的未知初相，不是精确长期相位跟踪模型。

### 静止终端、共同方向不是必须修掉的问题

TR38.811 §6.9.1允许卫星端角扩展近似为零；上行互易解释支持共同卫星到达方向。Shen等上行模型§II-A式(1)–(3)也明确提取共同阵列响应。

TR38.901 §7.7.2局部Jakes最大Doppler为v/λ。在终端和局部散射体静止、卫星端共角近似下，局部谱退化，随机tap在块内固定再乘共同卫星Doppler是合理特例。不能仅因没有路径独立Doppler就判生成器错误，也不应为增加难度任意添加它。

50°是参考几何，标准允许目标角及DS/K缩放。当前将固定D-profile、固定K和30–50ns DS与实际几何组合，是研究指定的LOS情形；尚未指定某种城市/郊区环境下DS、K、阴影随仰角变化的联合统计。这个范围需要说明，但不是“非50°就不可使用”的错误。

来源及详细核对见[channel_model_followup_physics.md](channel_model_followup_physics.md)。

## 2. 近单径的根源是局部传播尺度与带宽，而不是四行误生成

采样周期1/B=2.0833μs，局部RMS DS仅30–50ns，B×DS=.0144–.024。最大局部超额时延220.02–366.70ns，仅.1056–.1760采样。

剥离用户共同宏观时延，定义局部频响`H_local(f)=Σg_i exp(−j2πf d_i DS)`。以功率表作二阶统计，跨480kHz整个频带的相关幅值为.99604至.98965。用频带中心响应替代整带局部响应，其带内平均误差/平均信道功率为−31.53至−27.14dB。该计算是传播频响的解析统计，不是AFDM矩阵误差或接收机结果；深衰落实例不受该平均比值逐点保证。

所以当前局部传播确实接近频率平坦，但宏观差分时延仍在，公共Doppler仍在。宏观时延给用户间不同相位斜率，不会把一个用户30ns的局部DS变成几百μs。不能把大差分时延、DAFT矩阵泄漏和丰富可分辨多径当成同一件事。

这支持“当前场景物理自由度低”的判断，不支持“TDL-D模型造假”的判断。也不能单凭这个结论决定算法优劣。

## 3. 新确认的主要缺口：连续CPP与带宽

`system/afdm/continuous.py:6–28` 与论文草稿式(7)将实数样点坐标ξ上的子载波定义为

\[
\varphi_s(\xi)=N^{-1/2}\exp\{j2\pi[c_2s^2+c_1\xi^2+sw/N-\rho_s(w)w]\},
\quad w=\xi\bmod N,\quad \rho_s(w)=\lfloor2c_1w+s/N\rfloor.
\]

### 3.1 数字CPP在当前参数下恰好是CP

N=16,c1=7/32，故2Nc1=7、c1N²=56。对于整数样点ξ=w−kN，CPP相位因子

\[
\exp\{j2\pi c_1(\xi^2-w^2)\}
=\exp\{j2\pi(-7kw+56k^2)\}=1.
\]

本轮对全部336个负整数样点数值核对，与周期复制的最大绝对差约5.05e−12。Bemani博士论文§3.1.1式(3.2)，印刷p23，也明确指出偶数N、整数2Nc1下数字CPP等价CP。

### 3.2 同一数字样点的模拟延拓却并非周期复制

在不跨wrap边界的小区间内，对相位求导：

\[
f_s(\xi)=B[2c_1\xi+s/N-\rho_s(w)]
=f_s(w)-7kB.
\]

取s=0、ξ=−335.25，w=.75,k=21：

\[
f_s(\xi)=-70.4025\ \mathrm{MHz},\qquad f_s(w)=0.1575\ \mathrm{MHz}.
\]

两者相差147个采样率，即70.56MHz。有限差分独立验证一致。这是按当前公式得到的**前缀内部瞬时相位斜率**，不是卫星Doppler，也不是整个波形占用带宽的测量值；不能把它写成“卫星产生70MHz频移”。

这些整数倍采样率的差异在整数时刻不可见，但在分数采样时刻不再相同。因此检查整数IDAFT与矩阵恒等式，无法验证连续模型是否等同于普通480kHz带限DAC输出。

此连续CPP形式有文献来源：Bemani论文§3.2式(3.14)，印刷p29/PDF p55给出一个周期的模拟chirp相位延拓；项目把它延伸到多周期长CPP。因此不能简单称它为程序员凭空添加的错误。然而，把这种公式与普通带限收发链路等同，仍需模拟实现与滤波依据。480kHz若仅作为采样率、允许更宽频模拟chirp，可以定义另一套数学系统；当前尚未明确这种系统。

### 3.3 分数时延处存在真正的跳变

在d=1/7两侧，比较单路径矩阵G(d−ε)、G(d+ε)，得到相对Frobenius距离：

| ε（采样单位） | 相对距离 |
|---:|---:|
|1e−4|.2169700|
|1e−6|.2169420|
|1e−8|.2169419|
|1e−10|.2169419|

极限不趋于零，说明这是模型的分段跳变，不是浮点舍入误差。21.7%是矩阵范数距离，不是估计NMSE或能量损失。

该现象与2026年预印本Cao–Shao §II-A式(1)–(3)、Proposition1分析的频率wrap相位修正相同。该文不是本项目正确性的权威证明；本结论由当前公式和独立数值检查得到，文献提供相关背景。当前参数c1=7/32不满足其波形全局连续的特殊条件。

普通有限带宽滤波后的波形不会保留这种内部突跳的原样点值。分数时延必须作用于实际连续波形，再经过接收滤波和采样；不能默认未滤波的解析点采样与该过程相同。

### 3.4 为什么这影响信道模型

传播信道是延迟/Doppler作用于发射波形；有效AFDM矩阵同时依赖传播参数与收发波形。当前数据的分数时延响应、非酉性质、泄漏结构及对局部小延迟的敏感性，都可能受到该连续延拓选择影响。

补充比较仅改变模拟prefix为周期wrapped基：整数延迟1时矩阵差约9e−15；d=.1、.5时，即便允许拟合自由复标量，残差仍约39.2%、48.4%。这不是建议直接采用该替代基，也不是新真实信道结果，而是说明**相同整数样点不能确定分数时延模型**。某些其他延迟处二者恰好只差标量，不能把这两个控制推广成所有延迟都大幅不同。

本轮没有模拟完整模拟滤波，也没有宣称某种替代插值已是唯一正确模型。正确下一步是先明确实际发射/接收滤波及采样约定，再由连续卷积重新推导并独立验证有效G，而不是直接把floor删掉。

数值见[CHANNEL_WAVEFORM_CHECK.json](CHANNEL_WAVEFORM_CHECK.json)，复现脚本`experiments/implementation_audit_20261014/channel_waveform_check.py`。

## 4. 其余系统建模条件

- 几何产生的宏观时延、Doppler和UPA方向一致，现有符号在负载频复包络约定下自洽。块内固定时延、保留一阶载频Doppler是近似，并非精确移动传播；高SNR、长burst需评估其影响。
- 336点CPP覆盖声明差分时延，但占帧长95.45%。仅凭覆盖范围不能证明接入效率合理，也不能替代连续prefix建模。
- 跨帧相位由真Doppler生成并准确提供，这是条件模型。可以用于已知同步信息下的信道研究；不能据此声称已实现未知同步或完整GNSS-free获取流程。
- 大尺度损耗差异被模型去除，没有实际功控过程。DS、K与地理环境的联合统计未建模；若论文声明特定部署环境，应明确采用什么统计，而不是仅写“NTN-TDL-D”概括全部链路。

## 5. 建议的处理顺序

1. 首先闭合连续波形—长CPP—模拟滤波—采样模型，检查分数时延响应的连续性及与独立波形仿真的一致性。涉及生成数据的物理定义，不能靠当前同源矩阵交叉检验替代。
2. 将信道准确表述为静止LOS终端、TDL-D三个tap、共同卫星阵列方向与Doppler、局部弱频率选择性；不为增加难度任意加入大角扩展或独立路径Doppler。
3. 明确目标环境及是否需要DS/K/大尺度功率的场景统计；根据研究任务决定，不能因为某算法表现强就改分布。
4. 传播模型与波形模型确定后，若有效算子改变，再单独规划重新生成数据。现阶段没有替换旧样本或宣布旧性能结论已被新模型复现。
