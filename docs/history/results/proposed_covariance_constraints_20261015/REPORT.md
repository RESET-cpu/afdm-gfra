# 空间矩阵约束不能替代误差统计匹配

2026-10-15。已完成全部4个旧条件、285轮、两个固定步长的离线比较，
新增接收机运行、网络调用和训练均为零。原Proposed与已有候选保持不变。

按照[冻结协议](../../experiments/proposed_covariance_constraints_20261015/PROTOCOL.md)，
比较最近半正定矩阵、各向同性矩阵、保持估计迹的半正定矩阵。
三种处理只读估计矩阵，不使用真值选参数；真值只作后续比较。
60个合成数学控制全部通过，最大归一化误差2.36e−15。

以下为末轮Frobenius相对误差，目标是投影后平滑反馈的空间二阶矩，
不是实际网络输入的完整误差协方差。每格按步长0.01 / 0.02排列。

| 条件 | 未约束修正 | 最近半正定 | 各向同性 | 保持估计迹的半正定 |
|---|---:|---:|---:|---:|
| scene000 / −4 dB | 4.810 / 4.810 | 3.571 / 3.573 | 0.911 / 0.910 | 1.483 / 1.496 |
| scene008 / 0 dB | 1.435 / 1.435 | 1.033 / 1.034 | 0.908 / 0.908 | 0.636 / 0.638 |
| scene016 / 4 dB | 2.467 / 2.467 | 1.942 / 1.943 | 0.916 / 0.917 | 1.107 / 1.109 |
| scene024 / −4 dB | 2.500 / 2.499 | 1.728 / 1.728 | 0.835 / 0.835 | 0.944 / 0.945 |

三种候选均半正定。最近半正定处理在285/285轮降低原矩阵误差，
但只有89/285轮优于原谱收缩工作矩阵；末轮误差仍约1.03–3.57。
它把末轮迹推高至实际值的2.05–5.07倍，不能因没有负特征值就投入白化。

各向同性处理285/285轮优于零矩阵、244/285轮优于原工作矩阵，
但它只利用功率信息，本身不恢复空间方向。
原谱收缩在240/285轮为零矩阵，因此“优于原工作矩阵”也不是很高的空间准确性标准。

保持估计迹的处理204/285轮优于原工作矩阵，131/285轮优于各向同性；
末轮仅scene008同时在幅度与迹归一化矩阵形状上优于各向同性。
两步长的这些计数相同，并不构成独立重复实验。
shape统计的零迹情况明确记为空值；其他逐轮误差统计仍包括所有轮次。

结论：这些约束解决矩阵合法性、部分缓解噪声放大，但没有稳定恢复空间方向。
不能把其中某个场景的改善作为更改接收机的依据。
本阶段停止继续叠加此类矩阵约束，转而核对真正的查询误差及其交叉项，
见[实际查询分解](../proposed_query_terms_20261015/REPORT.md)。这不代表AWGN目标完成。
