## Cai 的 DFT 选择确有我们缺少的局部结构

来源为 Cai §II-A式(3)–(4)、§V-C式(66)，以及作者冻结程序
[pilot_matrix_generation，第49–68行](../cai_alignment_20261014/author_main_stmp_jadce.py.txt)。
以下单位响应结论针对作者使用的等模 DFT 选择；不能泛化为任意行正交矩阵都具有此性质。

用 C 表示 Cai 的观测矩阵，避免和本项目导频帧数 Q 混淆。
K 为用户数、T 为 OFDM 符号数、P_tx 为发射功率，C_k 为用户 k 的全部子载波列：

\[
CC^H=KP_{\rm tx}I,\qquad C_k^HC_k=TP_{\rm tx}I_N.
\tag{A1}
\]

第二式由两个事实得到：不同子载波的列作用于不相交的观测位置；
每个子载波列有 T 个等模、功率 P_tx 的导频元素。
原文的一般酉矩阵选择只保证第一式；其 DFT 实现同时保证第二式。

对共同标量 Gaussian 输入方差 γ，经过平均迹投影再相除输入消息，线性查询为

\[
r=z+W(y-Cz),\qquad W=(TP_{\rm tx})^{-1}C^H.
\tag{A2}
\]

于是对每用户严格有

\[
W_kC_k=I_N,\qquad
W_kW_k^H=(TP_{\rm tx})^{-1}I_N.
\tag{A3}
\]

展开查询：

\[
r_k=x_k+\sum_{j\ne k}W_kC_j(x_j-z_j)+W_kn.
\tag{A4}
\]

这意味着：自身信道坐标没有线性串扰，也没有直接自身旧均值项；
对于与固定矩阵独立的白 Gaussian 热噪声，其用户内热噪声协方差严格为标量阵。

若进一步采用其他用户误差独立、CN(0,γI)，且与目标信道、热噪声独立的工作假设，
则 A4 中残余误差是与目标信道独立的白 Gaussian，其方差为
\(\gamma(K/T-1)+\sigma^2/(TP_{\rm tx})\)：
\(\sum_{j\ne k}W_kC_jC_j^HW_k^H=(K/T-1)I\)。
这个局部模型的正确性仍依赖上述误差假设，有限学习网络和反馈历史不会自动保证这些假设。

独立合成代数控制采用K=40、N=16、T=8，A1–A3最大相对误差为1.54×10⁻¹⁴。
这只验证矩阵性质，维度不用于比较两种接收机性能。

## 我们整体行正交，但用户内不正交

当前原始导频 P₀ 是从 KP=640 维 DFT 随机抽取16行，并随机置换及旋转列。
其每用户每帧能量为1，满足

\[
P_0P_0^H=KI_Q,\qquad Q=P=16,
\quad\text{但一般}\quad P_{0,k}^HP_{0,k}\ne I_P.
\tag{A5}
\]

整体行正交不蕴含每用户列块内部正交。移除所有跨帧相位的纯矩阵控制下，
平均迹归一化后的线性滤波器为W=P₀ᴴ，因此

\[
W_kP_{0,k}=P_{0,k}^HP_{0,k},\qquad
W_kW_k^H=P_{0,k}^HP_{0,k}.
\tag{A6}
\]

其对角元素虽为1，非对角元素并不为0。因此，仅热噪声就已经在用户的 AFDM 输入坐标间相关；
自身信号与旧反馈也在这些坐标间混合。这不是“漏做一般矩阵LMMSE”的问题，而是随后采用标量消息模型的代价。
“移除跨帧相位”是矩阵控制，不是实际有 Doppler 场景中的“已知真实相位”。

实际算子为 A_k=D_kP₀,k，其中D_k是用户特有的单位模帧相位阵。
其用户块 Gram 矩阵严格不变：

\[
A_k^HA_k=P_{0,k}^HP_{0,k},
\qquad
AA^H=\sum_kD_kP_{0,k}P_{0,k}^HD_k^H.
\tag{A7}
\]

第二式通常不再为标量阵；即使完全知道真实相位，也不能一般地恢复整体行正交。
当前一般矩阵 LMMSE 正确处理这个变化，但不自动消除局部查询的相关性。

对已有两个原版末态，令
\(D_k^{\rm th}=\|W_kW_k^H/\bar c_k-I_P\|_F/\sqrt P\)，
\(\bar c_k=\operatorname{tr}(W_kW_k^H)/P\)。
这是固定滤波器下的 Gaussian 热噪声参照协方差的各向异性量，
不是实际反馈误差的统计检验或检测损失百分比；末态W依赖观测，不能无条件当作独立固定滤波器的噪声律。

## 伪AWGN的理论保证不能直接移植

Cai §V-B1明确将伪AWGN解释联系到大系统极限及右旋转不变随机矩阵，并承认有限维实际矩阵的偏离。
部分DFT行正交不等于右旋转不变；其实现也不能仅靠行正交获得任意有限维保证。
我们使用重复的16×640测量块、结构化 AFDM 信道与观测估计相位，
更不能把Tweedie恒等式直接当成实际消息服从AWGN的证明。

Tweedie恒等式针对给定Gaussian卷积模型成立；它没有证明消息传递生成的R恰好来自该卷积。
活动分类器的Bayes密度比推导也一样：训练类条件密度正确时成立，
实际查询发生信号方向偏差和相关误差时，有限分类器的置信度可以失配。

## 对各项近似的判断

| 近似 | 证据强度与判断 |
|---|---|
| 单用户单位响应＋标量白噪声查询 | 有明确结构差异和实际失败诊断；当前最需要重新验证的假设。 |
| 其他用户误差由独立匹配Gaussian消息代表 | 理论上依赖有限反馈误差的分布；实际残余方向偏差明显，属于重点问题，尚未唯一因果归因。 |
| 跨用户／天线共享方差 | 确有信息损失，但现有放宽未改善所选漏检，不能认定为首要瓶颈。 |
| 相位点估计且不传播其不确定性 | 是本项目额外近似。两个场景的方向分解不支持将全部漏检归因于相位；其他场景仍需单独检验。 |
| site复用、方差比裁剪 | 所审计304轮无支持外、拒绝site、反馈裁剪；各场景仅第2轮触发条件方差下限，不能把末态错误统一归咎于裁剪。 |
| 算术阻尼 | 有稳定作用，不会把相关、有偏误差自动变成独立白Gaussian。 |
| 一般矩阵LMMSE | 给定Gaussian工作输入后计算正确，不是当前需要补上的缺失环节。 |

后续最有区分力的是在固定观测、固定先验和同一接收机设置下，分开检验：
用户内相关性、其他用户残余的方向偏差、相位不确定性分别改变了多少活动证据与最终MD/FA。
不建议仅凭方差平均接近真实MSE继续增大协方差模型或重训旧AWGN分类器；
也不能将白化视为免费修复，因为它会改变噪声放大和信道先验的坐标分布。
本次只做判断与矩阵核验，没有启动这些候选实验。
