# 固定开发查询上的直接矩阵校正诊断

## Material Passport

- 模式：独立数学复核和单查询数值诊断；与主代理共享问题、代码及已有结论上下文。
- 对象：固定 step 30000 的 JointDenoiser，公开 solver_validation/scene00/SNR −4 首轮查询。
- 数据边界：仅 checkpoint、公开 input、冻结源码；不载入 truth，不运行接收机闭环，不使用独立 test。
- 输出：本目录内 PLAN、原始估计样本、完整行基参考、计时、RESULT 与审查结论。
- 主算法、训练、正式协议均未修改。本诊断比较校正计算误差，不比较信道恢复误差。

## 1. 公式与适用条件

矩阵输入为 R∈C^(KN×C)，C=MR=256；行索引为 (k,n)，n=1,…,N=16；Z∈C^(Q×C)，Q=16。当前网络对每个用户的全部 16 波束联合处理，但不同用户之间没有算子或批次统计耦合。因此冻结本轮 V、公开 ρ 和网络参数时，完整映射 D=pF 的 Wirtinger 导数满足

\[
J_{kn,b;k'n',a}=0\quad(k\ne k'),\qquad
B_{ab}=\frac1Q\sum_{k,n}J_{kn,b;kn,a}.
\tag{P1}
\]

表示变换可同时混合同一用户内的 n 和特征坐标；其用户局部性足以支持上述条件，无须假设跨波束或跨行导数为零。当前实现的 JVP 对完整表示变换、F、p 及逆变换求导；V 和 ρ 作为固定标签。此结论不适用于以后加入跨用户注意力、批次统计或依赖所有用户的归一化之后的网络。

接收机需要 C_corr=ZB，而非 B 的全部独立元素。取 η_kn,p，并对每个观测行 q 构造

\[
U^{p,q}_{kn,a}=\eta_{kn,p}Z_{qa}.
\tag{P2}
\]

Z 在这里仅为固定方向系数，不对递推历史求导。若 L 为完整实方向导数，则

\[
V^{p,q}=\frac{L(U^{p,q})-iL(iU^{p,q})}{2}=J_z[U^{p,q}].
\tag{P3}
\]

该组合消去共轭导数；不得改为对 Z 取共轭或把 a,b 顺序转置。每个行方向的校正样本为

\[
T_{p,qb}=\frac1Q\sum_{k,n}\overline{\eta_{kn,p}}V^{p,q}_{kn,b}.
\tag{P4}
\]

展开用户内的完整 Jacobian 得

\[
T_{p,qb}=\frac1Q\sum_{k,n,n',a}
\overline{\eta_{kn,p}}\eta_{kn',p}
J_{kn,b;kn',a}Z_{qa}.
\tag{P5}
\]

若 E[conj(η_kn,p)η_kn',p]=δ_nn'，则 E[T_p]=ZB。若每个用户使用完整 N 列、满足 η_k^Hη_k=NI 的方阵，则其行也正交，有限和本身满足

\[
\frac1N\sum_{p=1}^N T_p=ZB.
\tag{P6}
\]

因此完整 16 列不含部分迹抽样误差，仍包含实际 float32 JVP 和变换的浮点误差。稠密复线性/反线性合成检查同时保留跨行和跨特征耦合，显式 ZB 对照相对误差为 9.01×10^−16；这检验代数与索引，不能据此把实际网络数值精度声称为 double 精度。

## 2. 与精确跳连扣加的关系

当前 fullB16 对已知线性部分 S_kn,b U_kn,b 作精确扣加，S=p_k c_skip,b。完整导数中的 dp 和 CNN 项仍在 JVP 中。直接方法无需丢弃这些项。因为 |η_kn,p|=1，每个 T_p 中已知对角部分都恰为

\[
T^{\rm skip}_{p,qb}=Z_{qb}\frac1Q\sum_{k,n}S_{kn,b},
\tag{P7}
\]

与 p 无关。因此本次直接使用完整 JVP 与原 fullB16 的精确跳连扣加可以公平比较；并未把活动概率当作完整映射中的常量。两种随机估计的方向分布不同，本审查不声称普遍的方差排序。

## 3. 预算和有限总体标准误差

一对实 JVP 实现一个复方向。fullB16 需要 16 个复方向；直接 P=1、2、4 需要 QP=16、32、64 个复方向；完整参考需要 QN=256 个复方向。主要等预算对照是 fullB16 与 direct1。

本诊断先固定每用户完整随机相位正交基，再用一次独立、共用的列置换对 16 个 T_p 排序。条件于该完整基，前 P 列是有限总体中大小 P 的均匀无放回样本。它们不是 P 个独立 Monte Carlo 样本。对 P>1，报告的 Frobenius 均方误差尺度估计为

\[
\widehat{\mathrm{SE}}_P^2=
\frac{1-P/N}{P(P-1)}\sum_{p\in S}\|T_p-\bar T_S\|_F^2.
\tag{P8}
\]

其平方是条件抽样均方误差的无偏估计；平方根本身不声称无偏。P=1 无法由单样本估计标准误差，记为 null。P=N 的抽样误差为零，不能用这个零值估计浮点导数误差。

完整总体已经计算后，还可直接计算同一固定基内所有均匀大小 P 子集的均方误差：

\[
\mathrm{RMS}_{P,\rm frame}^2=
\frac{1-P/N}{P(N-1)}\sum_{p=1}^N\|T_p-\bar T\|_F^2.
\tag{P9}
\]

这是已知参考下的条件有限总体量，P=1 也可计算；它不是从一个 P=1 样本估出的 SE，也不是跨独立行基或跨查询的置信区间。RESULT 另外保留同一基内所有互不重叠 P 列分组的实际误差，这些分组也不称为独立重跑。

fullB16 使用 16 个独立矩阵探针，沿用现有独立样本 SE 公式，样本数明确为 16。所有方法主要比较其校正与完整行基参考的实际误差，统一除以 ||Z||，另报告除以 ||ZB|| 的相对误差。

## 4. 边界

这个精确性结论仅关乎给定去噪器和给定查询处 ZB 的计算。它不证明 AFDM 查询误差为 AWGN、不证明状态演化适用、不证明阻尼递推收敛，也不证明信道恢复或活动检测改善。正式方案若修订，应记录为校正估计器的变更，并保留原 fullB16 结果和预先固定的其他设置。
