# Proposed 活动检测错误诊断

本报告复核同十个场景、六档 SNR 的已保存结果，并补做三项真值相位辅助诊断。后者明确使用模拟真值，单独保存，不参与未知相位性能比较。网络、活动门限和原条件推断规则保持不变。

## 漏检对活跃用户的影响

每档共有 400 个候选用户判决，其中 49 个活跃、351 个非活跃。AER 的分母为 400，活跃用户漏检比例的分母为 49。

| SNR / dB | 迭代相位 Proposed 漏检 / 虚警 | 活跃用户漏检比例 | Off-grid SBL 漏检 / 虚警 | 活跃用户漏检比例 |
|---:|---:|---:|---:|---:|
| −4 | 6 / 0 | 12.24% | 2 / 0 | 4.08% |
| −2 | 4 / 1 | 8.16% | 1 / 0 | 2.04% |

原两阶段 Proposed 在上述两档仍分别漏检 5、2 名用户。因此当前低 SNR 活动检测的差距在相位外迭代之前已经存在。

## 相位更新次数与错误变化

从每次条件推断末轮保存的概率重算活动判决；两次更新后的概率与原输出逐项一致。

| SNR / dB | 相位不作外迭代 AER / % | 一次相位更新 AER / % | 两次相位更新 AER / % |
|---:|---:|---:|---:|
| −4 | 1.25 | 1.25 | 1.50 |
| −2 | 0.50 | 0.50 | 1.25 |
| 0 | 0.25 | 0.25 | 0.25 |
| 2 | 0.25 | 0.25 | 0.25 |
| 4 | 0.25 | 0.25 | 0.25 |
| 6 | 0.25 | 0.25 | 0.25 |

新增的三次漏检和一次虚警均出现在第二次相位更新后的推断。一次更新的中间信道数组未保存在该批结果中，此处不推断其 NMSE。

- scene003/−2 dB：真实活跃用户 20 的概率从 1 降至 0.00121；非活跃用户 31 从 0.00212 升至 0.99994，产生一次漏检和一次虚警。
- scene007/−2 dB：真实活跃用户 24 从接近 1 降至 0.01408，产生一次漏检。
- scene007/−4 dB：真实活跃用户 16 从接近 1 降至 0.01345，产生一次漏检。

前两项条件推断均满足原停止条件。它们在保持最后相位算子不变、将概率停止门限放宽至 1e-3 的逐轮记录检查中，错误仍然存在。最后一项可由较早停止避免，见原停止诊断。完整外迭代采用宽松停止规则的效果尚未验证。

## 真值相位对照

以下诊断均从原初始化重新运行条件 Proposed。比较对象为原两阶段结果，不使用新的迭代相位输出作为初始化。场景与目标用户根据已观察错误选择，属于事后诊断。

| 条件 | 相位输入 | 漏检 / 虚警 | NMSE / dB |
|---|---|---:|---:|
| scene003/−4 dB | 原估计相位 | 2 / 0 | −5.5064 |
| scene003/−4 dB | 全部真实相位 | 2 / 0 | −5.6794 |
| scene008/6 dB | 原估计相位 | 1 / 0 | −13.5606 |
| scene008/6 dB | 全部真实相位 | 1 / 0 | −14.2122 |
| scene008/6 dB | 仅替换用户 36 为真实相位 | 1 / 0 | −13.5596 |

三项诊断均达到原停止条件。第一项仍漏掉用户 20、37；五个 baseline 用原估计相位都能检测到这两名用户。因而这两次漏检不能仅用相位估计误差解释。

scene008 的用户 36 在 0～6 dB 始终被 Proposed 和五个 baseline 漏掉。其真实信道能量为该场景活跃用户中位数的 5.67%，占本批全部活跃信道总能量约 0.103%。准确相位也未使 Proposed 检出它。该对照说明相位精度本身不足以解决这一弱用户漏检，但并未证明该用户不可检测。

## 降低判决门限的诊断

在全部冻结的最终概率上检查 0.5、0.1、0.01 三个门限，未选择或部署新门限。

- 0.5 改为 0.1：六档均没有追回漏检；−4 dB 虚警从 0 增至 1。
- 0.5 改为 0.01：−4 dB 漏检从 6 降至 4，但虚警增至 23，AER 从 1.50% 升至 6.75%；−2 dB AER 从 1.25% 升至 2.75%。

现有错误包含很低概率的真实活跃用户和接近 1 概率的非活跃用户，简单移动门限无法解决这些已观察错误。

## 结论与下一步依据

当前最明确的短板是低 SNR 活动推断，其次是第二次相位更新造成的额外判决退化。停止条件对一个案例有明显影响，但不足以解释全部新增错误。尚未区分分类器本身、实际迭代输入及消息更新近似各自的贡献。

NMSE 按信道误差能量计权，活动错误按用户等权计数；弱用户漏检可以对总 NMSE 影响很小。因此必须同时检查漏检、虚警和活跃用户漏检比例，不能把 NMSE 改善当作活动推断改善的证据。

原两阶段配置继续作为当前比较入口。后续应优先检查实际迭代输入上的活动推断，再在独立开发场景上验证相位更新次数和停止规则；本批十场景只提供已观察面板上的诊断证据。
