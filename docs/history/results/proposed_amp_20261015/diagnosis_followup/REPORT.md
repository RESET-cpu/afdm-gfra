# 新 AMP 的失败位置与文献指导

2026-10-15。Origin Skill: academic-research-suite。性质：事后机制诊断与原文核对；未训练网络、未修改接收机。
完整初次实现、推导和配对运行仍见[上一阶段报告](../REPORT.md)及[推导](../../../docs/PROPOSED_AMP.md)。

## 1. 判断与证据边界

目前有两个需要分开的层面：

1. **已直接验证的网络弱点：** 当前冻结的联合去噪器只接收标量噪声方差。固定实际信道与标称噪声功率，仅引入与首轮误差匹配的天线相关性，就足以在这四个条件下复现活动概率饱和与估计恶化；噪声可以是严格 Gaussian。
2. **尚未分离的循环稳定性问题：** 新无阻尼 AMP 很快离开网络训练方差范围；旧 Proposed 首轮也几乎全判活跃，却在后续恢复。不能由第1点推出它是新循环失败的唯一原因，也不能把旧循环恢复单独归功于阻尼。

因此，Onsager 是否实现了有益反馈校正、去噪器是否匹配输入统计，以及整个迭代是否稳定，是不同的检查项目。Huang 的 L-DAMP 曲线不能替代这三个项目在当前具体模型中的验证。

## 2. 固定输入的40次网络前向

预先保存的[本轮协议](../../../experiments/proposed_amp_20261015/diagnosis_followup/NETWORK_PROTOCOL.md)固定了四个已失败的开发条件和每条件三个噪声种子。
对同一真实信道，分别测试实际首轮查询，以及三种具有相同标称总方差的合成 Gaussian 查询。
三种合成查询共用底层独立 Gaussian 抽样；没有调整阈值、模型或噪声标签。

| 单次查询类型 | 查询数 | 漏检 / 活跃输入 | 虚警 / 不活跃输入 | 联合 NMSE |
|---|---:|---:|---:|---:|
| 实际 AMP 首轮 | 4 | 0 / 18 | 142 / 142 | +11.7704 dB |
| 独立同分布复 AWGN | 12 | 4 / 54 | 0 / 426 | −8.7861 dB |
| 只匹配各天线噪声功率，天线间独立 | 12 | 4 / 54 | 0 / 426 | −8.7984 dB |
| 匹配完整16×16天线协方差的复 Gaussian | 12 | 0 / 54 | 426 / 426 | +11.7330 dB |

NMSE 为全部误差能量之和除以全部真实信道能量之和，再转 dB；不是逐例 dB 的平均。
这些是**真值辅助的单次去噪诊断**，不是可部署接收机结果。合成协方差取自该场景真实查询误差；真实信道也直接用于构造查询。
每个固定场景下合成噪声独立抽取，但协方差参数依赖该场景的真实误差。
12次查询只是4个物理场景各3次噪声重复，不能当成12个独立物理场景，更不能把426次重复输入当成独立总体样本计算置信度。

仅匹配天线协方差并未保留真实误差的全部跨用户、AFDM坐标或历史相关性。因此，结果支持“天线相关性在这些条件下已足以复现异常”，不支持“全部失败机制已识别”。

不仅活动概率有问题，活跃用户条件均值也恶化。例如scene008的条件均值NMSE：实际查询为+4.3151 dB；独立AWGN的三次结果平均为−8.2523 dB；相关Gaussian为+4.1345 dB。
所以仅修改活动阈值或分类器，不能视为完整修复；score均值也需要适配。

原始输出见[RESULT.json](network/RESULT.json)和[汇总](network/SUMMARY.json)。
独立离线核对[VERIFY.json](VERIFY.json)重算了全部40次查询指标，4次实际查询与原快照完全重合；28个受保护的旧Proposed文件和权重哈希全部未变。

## 3. 统计问题出现于第一次 Onsager 之前

采用归一化模型 \(Y=AX+W\)，初值 \(X^0=0,Z^0=Y\)。按用户分块，首轮误差精确为

\[
R_k^0-X_k=(A_k^HA_k-I)X_k
+\sum_{j\ne k}A_k^HA_jX_j+A_k^HW.
\]

这里除了热噪声，还有用户内混合和多用户干扰。当前算子混合用户和输入坐标，不混合天线轴；因此信道的阵列方向可以保留在干扰中。
第一轮尚未使用 Onsager，四个新AMP查询的活动概率已经全部饱和为1。
首轮真实平均误差功率与传入方差之比约0.991–1.002；这表明“平均功率基本准确”没有解决协方差失配。

这也不是单凭边缘直方图判断的结果。匹配 Gaussian 的对照直接说明：Gaussian 性和白性不能合并判断。

多测量向量 AMP 的一般状态演化传播协方差 \(\Sigma_t\)，等效查询形如

\[
R_t=X+\Sigma_t^{1/2}V,\qquad V\sim\mathcal{CN}(0,I).
\]

\(V\) 是标准 Gaussian 不代表 \(\Sigma_t^{1/2}V\) 在天线间是白噪声。
Liu–Yu 的[原文](https://arxiv.org/html/1706.06438v2#S3.SS2)§III-B式(16)–(18)保留矩阵协方差；§III-D Theorem 1式(23)将其简化为标量阵，依赖该文各向同性Rayleigh信道和匹配MMSE等设定。
这个理论用于指出正确的统计接口，不证明有限结构化AFDM算子满足该文状态演化条件。

## 4. 旧 Proposed 的恢复限制了因果解释

| 条件 | 旧Proposed首轮NMSE | 首次零虚警轮数 | 最终NMSE | 停止轮数 |
|---|---:|---:|---:|---:|
| scene000 / −4 dB | +14.2311 | 10 | −12.2109 | 62 |
| scene008 / 0 dB | +11.6420 | 9 | −9.6002 | 66 |
| scene016 / 4 dB | +13.6197 | 15 | −16.9422 | 99 |
| scene024 / −4 dB | +10.2952 | 9 | −8.0794 | 111 |

四个旧Proposed首轮在0.5阈值下也全部判活跃。其后续使用外信息更新、方差/矩更新、两方向0.2阻尼和原有site处理；新实现采用无阻尼残差AMP和不同方差标签规则。
旧Proposed中多个机制同时存在，现有配对结果不能识别其中某一个的独立贡献。
应将“网络存在统计失配”和“新循环未能从早期误差恢复”作为两个可分别消融的问题。

Onsager自身也不是完全没有作用：scene000从同一首轮标签4.7045出发，下一轮残差方差在有校正时为29.3625，无校正时为672.3418。
这里只能说这一次更新的残差功率较小，不能据此宣称已经恢复AWGN。
更高精度的校正参考仍在第三次查询前超出范围，说明8个随机探针的误差不能独自解释失败。
所有“超出范围”均指网络训练方差上界100；这不等于数学上证明无限迭代发散。

## 5. 矩阵性质：需要谨慎适配，但不是严重全局病态

公开输入矩阵的非零谱条件数为1.265–1.316。
四个历史有效算子不是精确行正交：基础DFT导频虽然行正交，各用户不同的跨帧相位破坏了拼接后整体恒等式。
逐用户子块条件数较大，不能与全局观测子空间的非零条件数混淆。

标量LMMSE的迹归一化确实改变了四个实际首轮查询，相对匹配滤波的变化为7.56%、5.62%、10.47%、3.05%。
作为条件命题，若 \(AA^H=(KN/Q)I\) 且平均列能量为1，迹归一化LMMSE恰好退化为 \(A^H\)；仅更换线性块不一定改变查询。
严格推导和公开输入的独立重建见[算子复核](../../../experiments/proposed_amp_20261015/diagnosis_followup/NOTE.md)。

VAMP对右正交不变随机矩阵提供更广的理论范围，但不是任意结构化AFDM矩阵的保证。相关出处为[原文](https://arxiv.org/html/1610.03082v2)§III Algorithms 2–3与§IV。
原Proposed已经含迹归一化LMMSE和外信息交换；不能把“换VAMP”描述为仅添加一项从未存在的机制。

## 6. 已有研究如何指导修改

### 6.1 先用稳定性消融定位新循环能否恢复

[MRI Image Recovery using Damped Denoising Vector AMP](https://arxiv.org/pdf/2010.11321v1)，Sarkar、Ahmad、Schniter，ICASSP 2021，§3.1 Algorithm 1与式(9)–(14)，对去噪灵敏度、精度和均值分别施加一致的阻尼；§3.2研究初始化。
这是学习去噪器配合结构化算子时的经验依据，不能直接把其标量非负精度的平方根操作套到当前一般复数Onsager矩阵。

建议先保持网络不变，单独比较有明确递推公式的阻尼与初始化。阻尼后的实际映射、反馈系数和历史依赖应一起说明；不能只乘小Onsager项却声称保留原公式。
评估应保留真实超范围状态，不以裁剪标签掩盖输入变大，并记录固定网络调用成本下的误差、虚警和方差校准。
这一消融尚未执行。即使稳定性改善，也不证明输入变白。

### 6.2 对已验证的统计弱点，修改 score 与活动分类器的条件分布

[Denoising Generalized Expectation-Consistent Approximation for MR Image Recovery](https://phil-schniter.web.app/pdf/jsait22_dgec.pdf)，Shastri等，IEEE JSAIT 2022，§III-A Algorithms 2–3与式(31)、(36)，§III-B式(38)–(40)，针对可预测的有色Gaussian误差配套设计去噪器。
它在MRI中的分组误差模型是经验结论；可借鉴“按实际噪声结构训练并提供噪声信息”，不能直接移植其小波分组或声明AFDM获得相同保证。

对本项目，最小可检验候选是先保留16×16天线协方差 \(C_t\)，而非把所有信息压成一个迹均值。
在实坐标 \(u=(\Re r,\Im r)\) 与工作误差协方差 \(\Gamma_t\) 下，匹配的活动条件均值满足

\[
F_{\Gamma_t}(u)=u+\Gamma_t\nabla_u\log q_{1,\Gamma_t}(u),
\]
\[
p_{\Gamma_t}(u)=\operatorname{sigmoid}\!\left(
\log\frac{q_{1,\Gamma_t}(u)}{q_{0,\Gamma_t}(u)}
+\log\frac{\rho}{1-\rho}\right),\qquad
D_{\Gamma_t}(u)=p_{\Gamma_t}(u)F_{\Gamma_t}(u).
\]

这里 \(q_{1,\Gamma}\) 是活动信道先验与该协方差Gaussian核的卷积，\(q_{0,\Gamma}\) 是同协方差纯噪声密度。
若在全查询中暂用重复的天线协方差块，这是工作近似，尚未表达跨坐标和历史的全部相关性。
训练需让score与活动似然比共同接触这些有色噪声条件，并继续保留白噪声条件。
只把旧score前面的 \(v/2\) 换成矩阵并不正确，因为score对应的平滑密度本身也变了。

部署时不应使用真实查询误差协方差。一个可检验的公开输入估计是按天线聚合残差：

\[
\widehat C_t[m,j]=\frac1{QR}\sum_{q,r}Z^t[q,m,r]\overline{Z^t[q,j,r]}.
\]

在这四个首轮，\(Z^0=Y/(sg)\) 给出的估计与真值误差天线二阶矩的相对Frobenius差为2.28%、1.94%、1.46%、2.63%。
估计本身只用公开观测；真值只用于离线检验。见[协方差核对](RESIDUAL_COVARIANCE_CHECK.json)。
该结果支持尝试这个统计量，**不证明后续各轮校准，也不证明它是充分统计量**。
先以新场景上的单次去噪检查确认改进，再接入完整AMP；单次结果通过并不替代闭环验证。

### 6.3 两个不应直接采用的简化

- **白化后直接复用冻结网络：** 白化 \(Tr=T h+T e\) 也改变信道先验。一般 \(T^{-1}F_v(Tr)\) 不是原先验下的正确后验均值。[解析反例](../../../experiments/proposed_amp_20261015/diagnosis_followup/NOTE.md#4-白化后直接复用原网络为何一般不成立)即使对理想Gaussian后验均值也成立。
- **仅增大探针数或更换算法名称：** 完整参考仍越界；首轮异常也发生在首次校正之前。需要先检验统计模型和循环稳定性，而不是把有限探针视为唯一原因。OAMP/VAMP可作为独立结构对照，其适用假设和真实导数应另行核对。

建议的研究顺序是：保持原Proposed及本次无阻尼AMP为基线；先做冻结网络的稳定性消融，隔离循环因素；同时据现有单次证据设计协方差条件训练，验证输入统计适配，再决定是否更换线性/外信息框架。
以上新方案均尚未实现或确认性能。本轮实际完成的是40次固定网络诊断、公开算子与首轮协方差复核、独立数值验证和文献核对。
