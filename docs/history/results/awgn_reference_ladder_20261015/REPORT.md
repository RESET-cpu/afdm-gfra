# AWGN参考递推与算子替换：分阶段验证

2026-10-15。Origin Skill: academic-research-suite / experiment-agent。
本轮没有训练网络、改变主线配置或推广新接收机。不是Cai原论文的完整复现，也未实现完整OAMP-MMV或LM-OAMP。

**本轮没有找到可以替代原推断的改进版本。** −4 dB三组AER均为1.25%；真相位改善了NMSE，但没有减少该档活动错误；随机化右奇异向量也没有稳定改善AER。输入列二阶矩仍明显偏离同尺寸AWGN参照，说明随机化基础算子不足以恢复原网络所需的白噪声输入。

这批结果不支持将低SNR漏检单独归因于相位估计、基础矩阵不够随机或score训练不足。它也没有否定第一条路线：尚待验证的是与MMV结构匹配的完整模块间反馈，而不是把一个随机矩阵或一次白化操作直接视为修复。对固定AFDM和当前网络，未给出AWGN保证。

## 设计与可比范围

先核验解析VAMP递推，再在同一批物理信道上逐项更换测量算子与相位信息。原三个网络、分类器0.5阈值、双向0.2阻尼及停止规则保持一致，所有SNR使用同一算法。

- 解析参考：120次，4种固定配置×10场景×3个SNR，固定30轮。
- 逐列独立算子补充：30次，配对相同信道与热噪声，固定30轮。
- 统一阻尼补充：首次60次，补齐零方差极限后完整重跑60次；β=1/0.2各30次，均固定100轮。首次异常保留。
- 物理面板：90次，10个历史开发场景×3个SNR×3种算子条件。场景跨条件复用，不能当90个独立场景。

随机算子保留真相位AFDM矩阵的左奇异向量、奇异值和行Gram，只独立重抽右子空间。由相同真实信道H和原热噪声N生成新观测。它不是当前可部署AFDM导频；真相位也是oracle诊断。真值用于输入生成、观察器及评分，不进入原推断的四字段接口。真相位控制不是近似接收机性能的数学上下界，仍可能到达不同固定点。

## 核验与保存

独立公式核对最大误差1.79e-11，采用RuntimeWarning提升为异常的验证。保存输出重算269例，NMSE能量/活动判决核对通过。物理原主线30例全部逐数组精确复现，源码、配置和权重哈希未变。
 
最初reference数学核验在NumPy @计算QR Gram时出现divide/overflow/invalid警告，结果有限。原始日志保留；独立核验改用显式收缩并将RuntimeWarning视为异常，全部通过。未以屏蔽警告代替验证。物理每次运行的警告单独保存。

查询以complex64落盘，推断仍用原精度；360个保存查询重算统计的最大缩放差为1.06e-08，量化误差未影响原推断。
 
方案与后续补充均在运行前分别登记：
- experiments/awgn_reference_ladder_20261015/PROTOCOL.md
- COLUMN_CONTROL.md：共享/独立算子单因素诊断。
- DAMPING_CONTROL.md：统一阻尼与相同轮数。

## 文献适用边界

- [VAMP，TIT 2019](https://phil-schniter.web.app/pdf/tit19_vamp.pdf)：Algorithm 3、§IV-A/§IV-E。标量参考遵循其外信息递推；不把MMV复制算子当完整右酉不变矩阵。
- [OAMP-MMV，TSP 2023](https://arxiv.org/html/2304.08038v1)：§III-B、Assumption18/Theorem19、§III-F。矩阵误差模型允许特征协方差，不保证所有网络坐标均白。
- [LM-OAMP，TIT 2022](https://arxiv.org/html/2111.05522v2)：§IV-B式63–78。阻尼的实际方差涉及历史交叉项；本次没有实现完整历史协方差递推。
