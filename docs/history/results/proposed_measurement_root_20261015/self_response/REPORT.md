# 完整观测响应的稳定性与空间协方差

2026-10-15。本阶段改进了完整观测响应的数值估计，并确认了新的限制：
标量误差功率估计明显改善，但直接恢复完整空间误差协方差仍不可靠。
没有把修正项写入接收机反馈，也没有实现AWGN目标或替换原Proposed。
原主线28个文件及备份的完整性以[最终核对](FINAL_AUDIT.json)为准。

## 实际完成的范围

父阶段的4条控制只有1条通过预定的原数值路径复现门槛；其32条扰动没有启动。
输出信道相对二范数差最高4.54e−6，条件均值最高1.30e−5，活动判决和分支相同。
这是数值重放差异，不是相对于真值的性能损失。失败保留于[父阶段报告](../REPORT.md)。

本阶段另行冻结[协议](../../../experiments/proposed_measurement_root_20261015/self_response/PROTOCOL.md)，
先要求半正定平方根数值映射严格复现自身。4/4通过，预测、全部轮次的观测反馈映射、
补噪数组及分支逐元素一致；随后完成32条完整历史扰动，共36条。
固定四个已有开发条件及轮数60、60、63、102，两个方向、两个步长0.01/0.02。
这些不是36个独立性能样本；独立条件仍只有4个，且本阶段没有新增测试场景。

每轮均使用相同Hermitian半正定平方根规则及固定的原坐标Gaussian方向。
矩阵级条件分布与随机流检查通过，不等于有限精度迭代与原路径完全相同。
本阶段分析的是这个映射自己的响应；未将父阶段失败改称通过。

## 空间矩阵仍不可靠

线性模块实际使用平滑反馈S_t，而非当轮F_t。用全部AF_t精确重建
S_1=0、S_{t+1}=0.8S_t+0.2F_t，并对其完整观测响应展开空间矩阵修正。
复数线性/共轭线性解析检查最大恒等式误差4.37e−15；
重建残差对应原轨迹全部信号秩，特征向量对角化相对误差不超过1.19e−15。

下表的目标是投影后平滑反馈误差的16×16空间二阶矩，

平均功率接近不代表各空间方向估计准确，也不代表查询或反馈已经独立、白或Gaussian。

## 剩余误差的来源

[额外离线分解](DECOMPOSITION.json)只读取已保存结果，无新增接收机调用。
令E=A(S−H)、N=Y−AH，按16×256排列，L=256，p=40，则逐样本严格满足

    C_corrected − C_actual = Q + R,
    Q = (N N^H/L − sigma² I)/p,
    R = estimated_cross − (E N^H + N E^H)/(L p).

真值仅用于推断结束后的分解，不进入任何接收机或参数选择。

| 条件 | 末轮Q范数/实际矩阵范数 | 末轮R范数/实际矩阵范数，0.01 / 0.02 |
|---|---:|---:|
| scene000 / −4 dB | 4.647 | 1.280 / 1.280 |
| scene008 / 0 dB | 1.319 | 0.766 / 0.766 |
| scene016 / 4 dB | 2.455 | 0.951 / 0.951 |
| scene024 / −4 dB | 2.278 | 1.105 / 1.105 |

四条件末轮的Q范数均大于R；它们并非可直接相加的标量，精确矩阵和及内积也已保存。
Q是一次白噪声实现的样本二阶矩波动，不能据此断言物理噪声非白。
R同时含实际交叉项与期望关系之间的波动、有限方向/步长误差和映射正则性问题，
不能全部归因于探针数不足。同一场景各轮共用同一Q，轮次不是独立噪声样本。

## 判断与下一步

已验证：更稳定的补噪表示使完整响应与历史标量风险更可用。
已验证：当前无约束空间矩阵估计不适合直接接入闭环；有限样本波动是明显因素。
尚未验证：任何新的协方差估计能改善真实查询统计、反馈统计或完整接收机性能。
已有两步长修正都未进入推断，当前结果不能支持新的NMSE优势或提速结论。

[下一步设计](../../../experiments/proposed_measurement_root_20261015/self_response/NEXT_DESIGN.md)
先利用现有数据比较有明确优化定义的低自由度矩阵估计，另推导包含反馈与原噪声交叉项的
查询协方差。仅将矩阵改成半正定不能作为AWGN已经成立的证据。

本阶段36条运行共5130次score批调用、2565次分类器批调用，接收机循环475.69秒；
另有父阶段4条控制570次score批调用、52.58秒。

36条响应审计相当于其4条对照的9倍score调用，不能当作可部署的加速方案。
分析器全部正常结束，无剩余接收机进程。原Proposed、各已有候选及训练权重保持原状。
