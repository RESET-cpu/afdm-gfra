# 四个 baseline 的噪声核验与 off-grid SBL 修正

Verification Status: VERIFIED（限本报告的数值、输入边界及固定场景验证）。

SOMP、GNN-ASPL 和 L-DAMP 未发现与 GAMP 相同的物理噪声迭代低估问题。Off-grid SBL 存在持续向下偏差；后验公式核对正确，当前修正 Gamma 先验，属于项目适配。

## 逐方法结论

| 方法 | 核查与处理 |
|---|---|
| SOMP | 空间 MDL 噪声传入残差停止阈值及 SNR 门限选择；不迭代更新物理噪声，保留实现。 |
| GNN-ASPL | 空间 MDL 噪声传入原网络 σ² 位置及活动读出；权重保持，保留实现。 |
| off-grid SBL | 保留 Wei 后验期望残差与噪声初值，增加观测估计的 Gamma 先验尺度；详见下文。 |
| L-DAMP | 原校正残差估计的是归一化等效误差；复方差、算子增益和固定信道归一化尺度经独立测试，保留实现。物理噪声估计仅诊断。 |

## 诊断与来源

原六条件的 SBL 噪声估计为真值的 72.4%–83.8%。固定两个诊断条件是 scene000/0 dB 和 scene001/−4 dB。改变初值后比值为 0.7994、0.7369；增加预算后分别在 351、493 轮满足停止条件，比值仍为 0.8077、0.7397。因此，这两个条件的低估不能仅归因于初值或迭代不足。

[Wei 作者稿](https://arxiv.org/html/2101.05629v1)式(45)–(46)给出 Gamma-MAP 更新；Algorithm 1 的初始噪声 mean|Y|²/100 保留。原文 §VI-A 用 c=d=1e−4。当前改为 c=1+LM、d=LMσ̂²_spatial，单位权重与既有 GAMP 设置一致，未搜索权重。完整期望残差 E=‖Y−Aμ‖²+M tr(AΣAᴴ)，因此 σ²_new=(E/(LM)+σ̂²_spatial)/2 ≥ σ̂²_spatial/2。

该先验和共享 MMV 都是项目适配，不能写成原论文给定的超参数。同一观测用于先验尺度与似然，不是独立额外观测。这里只缓解实际模型的持续低估，不保证无偏；原弱先验代码参数和全部历史输出保留。

诊断结果、所用参数和全部警告见 `DIAGNOSTIC.json` 与 `diagnostic/`。新场景生成前已冻结 `VALIDATION_PLAN.json`。

## 核验与限制

- 75 项相关测试通过；完整系数协方差独立核对 SBL 的 MMV 因子及 Gamma 更新，检查输入噪声替换和 L-DAMP 等效噪声单位。
- 固定验证共 37 次推断，另有 6 次诊断；保存 30 行配对/回归性能记录。全部输出有限，全部性能行从预测文件重新计分一致。
- SBL 全流程分别保留、删除及污染旧 noise_variance 字段，结果完全一致。其余三法新场景 NaN 字段全流程与三字段条件运行完全一致。GAMP 一例与上一轮修正完全一致。
- L-DAMP 两个新条件的准确噪声/估计噪声原生输出完全一致，符合其不依赖输入物理噪声字段的实现。
- 字典、原生求解器、训练权重和活动门限的登记散列保持，仅更新噪声适配入口及配置。所有警告保留；测试有 84 条 RuntimeWarning，既有 Accelerate 诊断见 `results/baseline_phase_learning_20261015/BLAS_DIAGNOSTIC.json`，不能据此宣称每个中间量已被证明正确。
- 两个新物理场景是有限验证，同一场景的不同 SNR 不是独立场景。SBL 仍有向下偏差，并保留 120 轮预算；MAX_ITERATIONS 不等于收敛。活动门限未重新校准。
- SBL 固定中心的一阶字典与精确重建仍有差异，逐例 linearization_relative_error 已保存；噪声修正不消除这一模型近似。
- 空间 MDL 依赖空间白噪声与低秩信号；L-DAMP 的相关等效误差与去噪器训练分布失配属于另一个限制。
