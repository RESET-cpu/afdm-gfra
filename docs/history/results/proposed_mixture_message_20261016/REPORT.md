# 活动混合消息的连续模型核验与原末态联合诊断

## Material Passport

- 2026-10-16；academic-research-suite / experiment-agent，inline validate与已授权实现。
- 前序：[实际查询分布诊断](../proposed_query_distribution_20261015/REPORT.md)。
- 本轮完成：混合外部因子、同一局部先验下的矩、正标量Gaussian site拟合；432个连续小系统条件；
  两个K6采样对照及两个真实K40保存末态的联合拟合模型诊断。
- 状态：本轮核验完成，完整物理接收机修复未完成；默认Proposed、网络和冻结包不变。
- 真值边界：小系统后验参考来自全枚举；真实场景的采样不读真值，保存预测后才评分。

**本轮实现了与混合外部因子一致的局部积分，并验证了Gaussian压缩可以造成很大的活动后验误差。
但把原两个困难场景的全部40用户拟合活动因子联合处理，仍然是3次漏检、0虚警。
现有证据不支持仅扩大末态活动求和就能修好原Proposed。**

## 1. 已实现的修正针对明确的局部概率对象

给定其他用户独立的Bernoulli–Gaussian消息，线性Gaussian观测的外部因子为

    L_k(h)=Σ_s exp(c_s+2Re b_sᴴh−hᴴJ_sh)。

s枚举其他用户活动组合；c_s含组合权重、观测协方差行列式和残差二次型。
代码保留全部常数，再把目标先验与L_k相乘，统一计算活动概率、条件均值及中心协方差。
这些是给定消息近似后的积分，没有把实际算法误差重新假设成独立AWGN。

若输出仍用正标量精度site S(h)=exp(2Reηᴴh−α||h||²)，应对L_kS/Z匹配均值和协方差迹。
实现最小化自然参数凸目标

    log Z(α,η)−2Reηᴴm+α(||m||²+tr V)。

这匹配均值和协方差迹，保留标量精度限制；不声称匹配全协方差。
不能先把L_k改为另一个Gaussian，再将两组精度相减后声称仍匹配原混合对象。
来源边界和全部(G1)–(G6)见[推导](../../experiments/proposed_mixture_message_20261016/DERIVATION.md)；
一般moment matching及因子替换规则见[Minka §2–3](https://tminka.github.io/papers/ep/minka-ep-uai.pdf)。

## 2. 连续小系统：隔离了其他用户Gaussian压缩的影响

K=2/3，每用户2个复坐标，活动条件先验CN(0,I)，活动率0.1；固定复观测矩阵及外生噪声。
矩阵生成关联参数c取0、0.9、0.99，每组4个独立bank，每bank遍历全部活动状态和σ²=0.2/2/20。
共24个独立bank、432个观测条件、1152个用户后验。
c是生成参数，不是每次实现的实测列相关系数；σ²是工作模型的噪声方差，不是接收SNR。

保留全部活动混合的局部积分与独立全枚举的最大绝对差：

| 对象 | 最大差 |
|---|---:|
| 活动概率 | 5.83×10⁻¹⁵ |
| 联合均值 | 1.28×10⁻¹⁴ |
| 联合中心协方差 | 7.33×10⁻¹⁵ |
| 对数观测证据 | 1.78×10⁻¹⁴ |

这清楚区分了“保留二阶矩”与“保留活动后验信息”。它不证明误差随c单调增大，
也不代表原AFDM接收机的实际错误率。活动状态刻意等频覆盖，并非从ρ=0.1自然采样；
同一bank的状态和噪声条件相关，表中只是描述性后验近似误差。

## 3. 正标量反馈并不总与精确混合矩相容

1152次正标量site拟合中，1151次达到事先固定的2×10⁻⁷矩残差容差；
这些通过项的最大归一均值残差为6.98×10⁻⁸、相对方差迹残差为6.71×10⁻⁸。
24个额外Gaussian先验恢复检查中，α相对1的最大偏差2.68×10⁻⁸，η范数最大1.18×10⁻⁷。

唯一边界案例为K2/c0/bank03/state01/σ²0.2的用户1：

- 目标平均中心方差0.3489811911。
- 在α=0且均值方程精确满足时，方差为0.3427632125，低1.78175%。
- 此处目标对α的导数为+0.0124359573，均值方向导数约10⁻¹⁵。
- 目标凸，固定均值后的方差随α不增，因此该正精度约束确实不相容，不是求解器误差。
- 单独放宽到允许局部负精度后，α=−0.0599378576恢复目标矩；
  每个乘积因子的最小精度特征值仍为2.5638740，局部积分有效。

负精度site本身不是可归一化Gaussian消息，尚未验证它能进入原正方差线性接口。
原正精度失败保留，负精度仅作[事后局部约束诊断](BOUNDARY_CHECK.json)，没有切换原协议或接收机。

显式的“先Gaussian投影再精度相减”对照中，86/1152次与原混合因子相乘后不再可积分；
其余1066次也都超过相同矩残差容差。这是新混合接口的反例，不能说成原单Gaussian接口出现了86次故障。

## 4. 回到真实末态：联合全部40用户仍未减少漏检

沿用原两个困难场景的保存末态，由q_k/g_k构造既有Bernoulli–Gaussian拟合因子t_k。
固定它们，计算

    q_fit(H,a) ∝ CN(Y;ΣA_kH_k,σ²I) ∏_k t_k(H_k,a_k)。

t_k包含数据依赖的均值、方差和活动权重；q_fit不是已证明正确的物理后验。
与既有双用户末端对照相比，这次不再用单Gaussian反馈替换其余38名用户。
原循环没有运行、修改或回灌；本结果是保存末态的联合模型诊断。

沿用已有Barker balancing function + MH采样器，四链分别从全零、全一和两份固定先验抽样启动。
两个K6非零均值/异方差模型先通过独立64状态枚举门槛：
最大边际误差0.003740，归一均值误差0.003060，均低于预定0.03。
随后两场景各运行2048 burn-in和32768保留transition/链，全部链等权汇总，保留拒绝与停留。
一般采样规则来源见[既有推导与验证](../activity_posterior_refinement_20261015/REPORT.md)。

| 场景 | 原版MD / FA | 联合拟合模型MD / FA | 原版NMSE / dB | 联合拟合模型NMSE / dB |
|---|---:|---:|---:|---:|
| scene003 / −4 dB | 2 / 0 | 2 / 0 | −5.506429 | −5.506112 |
| scene007 / −4 dB | 1 / 0 | 1 / 0 | −6.010422 | −6.017358 |
| 合计 | 3 / 0 | 3 / 0 | −5.758333 | −5.761534 |

80个活动判决逐位相同；合并NMSE变化约−0.0032 dB，不作性能改善结论。
三个旧漏检者在联合拟合模型中的采样概率分别约4.58×10⁻⁵、4.58×10⁻⁵、8.32×10⁻⁴。
没有得到支持扩大同类末态活动求和的实际检测收益。

两场景的最大逐链边际范围为0.000275、0.003021，最大前后半链差为0.000793、0.003418。
保留期各链接受移动次数为[73,85,6,79]及[553,354,438,437]；第一场景第三链移动较少也完整报告。
这些是有限预算的描述性诊断，不是全局混合或真实后验误差界。
不能以采样结果断言所有重要支持均已探索，不能以该拟合模型的失败否定所有非Gaussian消息修正。

## 5. 独立核验、失败和下一步

12项不同的确定性测试通过，覆盖复积分、常数、秩亏、因子移除、梯度、Gaussian退化、
不相容边界、非零均值/异方差以及采样详细平衡与重复样本汇总。
全部432输入重新求独立枚举，327680个保留状态逐个复算边际，所有唯一状态的信道均值通过潜变量空间公式重算。
两个真实输出独立评分一致；979个冻结文件及56个当前主线文件身份一致。

稠密独立参考在macOS数值库调用中出现divide/overflow/invalid警告，但结果有限。
完整保留复现的612条警告，并另以显式收缩及Cholesky公式在严格警告模式核查全部68个K40唯一保留支持：
无新警告，最大对数权重差3.28×10⁻¹⁰，条件均值差1.66×10⁻¹⁴。
没有隐藏警告或修改算法，也不声称已经修复数值库。见[数值核验](PRECISION_AUDIT.json)。

下一步应检查原三网络的局部概率一致性：活动对数密度比的梯度能否恢复一阶均值，
其曲率能否与中心协方差相容，并与实际查询和匹配Gaussian查询分别比较。
活动混合已经给出可核验内核；当前更需要定位拟合信道因子本身的误差，
而不是把本轮小系统精确结果直接移植为完整物理接收机成绩。
具体待办及必要恒等式见[NEXT_ACTION.md](NEXT_ACTION.md)。整体目标继续。
