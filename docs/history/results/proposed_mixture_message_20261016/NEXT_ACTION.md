## 本轮改变了下一步决策的证据

1. 保留活动混合并正确积分，可以在明确小模型内消除其他用户Gaussian压缩产生的后验误差。
2. 正标量Gaussian site可能与精确混合矩不相容；不能把旧相除公式直接搬来。
3. 把原两个困难末态的40个拟合混合因子联合处理，80个活动判决逐位不变，仍3 MD、0 FA。
   采样诊断改善不等同精确后验；仍不足以支持继续扩大同类末端求和。
4. 原因子来自三个分别训练的网络。它们是否在实际查询附近对应同一个概率模型，尚未定量核验。

## 下一项应先检验的恒等式

令x为D个复系数的2D维实表示，复Gaussian噪声方差为v。
若活动证据L(x,v)=log p(x|a=1,v)−log p(x|a=0,v)，不活动信道严格为0，
且F是同一先验/同一Gaussian因子下的活动条件均值，则逐点有

    ∇_x L = 2 F_real / v，
    ∂F_real/∂x = (v/2) ∇²_x L，
    Cov_real(H|x,a=1) = (v²/4) ∇²_x L，
    平均复中心方差 = (v²/(4D)) Δ_x L。

这由Gaussian卷积对数密度求导直接得到；不以实际R的生成机制为独立AWGN作为前提。
它要求同一局部概率对象，有限网络可以违反这些恒等式。
不能因为分类误差小，就推断梯度和曲率足以提供正确均值/方差。

## 实现时必须处理的细节

原EvidenceNetwork的输入含F(r)，训练中用mean.detach()冻结一阶网络。
若检查推断映射r↦L(r,F(r))的数学导数，必须计入F(r)的链式导数；
直接对保留detach的原前向求自动梯度得到的是另一个偏导，不能当作上述∇L。
应在独立诊断中重建数值上相同的完整函数，原权重不变，先用有限差分核对总导数。
这不是修改训练规则，也不是将新梯度映射直接替换接收机。

先在全部保存的实际查询以及对应的独立Gaussian工作模型查询上分别核查均值关系；
再按必要性检查方向曲率、中心方差或Jacobian对称性。
结果前固定样本、尺度和容差，所有用户保留，不能只看三个漏检者。
若发现不一致，下一项修正须使均值、活动和方差来自同一个明确的局部因子，
并通过原完整闭环；不能再次仅用实际MSE或直接监督条件矩替代原因子后验方差。
