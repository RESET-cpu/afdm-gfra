在同一个40用户首轮查询上，用原权重、float32精度，预热后交替执行12次，并在每次计时前后同步MPS。没有保存额外的大网络权重。所有执行变体在这个查询上的均值和方差与原版本逐项相同。

|---|---:|---:|
| 当前实现 | 139.34 ms | 1.000 |
| 在主机验证后排队运行，延后输出拷贝 | 136.83 ms | 1.018 |
| 调整卷积内存布局 | 137.77 ms | 1.011 |
| 固定推理图 | 133.85 ms | 1.041 |

测试期间观察到另一个L-DAMP训练/评估进程使用同一设备。这些计时是开发筛查，1%–4%的差异不足以确立稳定提速，也不是端到端时延结论。没有据此修改生产路径。数据见 [RUNTIME.json](RUNTIME.json)。

额外比较批大小：每批8用户需375.68 ms/场景，20用户154.68 ms，当前40用户139.83 ms；合并两个40用户样本组，折算129.23 ms/场景（吞吐1.082倍），合并四组134.49 ms（1.040倍）。输入是同一数组的独立批维复制，用来检查执行吞吐与数值一致性，不能当成新物理场景。真正的多场景接收机还需分别维护消息与停止状态，当前没有实施。数据见 [BATCH_RUNTIME.json](BATCH_RUNTIME.json)。

网络单独计时显示，一阶/二阶网络分别约58.66/59.17 ms，分类器约2.55 ms；两个score网络各32,575,328个参数，分类器874,433个。这组计时与上一表的调度方式及测量时段不同，不能相减后将差额全部归因于数据拷贝。若假想二阶网络成本完全消失，三网络部分的计算时间上界改善约1.97倍；这是零成本替代的算力估计，不是可实现的接收机加速结果。[COMPONENTS.json](COMPONENTS.json)

**建议的最小训练改动：**冻结旧一阶网络及分类器，在一阶网络最后的特征上增加一个小的标量输出模块，估计每用户的条件误差方差。原二阶网络仅用于离线提供对照输出；同时用训练库的真实误差标签评价小模块是否保留原读出质量。由于接收机只使用全坐标平均方差，没有必要重新生成8192个实坐标上的二阶输出再平均。第一阶段保持一阶均值逐项不变，仅考察替代方差计算的精度和开销。

这一方案仍需训练和完整接收机验证；本轮未实现或宣称成功。活动网络仅占小部分算力，暂不优先合并，避免同时改变三个输出。

## 2. 一致性：问题已进一步定位

对完整映射D(r)=p(r)F(r)，分别估计p·J_F和F·grad(p)的归一化迹贡献。每个查询使用3条独立复高斯探针、3个中心差分步长（0.005/0.01/0.02乘以sqrt(v)）；有限差分包含分类器对同查询均值特征的全部依赖，没有把代码中的训练detach误当成推断函数不依赖F。

四个预先列出的开发条件为scene000/−4 dB、scene008/0 dB、scene016/4 dB、scene024/−4 dB。除首轮外，保持原0.2配置运行到原停止条件，再检查终点。另取现有训练验证库的前160个信道，每组40用户，按rho=0.1生成活动和独立CN(0,v)噪声，用相同首轮方差标签作合成AWGN控制。控制不是独立测试集，也没有用于拟合参数。

| 条件 | 首轮一阶映射归一化导数均值 | 合成AWGN控制 | 收敛终点 | 原接收机轮数 |
|---|---:|---:|---:|---:|
| scene000 / −4 dB | −0.3749 | +0.00792 | +0.00667 | 62 |
| scene008 / 0 dB | −0.1273 | +0.00855 | +0.00776 | 66 |
| scene016 / 4 dB | −0.6364 | +0.00796 | +0.01427 | 99 |
| scene024 / −4 dB | −0.04288 | +0.00857 | +0.00937 | 111 |

首轮p几乎全为1，F·grad(p)的平均贡献不超过约1e−11；负号主要来自F本身。所有四例在第1和第5轮都把40用户判活跃，随后才逐渐分离。这说明分类器早期同样存在严重失配，但它的导数项不是这里负迹的主要来源。不能从这项分解推断分类器无需优化。

在所测查询中，首轮的9次平均导数估计均为负，合成AWGN和终点的9次平均估计均为正。这里的平均正值不证明完整Jacobian正半定，也不证明每个用户都符合条件均值性质；逐用户结果保留在 [CONSISTENCY.json](CONSISTENCY.json)、[ENDPOINT_CONSISTENCY.json](ENDPOINT_CONSISTENCY.json)。首轮与终点同时改变了查询和噪声标签，不能将两者差异单独归因于迭代次数。

**合理推断：**旧网络在真实接收机早期查询附近的响应，与它在训练型AWGN查询上的响应有明显差异。后续应优先改善这个区域的均值映射和活动校准，而不是仅将方差输出改得更接近一个负导数。尚未通过干预实验证明这一局部现象是慢收敛的唯一原因，也未测中间所有轮次。

## 3. 为什么不能把方差直接替换为导数

令D为复坐标数，实坐标数为2D，复查询噪声方差为v。旧一阶映射为

\[
F_\theta(r,v)=r+\frac v2 s_\theta(r,v).
\]

由当前二阶训练损失直接整理，在一阶网络冻结、二阶函数容量及优化理想时，读出的最优标量为

\[
\tau_\theta^*(r,v)
=\frac1D\mathbb E[\|H-F_\theta(r,v)\|^2\mid r,v,a=1]
=\frac{\operatorname{tr}C_{H\mid r}}D
 +\frac{\|F_\theta-m\|^2}D,
\]

其中m为精确条件均值。有限一阶网络的条件误差风险包含均值偏差平方，不自动等于后验方差，也不自动等于v·tr(J_F)/(2D)。这已与项目 [THEORY.md 附录A](../../docs/THEORY.md) 的推导一致；本轮补充了独立数值恒等式检查。不能将此次差异直接归为二阶网络实现错误。

精确AWGN后验均值满足J_m=2C/v，故归一化迹非负；见 [Dytso–Poor–Shamai，作者稿§IV Proposition 1式(22)、Corollary 1式(23)，PDF pp.5–6](https://arxiv.org/pdf/2104.01883)。Cai以学得的一阶score替代真实score训练二阶网络，见 [Cai v2 §IV-C 式(51)–(54)](https://arxiv.org/html/2506.00581v2#S4.SS3)；本项目的风险分解是对有限网络训练目标的代数解释，不是额外的文献结论。

当前首轮直接令tau=v·alpha会产生负方差；截断为正数又会失去所声称的等式。因此这不是合适的直接替换方案。额外用多次一阶调用估计每轮导数，还可能抵消删除二阶网络的速度收益。

## 4. 改进训练的具体顺序

1. **先降低方差估计的单轮成本。**冻结一阶和活动网络，训练上述小标量模块。训练场景与接收机验收场景分开；保留原方差模块作为对照。若完整接收机精度不能维持，则不接入主线。
2. **另行改善一阶响应。**保留AWGN去噪目标，并使用训练场景产生的早、中、后期公开查询作为约束点，惩罚随机方向上的负响应。例如直接对qᵀ[F(r+εq)−F(r−εq)]/(2ε||q||²)的负部加平方损失。这是由精确条件均值必要性质提出的项目训练建议，不是已有命名算法；有限随机方向约束不构成全局正半定或收敛证明。需要按验证集同时检查去噪精度和局部导数，不能只追求导数变正。
3. **一阶改变后重新校准方差和活动输出。**前者的监督风险以新均值为中心，后者的输入也含新均值。不能继续把旧二阶/分类器与新均值的组合当作已经验证。对均值—方差的导数一致性只能施加适度约束，并同步减小均值误差；强迫有限均值的风险与导数完全相等会制造不必要的目标冲突。

整个推断阶段仍可各轮使用同一规则，不需首轮特殊处理。步骤1只针对算力；步骤2–3才针对当前查到的一致性与查询失配。

较强的架构方案是把均值写成标量函数的梯度，并控制其局部导数；[Hurault–Leclaire–Papadakis，ICML 2022 §3式(4)–(5)、Proposition 3.1](https://proceedings.mlr.press/v162/hurault22a/hurault22a.pdf)给出了相应结构和附加条件的先例。但梯度结构本身只保证Jacobian对称，需要额外条件才正定；其PnP收敛定理不适用于当前AFDM消息传递。因此本轮不建议优先重建整套网络。
