# L-DAMP 失败诊断与训练对照

2026-10-14。当前结论：**旧实现的训练与接收机质量验证失败；已修复错误放行流程，但尚未得到可替换主线的 L-DAMP 权重。** 默认配置保留原权重和推断参数供复查，状态更正为 `FAILED_RECEIVER_VALIDATION`。本轮没有安装训练候选。

同日原论文及作者训练代码复核补充：**第一次去噪前的实际查询误差已明显不符合独立 AWGN 训练分布，设计适配与训练需要一起处理。** 见[原文对照报告](../ldamp_paper_audit_20261014/REPORT.md)。以下训练对照是完整开发记录，不再把继续高噪声训练视为唯一的先行修复。

## 失败机制与排查范围

独立实矩阵检查验证了复数前向/伴随算子，以及所选实数等价散度和标量 Onsager 更新的代码代数一致性；没有证明该标量更新适用于当前重复观测算子和联合去噪器。实际公开算子归一化后列范数为 1，测量比为 16/640 = 0.025。本轮未发现所选表达式中少乘或多乘 2、复噪声方差约定或简单归一化错误。CPU 与 MPS 的去噪输出相对差约为 3×10⁻⁷ 至 3.4×10⁻⁶，不能解释数量级上的失败。

旧去噪器在独立 64 样本、各段几何中点 AWGN 检查中仍保留大量输入噪声，输出对输入的回归系数约 0.79–1.00。若 D(q) 接近 q，实散度就接近未知量维数 327680；除以实观测维数 8192，Onsager 系数接近 40。旧轨迹确实逐渐接近这一值，残差快速放大。示例场景的有效复方差由 10.614 增至第二轮 797.679、第十轮 3.32×10¹⁵；600 个接收机记录全部出现去噪区间越界，每次 20 个去噪调用中有 16–18 个越界。

这些事实支持“去噪器训练失败与 AMP 误差放大相互作用”的解释，不能据此证明原 L-DAMP 算法在 AFDM 上普遍无效，也未排除结构化算子和去噪训练分布不匹配。算子、设备与去噪数据见 [DENOISER_AUDIT.json](DENOISER_AUDIT.json)。

算法核对依据为 [He 等作者稿](https://arxiv.org/html/1802.01290v2) §III-A 式(4)–(8)、Fig.3，以及 [作者代码](https://github.com/hehengtao/LDAMP_based-Channel-estimation) 的 `Algorithms/DAMP.m`、`denoise.m`；本地来源记录位于 `references/ldamp_20261014/SOURCES.json`。32 实通道、五个噪声区间、活动混合训练及固定尺度是项目适配。

## 训练对照

全部训练对照保留原 20 层、64 隐藏特征、32 实通道网络；完整接收机保留原 AMP 公式和十次迭代。训练及训练验证物理场景身份不重叠。下列 512 样本验证集用于开发选择，不是独立接收机测试集。每次试验的计划均在执行前保存。

首先做纯噪声控制：现有 32 通道网络在 300 次更新后误差仍接近输入噪声；2 通道控制降至约 0.0756。该控制并非匹配参数量或每次样本信息量的架构比较，只提示现有训练的可学习性问题，不能直接推出应采用 2 通道结构。见 [CHANNEL_TRAINABILITY.json](CHANNEL_TRAINABILITY.json) 和 [ZERO_SIGNAL_TRAINABILITY.json](ZERO_SIGNAL_TRAINABILITY.json)。

随后设置噪声预测支路 F(x)=x，使初始清洁输出 x−F(x)=0。该等式在推断模式下成立，但同一个高噪声训练批次在正常训练模式下的 MSE 为 0.033244，推断模式为 0.00136024，零估计为 0.00136025，尚未进行优化就已出现差异。见 [INITIAL_BATCHNORM_CONTROL.json](INITIAL_BATCHNORM_CONTROL.json)。

Batch normalization 的训练批统计与推断固定统计之区别见 [Ioffe–Szegedy](https://proceedings.mlr.press/v37/ioffe15.pdf) §3.1、Algorithm 2。训练期间也固定统计、继续学习仿射参数是本轮项目对照，不是原论文的配方。

| 对照 | 预算 | 结果 |
|---|---|---|
| F(x)=x 初始化，正常 BatchNorm 训练 | 每段 500 次更新，batch 32，学习率 10⁻⁴ | 高两段选中训练前的零输出，失败 |
| 同一初始化、同一批次流，固定 BatchNorm 统计 | 每段同样 500 次更新 | 前四段优于零估计；最高噪声段仍选中零输出，失败 |
| 保留前四段，最高段初始化为 D(x)=a·x | 最高段 1000 次更新，学习率 10⁻⁵ | 仍选中 step 0；训练没有优于初始状态 |

第三项 a=0.002553020061538536，由训练库总体信道功率和已声明的区间内对数均匀噪声分布计算；没有使用接收机真值。其最高段 MSE 仅比零估计低约 0.195%，不能把这一训练前的线性初始输出说成训练成功。它只作为完整接收机诊断控制。

固定统计对照的前四段 MSE/零估计 MSE 分别为 0.01236、0.05534、0.30618、0.89470。低噪声区间改善明确；最高噪声区间的有效学习仍未解决。

## 已完成的代码与状态修正

- `validate_ldamp.py` 核验选中权重对应的训练验证指标；各去噪区间须优于零估计。校准和独立接收机验证还须同时优于零信道估计与最佳恒定活动判决。失败退出并保留结果。
- `compare.py` 要求接收机验证已通过，完整比较逐 SNR 重查最低效用；失败保留全部指标及图，并阻止安装。
- `run.py` 在安装前确认质量状态。新训练输出保存各选中模型的验证指标，清除旧接收机验证通过标记及旧比较报告。
- 默认配置、主线索引和说明文档准确记录失败状态。原 L-DAMP 推断代码、权重、门限以及原图其他方法的冻结资产均未更换。`verify` 的 PASS 表示资产身份匹配，不表示性能合格。

14 项相关测试通过，包括独立实矩阵检查、训练恢复、初始化恒等式、有限但无效输出的拒绝，以及主线选择。旧权重通过真实验证入口被拒绝，旧配置通过比较入口也被拒绝。详见 [TESTS.log](TESTS.log)、[PIPELINE_GUARD_CHECK.json](PIPELINE_GUARD_CHECK.json)、[VERIFICATION.json](VERIFICATION.json)。

## 尚未解决的研究问题

下一步按[原文对照报告](../ldamp_paper_audit_20261014/REPORT.md)先建立忠实的小规模单通道参考，并核对当前联合去噪的观测模型扩展；随后再做各噪声段训练与接收机验证。现有证据不足以支持继续增加 AMP 次数，也不足以将单独修改 BatchNorm 宣称为完整修复。

需要区分两件事：32 实通道适配下的高噪声训练是否有效，以及完整 AMP 查询误差是否符合训练 AWGN 分布。可先对输入表示、训练目标数值尺度和各噪声段学习过程作独立控制；若调整表示或网络结构，应明确记录相对原论文的适配。再次训练后必须使用未参与选择的新接收机场景验证。本轮没有给出原 L-DAMP 在此系统中必然有效或无效的结论。
