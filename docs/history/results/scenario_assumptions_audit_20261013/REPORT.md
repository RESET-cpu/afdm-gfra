## 1. 结论

**场景合并的物理思路合理：用Shen的GNSS-Free多用户卫星接入环境，搭配Huang的AFDM分数时延/分数Doppler信道。** 两者共享稀疏路径星地信道，可以在同一连续时间传播模型上重新推导，而不是把互不兼容的接收公式直接拼接。

但是，**当前实现是这个场景在准确已知跨帧相位条件下的JADCE实验，还不是完整的GNSS-Free接收机验证**。AFDM和off-grid两个标签成立；GNSS-Free的终端及传播环境设定基本成立，但接收端的同步信息获取被理想化。另有很高的长前缀开销和需要验证的块内固定参数近似。

前轮“数据能表征当前场景”指给定已写出的模型，数据生成与其一致；它不能替代本轮关于这些模型假设是否足以支撑研究目标的审查。

## 3. GNSS-Free：环境成立，接收机条件尚不完整

### 3.1 公共时延补偿不违背GNSS-Free

Shen明确允许卫星广播共同参考时延。GNSS-Free并不要求终端完全没有下行定时参考，也不要求卫星不知道自己的轨道。关键是终端不依靠自身GNSS位置对每个用户的差分时延与Doppler做精确预补偿。

当前模型为

\[
\tau_{k\ell}=\frac{\|g_k-s\|}{c}-\tau_c+\delta_\ell\tau_{{spread},k}.
\]

公共参考可以由卫星覆盖几何确定，不需要接收机事先知道每个用户的真实位置。仿真为了生成信号而使用用户真值，也不等于终端或接收机获得这些真值。当前生成器没有把所有用户残余时延和Doppler消掉，因此GNSS-Free的主要传播困难确实存在。

此判断继承Shen的理想公共定时参考和大尺度补偿假设；当前没有详细模拟初始小区搜索、公共广播误差、终端时钟偏差/漂移或额外本振频偏。这些是研究范围边界，不应凭GNSS-Free三个字自动视为已经覆盖。

### 3.2 准确已知相位是重要的额外条件

当前有效导频为

\[
A_{qkn}=P_{qkn}e^{jq\beta_k},\qquad
\beta_k=\operatorname{wrap}(2\pi\nu_kT_f).
\]

`generate_case`用真实Doppler计算所有候选用户的β，再通过 `operator` 交给接收机。当前接收机没有从接收信号估计β的步骤。[生成代码](../../src/afdm_jadcedd/experiment/generate.py)，[相位构造](../../src/afdm_jadcedd/system/phase.py)，[当前模型](../../docs/SYSTEM_MODEL.md)。

这是当前明确保留的已知相位实验条件。它不证明终端用了GNSS，也不是逻辑上不可能由卫星端估计得到的信息；但实验没有提供其获取流程、误差或导频开销。尤其对于尚未确定是否活跃的全部候选用户，准确相位不能仅凭“导频已知”而自动成立。

Shen对应的相位在式(10)、(14)中出现，并在§III-C式(47)–(54)学习；p.12还明确区分on-grid无该分数相位与off-grid需要相位更新。因而“继承Shen场景”并不能为当前准确已知相位提供直接依据。

注意：已知β并不等于已知完整ν。当前 `1/T_f=1363.636 Hz`，同一β允许多个相差该频率间隔的Doppler；矩阵内部的连续Doppler仍需通过信道估计解释。因此不应把当前实验说成“所有Doppler全已知”，也不能说它已经处理完全部未知Doppler问题。

真实方向小网络实验又额外给定了方向；在当前几何中方向决定Doppler。它是评价降维与先验学习的oracle诊断，不能直接当作普通未知方向GNSS-Free接收机结果。

## 4. AFDM：波形与矩阵成立，但资源效率代价很大

发射端使用IDAFT，接收端用DAFT，保留啁啾参数和长CPP，并且有独立时域计算验证，所以“AFDM”标签成立。它不是把普通线性测量随机矩阵改名为AFDM。

从Shen的大差分时延支持移到16点AFDM后，必须重新计算前缀：

\[
T_s=1/(16\cdot30\,000)=2.0833\,\mu s,\quad
T_u=16T_s=33.3333\,\mu s,
\]
\[
N_{CPP}=\lceil699\,\mu s/T_s\rceil=336,\quad
T_{CPP}=700\,\mu s,\quad T_f=733.3333\,\mu s.
\]

**336点前缀对应16点有用样本，95.45%的时间在前缀，有用窗口仅4.55%。** 16帧整个块持续11.7333 ms，其中有用窗口累计0.5333 ms。当前接收机丢弃前缀，仅处理每帧16点。

这在数学上可以实现：前缀重复足够多周期，所有合法残余延迟的有用接收窗口仍落在当前帧扩展波形内。前轮已验证完整长时延及跨周期相位。Shen本身也要求CP覆盖最大差分时延，因此代价不是AFDM独有的实现错误；但不能因为参考论文采用了长CP就省略本项目的效率核算。

本参数恰有 `N_CPP=21N`。离散CPP样本幅度与有用样本相同，在相同采样功率下，前缀加有用段的离散样本能量是有用段的22倍。该数字是离散实现尺度，不是已验证的连续波形带外能量或完整链路预算。当前固定接收SNR的NMSE/AER比较没有独立证明能效或吞吐率优势。

此外，不能把标准AFDM在一定延迟/Doppler支持下的路径分离、全分集结论原封不动搬过来。Bemani等§IV Theorem 1式(51)对支持范围有条件；当前全时延最大335.52点，而N仅16，常用支持分离保证不能直接套用。**不满足该定理适用条件不等于波形无效，也不证明当前稀疏TDL实例不能估计。** [AFDM原始论文](https://arxiv.org/html/2204.12798v2)

## 5. off-grid：成立，而且扩展了Shen的时延设定

当前默认 `grid_mode='off_grid'`；路径时延来自连续几何和30–50 ns随机时延扩展，Doppler来自连续方向；没有将它们舍入到整数采样或整数子载波网格。路径矩阵在这些实值参数上计算。

因此，同时包含分数时延与分数Doppler。Shen明确忽略分数时延，Huang保留分数时延；将后者加入前者的场景是合理扩展。路径同向/同Doppler以及只有少量TDL分量，不会使参数变成on-grid。

两点限制：

1. 保留off-grid真值，不意味着所有与它相关的未知量都由算法解决。跨帧相位被给定，仍属于有额外已知信息的off-grid实验。
2. 当前连续波形的分支跳变是所选波形定义的性质，不是off-grid必须具有的性质。它与实际发送波形及接收滤波是否匹配，需要明确连续时间实现；前轮已单独记录，不能称作任意AFDM硬件的通用信道。

## 6. 为什么合并在物理上合理，以及哪些结论不能继承

可组合的统一传播模型是

\[
h_k(\tau,\nu)=a_k\sum_\ell g_{k\ell}
\delta(\tau-\tau_{{macro},k}-\tau_{{local},k\ell})
\delta(\nu-\nu_k).
\]

其中宏观几何和公共时延来自GNSS-Free多用户环境；局部超额时延与增益来自TDL；共同空间方向和共同Doppler是远距离、小路径角扩展近似。再把AFDM连续波形通过该传播模型得到有效矩阵，是可解释的一条推导链。宏观时延加局部超额时延，没有重复加入公共传播距离；四个分量中的两个同零超额时延分量合成一个Rician tap，也没有多算路径功率。

但下列事项是本项目自己的选择或额外假设：

- 从OTFS替换成AFDM后，需要自己推导长前缀与跨帧观测，不能直接复用Shen的OTFS二维卷积公式。
- 当前只估计活动与有效信道，没有继承Shen的未知数据符号检测任务。
- 采用准确已知相位，减少了一部分接收端未知量。
- 当前空间、时延、Doppler严格绑定于一个几何场景；不能声称这是复刻Shen每个角度/参数的抽样实现。
- 部分DFT导频、Q=16、非空活动条件和当前score网络训练方式，不由两篇论文共同唯一确定。
- “Huang的score方法优于其基线”不是这个新任务中score必然优于当前优化物理基线的理论保证。

### 6.1 估计有效信道不等于解决绝对时延歧义

当前路径矩阵满足

\[
G(d,\nu)=e^{j2\pi c_1(d^2-d_0^2)}G(d_0,\nu),\quad d_0=d\bmod16.
\]

本轮额外检查20个跨周期延迟，相对误差最大2.53×10⁻¹¹。若允许自由复路径系数，仅凭此有效路径矩阵不能唯一恢复完整绝对差分时延；跨帧共同Doppler相位也没有直接消除这个时延等价关系。几何先验或额外观测可能增加信息，但需单独建立辨识依据。

这不妨碍以有效信道NMSE和AER为目标，却意味着当前结果不能同时被解释为“已经解决了GNSS-Free绝对定时获取”。

### 6.2 块内固定参数需要专门敏感性检查

Shen在式(10)后讨论多帧准静态条件及Q增大造成的变化，不能把“LEO”直接等同于整个块严格恒定。当前采用11.7333 ms内固定包络延迟和方向、恒定Doppler的近似。

本轮保持同样的初始几何，额外让卫星沿600 km圆轨道运动，固定地面用户和公共参考。100个新场景、4000用户的块首到块末变化如下：

| 诊断量的绝对值 | 中位数 | 95%分位数 | 抽样最大值 |
|---|---:|---:|---:|
| 包络延迟变化，采样点 | 0.0553 | 0.1029 | 0.1114 |
| Doppler变化，Hz | 4.030 | 6.279 | 6.817 |
| 实际距离载波相位与恒定Doppler预测差，rad | 0.1485 | 0.2315 | 0.2513 |

方向向量变化很小，最大约1.48×10⁻⁴。以上是模型敏感性计算，不是实际接收机NMSE，也不是完整地球自转/轨道/散射仿真。它不足以宣判固定模型不可用，但若追求很低NMSE，尤其采用有分支跳变的分数时延波形，不能仅凭“时延小于一个采样点”就保证误差可忽略。应通过时变信道对照或缩短块长验证。

## 7. 当前可以支持什么结论

| 研究结论 | 判断 |
|---|---|
| GNSS-Free背景下，大差分时延/大Doppler多用户AFDM有效信道的JADCE | 可以作为研究场景，但需保留准确已知相位等条件 |
| 同时包含分数时延和分数Doppler的off-grid仿真 | 成立 |
| 由Shen环境与Huang波形/信道建模合并而来 | 大体成立，但包含项目新增假设，并非任何一篇的复现 |
| 卫星端从未知同步状态完成GNSS-Free接入 | 当前未验证，准确相位来源缺失 |
| 不依赖真实方向的完整网络，与已知真实方向小网络是同信息比较 | 不成立，后者为oracle诊断 |
| 在相同公开输入下比较估计器NMSE和AER | 有意义，结论限于该条件实验 |
| 优于其他波形的能效、频谱效率、完整随机接入性能 | 当前实验不支持 |
| 已恢复绝对差分时延、完成物理定时同步 | 当前有效信道指标不支持这一推论 |

建议保留当前模型与数据作为已知相位的估计器比较版本。若下一阶段研究目标是完整GNSS-Free接入，应补上卫星端相位获取/联合估计及误差影响，再核查前缀与导频开销。时变敏感性和实际连续波形也需要对应验证。无需仅因两个文献设置不同就推翻现有数据；真正需要补齐的是信息条件与目标结论之间的缺口。
