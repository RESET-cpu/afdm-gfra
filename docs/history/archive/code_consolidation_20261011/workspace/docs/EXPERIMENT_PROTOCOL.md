# 完整信道 score 主线的实验协议

## 活动判决规则的冻结与复用（2026-10-11）

主比较在扫用户数、SNR或活动概率之前固定活动判决规则，逐点实验沿用同一规则，不能每换一个用户数就另取带标签样本重新选择门限。校准应在独立数据上完成；若要开发覆盖更广运行范围的新规则，应单独定义校准范围并冻结新版本，再统一用于完整比较。

固定规则可以按事先声明的函数使用接收信号、公开噪声方差等输入量进行适配；规则及其系数保持不变。这与在每个测试条件重新拟合门限不同。数值门限能够复用，并不自动证明它在任意负载下均最优或均达到目标错误率，适用范围由冻结后的实验确定。

当前40用户、至少一人活跃的五方法比较复用原100个off-grid场景。SOMP、GAMP-SBL MMV和GNN-ASPL统一沿用上一轮冻结的完整十节点公共SNR规则，来源见[READOUT_POLICY.json](../results/proposed_baselines_40_20261011/READOUT_POLICY.json)；两版proposed均保持0.5门限。本轮属于已有规则从80用户校准条件向40用户非空场景的迁移检查，具体计划的门限条目以该判决规则文件的协议补充为准。历史阶段的校准与运行记录保留各自原有口径。

## 当前论文实验矩阵

2026-10-10按用户澄清的范围，保留现有已验证的 GNN-ASPL 权重；未来如需重新训练，训练和选权重验证集采用 on-grid。后续新增门限校准、性能实验和图表只采用连续时延与 Doppler 的 off-grid 场景。论文仍采用以下六组独立实验。唯一主线为 full_score，使用分类器活动证据及 [mainline.json](../configs/mainline.json)。各方法共享场景和公开输入，信道主指标统一采用完整物理信道重构后的误差。已有实验按各自冻结协议保留。

| 实验组 | 改变的条件 | 主要输出 | 目的 |
|---|---|---|---|
| 1. SNR性能 | SNR；连续参数 off-grid 信道 | AER、active/full NMSE | 评价噪声水平对整体性能的影响 |
| 2. 导频资源 | 导频帧数Q；其余条件固定 | AER、NMSE、达到目标精度所需的导频资源 | 导频需求 |
| 3. 用户规模 | 候选用户数K；固定活动抽样概率p和导频资源 | AER、NMSE、实际平均活跃人数 | 接入规模增大时的性能；K增加也会改变平均活跃人数 |
| 4. 活动负载 | 活动抽样概率p；固定K和导频资源 | AER、NMSE、边缘活动率ρ及平均活跃人数 | 活跃用户增多时的性能 |
| 5. 信道分布泛化 | 固定权重，改变一项明确的信道分布条件 | AER、NMSE；训练与测试分布说明 | 同维度信道分布变化下的性能 |
| 6. 迭代与计算成本 | 同一代表条件下的收敛与运行时间 | 一张NMSE随迭代数的收敛图；一张单场景推断运行时间对比图 | 迭代行为及实际计算代价 |

六组均采用连续时延和Doppler的off-grid信道。第5组保持连续参数模型、网络维度及权重不变，选定例如Rician因子或功率时延分布的一项变化，并列出训练条件与测试条件；具体变化轴及数值待执行配置冻结。按用户2026-10-08的进一步选择，第6组保留收敛、运行时间两个实验即可，不再增加独立的成本子实验。收敛图采用多场景逐轮误差能量汇总；运行时间包含网络前向，固定设备、线程与批量，模型加载单列，记录重复运行的离散程度。读取真值评分的逐轮观察不参与算法更新或停止，带观察器的耗时不直接作为正式运行时间比较。达到上限不改称已收敛。

六组范围已确定。2026-10-09首轮SNR性能实验的扫点、100个独立基础种子及proposed配置已单独冻结，见下文；其余实验组与完整基线比较的执行配置尚待冻结。当前可执行四轴开发配置不等于六组均已实现。完整矩阵以主线与外部基线的比较为主体；结果可支持整机性能结论，单独组件增益需相应受控证据。

### 连续参数场景

off-grid 保留几何场景生成的连续时延和 Doppler，按完整物理公式生成信道、有效跨帧相位算子、观测和噪声方差。所有方法共享准确已知的有效相位算子。有限接收字典用于估计，不改变评价信道的连续参数。保留的 GNN-ASPL 权重经过 29 阶段、39 个 epoch 的预训练以及 5 个 epoch 的细网格物理 H 联合微调，两次历史训练均含 on/off-grid 混合样本，不能改称纯 on-grid 训练。未来重训入口使用 10001 个 on-grid 训练样本和 256 个 on-grid 训练验证样本，保留单套混合 SNR 权重；固定先验方差仅由训练样本真实占用行系数拟合。额外重训已停止，本轮沿用现有 GNN 权重。训练验证集用于选择权重，新增独立 off-grid 校准集只拟合活动门限，off-grid 测试集用于报告性能。

术语依据沿用[Shen等 §V](../references/shen2025_large_differential_delay_doppler.pdf)及[术语记录](TERMINOLOGY.md)。本项目的信息条件与该论文的未知相位设置分别说明。后续新增校准采用独立 off-grid 数据。当前三个传统方法已完成 off-grid 门限重算；GNN 保留历史独立校准的固定门限及其已验证权重，历史校准包含两种网格条件。各方法跨 SNR 使用同一门限及其声明的权重。图表展示 off-grid 的 AER、NMSE 和必要的统计区间。2026-10-09的两分支实验属于下文历史记录，其配置与输出保持原样。

### proposed先行与耗时诊断

proposed可以先于基线完成同一套冻结场景上的推断，保存公开输入、真值和输出身份，之后基线复用同一场景。一次推断同时计算AER和NMSE。当前完整队列尚未启动，先处理单场景耗时；基线在另一个线程继续准备。

2026-10-08的[旧轨迹成本审计](../results/proposed_speed_20261008/TRACE_COST_AUDIT.json)覆盖31个已完成开发场景，迭代中位数304，两张score网络及紧邻矩转换约占原生推断时间84.1%。[默认4 dB首场景逐轮诊断](../results/proposed_speed_20261008/CONVERGENCE_CURRENT.json)在不改更新和停止规则的情况下完成290轮，最终输出与归档逐位相同；150/200轮与最终NMSE分别相差0.159/0.027 dB。此单例不认证新的迭代预算。[有界网络计时](../results/proposed_speed_20261008/NETWORK_BENCHMARK.json)未发现缩小批量或channels_last布局优于当前FP32批量40。上述计时有并发CPU训练，逐轮诊断还包含评分观察器，均为开发诊断；当前主线停止规则和配置未改。

针对用户优先保留AER的要求，[停止规则回放](../results/proposed_stopping_20261008/AER_REPLAY_V2.json)利用上述31条已保存轨迹逐轮检查活动概率，未新增网络推断。原停止轮在31条轨迹上全部精确复现；仅放宽外层阈值没有减少迭代，内部site稳定要求是瓶颈。候选一仅将site自然参数残差从1e−4放宽到1e−3，保留外层均值/协方差/活动概率变化及活动平滑残差1e−4、至少60轮、两个连续10轮窗口，并增加完整活动判决向量连续10轮相同的条件（含首轮，即9次相邻比较）。其停止轮中位数230，总迭代数减少25.24%；候选二同时将均值/协方差变化放宽到1e−3，中位数204，总迭代数减少33.13%。两候选的1240个用户判决均与原最终判决一致，均无漏检或虚警；固定100轮则新增4次虚警。停止只依赖当时及过去诊断，真值只用于事后评分。

这些31条轨迹覆盖0/2/4/6 dB、K40、Q16，只有8个不同场景种子，不能视作31次独立重复或AER不劣的总体保证。该轮只有一个场景有逐轮NMSE：候选一、二相对原最终值分别损失0.026、0.045 dB。该轮首先保留仅放宽site残差的最小变更作为候选，未替换主线默认；随后的进一步缩减及困难条件补测见下。迭代节省为轨迹回放值，不冒充新测运行时间。

用户继续要求缩减后，先固定六个停止候选，再以三个新种子补测SNR−4 dB、Q8、活动抽样概率p=0.2（其余分别为默认条件）。三个输入都运行原600/60/10规则，全部满足原停止条件，未改变任何更新或读取真值作停止判断。它们连同31条原轨迹的[比较结果](../results/proposed_stopping_20261008/SHORTER_COMPARISON.json)覆盖34组输入、11个不同种子；1360个用户判决在六个候选下均与原最终结果一致，无新增漏检、虚警或后续改判。原31条轨迹还经独立窗口实现复核，每个候选的停止轮逐场景一致。

候选B采用均值/输入协方差变化1e−3、site残差3e−3，活动概率变化和活动平滑残差仍为1e−4；外层与site检查均连续5轮，完整判决仍连续10轮相同，最少60轮、最多600轮。34组输入上迭代中位数305→164，总轮数减少46.66%；四条有逐轮NMSE的轨迹中，相对原输出最大损失0.159 dB。进一步将site残差放到1e−2得到候选C，总轮数减少54.17%，但四条轨迹最大NMSE损失0.437 dB；候选D进一步将均值/输入协方差阈值设为3e−3，总轮数减少56.85%，最大损失0.650 dB。这些数值是项目开发设置，未修改主线默认、阻尼、网络权重或基线。该轮NMSE检查仅四条轨迹，三种困难条件各一个新场景。

按用户优先保持AER的要求，随后冻结候选D，以[预定计划](../results/proposed_stopping_confirm_20261008/PLAN.json)运行20个新独立种子，与此前11个种子无重叠：10条件各2场景，覆盖SNR−16/−12/−8 dB、Q8、K80、活动概率0.2、on-grid、Rician因子0/20 dB及默认条件。每个输入仅运行一次原停止规则，真值观察器独立记录逐轮指标，再按冻结D的过去轨迹确定停止点；模型、更新与源码在完整队列中保持不变。[逐用户配对结果](../results/proposed_stopping_confirm_20261008/SUMMARY.json)显示880个判决全部相同，双方均18次漏检、0次虚警，AER均18/880≈0.02045，没有新增错误或通过纠正别的错误抵消新增错误。

其中17例实际提前停止（16例原收敛、1例原达到上限），3例低SNR在双方均不满足停止条件并达到600轮上限。上限输出和其漏检完整计入指标，不将这3例计作提前停止成功。全部20例的总轮数7710→4876，减少36.76%；17个实际提前停止场景为5910→3076，减少47.95%。本次逐轮NMSE的最大损失为0.965 dB，出现在一个Rician因子0 dB场景，更新了此前仅四条轨迹观察到的0.650 dB。[独立审核](../results/proposed_stopping_confirm_20261008/INDEPENDENT_AUDIT.json)复核了所有停止轮、逐用户判决、源码/权重身份及上限语义，与汇总逐例一致。候选D通过本次有限面板的“无新增错误”核验，可据此准备后续完整实验；两场景/条件不构成总体AER不劣保证。默认主线配置尚未替换，带观察器的前缀计时不作为新实现的正式运行时间。

## 2026-10-09首轮proposed SNR性能实验

用户指定SNR范围−4至6 dB，沿用2 dB间隔，取−4、−2、0、2、4、6 dB。每个SNR点在on-grid和off-grid各运行100个场景，共1200次proposed推断。本轮只运行full_score分类器活动证据主线。配置分别保存于[实验配置](../configs/proposed_snr_100_20261009.json)和[接收机配置](../configs/proposed_snr_receiver_20261009.json)。

固定K=40、Q=16、4×4接收阵列、条件化前活动概率p=0.1、默认TDL-D参数和准确已知有效相位算子。基础种子为202610090100001至202610090100100，与前述停止规则开发及验证种子分离；同一100个基础种子在所有SNR和两种网格条件下复用，因此每个点有100个独立场景，跨点和跨网格为配对结果，不能把1200次推断当作1200个独立随机场景。

本轮接收机采用已验证的停止参数：均值/输入协方差变化阈值3e−3，活动概率变化阈值1e−4，site自然参数残差1e−2，活动平滑残差1e−4，外层与site条件各连续5轮，完整活动判决向量连续10轮相同，最少60轮、最多600轮。停止只读取当前及过去的接收机量。权重、FP32网络计算、完整均值、二阶统计量处理、0.1阻尼和0.5判决门限均沿用冻结设置。旧开发入口[mainline.json](../configs/mainline.json)保留其原停止参数，本轮使用单独接收机配置。

执行入口为[scripts/run_proposed_snr.py](../scripts/run_proposed_snr.py)，运行目录为[results/proposed_snr_100_20261009](../results/proposed_snr_100_20261009)。启动前核对原生加速实现与已保存验证轨迹；执行时冻结运行源码和配置，每个进程只加载一次网络，按基础场景、SNR、网格条件依次运行。逐场景保存四字段公开输入、分离的真值、生成参数、完整信道估计、活动概率、判决、原生迭代诊断及文件指纹，后续基线可直接复用相同输入。

[原生实现复核](../results/proposed_snr_20261009_preflight/NATIVE_VALIDATION.json)已通过：四例分别在174、161、398、600轮结束，其中600轮保持MAX_ITERATIONS标记；每一轮活动概率与原保存轨迹完全相同，停止轮、最终判决与NMSE均匹配冻结候选。这些是已用验证输入的实现一致性检查，不计入本轮100个新基础场景。

每个SNR/网格组合独立汇总AER及active/full NMSE，NMSE按误差和信号能量求和后计算。达到600轮上限、超出网络查询支持范围、警告和失败均保留。结果状态以运行目录中的STATUS.json及SUMMARY.json为准；未完成时只显示明确标注的已完成子集，不将100次先行实验视为完整基线比较或低错误率的最终精度认证。

## 既有开发配置与活动抽样

既有开发配置固定一阶/二阶及分类器权重、训练先验、归一化、完整均值、原始二阶普通平均及下限、零均值初始化、两个方向的0.1阻尼、site回退、0.5判决门限与600/60/10停止规则。2026-10-09先行SNR实验的停止参数在上一节单独列出。

四轴开发面板：SNR 0/2/4/6 dB、K=20/40/60/80、活动抽样概率p=0.01/0.05/0.1/0.15、Q=8/12/16/24/32，共17点，每点8场景。主线与基线使用同一公开输入和真值文件。现用基线为SOMP和GAMP-SBL；EM-BG-AMP、AMP-NNSPL及Ding GNN-ASPL完成各自训练、独立校准和检查后加入，状态见[BASELINE_REVISION.md](BASELINE_REVISION.md)。已暂停的旧面板仍按启动时协议保存。默认生成采用完整几何分布。

2026-10-08起，主实验及默认simulate生成均要求每场景至少一个活跃用户，生成版本为known_phase_geometry_v4。先按参数p独立抽取每用户活动指示；若全零，只沿同一活动随机流重抽活动向量，直到非空，再生成观测。几何、路径、导频及标准化噪声随机流保持原规则。抽样在运行任何接收机之前完成，所有方法共享同一场景，不按推断结果或方向选场景。

令J为活跃人数，Z=1-(1-p)^K，则生成分布为P(a|J≥1)=1[J≥1]∏ₖp^{aₖ}(1-p)^{1-aₖ}/Z。公开activity_prior取边缘概率ρ=p/Z，E[J|J≥1]=Kρ，按参数计算，不使用场景真实人数。activity轴中的p是条件化前的抽样概率；图表须区分p与实际边缘活动率ρ，并报告真实人数统计。例如K=40、p=0.01时ρ≈0.0302、平均人数≈1.208；默认p=0.1时原平均为4、条件平均约4.060。非空条件使用户活动不再独立；当前接收机仍采用以ρ为参数的独立Bernoulli工作近似，未加入全局人数约束，也不修改判决输出以保证至少一个预测活跃用户。

生成记录保存活动抽样次数、Z、ρ、期望人数和真实人数。旧v3场景与结果完整保留，供历史复核；新协议必须重新生成并运行全部方法，不能事后删除旧空场景或把旧结果视为新协议完整面板。已有六条件F0证据属于旧生成协议。

可执行入口是 scripts/run_comparison.py 和 configs/current_comparison_experiment.json，当前方法表包含full_score和已准备好的外部基线。新运行必须使用新输出目录。旧结果的源文件身份保持原记录，不能与新运行拼接成一个被冻结的完整面板。

## 指标及选择

论文活动检测主图展示 AER：
\[
 {\rm AER}=\frac{\sum_{\rm scenes}\sum_k1[\widehat a_k\ne a_k]}
                 {\sum_{\rm scenes}K}.
\]
漏检/虚警计数作为内部可复核数据保留，无须各画一组主图。报告总决策数和错误数；同场景用户不能简单当作独立重复。

信道报告 active/full NMSE，先汇总误差能量和真值能量再取比值、转dB。新主实验全部采用非空活动场景；非活跃用户仍进入AER和全信道误差，虚警与漏检均保留。报告实际推断耗时、迭代数、MAX_ITERATIONS、失败/超时及网络调用数，保留所有警告。

如果完整面板有失败，完整面板指标为空，并单列已完成子集，不能删除失败后宣称完成。开发耗时需区分网络加载及端到端时间与原生推断时间；对照比较须使用同一设备和线程设置。停止加速已通过单独的配对轨迹验证，本轮原生实现与实验配置亦单独保存，不能将旧停止规则输出混入新面板。

2026-10-08，用户在暂停后的SNR AER检查基础上确定分类器为主线默认活动证据。6 dB下五方法共同完成的6个场景中，分类器为0/240个错误，解析证据为9/240个错误（均为虚警）；0、2、4 dB各8个场景中，分类器也均无错误。逐场景开发证据见 [AER_REVIEW.json](../results/full_score_nonempty_20261008_100345/review/snr_paused_20261008/AER_REVIEW.json)。解析配置及已有结果保留为历史开发记录；本次默认选择不构成独立性能确认或统计非劣证明。后续主线确认采用冻结分类器权重和判决门限，计入分类器计算成本。

## 独立确认

开发结果仅用于选择实现及确定实验设置。六组实验的正式扫点和逐点样本数依据先导结果预先确定，以独立场景种子冻结确认协议；NMSE每点500次、活动检测每点5000次可作为Cai §VI-A3的样本量参照，最终预算按本项目错误率与场景级不确定性确定。一次接收输出同时计算AER和NMSE，无须为两个指标重复相同推断。不得把当前沿用的开发种子表改名成独立确认。最终比较方法与各自训练、校准设置在启动前冻结。

当前六组完整实验和独立确认尚未完成。切换入口时的限定复现只验证迁移及运行能力。
