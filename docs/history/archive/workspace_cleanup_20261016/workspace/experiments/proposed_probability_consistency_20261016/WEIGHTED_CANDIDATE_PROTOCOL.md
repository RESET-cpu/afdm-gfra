## 数学目标与理由

令s=E‖H‖²/D，以原50000个训练信道的固定估计s=1.000440418139489使用。
活跃Gaussian训练查询X=H+CN(0,vI)的每坐标期望能量为s+v。
定义正权重w(v)=1/(s+v)，采用

    J = balanced BCE + E[w(v) ‖(v/2)∇_x Lθ(X,v) − H‖²/D]。

给定X,v展开平方，有

    E[w(v)‖μθ−H‖²/D]
      = E[w(v)‖μθ−E(H|X,v,a=1)‖²/D]
        + E[w(v) tr Cov(H|X,v,a=1)/D]。

第二项与参数无关，且w(v)>0，所以不限制函数类时仍以同一Gaussian局部后验均值为共同最优目标。
这是DERIVATION.md P6–P8的直接加权推论；不赋予新的方法名称，也不是用真实迭代误差作标签。
实际有限网络和有限优化中，噪声尺度的权重会改变折中，必须用相同原验收规则检验。
该改变不保证分类改善、处处凸、跨v一致或用户间反馈独立。

前一候选的分类差距主要在v≥1区间，均值损失与分类损失并未同时改善到原版水平。
仅拟合c(v)加法项的开发诊断也没有把分类损失降到原版：
step600的选择集BCE从0.06768降至拟合数据上的0.05735，原版为0.05097。
这个拟合使用选择标签，是乐观开发诊断，未用于候选输出或确认；原数值警告及独立显式求和复核均保存。
目前不能据此断言任意c(v)都不够，也不能断言联合目标已收敛。
