# Cai 推导完整性审查

审查日期：2026-10-08。对象是当前完整信道 score 主线及论文第二、三章，以
[Cai 正式版原论文](../references/cai2026_score_based_jadce.pdf)的§II–V、Algorithm 2和§VI-A2为逐项参照。
在线版本为 [arXiv v2](https://arxiv.org/html/2506.00581v2)。

**本次结论：在已声明的物理模型、工作后验及统计近似范围内，当前方法的推导链已经闭合；
未发现仍需修改接收机或训练网络才能解决的推导阻塞项，可以固定当前算法转入完整实验。**
这一结论针对推导完整性和公式与实现的一致性，不认证论文录用、新颖性等级、实际性能或全局收敛。

## 核验标准与材料

核验每个更新的输入、输出、维度、概率含义、推导及适用条件；核验有限网络目标与使用方式；
核验初始化、顺序、支持范围、拒绝／回退、裁剪、阻尼、停止和复杂度是否写全。
与 Cai 不同的选择只要定义完整、代数正确、近似明确，不因“没有照搬”而判为缺失。
原论文未证明的完整实用算法全局收敛，不额外作为本次转入实验的条件。

## 本次关闭的具体缺口

1. **局部后验的连接推导。** 补T6a–T6b，避免直接从全局工作后验跳到两个互不说明关系的学习模块。
2. **线性更新的条件与投影。** 补正噪声、正先验方差、非零算子及先投影再相除，写清完整向量与MMV平均迹的分母。
3. **学习目标的证明。** 补Tweedie求导、DSM条件最优解、有限均值的条件MSE、总迹的可辨识范围及共享方差拟合。
4. **活动证据与联合矩。** 补BCE最优解、先验修正、Gaussian积分及混合分布的矩，明确“精确代数”和“实际近似”的对象。
5. **物理表示。** 补连续时间wrapped-chirp波形、元素展开与整数极限；补一致的复包络、阵元索引和Doppler符号，明确Huang参数反号转换。保持当前生成分布。
6. **完整实现定义。** 补停止归一化、计数器、非有限值失败处理、条件信道输出和完整复杂度，并同步LaTeX。

额外提供A8–A9的四相位合成例子：两个先验在同一查询处具有完全相同的条件均值与实协方差，
但真实活动密度比约为0.6065306597和0.5378828427，而相同Gaussian矩拟合均给出0.5。
该构造证明局部条件矩不唯一确定活动证据，支持区分两种证据机制；不预判实际分类器性能。

## 转入实验时采用的结论

可以将当前接收机作为固定算法，开展完整性能实验。对外可表述为：
当前方法在明确工作模型及近似下，已完整给出模型、训练目标、推断更新、数值实现与复杂度。
需要由完整实验回答的是学习活动证据的收益、实际查询失配、数值策略触发及运行成本，
这些属于算法效果验证，不是本轮仍未闭合的推导。

保留当前已知有效相位、已知噪声方差和固定网络维度的范围。实际AFDM查询的精确AWGN性、
有限网络的精确后验解释及整个实用迭代的全局收敛都不是本文已证明的命题。
改变这些主张或系统已知条件时，需要重新核对对应推导。
