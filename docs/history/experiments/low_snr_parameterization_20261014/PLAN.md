# 强噪声下的配对一阶训练

## Material Passport

2026-10-14；academic-research-suite / experiment-agent。用户授权开始三个训练对照及清理近期 beam-channel 权重。只训练一阶均值估计，所有模型与默认接收机分开保存。文献依据见 [定向调研](../../references/low_snr_score_20261014/REPORT.md) 与 [术语表](../../docs/TERMINOLOGY.md)。

## 问题和控制变量

在旧固定总体 RMS 归一化、相同完整信道先验和相同 Cai 骨干下，EDM 参数化或把训练集中到固定强噪声档，能否改善一阶 AWGN 去噪？

五个任务：原参数化、EDM 参数化、固定 v=1、sqrt(10)、10 的原参数化专门模型。后三个分别计费，每个训练预算与共享模型相同，合计是其三倍。全部使用同一随机骨干初始化，保留 legacy_image 变换、连续 log(v) 噪声条件及其初始化。旧第81轮 first 是独立历史参考；它有不同预训练历史，不能把其结果与从头模型当作同预算对照。

沿用 50000 个训练信道与 5000 个验证信道，按原物理场景隔离；每场景四个候选信道。源文件 SHA256 对照原 prior 校验。训练 identity 原路径为 macOS dataless 文件，读取使用共享 angular 数据目录中 SHA256 完全相同的 identity 副本，不改变信道或身份。保留固定 s0=0.2647966452702405，不逐样本归一化；EDM 的实坐标信号方差由完整训练库二阶矩计算，依据独立随机路径相位下先验零均值，不读取测试真值。

## 公式

令 nu=v/2。旧读出 F=r+nu*s，保持原目标 mean((F-h)^2/nu)。EDM 只改为

```
c_skip = tau2/(tau2+nu)
c_out  = sqrt(nu*tau2/(tau2+nu))
c_in   = 1/sqrt(tau2+nu)
F      = c_skip*r + c_out*G(c_in*r, v)
```

G 是相同未做 1/sqrt(nu) 缩放的原始骨干输出。此复坐标换算对应 Karras 等 NeurIPS 2022 §5 式(7)–(8)；原文输入、输出预条件化的使用边界已记入术语表。当前不引入 EDM 的额外损失权重或新噪声抽样。

共享任务的 SNR 在 [-20,30] dB 均匀抽样。专门任务消耗完全相同的 uniform 和标准 Gaussian 随机数，只覆盖 v，因此样本顺序、标准噪声以及后续 epoch shuffle 保持配对。报告按 5 dB 档累计暴露量；专门训练效果可能来自增加本档样本暴露量，不能单凭其胜出声称已证明梯度冲突。

## 首轮预算与进程

每任务固定10轮、每轮50000信道、batch64/micro16，共7820次Adam更新。共39100次更新。Adam lr=1e-4，按轮cosine至1e-6，clip_norm=1，EMA=0.999；与旧优化器设置一致，但该10轮学习率日程不是旧100轮轨迹的复现。单种子为初筛，不证明收敛或排除候选上限。

MPS上按轮串行五任务，每120秒及每轮保存model/EMA/Adam/随机数/样本游标完整断点。每任务仅保留 latest resume、best EMA、final EMA。主比较使用同轮final EMA，best只作次要诊断。冻结运行源码和配置；进程监控每10秒记liveness，整个队列12小时上限，超时先请求保存退出。写入结果目录的pause.request也可停止；失败保留日志，不自动重启。预计时间参考旧骨干历史每轮约7–9分钟，五任务10轮约6–8小时，实际以状态为准。

## 评估及下一步

每轮完整5000验证集评估各任务自身训练噪声分布的DSM与两种NMSE；不同噪声分布的汇总指标不直接排序。在1/5/10轮，用预先固定的首128个验证场景（512信道）评估 v 对应 SNR [-15,-10,-5,0,5,10,20,30] dB。所有模型共享同档输入噪声，固定噪声模型只在各自已训练档作主比较，不作逐样本oracle选择。

保存每个样本的误差、信号能量及场景ID。报告总能量NMSE、逐信道等权NMSE（每场景候选数相同，等同场景等权比值平均）及按物理场景配对bootstrap区间。单初始化、验证场景区间不刻画训练随机性。高SNR档用于检查是否损伤已有能力。5000独立测试库不用于本轮调参/选模。

首轮结束后再决定有希望方案的多种子或更长训练；先做同输入实际查询重放，再考虑重训二阶和活动模块及闭环接收机。只换一阶不能声称完整JADCE已经改善。

执行入口：`prepare.py`冻结后由`watch.py`启动冻结的`run.py`。启动前验证包含公式/梯度等价、随机数配对、EDM零分支解析结果、有限梯度和真实MPS中途断点恢复；结果见`TESTS.json`。
