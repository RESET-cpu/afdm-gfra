# 保留活动混合时的外部因子与标量Gaussian site

以下公式针对给定独立用户消息的线性Gaussian工作模型。
它们不把实际迭代误差重新假设成独立AWGN，也不声称用户后验独立。

## 1. 其他用户积分

Y=Σ_j A_jH_j+N，N~CN(0,σ²I)，其他用户消息为

    q_j(H_j)=(1−p_j)δ_0(H_j)+p_j CN(H_j;m_j,V_j)。

对其他用户活动组合s枚举，记其先验组合权重w_s，

    e_s=Y−Σ_{j≠k:s_j=1}A_jm_j,
    C_s=σ²I+Σ_{j≠k:s_j=1}A_jV_jA_jᴴ。

直接积分得到（没有使用目标用户自身消息）

    L_k(h)=Σ_s w_s CN(Y;A_kh+Σ_{j≠k:s_j=1}A_jm_j,C_s)
          =Σ_s exp(c_s+2Re b_sᴴh−hᴴJ_sh)，                         (G1)
    J_s=A_kᴴC_s⁻¹A_k，b_s=A_kᴴC_s⁻¹e_s，
    c_s=log w_s−M logπ−log det C_s−e_sᴴC_s⁻¹e_s。

J_s半正定即可；L_k本身不必在h上归一化。保留c_s是必要条件，
否则不同活动组合的似然比例改变。每个分量只使用正定C_s求解，不求A_k逆。

## 2. 同一局部分布的活动和条件矩

目标先验为(1−ρ)δ_0+ρ CN(0,V_0)。每个分量：

    U_s=(J_s+V_0⁻¹)⁻¹，μ_s=U_sb_s，
    ℓ_s=c_s−log det V_0−log det(J_s+V_0⁻¹)+b_sᴴU_sb_s。

定义log Z_1=logsumexp_s ℓ_s，log Z_0=logsumexp_s c_s，

    p=logistic(logitρ+log Z_1−log Z_0)，
    ω_s=exp(ℓ_s−log Z_1)，μ=Σ_sω_sμ_s，
    V_1=Σ_sω_s[U_s+(μ_s−μ)(μ_s−μ)ᴴ]，
    m=pμ，V=pV_1+p(1−p)μμᴴ。                                  (G2)

其中V_1及V都是中心协方差；最后一项包含活动不确定性。
J_s秩亏不妨碍V_0正定时的积分。代码另用复平面的Gauss–Hermite求积核查归一化与矩。

## 3. 保持原正标量Gaussian反馈的矩投影

若输出仍限制为S(h)=exp(2Reηᴴh−α||h||²)，α>0，
应使Q(h)=L_k(h)S(h)/Z(α,η)匹配(G2)的均值和协方差迹。
Q仍为混合分布，不是Gaussian。其分量矩为

    C_s(α)=(J_s+αI)⁻¹，u_s=C_s(α)(b_s+η)，
    log z_s=c_s+d logπ−log det(J_s+αI)+(b_s+η)ᴴC_s(α)(b_s+η)，
    log Z=logsumexp_s log z_s。                                (G3)

令t=||m||²+tr V，最小化自然参数凸目标

    F(α,η)=log Z(α,η)−2Reηᴴm+αt。                             (G4)

其导数为

    ∂F/∂α=t−E_Q||H||²，
    ∂F/∂Reη=2Re(E_QH−m)，∂F/∂Imη=2Im(E_QH−m)。                (G5)

对数配分函数的Hessian为充分统计量的协方差，因此目标在可积域凸。
内点驻点正好匹配均值和总二阶矩；均值匹配后等价于匹配中心协方差迹。
这仍是标量精度限制，**不匹配全协方差矩阵，也不恢复全部活动联合模式**。
若α>0约束下不可行，应保存边界及矩残差；不能裁剪后把它称为精确匹配。

L_k只有一个Gaussian分量且J=I/v时，解退化为

    α=1/u−1/v，η=m/u−r/v，u=tr V/d，                         (G6)

前提是u<v。这里是L_k只有一个分量；一般混合情形没有(G6)的相减公式。
若目标先验本来就是CN(0,I)，则无论L_k如何混合，α=1、η=0一定精确恢复原先验site。
将L_k先拟合成Gaussian后再相除，通常不满足这一恢复性质。

## 4. 与本项目完整目标的关系

该内核解决了“混合外部因子对应哪个局部矩、怎样合法反馈”的代数接口。
完整K40枚举需2^39个其他用户活动组合，不能直接部署。
只保留少量组合、限制伙伴数或再次压缩其余用户都会引入需要单独验证的近似。
原活跃信道先验也不是CN(0,I)，旧标量AWGN网络不能直接计算一般(G2)。
因此本阶段成功只构成后续修正的必要基础，完整物理接收机的AER和误差分布尚待验证。
