# 利用训练信道相关性的线性响应核对

2026-10-15。独立候选；原Proposed的源码、配置、三权重和五个baseline保持不变。
来源方法沿用academic-research-suite的原文核对及实验验证流程。

## 问题与依据

前阶段查明trace-normalized LMMSE的每用户Gk=WkAk不是单位阵，
按工作C⁻¹加权后，自身项(Gk−I)Hk造成明显信号/误差负相关。
直接求Ak⁻¹则放大噪声。这一轮先检验训练先验中的AFDM输出/输入相关是否可降低单位响应的代价。
不能将4个物理路径等同于4维固定线性子空间；各样本连续参数不同，必须量化总体谱与截断误差。

术语依据为Edfors等，VTC 1996会议版（并非1998期刊版）：
*OFDM Channel Estimation by Singular Value Decomposition*，
§III-B式(6)–(9)、印刷p.925，§III-C式(10)–(11)、p.926。
作者机构全文：https://lucris.lub.lu.se/ws/portalfiles/portal/6289557/1056818.pdf
该文提供channel correlation、low-rank approximation、Karhunen–Loève transform和MSE floor的出处。
它没有给出本项目AFDM多用户AWGN保证。以下观测展开、线性约束和统计估计是项目推导。

## 固定范围

1. 用原50000个训练物理信道的全部16个天线AFDM矩阵估计256×256二阶矩。
   全部按原尺度归一；均值按已知随机复相位先验取0，不依据测试数据中心化。
   特征分解后保留累计训练能量99%与99.9%的两个预定秩。
2. 在原5000个验证候选上记录投影NMSE、按物理场景聚合及逐样本分位数，不能隐瞒弱尾部。
3. 对四个已有开发观测，只使用公开Ak、噪声与训练U构造每用户受限线性逆。
   首先报告条件数、热噪声方差及均匀先验干扰模型的噪声代价，不训练新网络。
4. 只有线性查询有可用支持范围，才检查旧AWGN网络的单次查询与实际误差。
   不选择最有利秩/场景来覆盖失败；每个预定分支独立记录。
5. 逐轮反馈与全接收机仍须单独验证，低秩几何改善不是目标完成。

## 操作的明确公式

对每个天线，将Hk的AFDM输出/输入矩阵展平为h_k∈C^256，先验二阶矩R。
U∈C^(256×r)由训练R的前r个特征向量组成；h_k=U z_k+δ_k，Uᴴδ_k=0。
输出先、帧后展平接收数据，得到y=Σ B_k z_k+Σ (I_output⊗A_k)δ_k+n，
B_k=(I_output⊗A_k)U。当前输出与输入均16、帧数16，B_k为256×r。

先检验V_k=(B_kᴴB_k)⁻¹B_kᴴ，因此V_kB_k=I_r，
物理信道查询可写R_k=U V_k(y−Σ_{j≠k}B_j m_j)。
它在训练子空间内对自身信道具有单位响应；完整真实误差还包含截断项、其他用户残差与热噪声。
禁止删除δ_k或把其当作独立Gaussian。固定U不使用目标用户的真实时延、多普勒、方向或活动身份。

热噪声协方差为σ²U V_kV_kᴴUᴴ。工作干扰模型首先取各用户系数协方差ρΛ_r，ρ=.1，
其中Λ_r为训练二阶矩的保留特征值；此模型只用训练总体，不依赖真实活动数。
若要在原256维坐标补加Gaussian噪声至vI，需要v至少为工作误差协方差最大特征值。
实际误差的非Gaussian性、信号依赖、空间相关均不得由此视为已解决。
