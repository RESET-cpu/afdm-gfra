# 对公开工作干扰协方差加权的受限线性解

在训练秩88、132均已由预定能量阈值确定后，直接最小二乘几何显示部分白化方差超支持。
进一步使用同一训练Λ与公开热噪声，对其他用户干扰作加权；不改变U、阈值、噪声或活动先验。

令S=σ²I+ρΣ_j B_jΛB_jᴴ，G_k=B_kᴴS⁻¹B_k，V_k=G_k⁻¹B_kᴴS⁻¹。
有V_k B_k=I。该式也是将S替换为S−ρB_kΛB_kᴴ后的相同受限解。
工作误差协方差C_k=V_k(S−ρB_kΛB_kᴴ)V_kᴴ=G_k⁻¹−ρΛ。
其与直接最小二乘的差应为半正定（相同约束与工作模型下），以数值核对为准。
本项目从约束线性估计的二次目标推导此式，不把它命名为新的既有算法。

先保存纯公开几何与测试结果，再在冻结规则下做单次实际查询。
空间工作协方差暂为单位阵，各天线使用相同V_k；实际误差的空间颜色将离线报告。
各用户v_k=λmax(C_k)，在原256维AFDM坐标补加协方差v_k I−U C_k Uᴴ的独立Gaussian扰动。
此时模型协方差为v_k I；真实误差不因此自动Gaussian，遗漏方向δ必须保留在实际误差中。
超出原支持[.001,100]的条件记录不支持，不夹住v或删除该条件。

单次查询使用原first与activity，不训练或改权重；固定4个扰动种子，分别评价每次输出，不平均预测。
真实活动与信道仅在输出保存后用于指标与AWGN误差诊断。
两个训练秩都报告，不依据这四个条件择优后宣称独立验证。
