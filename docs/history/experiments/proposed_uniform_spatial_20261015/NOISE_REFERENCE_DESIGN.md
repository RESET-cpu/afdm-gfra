# 补充机制核查：有限样本噪声谱与阻尼

2026-10-15；在固定20条接收机运行期间新增的离线诊断，不改变其算法、参数或停止规则。
动机是已完成的场景0在谱收缩下精度恢复，但仍有小量补噪和停止残差。

固定M=16、L=256，生成20000个独立CN(0,I)噪声矩阵，保存每个ZZᴴ/L的最大特征值。
另用独立种子生成20000个噪声矩阵，核对前一批99%经验分位数的实际超越率。
这里只建立已知热噪声模型的有限样本参照，没有把分位数用于正在运行的接收机。
不根据接收机精度选择分位数；本诊断固定99%，不扫描其他门限。
实测闭环残差依赖同一观测，其参照百分位**不是**具有校准显著性水平的闭环p值。

独立另核对固定协方差补加噪声η_t下的算术阻尼：
s_1=η_1，s_t=(1−β)s_(t−1)+βη_t，β=0.2。
若Cov(η_t)=C_add且各轮独立，V_t=(1−β)²V_(t−1)+β²C_add，
V_∞=β/(2−β)C_add=C_add/9。
原方差标签算术插值对稳定C_add仍给C_add，不能解释为上述点估计的误差方差。
该恒等式只针对独立补加分量；真实闭环中原始查询还依赖历次噪声，
不能用C_add/9替换完整误差协方差。每轮C_add改变时记录同样权重下的工作二阶矩递推，
并显式保留其对历史依赖的局限。

文献依据：Kritchman–Nadler，2008作者稿§2–2.1对有限样本噪声谱及最大特征值的讨论；
Takeuchi已登记的跨轮误差协方差与阻尼公式。Gaussian参照分位数使用直接模拟，
不冒充原文Tracy–Widom算法或给现有闭环额外的统计保证。
