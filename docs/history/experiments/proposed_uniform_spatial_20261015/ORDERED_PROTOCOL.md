# 调整阻尼与补噪的顺序：独立后续实验

2026-10-15。此前固定20条运行保持原样。其首轮改善随后失稳，同时查询MSE/v降至约0.4。
独立补加分量在0.2算术阻尼下具有1/9稳态方差，而标签未体现这一点；
本轮据此更换查询构造，不对前一版本扫描阻尼、停止容差或噪声预算。

## 每轮统一规则

记A为16×640导频算子，n=640。固定W=n Aᴴ/trace(AᴴA)，不随轮次改变。
这是OAMP中迹归一化的matched filter形式，满足trace(WA)=n，不构成当前算子的状态演化保证。

反馈均值记M_t，另保存平滑均值P_t=(1−β)P_(t−1)+β M_t，β=0.2，第一轮P_1=M_1=0。
构造物理查询R_t=P_t+W(Y−AP_t)。因为W和Y固定，
该式严格等价于对**未补噪的**物理查询作相同算术阻尼。补加噪声没有进入查询的历史平均。
原非线性Gaussian外信息及反馈均值/方差的0.2阻尼保持原定义。

从Y−AP_t的16×256天线展开估计空间误差C_t，采用前一阶段预定的奇异值收缩公式。
在独立同分布行误差、同一天线协方差、与热噪声独立的工作模型下，
B=I−WA，用户k的空间平均查询二阶矩为

C_q,k = ||B_k||F²/N_in · C_t + σ² ||W_k||F²/N_in · I。

保留每用户的两个系数，而不是直接把总平均当成每用户协方差。
以最大特征值为共同目标给每用户补加独立Gaussian噪声，确保在工作模型内得到共同标量标签。
训练支持不足时沿用明确的95%上限内部分补齐；共同目标均值不得低于任一用户的原均值，
超支持的实际标签交由原Denoiser处理并明确计数。补噪使用每轮新抽样，不在采样后再次阻尼。

每轮仍由原first/second/activity及其pF联合矩给出后验均值和标量Gaussian外信息。
输出采用最后实际后验均值，不选最好轮，不改活动门限。原反馈方差仍生成并记录，
线性不确定性由当前公开残差估计；这是一项明确适配，不宣称等同原EP或FIRE原算法。
真实残差的信号依赖、非Gaussian性、行间相关和原反馈方差代理误差仍须检查。

## 两个预定版本

- ordered：原Gavish–Donoho收缩谱边界(1+sqrt(β_s))²，β_s=16/256。
- calibrated：同一收缩函数，只将纯噪声不易区分的样本特征值设为零。
  边界固定为独立20000份CN(0,I)噪声矩阵最大样本特征值的99%分位数1.58661918434336。
  独立20000份噪声核对的超越率为0.995%。该校准未使用信道、接收机输出或精度。
  它是有限样本噪声参照，不能宣称数据拟合后的闭环残差具有同样的显著性水平。

99%是此次唯一固定选择；不根据接收机结果扫描其他分位数。
两个版本区分顺序修复与额外有限样本谱判断，不将后一判断冒充已证必要条件。
