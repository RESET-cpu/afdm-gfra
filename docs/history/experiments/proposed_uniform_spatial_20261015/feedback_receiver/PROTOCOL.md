# 实际当轮映射导数的反馈校正

2026-10-15。上一阶段48条独立确认及其离线逐用户检查已经完成，属于有证据的进展。
本阶段在独立目录推进反馈规则；原Proposed的28个受保护文件、权重和备份保持不变。
不修改已确认的空间处理实现及其结果。本文件在本阶段闭环运行之前确定。

## 固定公式与估计对象

沿用calibrated空间规则、相同残差估计、先平滑物理均值再补噪、双向0.2阻尼及原停止规则。
给定当轮之前的Gaussian site等历史状态S，记原Denoiser的实际返回均值为D(R;v,S)。
先复制S，再在同一S上分别计算D(R+εZ)和D(R−εZ)；包括一阶网络、二阶网络的site接受判断、
活动分类器以及复用site分支，不能把它缩写为仅对条件均值或pF求导。

每轮使用一个新独立复Gaussian探针，E|Z_i|²=1，ε=0.01√v，
α=Re<Z,D(R+εZ)−D(R−εZ)>/(2εd)，d为全部复坐标数。
这是归一化实Jacobian迹tr(J)/(2d)的Monte Carlo中心差分估计，不是精确Jacobian。
旧开发查询的三个探针通常相差数个百分点；本阶段保留这种估计误差，不靠额外阻尼掩盖它。
探针种子固定为202610156800000+100×开发场景编号，随轮数顺序抽取。
正负扰动与基准的site接受/方差floor分支不一致时，记录分支切换并判为该运行不适用；不选一侧结果。

令ρ=tr(平均原联合后验协方差)/M，为原二阶及活动混合的风险代理。
候选反馈（加原反馈阻尼之前）为

U=(D−αR)/(1−α)，ν=(ρ−vα²)/(1−α)²。

ν使用近似Stein关系E Re<e,D−H>/d=vα；它不是对实际风险的无偏保证。
α的符号保留；若1−α≤0.001或ρ−vα²≤0，则明确记录不适用失败，不裁剪为正数。
当前线性规则直接从残差估计工作协方差，传入ν不决定该协方差；ν仍用于反馈标签及诊断。
反馈算术阻尼及其方差标签保持原样，以隔离本阶段改动；跨轮相关可能使标签偏离真实MSE。

## 最小完整接收机比较

- 使用四个旧开发条件(0,−4)、(8,0)、(16,4)、(24,−4)，不是新场景确认。
- 空间原反馈对照与实际导数反馈各4条，共8条；两者均600轮上限及原完整停止条件。
- 补噪种子沿用开发rep0：202610156300000+100×场景编号。无参数搜索、无阈值改动、无重训。
- 重新运行空间对照是为了记录每轮阻尼前反馈，并做同机计时；输出须复现旧记录
  （场景24使用已完成的121轮检查，其余使用原已收敛输出）。
- 每轮额外两次完整网络查询全部计入成本。分别记录基准调用、探针调用、实际迭代与推断秒数。
- 接收机只接收ReceiverInput四字段；预测和推断记录保存之后才读取真值作离线诊断。
- 所有异常、未收敛及最后有限输出保留。超支持范围不冒充正常完成，不以截断后调用少表示加速。

性能检查沿用汇总损失≤0.1 dB、每条件损失≤0.25 dB、逐条件不增加MD/FA、全部按原条件收敛。
通过这些只表明值得进一步研究；不等于完成AWGN目标。
主要机制量为每轮阻尼前及阻尼后查询/反馈实交叉相关，同时报告天线、AFDM输入/输出协方差、
伪协方差、四阶矩及MSE/标签。均保留全部条件，不按活动真值改变推断。
