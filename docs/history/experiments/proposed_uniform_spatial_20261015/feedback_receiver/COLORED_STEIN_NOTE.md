# 相关输入下交叉项的公式边界

本文件是下一步诊断的推导，不改变正在运行的八条已预定接收机，也不提供新性能结论。

## 需要区分的两个量

将d个复坐标写成2d个实坐标，设查询R=H+e，条件e为零均值Gaussian，实协方差Σ。
固定H、方差条件和进入本轮之前的历史，去噪映射的实Jacobian为J。
普通归一化迹是α=tr(J)/(2d)。Stein恒等式给出

E Re<e,D(R)−H>/d = E tr(ΣJ)/d。

只有Σ=(v/2)I时，右侧才化为v Eα。
因此把实际导数测得更准，仍不自动消除相关输入下的交叉项误差。
当前空间候选的末轮输入维协方差仍有颜色，不能把此处的白噪声条件视为已成立。
历史状态本身与观测噪声相关；条件于历史后是否仍有该Gaussian模型，还须单独检验。

对给定工作协方差，可用复探针Z（对应实协方差Σ/v）估计

β_C = E_Z Re<Z,J[Z]>/d = tr(ΣJ)/(d v)。

当工作协方差等于真实条件协方差、v=E||e||²/d且Stein条件成立时，
以β_C替代α可消除固定系数反馈的平均实交叉项。
β_C是协方差加权的Jacobian迹，不是普通散度；不能称其让普通divergence变为零。
经验系数依赖输入时还涉及系数自身的导数，不能将上述固定系数恒等式写成完整有限维闭环定理。

## 现有线性模块已经包含哪些协方差信息

令A为16×640公开观测矩阵、W=640Aᴴ/tr(AᴴA)、B=I−WA。
若暂以各用户/输入坐标独立且共享空间工作协方差C描述平滑反馈误差，
并暂忽略它与原观测热噪声的相关，则用户k的查询误差工作协方差包括

G_k=B_k B_kᴴ，T_k=W_k W_kᴴ；
在输入×天线坐标顺序下，C_q,k = G_k⊗C + σ²T_k⊗I + I⊗C_add,k。

AFDM输出坐标在这个工作模型中独立复制上述块。
现有标量空间补齐使用这些输入矩阵的部分迹；T_k非标量阵时，空间补齐不消除输入维颜色。
本式仍遗漏真实跨轮反馈/热噪声交叉项；不能因为能生成Gaussian探针就把其协方差称为真实误差协方差。
对于固定历史下逐用户可分的映射，迹只依赖对角用户块，但真实误差的跨用户相关仍存在。

## 可检验的下一步

当前八条运行结束后，先在已保存的实际查询上比较普通迹和按公开算子传播的协方差加权迹，
同时用保存后的真值仅作诊断核对实际交叉项。先验证各向同性极限、复坐标因子、
线性映射的解析迹和工作协方差的部分迹，再判断是否值得接入闭环。
不把单个真实误差样本的协方差用于推断，不据此事后更改本阶段规则。
