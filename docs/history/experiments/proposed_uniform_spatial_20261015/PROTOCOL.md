# 原标量反馈下的逐轮空间处理

2026-10-15；academic-research-suite，隔离开发实验。原Proposed代码、配置、权重保持冻结。

## 新假设及与已有实验的区别

逐维Gaussian诊断已证明，天线边缘协方差本身足以使旧pF映射大量虚警。
此前的每轮空间处理配合D-OAMP或逐用户矩阵反馈；本轮保留原Denoiser、标量Gaussian外信息、
两向新值权重0.2及原停止规则，仅替换线性模块。每轮都采用同一处理，没有首轮开关。

从当前公开残差D=Y−A M构造16×256天线展开T，L=Q N_out=256，β=M_rx/L=1/16。
设S=T Tᴴ/L=U diag(λ) Uᴴ，已知复热噪声功率σ²，a=||A||F²/Q。
两个预先固定的残差信号谱估计：

- psd：b_j=max(λ_j−σ²,0)。
- shrink：当λ_j/σ²>(1+sqrt(β))²时，
  b_j=σ²[((λ_j/σ²−β−1)²−4β)/(λ_j/σ²)]，否则b_j=0。

第二式来自Gavish–Donoho的Frobenius损失奇异值收缩函数，作者稿1405.7511v3式(7)、
§2.1与§4；使用b_j作为去噪残差矩阵的空间二阶矩。它不是协方差最优收缩定理。
论文是实矩阵大系统低秩模型；本实验把相同函数用于复残差，并不主张有限AFDM闭环最优。
后续残差还依赖同一观测噪声，已不满足独立添加噪声的直接假设，须实测其偏差。

工作先验空间协方差取C=U diag(max(b_j/a,δ)) Uᴴ，
δ=1e−12 max(σ²/a,1)只保证数值正定，不改变低秩谱的实质功率。
此处每轮从残差重新估计C，**不把原反馈方差当作C的trace**；原反馈均值仍用于D及线性查询。
因此这是残差估计的不确定性与原Gaussian外信息均值组合的项目适配，不是原论文的原样EP。
incoming feedback covariance仍记录且参与原非线性外信息及其阻尼，但不直接传入新的LMMSE。

用原SpatialLinear完成共同C的LMMSE和外信息，得到(r_raw,C_raw)。在原信道坐标下
增加本轮新抽取的独立CN(0,C_add)扰动，补齐C_raw的小特征值。
可支持时补齐为λmax(C_raw)I；超出训练上限时沿用已有明确规则：在95%的训练上限内
最大化补齐，实际标签取补齐后trace/M，保留未补齐标记；若平均值本就超支持则保留失败。
不截断噪声标签来伪装支持范围。补齐后的(r,vI)再进入原查询阻尼、三个网络和反馈。

该协方差加法只在工作模型内成立。新噪声独立于过去查询；原查询阻尼带来的跨轮相关，
残差估计误差、空间以外的相关性及自身响应偏差均不因此消失。逐轮诊断保留全部这些限制。
工作规则各轮一致，未宣称实际误差已是AWGN。

## 固定面板、预算与门槛

四个旧开发条件：0/−4 dB、8/0 dB、16/4 dB、24/−4 dB。
原算法每条件一次，两候选每条件各两个固定扰动种子，合计20条完整轨迹。
同一场景、同一重复的两候选使用同一随机种子；不同轮使用新噪声。
上限120轮，最少60轮、原收敛窗口/容差、门限0.5不变；每条推断600秒上限。
网络调用计数含全部实际调用。不训练、不扫谱阈值或噪声预算、不按最优轮回选结果。

先核对小型复数Gaussian更新、谱函数缩放、完全/部分补齐及其因子；
每个原算法输出与已保存同输入结果核对。全部轨迹先保存预测再读取真值评分。
失败时保留最后有效输出并明确其失败状态，不能把它冒充收敛；原始异常保留。

开发性能条件沿用此前门槛：汇总NMSE损失≤0.1 dB，各条件/重复≤0.25 dB，
逐条件MD与FA均不增加，全部达到原收敛条件。两个随机重复不是新物理场景。
机制指标报告首10轮与末轮的三维查询颜色、活动用户反馈颜色、MSE/标签、查询反馈相关，
以及补加功率和停止状态，不用单一颜色指标代替完整AWGN目标。
若候选不能通过完整门槛，完成全部预定运行后归档，不以追加调参挽救。
若通过，则仍只作为开发候选，尚需独立新物理场景及完整统计核查，绝不自动替换原Proposed。
