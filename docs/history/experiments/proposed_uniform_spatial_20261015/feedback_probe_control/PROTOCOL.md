# 跨轮复用导数探针的完整接收机诊断

2026-10-15。在本阶段执行任何接收机之前固定本协议。
上一阶段完成了8条闭环运行、完整映射重放与协方差加权迹离线诊断，属于已完成的进展。
普通迹反馈降低平均实相关，但4/4条件均达600轮且性能变差。
本阶段只检查每轮重新抽取导数探针是否是持续波动的必要原因，继续保留原Proposed的28个文件及备份。

## 唯一变化与解释边界

沿用上一阶段的完整Denoiser映射、中心差分、反馈公式、空间查询处理、
双向0.2阻尼、原600轮上限及全部原停止条件。每轮仍计算D(R+εZ)、D(R−εZ)，
ε=0.01√v；α随当前查询及历史重新计算，不能固定为首轮系数。

唯一规则变化是：每个场景第一次生成Z后，全部后续轮次复用同一个Z。
其种子仍为202610156800000+100×scene；首轮应与上一阶段新探针版本逐元素相同。
补噪使用独立的原随机数流202610156300000+100×scene，完全不变。
空间模块、旧三个网络、活动阈值、二阶风险代理、分支失败判定均不改。

该操作属于定位随机估计波动的对照，不宣称固定探针是更优的统计估计器。
Z复用后与闭环轨迹相关，不能据此继承独立随机探针或OAMP状态演化的保证。
若固定探针后仍失败，可排除“每轮重抽探针是全部失败的唯一原因”；
若恢复收敛，也只支持它在这些开发条件下有影响，不证明输入已是AWGN或反馈已满足全部推断假设。

## 条件、预算与证据

- 四个旧开发条件(0,−4)、(8,0)、(16,4)、(24,−4)，顺序固定，无新场景确认。
- 每条件新增一条固定探针闭环，共4条。对照使用已冻结、已核对的空间原反馈和每轮新探针输出。
- 预算、停止条件、成本计数完全沿用原协议。两个额外完整映射的网络调用全部计入。
- 不重新训练，不搜索种子、步长、容差或探针数量。失败、截断及最后有限输出全部保留。
- 仅四字段ReceiverInput进入推断；先保存预测和推断记录，再读真值作离线评分。
- 核对首轮查询、原映射、活动概率、历史和α与先前新探针版本精确一致；记录全部轮次。
- 比较末100轮的活动概率变化、活动平滑残差、估计变化、site残差、补噪量与α波动，
  连同查询/反馈实相关、各维协方差偏离、伪协方差、四阶矩及MSE/标签报告。
- 性能检查仍为相对空间原反馈汇总损失≤0.1 dB、各条件≤0.25 dB、逐条件不新增MD/FA、全部原规则收敛。
  只有同时改善统计匹配和完整接收机表现，才值得继续；通过开发门槛也不等于完成AWGN目标。
