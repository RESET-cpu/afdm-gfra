# 输入维滤波与空间查询处理的组合：公开算子推导

本文件只给出下一项候选的可组合公式，尚未运行组合接收机。
当前固定导数探针对照继续按其原协议运行；本推导不更改任何已冻结算法或结果。

此前独立确认分别显示：空间查询处理改善早期天线颜色，温和奇异值滤波改善末轮输入维颜色。
两者作用的维度不同，组合是否有益需另行完整接收机验证，不能把各自收益直接相加。
本设计沿用已有0.1 dB纯热噪声预算，不依据接收机真值重新搜索预算。

## 逐用户约束

公开导频块A_k=U_k diag(s_k) V_kᴴ，每块N=16，现有归一化满足||s_k||²=N。
记μ_k=mean(s_k)，B=10^(0.1/10)。若1<B<1/μ_k²，令

c_k=sqrt((B−1)/(1−μ_k²))，w_k=s_k+c_k(1−μ_k s_k)，
W_k=V_k diag(w_k) U_kᴴ。

直接可得tr(W_k A_k)=N、||W_k||²/N=B，对每个用户分别成立。
在固定这两个约束时，Cauchy–Schwarz给出上述方向使mean(w_k)最大，
即最小化滤波奇异值关于自身均值的平方偏差。它不直接最小化真实闭环误差协方差。
这只是已有[全局预算推导](../../proposed_polar_20261015/bounded/PROTOCOL.md)的逐用户约束版本，
不赋予新的既有算法名称。

采用逐用户约束的原因是现有空间模块向所有用户提供同一方差标签。
仅约束全局平均||W||²/(KN)=B时，各用户热噪声功率仍略有不同，
统一标签需要按最大用户功率补齐。逐用户相同B使纯热噪声部分不再需要这项额外补齐。
公开算子预检查同时报告全局方案和逐用户方案的最大功率、迹误差与热噪声颜色，
没有使用观测Y、信道H、活动真值或接收机输出作选择。

## 接入已有每轮空间公式所需的量

拼接A=[A_1,…,A_K]，W按用户堆叠，G_k=(I−WA)_k(I−WA)_kᴴ，T_k=W_kW_kᴴ。
空间工作协方差仍记为C，则用户k的工作查询协方差为

C_q,k = G_k⊗C + σ²T_k⊗I。

原空间处理使用它的输入维部分迹：q_k=tr(G_k)/N，n_k=tr(T_k)/N=B，
相应空间矩阵为q_k C+σ²B I。须重新计算q_k，不能沿用匹配滤波的系数。
补噪顺序继续为先平滑物理反馈均值、构造查询、再补加当轮独立噪声。
若工作C为零，各用户标签均为σ²B，不应产生舍入量级的人工补噪。

G_k、T_k及共享C仍是工作模型，遗漏的反馈/观测噪声跨轮交叉项并未消失。
T_k也仍非标量阵，0.1 dB约束只减小其特征值离散，不保证AWGN。
将来若开展完整比较，应先保持已确认空间候选的原反馈规则，单独评价这一线性改动。
当前不新增网络、不替换原Proposed，也不声称组合后的性能已经验证。
