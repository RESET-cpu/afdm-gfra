# 初始化依赖的噪声尺度诊断

2026-10-16；原 AWGN 三网络保留；固定512步试验结束后提出的机制诊断，不是预注册性能检验。
两个初始化族最终活动模式不同。待检验解释：首次试验最大 v≈3 仍不足以使活动/不活动输入相近。
不把这一解释提前认定为唯一原因，也不继续延长旧链。

只读已有公开输入和冻结估计；不读开发真值或确认集。每场景固定 v=[16 v_final,12,48,96]，
各取4个独立Gaussian增量，分别构造原估计条件中心与全零条件中心的成对辅助变量。
β=v_final/v，观测噪声=原σ²/β，保持精确观测分解和同一 M。
全程 v∈[.001,100]。两类初始化共享每次Gaussian增量，减少尺度比较的噪声。
种子202610164701，按场景/重复派生，跨尺度复用标准Gaussian增量。

记录全部2×4×4×2×40=2560个活动概率及second读出，报告各层概率分布、接近先验程度、
两类初始化差异。不用0.5阈值筛选要报告的输入，不以读出变化证明后验正确。

另外计算两个精确Gaussian条件分布的均值分离：每个用户单独放入其冻结信道估计 H_k，
δ=M H_k，P=v M，则 KL[CN(δ+b,P)||CN(b,P)]=tr(H_kᴴ M H_k)/v。
这是初始化Gaussian分布间的解析距离，不是信道真实误差、神经密度误差或最终后验模式距离。
固定取每场景每尺度第0次重复、两类初始化的用户0/39，32个读出做CPU双精度核对，门槛10⁻³。
本诊断预算180秒；无新训练、无轨迹采样、无参数按评分选择。
