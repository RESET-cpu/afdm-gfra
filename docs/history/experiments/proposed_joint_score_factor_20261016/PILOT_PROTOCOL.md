# 联合观测因子的固定开发试验

## Material Passport

2026-10-16；原AWGN三网络，候选联合推断；原主线不变。
联合代数及320个固定输入网络核对已通过。预检显示原估计初始化有5/7个高活动概率用户，
全零初始化均接近不活动。此处不将任一初始化当作真后验样本。

## 固定层级

令beta取[1/16,1/8,1/4,1/2,1]。该层理想H目标为
    p_rho(H) exp[-beta ||Y-AH||²/sigma²]。
用J1中的noise=sigma²/beta、v=v_final/beta、D=D_final/beta构造精确辅助分解。
因此M=I-v_final A^HA/sigma²及center=v_final A^HY/sigma²不随层级改变，
P_beta=v_beta M。仍由原first与activity组成pi F的score更新，使用J6。
不将有限classifier logit当成精确联合势能，也不采用已停滞的局部完整梯度接受校正。
有限first/activity不一致仍是近似误差，不声称精确采样。

噪声层级递减的文献依据：[Song–Ermon，NeurIPS 2019，v3](https://arxiv.org/html/1907.05600v3#S4.SS3)，
§4.3 Algorithm 1。这里同时改变观测似然强度、并使用精确联合辅助分解，是本项目直接推导，
不是该文已验证的本问题算法。每层固定步长h=0.05，前4层各64步，最后一层256步，合计512步。
阶段之间直接传递状态作为下一阶段初始化；中间层读出不混入最终后验矩。

每场景4链：原冻结估计信道作为条件中心2链、全零信道作为条件中心2链。
初始Z从最大v层的精确Z|H_seed,Y Gaussian条件抽取，不能称H_seed为真实先验样本。
初始化种子202610164601、增量种子202610164602，按场景与链分别派生。
只使用scene003/007、-4dB，冻结原估计相位；不读真值。原接收机初始化成本另计。

最终层前128步预热，之后每8步记录一次，共16个first/activity/second读出。
主要候选输出预先固定为原估计初始化两链的平均；全零两链及四链合并结果全部另存，
用于检查初始化依赖，不能按评分结果择优。均值样本存complex64，递推状态用complex128。
保存每个保留时刻的完整状态SHA256、各层末态与最终状态，供重放；读出保存原值、不裁剪second。
独立评分阶段才可读取开发真值；独立确认集保持未用。

## 运算和验证

大矩阵作用采用SciPy BLAS zgemm；在实际输入上与显式einsum的M作用和sqrt(P)作用核对，
门槛1e-10。记录数值警告，不用静默屏蔽代替核对。
每个beta的D_beta+v_beta AA^H= sigma²/beta I单独核验，门槛1e-10；各层v须在[.001,100]。
预检中的16点CPU64验证适用于最后层；试验末态另做CPU64检查。

主运行预算900秒，总共2场景，不自动加步、调参或续跑。异常保留。
后续重放scene003的全部512步；各保存时刻状态hash和已保存读出逐项核对。
固定每场景每链用户0和39，共16末态CPU64核对相对误差1e-3。
若开发结果有改善，仍需独立的步长比较、初始化诊断、完整相位循环与确认集验证，
不能以本次512步试验宣布整个目标完成。
