# 精确积分线性 Gaussian 部分的固定对照

## Material Passport

比较对象为已完成的local_inference；本试验不改变网络、因素、初值、时间范围或读出。
目标是修正已确认的线性Gaussian离散偏差，并判断其是否解释实际链的步长差异。

## 推导

由S5定义P=(I/v+Jv)⁻¹，预条件方向为

    Pgθ(Z)=−Z+uθ(Z),  uθ(Z)=PBv+Pπφ(Z)Fθ(Z)/v.             (E1)

在一个步长内固定uθ于当前Z，精确积分剩余线性随机方程，得到

    a=exp(−h), α=1−a, β=sqrt(1−a²),
    Znext=Z+α Pgθ(Z)+β chol(P)E, Eij~CN(0,I).              (E2)

线性Gaussian解来源为[Wibisono 2018](https://proceedings.mlr.press/v75/wibisono18a/wibisono18a.pdf)
§2.1 Example 1，PDF p.4。固定非线性项与复数预条件表达是本项目直接推导。
只对πF=0或常量的情形，E2是准确Gaussian转移；一般有限网络下仍有非线性离散误差。
不称为完整后验精确采样，也不消除有限网络不一致或其他用户反馈近似。

零活动贡献时u=PBv=m0，E2的稳态协方差满足a²P+β²P=P，任意h>0均无原ULA膨胀。
一般Gaussian目标精度K下，离散A=I−αPK，噪声协方差β²P；
固定点均值仍为K⁻¹Bv，协方差需解离散Lyapunov方程，不假定等于K⁻¹。
