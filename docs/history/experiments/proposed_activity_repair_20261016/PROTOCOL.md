# 重新构造活动判决查询：固定开发协议

日期：2026-10-16。继续修复两个 −4 dB 困难场景的漏检，保留原三网络、原先验输入、原 0.5 门限。
候选只放在本目录及独立 results 目录；不修改已冻结主线。先保存预测再评分。

## 动机及与已失败方案的区别

最新单一 Gaussian site EP 的两个漏检用户，在末态 query 中沿真实信道的投影约为 .75/.73；
其他用户估计误差贡献约为 −.30/−.31。真实值只用于已完成输出的诊断。
平均 MSE/方差接近一并不能排除这样的信号方向抵消。继续调整标量方差没有直接解决该问题。

旧秩三后验均值投影曾改善低 SNR，但引入大量虚警；只投影均值和缩小风险并不保证新查询统计。
旧固定训练秩 88/132 的左逆存在噪声超支持和剩余多用户干扰。
本次以已有观测估计的每用户 AFDM 原子及两导数形成正交 B_k（256×3），
在原始观测上联合拟合所有用户系数。它是线性观测模块的替换实验，暂不把输出循环反馈。
三网络的输入、架构和权重保持原样；第二网络的原风险单独保存，不把它称为真实中心协方差。

## 明确公式

每个天线有 y=Σ_j T_j h_j+n，T_j=I_output ⊗ A_j（按实际 frame/output 行顺序排列）。
固定已有相位前端输出，近似 h_j=B_j c_j+δ_j，D_j=T_j B_j，D=[D_0,…,D_39]。
全用户联合最小二乘为 c_hat=D†y；L_k 为 D† 中第 k 个三行块。
满列秩时 L_k D_j=I(j=k)，因此 r_k^0=B_k L_k y 在指定模型内没有其他用户线性串扰。
完整误差仍含 −δ_k+B_k L_k Σ_j T_j δ_j；禁止丢弃此项或声称完整信道单位响应。

热噪声系数协方差 C_k=σ² L_k L_kᴴ，v_k=λ_max(C_k)。补加独立 proper complex
Gaussian ξ_k，协方差 v_k I−B_k C_k B_kᴴ，得到完整 256 维 query。
固定矩阵下热噪声加 ξ 的协方差严格为 v_k I；不同用户的热噪声仍相关。
由于 B_k 是从同一个 Y 估计出来的，条件于 B_k 时原热噪声一般并非原始 Gaussian：
这个代数恒等式不能消除数据选择依赖，更不能保证含 δ 的完整误差 AWGN。

原 first/second 在同一 (r_k,v_k) 查询；原 activity 使用原 raw first 均值。
p_k=expit(logit(ρ)+原分类器logit)，所有40用户以原 .5 判决。
主输出信道仍为 p_k μ_k s（不额外设能量门限、不借用 LS 信道替换主输出）。
所有支撑外 query 明确失败，不夹住方差。

## 冻结筛选与验证

1. 优先全40用户联合拟合；不读取旧概率或选择真实活跃用户。
2. 使用同一 polar_fixed_noise scene003/007，先 known-phase，再在两场景首次固定种子
   均零漏检零虚警时执行 estimated-phase 对照。物理几何两种条件都来自 observation-only 相位前端。
3. 固定补噪种子 [2026101601,2026101602,2026101603,2026101604]；第一个种子是主结果，
   其余只检查随机扰动稳定性，各自完整报告，不能择优或把四次算成四个独立物理场景。
4. 全用户若因噪声放大失败，可做一个已登记的较低噪声对照：固定旧 Proposed
   p≥.5 的集合 S，对每个目标 k 联合拟合 S∪{k}，始终包含 k。使用相同四个种子、门限、三网络。
   被遗漏用户的结构干扰此时仍存在，不能声称全部串扰为零。仅在该分支通过同一门槛时跟进估计相位。
5. 不进行大规模扫参、重训、反复改种子或阈值。两候选均保留全部结果。
6. 算法输入只包含公开观测/算子/噪声/先验及从同观测估计的 phase；使用旧输出集合时明示依赖。
7. 为直接回答原低SNR问题，再固定检查相同scene003/007的原导频、原估计相位观测。
   这两例与酉导频下漏检的用户身份不完全相同，因此独立记录为 original_estimated，
   不以酉导频条件是否过关来代替实际设置的验证。两个候选各只查询相同四个固定种子，
   全部报告，不用结果挑选用户或重新调参。已在网络运行前确认全部方差处于支持内。
