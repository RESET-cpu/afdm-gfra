# GAMP-SBL 与 off-grid SBL 的一次后验相位更新

日期：2026-10-15。先开发核验，再冻结实现并在独立物理场景验证。

## 固定比较

每个接收机比较三种设置：原物理前端后固定相位；一次后验相位更新（新值权重 1）；一次后验相位更新（圆周插值新值权重 0.5）。所有更新使用该接收机自己的后验。每次更新固定后验，做两轮逐用户一维搜索；每用户 256 个相位格点、4 个局部细化候选、每候选至多 50 次迭代。保留原点，仅接受目标下降。更新后从原初始化重新运行原条件接收机。禁止利用真值或测试结果选择用户、迭代次数、阻尼或活动阈值。

原相位前端、各基线求解器参数及活动读出保持冻结。SBL 使用最终线性化字典对应的完整 Gaussian 后验协方差；GAMP 使用其对角近似方差。完整推导及适用限制见 `docs/BASELINE_PHASE.md`。不宣称是 Shen 的 OTFS 算法复现，也不宣称整个外循环有精确 EM 单调性。

## 数据与证据顺序

- 开发：复用已经观察过的未知相位比较面板 scene003、scene008，在 −4、0、6 dB。两场景曾用于困难案例诊断，明确作为开发数据，不能用于无偏性能估计。重新运行原生接收机核对逐数组一致性，首个条件重新计算前端核对一致性。完整保存三设置结果。
- 独立验证：10 个新物理场景，种子 2026101588000000–2026101588000009；SNR 为 −4、−2、0、2、4、6 dB。两接收机 × 三设置 × 60 条件，共 360 输出。冻结实现、全部设置和本协议后才生成数据。验证后不在这些场景上调参。
- K=40，Q=N=M=16，4×4 UPA；连续离网多径，每用户共用物理 Doppler，活动概率 0.1 且条件于非空。生成器和能量尺度沿用已审计模型。
- 同一场景跨 SNR 共享物理信道、导频和标准化噪声；推断只接收 observation、pilot、noise_variance、activity_prior。生成器保存 truth 后立即丢弃内存真值，所有推断结果保存后才读 truth 评分。
- 种子检查覆盖既有训练/校准审计，以及可读取的既有 PLAN 文件中显式声明的种子；记录检查来源及缺失范围，不声称覆盖未留存的历史实验。

## 指标与决策

主要指标是未作活动掩码的完整信道 pooled NMSE，包含非活跃用户误差；同时报告漏检、虚警、AER、耗时、停止原因和全部警告。相位误差统计所有真活跃用户，不按估计活动筛选。后验目标下降仅作为数值检查，不代替真实信道或相位精度。

独立验证按物理场景进行 5000 次配对 bootstrap；六个 SNR 用相同重采样索引，报告每 SNR 相对固定相位的 NMSE 差值及点态 95% 区间。用户、路径和同场景多个 SNR 不当作独立样本。10 场景仅支持初步结论，不据此宣称普遍优越；若活动退化或 NMSE 不稳定，保留为实验入口，不替换默认比较。

每种设置计入完整前端时间；更新设置另计初次条件推断、后验矩计算、相位搜索和再次条件推断。公共计算可复用，但计费按独立运行所需步骤累加。数据生成、文件读写、单独校验时间不算推断时间。CPU、BLAS 单线程。阶段时限 3600 秒；失败样本保留，面板不完整时不报告成完整成功。

## 运行

```text
.venv/bin/python experiments/baseline_phase_learning_20261015/run.py --stage development --output results/baseline_phase_learning_20261015/development
.venv/bin/python experiments/baseline_phase_learning_20261015/run.py --stage validation --output results/baseline_phase_learning_20261015/validation
```

每次要求新输出目录；PLAN、源码快照和种子审计先于推断写入。ROWS 保存逐条件指标，输出 NPZ 和 JSON 保存算法结果、时间、停止信息、哈希和警告，SUMMARY 保存完整性及源码变更检查。
