# AWGN 参考递推与算子逐项替换

2026-10-15。Origin Skill: academic-research-suite / experiment-agent。
用户授权逐步实施验证；本轮不训练，不修改主线。不是 Cai 原论文复现。

## 顺序与预先定义的范围

1. 核对解析复 Bernoulli–Gaussian 后验、散度、SVD LMMSE 外信息公式。
   比较显式矩阵与 SVD、有限差分与后验方差/查询方差、Gaussian 全局后验。
2. 实现匹配解析去噪器的 VAMP 参考递推：去噪外信息均值
   `(D-alpha*r)/(1-alpha)`，方差 `v*alpha/(1-alpha)`；不使用残差功率代替它。
   各运行固定30轮，无按真值选择最优轮；异常完整保留。
   使用独立复 Gaussian QR 生成随机正交行矩阵（Haar），A A^H=(n/m)I。
   10个新合成场景、−4/−2/6 dB，四种配置：
   (n,m,columns,activity_block)=(640,256,1,1)、(640,16,1,1)、
   (640,16,256,16)、(2560,64,256,16)。后两者共享用户块活动。
   不同配置不是相同信道配对，不能仅把差别归因于单因素。
3. 原网络、原分类器、原推断和0.5阈值，10个历史物理场景0–9，−4/−2/6 dB，
   每例比较三种输入：
   - AFDM估计相位：重放原结果；相位是既有公开观测估计。
   - AFDM真相位：相同Y和噪声方差，oracle相位，仅作诊断。
   - 随机右奇异向量：用真相位A的U、奇异值，独立Haar右子空间替换V；
     保留H及原噪声实现N，生成Y_ref=A_ref H+N。是人工算子诊断，非可部署导频。
   保存并报告相同噪声功率下接收信号功率/SNR变化，不依据真值重缩放算子。
   三者均沿用原600轮上限、最少60轮及停止规则，不能将预算耗尽称为收敛。

## 指标和边界

主指标NMSE、AER、MD/FA。NMSE先汇总平方误差/信号能量再取dB。
保存第1、30、60轮和终态的实际网络查询（complex64存储，记录量化误差）；
其他推断与终态输出保持原精度。查询统计使用同尺寸同方差独立AWGN重抽作为有限样本参照。
记录功率/标签、输入列和天线二阶矩形状偏离、四阶量、活动用户信号方向投影。
统计只在观察器/离线评分读取真值，不将真值带回推断。
10个物理场景是重复使用的开发诊断，跨SNR/算子/轮次不算独立样本。
比较按场景配对bootstrap；不是低AER差别的确定性显著性证明。

本轮目标是定位第一条路线的适用条件，不承诺形成性能改进。
若参考递推数学核验失败，修实现后重验；若有限模型统计不理想，完整报告并继续已定义的诊断，
不以不现实的零误差为停止条件。不将小实验失败上升为整个OAMP/VAMP路线不适用。
运行总预算2小时，逐例状态落盘，保留所有失败。禁止Git操作。
