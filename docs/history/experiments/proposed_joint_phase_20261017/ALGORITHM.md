# 联合活动、离散相位与信道的独立候选

主线、原导频、三个训练权重保持原样。候选入口 `study.py`，实现 `candidate.py`。

依据：Sun et al., *Massive Grant-Free OFDMA With Timing and Frequency Offsets*, IEEE TWC 21(5), 3365–3380, 2022，DOI 10.1109/TWC.2021.3121066；作者稿 §II-C 式(18)–(19)、§III-A 式(20)–(41)、§IV。原文以用户内部最多一个非零行约束联合活动及偏移。这里用完整信道块替代其信道向量，并复用当前学习模块；不是 S-GAMP 复现。

## 模型和消息

对每个用户设置 s_k ∈ {0,1,...,G}，0 表示不活跃。先验为 P(s_k=0)=1-rho，P(s_k=g)=rho*w_kg，sum_g w_kg=1。使用 X_kg=1{s_k=g} H_k；观测为 Y=sum_kg A_k(beta_kg) X_kg+N，A_k(beta)=diag(exp(j q beta))P_k。物理信道输出为 sum_g E[X_kg|Y]。

第一候选的 G=16 均匀覆盖整圆，逐用户平移网格以包含原前端点估计。网格间距 2pi/16，权重 1/16。没有使用真值。有限网格采用数据相关对齐，这是经验离散化；不能把初始相位当成额外独立观测。

线性模块在扩展算子上沿用原 LMMSE、公共标量方差投影、外信息和0.2阻尼。初始化每个候选的二阶矩为 rho/G 乘训练二阶矩，保证总信号功率不随 G 增加。

假设查询 r_kg = X_kg + CN(0,v I)，且候选查询相互独立，则每个联合状态的查询密度除以“所有候选为0”的查询密度，得到：

- 不活跃状态相对似然为1；
- 候选g相对似然为 Lambda_kg=p_active(r_kg)/p_zero(r_kg)。

用平衡训练分类器的 logit 近似 log Lambda。联合归一化为 Z_k=1-rho+rho sum_g w_kg Lambda_kg，pi_k0=(1-rho)/Z_k，pi_kg=rho*w_kg*Lambda_kg/Z_k。不重复乘入上一轮后验。每用户活动概率为 sum_g pi_kg，不取最大候选的活动概率。

候选条件均值和方差沿用两网络及现有 Gaussian site 规则。候选后验均值 pi_g*mu_g、对角块协方差 pi_g*C_g+pi_g(1-pi_g)mu_g mu_g^H。互斥状态的跨候选协方差为 -pi_g*pi_h*mu_g*mu_h^H；本第一实现仍在反馈中舍弃此项，仅保留原公共标量投影。这是需要诊断的近似，不是完整矩阵消息。

## 必须保留的限制

1. 展开后的查询不是已证明独立的白高斯查询；归一化公式成立的概率模型与实际线性查询之间存在近似。
2. 三个冻结网络学习的是边缘 H 先验，不是条件于 beta 的物理 H 先验，忽略共享 Doppler 的先验依赖。
3. 有限网格存在离栅误差；若候选不能覆盖正确解，不能归因于联合状态路线本身。
4. 互斥约束保留在非线性概率与均值中，但跨候选协方差不保留到线性反馈。
5. 判决0.5，噪声为与主线相同的观测估计值；候选限240轮的首轮探索预算，未收敛须明确报告。

## 验证

- G=1 恢复原归一化；以真实冻结网络重放一个主线场景。
- 在独立 Gaussian 条件先验下，与显式枚举所有联合状态密度对照。
- 所有候选证据为1时，总活动概率为rho，不随候选数增加。
- 扩展算子与选择单一物理相位后的观测严格一致。
- 首轮四个配对场景：053、033（已知异常），000、001（正常对照）；统一4dB。
- 若未出现明显恶化，再用100–103（未参与本次诊断选参）检查。不能把上述四个开发场景当成独立性能验证。
- 真值仅在实验脚本外部评分，不进入候选接收机或候选生成。保留所有失败、中间轨迹、源码哈希。

## 对“候选相关性”的解释边界

共享观测并不禁止联合贝叶斯归一化：如果每个 Lambda_g 真正等于同一观测空间下的 p(Y|s=g)/p(Y|s=0)，上述归一化无需“不同候选观测独立”。本实现的问题是，冻结分类器只给出理想白噪声查询模型下的密度比，尚未证明等于该共同观测证据。不能仅凭候选相关就断言所有候选联合方法无效。

重复相同相位的控制只用于暴露投影近似的表示依赖，不是实际随机场景的性能评估，也不能单独证明真实不同相位场景的失败唯一由跨候选协方差引起。

## 后续可检验的连续更新（仅推导，尚未实现或验证）

开发试验显示：场景053受有限网格误差限制，而把联合概率压成单一MAP相位再细化会令场景033的虚警重新出现。可以保留各候选概率，将网格写成 beta_kg=theta_k+delta_g，delta_g=2pi*g/G，只更新每个用户共享的theta_k。

冻结当前近似后验，定义 z_k(q)=sum_g pi_kg exp(j*q*delta_g) [P_k mu_kg](q)，以及 R_k=Y-sum_(j!=k) D(theta_j)z_j。在用户之间后验独立、噪声各向同性、H与相位先验因子化的当前模型下，期望平方残差中与theta_k相关的部分为 ||R_k-D(theta_k)z_k||_F^2。原因是整个用户贡献的协方差被同一个酉对角矩阵D(theta_k)共轭变换，迹保持不变；这个迹不变结论本身不需要忽略用户内部候选交叉协方差。

因此可在单位圆上最大化 Re sum_q c_kq exp(j*q*theta_k)，其中 c_kq=sum_(m,r) conj(R_k(q,m,r))*z_k(q,m,r)，再重新运行联合候选消息。这样保留候选概率、均匀网格间距与总活动先验，不添加邻近重复候选，也不在更新前压成单个相位。

这是针对本项目模型直接展开的候选操作，不是已验证算法，也不声称是文献完整算法的复现。冻结后验时目标改善不保证完整近似消息迭代的似然、NMSE或AER改善；分类器证据校准、H/相位先验依赖及标量反馈问题依然存在。需要独立配对验证，不能把场景053与033的不同最优变体拼接为一个结果。
