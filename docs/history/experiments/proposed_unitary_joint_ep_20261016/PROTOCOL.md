# 酉导频与完整后验矩的高斯 EP 更新：固定两场景初筛

日期：2026-10-16。状态：实现前登记；三网络结构、权重、16帧和物理数据固定。
输出目录：`results/proposed_unitary_joint_ep_20261016`。不修改已冻结主线。

## 问题与范围

上一候选把多数 BG site 先按其自身活动质量取无条件矩，再送入观测因子。
已保存结果显示该顺序丢失观测可以重新激活的分量，外部干扰方差坍缩。
本候选先在当前 cavity 下计算完整活动混合后验矩，再作高斯 EP site 替换。
每个用户只有一个高斯 site，因此存在共同的全局高斯近似分布。
此处的高斯近似、标量协方差约束和有限三网络误差仍须明确保留。

## 唯一候选与公式

固定相位参考下，A_k 是16×16酉矩阵。每个用户有 D=4096 个复信道坐标。
噪声和信道以既有 scale 归一化。工作先验仍为独立用户 Bernoulli(ρ)，ρ=.1。
本轮不更改非空场景生成协议；这也不消除条件生成与独立工作先验的差别。

每个用户保存 t_k(x_k)∝exp(−α_k||x_k||²+2Re η_kᴴx_k)，要求 α_k>0。
令 c_k=1/α_k、e_k=η_k/α_k；共同近似为 q(x)∝p(y|x)∏_k t_k(x_k)。
对其余高斯 site 精确积分，得到

    r_k = A_kᴴ(y − Σ_{j≠k} A_j e_j),
    v_k = σ² + Σ_{j≠k} c_j.

因此当前自身 site 完全不出现在自身 cavity 中。
该等式是高斯近似模型中的精确消元，不是原物理后验已变成高斯的证明。

三网络在同一 (r_k,v_k) 下给出 active 条件均值 μ_k、条件风险 τ_k、
平衡分类器 log density ratio ℓ_k。只在这里加入一次工作先验：

    p_k = sigmoid(logit(ρ)+ℓ_k),
    m_k = p_k μ_k,
    V_k = p_k τ_k + p_k(1−p_k)||μ_k||²/D.

这里对有限第二网络风险作为中心方差的使用，仍是已知待校准近似。
不跨用户平均 τ，不把 p_k 当作下一轮独立先验。
取同一局部后验的球对称 proper complex Gaussian 投影，并除当前 cavity：

    α*_k = 1/V_k − 1/v_k,
    η*_k = m_k/V_k − r_k/v_k.

只有 α*>0 且全部参数有限时接受；否则保留该用户旧 site，计为失败，
本轮不能满足 fresh 停止条件。不裁剪 V/v 来制造正精度。
按原权重 β=.2 对 α、η 作自然参数阻尼；不另作 query 算术阻尼。
初始化 e=0,c=ρ×训练先验二阶矩。活动阈值保持 .5。

## 检查与实验门槛

先独立核验：完整精度矩阵/Schur 消元与 cavity 一致、自身排除、热噪声白化、
精确 Gaussian prior 恢复、Bernoulli–Gaussian 完整后验矩、site 除法恢复、
非正精度拒绝以及自然参数阻尼。合成测试不得以真值指导物理接收器。

原 max600/min60、收敛阈值和稳定次数保持。收敛额外必须本轮全部 site 接受，
并同时满足未经阻尼的 site 残差、活动残差和估计变化。
沿用既有 conditional variance floor；记录每次触发，不能把它当成精确矩。
遇到网络输入超出训练方差支持范围则明确失败，不编造活动反馈。
每场景硬时限1800秒。预测先保存，之后独立读取真值评分。

首阶段仅 scene003、scene007、polar_fixed_noise 的 known phase 配对输入。
已知相位是 oracle 参考。原同导频接收器结果直接复用，合计2 MD、0 FA。
允许继续 estimated phase 的门槛：两例均收敛、总 MD+FA 严格下降且 FA 不增加。
否则停止扩大实验；所有失败、警告、拒绝更新均保留。
最多4次新接收器运行，无参数扫点、阈值调优、权重训练或主线切换。
两场景属于已见困难开发场景，通过也不能声明独立泛化改进。
