# 完整观测似然与逐轮查询：隔离开发协议

日期：2026-10-15。Origin Skill：academic-research-suite。
现有Proposed代码、配置、三网络和正式结果不变；调用冻结副本的first及activity。
本候选尚未纳入主线，也不声称是Cai接收机的等价替换。

来源：Kawar等，Denoising Diffusion Restoration Models，NeurIPS 2022；
公式核对版本为[作者稿v2](https://arxiv.org/html/2201.11793v2)，§3.2式(3)–(8)、Proposition 3.1，
§3.3 Theorem 3.2，§5.1。原文在谱域用完整观测及热噪声构造扩散更新，并复用AWGN去噪器。
理想q的高斯边缘需对观测噪声积分；有限网络pθ轨迹不自动具有该性质。
原文反馈是均值预测，不要求预测误差本身AWGN，因此此候选至多检验查询AWGN化的替代路线。

项目改写：把40用户整体写为Y=AX+N。A为16×640，X为640×256；
各列对应接收天线/AFDM输出。SVD只保存16个非零右奇异向量，使用Hermitian转置。
复数噪声方差v=E|z|²，实部/虚部各v/2，原文方差比在此约定下保持不变。
τ_i=σ_N²/s_i²。所有观测和信道仍除以旧尺度.2647966452702405。
实现保存全部真实A的奇异值；不根据真值选择秩或去掉较小奇异值。

固定参数与计算范围：

- 四个已使用的开发条件：(scene,SNR)=(0,-4),(8,0),(16,4),(24,-4)。不能作为新确认集。
- 两个固定随机种子；每条件每规则32次查询，v从100到.001等比下降。末端返回最后一次均值预测。
- 两条预定规则：原文实验η=.85、η_b=1；原文定理选择η=1、η_b=2w/(w+τ_i)。
  w为下一层复数方差。噪声序列是项目对旧连续噪声网络的适配，并非原文1000步模型的直接复现。
- 联合均值D=pF，F=r+.5v score_first(r,v)，p由旧activity及公开活动先验给出；门限仍为.5。
  不训练、不改变权重、不做输出平均、不用真值挑选轮次/种子/规则。
- 首先核对薄SVD与显式谱域公式、复杂坐标打包、协方差恒等式及oracle-q的统计。
- 推断只读input；最终预测保存后再读truth。全部32轮记录误差功率及信道相关；
  第1、8、16、24、32轮记录完整轴向协方差和同H、同v AWGN对照。
- 去噪输出D的误差及相邻查询相关单独报告，不把它们称为外信息AWGN。
- 只保存选定查询快照及最终预测，其他逐轮数组在评价后释放；完整逐轮指标保留。

晋级要求：四条件都完成、查询误差随v下降保持与匹配AWGN对照接近，且末轮恢复和检测具备竞争力。
这只是开发可行性判断，不是显著性检验；失败不扩大同一开发集的调参搜索。
不满足则归档原因，继续保留原Proposed。主线28个文件与副本逐一校验。
