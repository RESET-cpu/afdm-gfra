# 原Proposed的跨轮协方差核对

2026-10-15。Origin Skill：academic-research-suite。主线及28项冻结文件保持不变。
本阶段先只观察原接收机，不把经验方差修正直接接入闭环。

依据：[Takeuchi，TIT 2022作者稿v2](https://arxiv.org/html/2111.05522v2)，
§III-C式(27)–(28)、§III-D式(44)–(45)；§IV-B Example 2式(63)–(78)。
跨轮误差协方差参与阻尼后的功率。论文的大系统、随机矩阵和去噪器条件未在本项目成立；
不把这次诊断称为LM-OAMP实现或AWGN证明。

项目使用如下有限数组恒等式，无需Gaussian、零均值或独立假设。
q=(1−b)q_old+b q_raw，d为复坐标数，P(q)=||q−h||²/d，则

P(q)=(1−b)P(q_old)+b P(q_raw)−b(1−b)||q_raw−q_old||²/d。

因此若旧、原始两端的方差标签真是误差功率，可用已知均值差得到混合功率。
反之，恒等式本身不能保证标签可靠。分别检查查询和回送线性模块的外信息，b固定为原配置0.2。
记录原始端点标签、真实MSE、原阻尼标签，以及减去均值差项后的局部/递推标签。
任何负数照实保留；没有裁剪、没有根据真值改标签或改阻尼。

四个旧开发条件：(0,-4)、(8,0)、(16,4)、(24,-4)，原停止规则和600轮上限不变。
每个条件先保存最终输出和少量查询快照，再读取truth作离线统计。
原始轨迹数组只在内存保留用于本次统计，不把全部中间阵列长期存盘。
与既有完整主线输出逐项核对：相对误差及概率差不超过1e-5，活动决策相同。

补充oracle诊断：只在已运行轨迹上计算相邻两估计的最优凸混合系数，
以及实际误差的历史Gram矩阵；不参与推断、不当作可实现性能或算法选择依据。
作用是判断单纯校正历史功率是否具有足够潜力，避免盲目实现记忆算法。

原Mac数值库的复数矩阵乘法告警用进程内等价einsum规避，沿用已核验表达；
主线磁盘代码不改，并再次对照同输入旧结果。所有后续尝试必须有独立协议和新结果目录。
