# 完整波束通道网络：宽度128容量实验

2026-10-13用户授权开始。将原宽度64扩大到128，残差块仍为6，参数1,994,528。32个实输入通道联合表示16个复波束，完整4×4 UPA二维酉FFT和16×16 AFDM矩阵处理方式不变。

本实验只改变特征宽度；训练与验证数据、数据划分、随机种子、噪声范围及均匀采样、每样本单位功率归一化、预测噪声目标、batch64、microbatch16、Adam、EMA和停止规则均与宽度64版本一致。配置差异见结果目录CONFIGURATION_DIFF.json。正式训练随机初始化，不继承小模型、计时或预检权重。最大200轮，固定验证集选择EMA；相同种子不代表不同容量网络有相同初始化。

宽度64模型此前已在第60轮写状态时异常退出，检查时磁盘近满，日志中的具体底层异常文本不完整。完整断点停在第59轮结束，最佳权重也为第59轮；错误证据和断点身份保留于旧目录FAILURE_BEFORE_CAPACITY.json及PAUSE_CAPACITY.json。该模型现保持暂停，不自动恢复。

新实验权威目录：results/full_power_channels_w128_20261013。沿用旧冻结运行源码，唯一网络配置改变为width=128。计时为一次性12步，丢弃前三步，测量batch64且microbatch16；计时权重不复用。正式训练前进行7项相关检查及MPS中断恢复预检。

启动前检查磁盘空间、worker.lock、实际进程、配置与源码散列及数据身份。由于已发生写文件异常，当前磁盘至少预留2 GiB后才启动长训练；这不是性能门槛，也不更改模型或数据。PREFLIGHT或WAITING_FOR_DISK阶段不重复启动。冻结入口为结果目录runtime/pipeline.py，传入该目录configuration.json。

一阶完成后，使用原冻结独立5,000测试信道，与旧完整第81轮权重在相同物理查询下比较。估计功率整体NMSE改善≥0.5 dB、场景配对95%置信区间下界>0、每个预设5 dB区间退化≤0.5 dB才放行。oracle只作诊断。测试不用于中途架构选择，门槛未通过则停止后续阶段。此前宽度64第51轮比较使用验证集，未读取独立测试集。

通过后冻结教师SHA，先实现并核验单位功率二阶平均迹目标与推断缩放，再训练二阶；随后训练保留原始幅度、使用估计功率一阶均值的证据网络。当前网络仍只实现一阶，不能直接套用总体RMS二阶训练器。默认接收机权重保持原状。

容量效果应首先比较两种宽度在相同训练轮数、相同验证查询上的结果；记录计算时间，不将不同结构的初始化或单一种子的差异当作容量原因的确定证明。此前噪声范围调整建议暂不实施，以免混淆容量影响。
