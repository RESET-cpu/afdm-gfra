# 相位增强与关系约束的一阶训练对照

## Material Passport

- Origin Skill: academic-research-suite / experiment-agent
- Origin Mode: plan + run
- Date: 2026-10-12
- Verification Status: DESIGN；结果以本次运行记录为准。

用户授权在保留原三个网络的基础上，开始修改训练方案的小规模试验。200/100/100 续训已按用户最新要求暂停，其断点与数据保留；本试验使用原第 81 轮选定 EMA，与该续训独立。本次不更换网络结构，不使用实际迭代查询作训练标签；先检验相位增强和关系约束能否改善现有有限一阶网络。相关群作用、等变性与 DSM 的论文定位已记录于 docs/TERMINOLOGY.md。本项目具体惩罚项来自 experiments/proposed_mean_feedback_20261012/PLAN.md 的待验证公式。

## 固定设计

三个训练组均从原第 81 轮选定 EMA 权重开始，新建 Adam；使用相同的训练信道顺序、独立 AWGN 抽样、1,000 次优化更新、batch 64 / microbatch 8、固定学习率 1e-5、EMA 0.999 和梯度范数上限 1。相位随机流独立于信道与噪声随机流。使用原 50,000 个训练信道，覆盖原 v∈[0.001,100]，不裁成接收 SNR 范围。

| 组 | 训练目标 |
|---|---|
| dsm | 原 DSM |
| augmentation | 原查询和随机旋转查询的 DSM 各占 1/2 |
| consistency | 与 augmentation 相同，再加 0.1 倍下述惩罚 |

对每个信道样本独立均匀取 g∈{1,i,−1,−i}，同时旋转干净信道和带噪输入。D 为复坐标数，F=R+(v/2)s（s 是两实通道的梯度）：

\[
L_{\rm phase}=\mathbb E\frac{\|g^{-1}F(gR,v)-F(R,v)\|^2}{Dv}.
\]

两支均参与梯度计算。0.1 是预先固定的探索设置，不由本次验证结果调节。主比较是相同步数的最终 EMA，不从多个验证轮次事后挑最好结果。增强和约束组每个样本需两次网络前向，原 DSM 需一次；记录前向次数与耗时，不宣称三组 FLOPs 或墙钟时间相同。部署均只调用一次一阶网络。

## 验证与数据边界

1. 原完整 5,000 信道固定 AWGN 验证：第 0、500、1,000 步评价损失、全局与分噪声尺度 NMSE；相位偏差另在固定 256 个验证样本上评估全部三个非平凡旋转。
2. 新开发面板预先固定物理 seeds 2026101227000000～2026101227000003，每个 −4、0、4 dB，共 12 条件。生成器、40 用户、非空活动条件、噪声与导频约定和默认接收机相同。核查与原训练/验证及既有比较的种子不重叠。
3. 用原网络完整运行新面板，保存第 1、20、60 轮及末轮查询，重复轮次合并。固定这些查询评价各一阶网络，按迭代阶段、原已检出活跃、原漏检活跃、弱活跃（同场景活跃信道能量不超过中位数）与非活跃用户分别报告。真值只用于评分和分组；不进入网络输入或停止规则。支持范围外查询计数单列，不混入支持内指标。
4. 完成训练后对三个最终一阶分别执行同面板完整迭代，保留原二阶与分类器，明确标记为“仅替换一阶的受控诊断，教师绑定未重新训练”。这不是可采用的新三网络组合，AUD/NMSE 不能作为正式新 proposed 性能。
5. 面板一经查看即为开发验证；不报告总体优势或显著性结论，不用既有困难测试场景训练或选权重。保留所有失败、上限输出及未检出用户。后续采用需要重新绑定二阶/分类器并进行新场景确认。

## 判断与执行

先报告全部三组的固定末步结果，不自动改默认权重。比较相位偏差、原 AWGN 能力、实际末态查询条件 NMSE、各用户组与完整迭代诊断；平均损失下降本身不算修复。归档的协方差训练不启动。

独立后台串行任务先生成查询面板，再依次训练三组并完成受控完整迭代，最后自动汇总。每 120 秒保存可恢复的模型、EMA、Adam、所有随机流及样本顺序，阶段完成也保存；每次更新检查有限性。仅监控本次输出。单次启动设 24 小时时限，超时在可保存边界退出并记录。进程退出、异常与完成均写入状态文件。
