# 由既有重要性权重拟合补充proposal

2026-10-16。沿用已核验的两部分物理先验及等价时延求和；不修改主线或训练网络。
参考Cappé等《Adaptive Importance Sampling in General Mixture Classes》v4，
§2.1 Algorithm 1式(6)–(7)、§3.1式(14)–(15)，PDF pp.4、8。
采用其以归一化重要性权重和混合责任更新Gaussian参数的原则；本项目的多次固定样本EM、
协方差约束、分量数、混合保留比例与轮次数均为明确的开发设置，不称原文逐项复现。

令上一轮样本s_i及其原权重w_i∝p(s_i)exp(L_i)/q_old(s_i)。
对两个不同维度的部分分别拟合，并保留该部分的总归一化权重β_b。
每部分目标是Σ_i w_i logΣ_k α_k N(s_i;μ_k,C_k)，
r_ik=α_k N(s_i;μ_k,C_k)/Σ_l α_l N(s_i;μ_l,C_l)。更新为

    n_k=Σ_i w_i r_ik, α_k=n_k,
    μ_k=Σ_i w_i r_ik s_i/n_k,
    C_k=Σ_i w_i r_ik(s_i−μ_k)(s_i−μ_k)^T/n_k.

部分内w归一化为1，最终拟合分量权重乘β_b。一般部分12分量、固定参考部分2分量。
按部分内加权均值和逐坐标标准差缩放后拟合，标准差下限1e-12；
缩放后协方差特征值下限1e-4，最多100步，相邻加权log似然相对增量≤1e-8时停止。
初始化中心由固定随机种子按权重及最近中心平方距离顺序选择，初始协方差为加权全局协方差。
保留所有EM目标值、约束次数和零权重数，不裁剪重要性权重或删除不利样本。
拟合结束后将协方差乘2，仅用于proposal覆盖；不拿它作后验协方差。

新q = 0.2 p_prior + 0.4 g_old + 0.4 g_fit，g_old是上一轮Gaussian部分归一化后的密度。
这样每轮保留原先验和已有Gaussian区域，新分量在独立样本中检验。
旧样本只用于拟合；每轮固定新seed并重新抽样，不能将旧样本分母替换成新q。
先验支持外新样本保留零权重，仍计入样本数。

预先固定3轮、8个旧开发查询、两组独立适配，各轮各8192样本及512/2048/8192前缀。
基础seed=202610163100，SeedSequence([seed,round,replicate,index,0拟合/1抽样])。
两组不互相共享拟合样本。真值及oracle只供评分；确认集未使用。
每轮沿用log密度差0.1、均值相对差0.05门槛，所有轮次报告，不挑最好一轮。
另外报告第2→3轮差异；没有全局收敛或完整接收机性能保证。

执行前核验单步加权更新与独立循环计算、加权目标单调性、Gaussian密度及混合p/q质量。
运行后独立重算所有q密度、前缀统计及固定0/16查询两组各轮的全部样本矩。
主线保持冻结，未通过完整检查时不执行接收机替换。
