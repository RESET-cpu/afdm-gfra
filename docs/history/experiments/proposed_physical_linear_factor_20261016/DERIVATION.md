# 保留观测矩阵和有色外部因子的物理路径积分

2026-10-16；项目直接概率代数。此项将已核验的标量局部积分推广到一般线性因子，
不是完整接收机结果，也未把实际反馈误差重新认定为Gaussian。

给定几何g，冻结物理模型的直达径与第一散射径具有相同延迟和方向，因此

    H=B_g(z+c t), z~CN(0,I_3), t=exp(iφ), φ~Uniform[0,2π),
    c=(sqrt(p_LOS/p_diffuse1),0,0)^T.                                  (L1)

这一列关系仅适用于本项目当前路径定义。B的列可以相关、重复或在观测中不可见。
外部因子明确写成CN(r;AH,C)，C正定，A任意矩形复矩阵。
令C=LL^H，y=L^-1 r，F=L^-1 A B，S=I+F^H F。
这里改变的是给定Gaussian因子的计算坐标，不声称真实反馈重抽后独立。

先积分z，得到CN(y;Fc t,I+FF^H)。利用行列式恒等式和Gaussian条件公式：

    η=S^-1 F^H y, d=B S^-1 c, a=c^H η, κ=2|a|,
    ℓ=log p(r|g,active)-log CN(r;0,C)
      =y^H F S^-1 F^H y-log det S
       -(Fc)^H F S^-1 c+log I_0(κ).                                  (L2)

相位矩m_j=I_j(κ)/I_0(κ) exp(ij arg a)，a=0时m_1=m_2=0。

    μ_g=Bη+d m_1,
    V_g=B S^-1 B^H+dd^H(1-|m_1|²),
    P_g=dd^T(m_2-m_1²).                                               (L3)

P是E[(H-μ)(H-μ)^T]，不能从proper热噪声推断条件P必为零。
噪声不要求标量，A不要求酉、方阵、正交或满列秩。令A=I、C=vI时退化回原固定几何公式。

采用增广QR分解[F;I]=QR，记Q上部为Q_F，则

    S=R^H R, η=R^-1 Q_F^H y,
    y^H F S^-1 F^H y=||Q_F^H y||²,
    tr(B S^-1 B^H)=||B R^-1||_F².                                    (L4)

这避免为计算二次型而相减两个大型接近量；数值稳定性仍须在控制上检查。
保留原物理路径增益，不把直达径改为Gaussian。

## 其他用户产生混合外部因子时

若外部近似为Σ_s w_s CN(Y;A H+M_s,C_s)，对每一分量使用r_s=Y-M_s。
必须保留

    ℓ0_s=-m logπ-log det C_s-r_s^H C_s^-1 r_s,
    Z0=Σ_s w_s exp(ℓ0_s),
    Z1=Σ_s w_s ∫p(g) exp(ℓ0_s+ℓ_sg) dg,
    p_active=ρ Z1 / ((1-ρ)Z0+ρ Z1).                                  (L5)

活动条件权重正比于w_s p(g) exp(ℓ0_s+ℓ_sg)。以它对(L3)作全期望和全协方差，
再加入不活动零点的混合项，得到

    m=p_active μ1,
    tr V=p_active tr V1+p_active(1-p_active)||μ1||².                    (L6)

不同s的ℓ0_s一般不同，不能因只关心似然比就丢掉。固定有限几何混合在控制中可精确求和；
真实连续几何仍需已声明的积分误差与覆盖检查。

这给出了物理先验与一般外部因子的一致局部矩接口。若输出仍要Gaussian site，
单Gaussian因子可按明确投影相除；混合因子必须沿用已推导的对原混合乘积的矩匹配问题，
不能把L5结果直接塞回原两Gaussian精度相减。其他用户独立消息、共同场景几何、相位误差、
连续积分和闭环收敛都仍是待验证近似，本式没有自动解决它们。

## 预定核验

种子202610163500。36个小维条件：6种观测算子（单位、矩形、秩一、零、重复列、
奇异值跨度1e6），3档噪声(.03,1,20)，有/无直达径；有色C正定。

另验证6个含2个外部分量、2个有限几何分量、活动率.1的完整混合控制，保留ℓ0_s。
所有相对/缩放误差门槛1e-9，真值不参与，结果前固定；失败不改门槛。
核验范围仅为公式与实现，不作物理接收机性能或独立确认声明。

## 与现有矩阵消息的接口及公共阵列向量

既有矩阵消息(M1)为exp(2Re tr(B_k^H X_k)-tr(X_k^H J_k X_k))，
其中X_k按AFDM输入维打包为16×256。J_k>0时取J_k=R_k^H R_k，
y_k=R_k^-H B_k。这将因子写成一个平方项，省略的常数对同一个因子的活动/不活动比值抵消。
对不同外部分量则仍按(L5)保留各自常数。`information.py`只在J_k正定时使用此方便表示；
不作特征值阈值截断，秩亏情形仍可用原观测空间(L2)。

当前物理模型中全部路径共用阵列向量a，所以B_g=a⊗T_g。
矩阵J_k只作用于AFDM输入轴、对各天线及输出行相同。令n=a^H a，
把y_k按[输入,天线,输出]重排后计算y_a=a^H y_k/sqrt(n)，并令

    F_small=sqrt(n) R_k T_g,
    μ_full=a⊗μ_small, tr V_full=n tr V_small.                          (L7)

(L7)中的乘法按输入轴进行。与a正交的观测部分，在同一因子下的活动与不活动密度中完全相同，
故从似然比抵消；增广QR的观测行数可从4096降到256。
这不是截断物理路径或丢弃原有天线子空间：它利用的是所有路径共有a的确切结构。
若以后各路径使用不同阵列方向，或外部协方差混合天线方向，这一压缩一般不再成立。

实际状态的接口核验见ACTUAL_FACTOR_PROTOCOL.md。压缩核验固定全部160因子，
使用两部分首个合法点及固定种子202610163510选出的另两个合法点，共640比较；
完整物理基底重构门槛1e-12，所有积分对象门槛1e-9。
这些仍为固定几何的数学控制，不能替代未知几何积分、概率质量覆盖或实际接收机成绩。
