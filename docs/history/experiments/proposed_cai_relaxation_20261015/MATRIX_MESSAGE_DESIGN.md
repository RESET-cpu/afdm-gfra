# 在原 TMP 内保留 A→B 用户块矩阵信息

2026-10-15。本文记录消息代数设计及独立计算内核阶段。后续已完成非线性适配和完整闭环初筛，
见[后续协议](matrix_receiver/PROTOCOL.md)及[结果](../../results/proposed_cai_relaxation_20261015/matrix_receiver/REPORT.md)；
以下实施边界保留设计阶段的原始记录。
动机是检查 Cai 的协方差标量压缩，不是已经证明该操作会降低 AER。
原 Proposed、两项标量方差对照及第三至第五项历史结果均保留。

## 1. 原公式与此次只放宽的一层

原实现 `linear.py:62–76` 对共同标量输入 CN(Z,γI) 作一般 A 的精确 Gaussian 更新，
把后验协方差压成一个标量，再相除输入消息。Cai v2 §III-A 式(7)–(11)给出其部分正交情形。
当前原版是一般矩阵推广，不需要再次“加入一般矩阵 LMMSE”。

本设计先在每用户块保留 Gaussian 边缘协方差，再除以该用户的输入因子。
其他用户仍用原 Gaussian 消息，用户间真实依赖仍被近似；只保留用户内 AFDM 输入维 P×P 矩阵，
不声称保留 4096×4096 条件协方差。各天线/输出坐标继续采用同一观测噪声模型。

## 2. A→B 的可计算形式

令 Y∈C^(Q×C)，Xk∈C^(P×C)，C=MN，Y=Σk AkXk+N。
输入各用户消息 CN(vec Xk;vec Zk,γI)，保持原共同 γ>0。对其他用户 Gaussian 积分得

    C−k = σ²I + γ Σj≠k AjAjᴴ,
    Ek = Y−Σj≠k AjZj,
    Jk = Akᴴ C−k⁻¹ Ak,
    Bk = Akᴴ C−k⁻¹ Ek.

略去与 Xk 无关的常数，传递的函数是

    Lk(Xk) ∝ exp(2 Re tr(Bkᴴ Xk) − tr(Xkᴴ Jk Xk)).          (M1)

计算仅解 Q×Q 正定线性方程，不求 Ak⁻¹ 或 Jk⁻¹。Jk 可以半正定；(M1)仍是有定义的
似然因子，不要求它在 Xk 上单独归一化。若 Jk 正定，则 Vk=Jk⁻¹、Rk=Vk Bk，
与 block Gaussian 外信息的均值/协方差等价。直接自反馈 Zk 不出现；
其他用户 Zj 对历史观测的依赖仍在，不能据此宣布全部历史反馈已经消除。

数值审计发现本面板 Vk 的最大特征值均超过100，不能把 Rk 配以平均方差直接交给旧网络。
保留 (Jk,Bk) 避免显式逆矩阵放大数值及输入量级，但不会创造缺失的观测信息，
也没有改变局部似然本身的统计信息量。

## 3. B 内部必须匹配同一因子

仍使用原活动先验 ρ 和活跃信道先验 PH。对于 (M1)，定义

    Z1,k = ∫ Lk(H) PH(dH),       Lk(0)=1,
    pk = ρ Z1,k / (1−ρ+ρ Z1,k),
    μk = E[H | Bk,Jk,a=1],
    mk = pk μk,
    uk = pk tr Cov(vec H | Bk,Jk,a=1)/(PC)
         + pk(1−pk)||μk||²/(PC).                              (M2)

式(M2)是给定 Gaussian 因子下的条件矩关系；不把它称为物理联合后验。
原网络仅训练 (R,v) 的标量 AWGN 条件，不能直接当作 (M2) 的实现。
当前尚未选择或训练 (J,B) 条件的 score/矩/证据估计器，也未将旧分类器直接移植。
既有有色训练、空间反馈失败仍须纳入后续适配设计；它们不能证明所有矩阵条件模型无效。
有限一阶估计误差和二阶条件风险不等于中心协方差的问题也仍需单独处理。

## 4. 保持原共同标量 B→A 消息的必要配套

不能把 Vk 先压成 v 再套旧外信息公式，否则又引入要取消的压缩。
同时不必预先改成全矩阵 B→A 或逐用户多种方差。限制输出因子仍为

    Sk(Xk) ∝ exp(2 Re tr(ηkᴴ Xk) − α||Xk||²),  α>0,

其中 α 跨用户共用。组合 Lk Sk 后的 Gaussian 均值与协方差为

    Ck(α)=(Jk+αI)⁻¹,
    mk,approx=Ck(α)(Bk+ηk).

以各用户均值及所有用户的平均平方范数作矩匹配，令 u=K⁻¹Σk uk，得到

    (KP)⁻¹ Σk tr Ck(α) = u,
    ηk=(Jk+αI)mk−Bk,
    γout=1/α,        Zout,k=ηk/α.                            (M3)

推导：最小化 tilted 分布下 Gaussian 近似的期望负对数密度，
对各 ηk 和共同 α 求导，分别匹配均值及总二阶矩；均值匹配后剩余量恰为平均协方差迹。
该目标对自然参数凸，存在上述正根时给出矩匹配解。tilted 分布包含不活动原子，
活跃信道也可能支撑于低维集合，因此一般不能将其称为有限的 KL(tilted || Gaussian) 最小化。
期望负对数 Gaussian 密度只要求相应二阶矩有限，不需要 tilted 具有 Lebesgue 密度。
这是受限 Gaussian 矩匹配的项目推导，依据 Minka §2 式(4)–(6)及§3因子相除；
共同标量限制仍保留，不包装成新命名算法。

f(α)=(KP)⁻¹Σk,i(λki+α)⁻¹ 严格递减，f(∞)=0。
若所有 Jk 正定，则正根存在当且仅当 0<u<f(0)；含零特征值时 f(0+)=∞。
不满足正根条件时，正方差输出限制与给定矩不相容。当前内核明确报告该情形，
尚未以新裁剪或回退规则掩盖它；完整接收机接入前须固定相应处理并报告发生率。

当 Jk=I/v、Bk=Rk/v、0<u<v 时，

    α=1/u−1/v,
    γout=uv/(v−u),
    Zout=(m−(u/v)R)/(1−u/v),                                 (M4)

恰好退回原 T17 的未裁剪公式。这说明改变的是同一 TMP 的投影位置和输入信息，
没有增加 AMP 残差递推或第三条并行算法。原双向阻尼仅在完整实现时沿用，
当前内核不宣称已经推导矩阵输入消息的阻尼及停止规则。
