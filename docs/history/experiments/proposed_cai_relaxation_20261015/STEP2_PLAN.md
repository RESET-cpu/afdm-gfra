# 第二项：将共同反馈方差改为逐用户标量

2026-10-15。在候选运行前固定。本轮仅2个条件×2版本，共4次完整接收机运行。
目标为降低AER，NMSE仅作辅助记录。原Proposed及原网络不修改。

## 范围及依据

第一项保留逐用户条件二阶读数，但形成活动混合矩后仍跨用户平均。
本项进一步将Gaussian消息的线性和非线性两端都改为每用户一个标量，保留用户内
各信道坐标的共同方差。使用已有实现
`experiments/proposed_mean_feedback_20261012/user_scalar.py`，不新增算法名称。

Cai v2 §III-A式(7)–(11)规定Gaussian条件更新与协方差投影。
Fletcher等GEC §II-A式(8)–(9)、§II-B Algorithm 1（PDF pp.2–3）的
block uniform diagonalization允许不同变量块保留不同标量。
下述复数MMV和用户分块公式为项目适配，不是原文对本AFDM场景的性能保证。

- https://arxiv.org/html/2506.00581v2#S3.SS1
- https://arxiv.org/pdf/1602.07795v2

已有负面证据：20261012已知相位、0.1阻尼的六条件实验中，完整逐用户反馈未减少漏检。
本次检验当前估计相位、0.2阻尼条件，不将其称为首次验证。

## 推导和保留的近似

将各天线及输出坐标作为MMV列，写成 Y=Σ_k A_k X_k+N，其中A_k为Q×P，
X_k为P×C，C为天线数乘输出坐标数；每用户D=PC个复数坐标。
以下变量处于原接收机归一化尺度，噪声方差为物理方差除以scale²。
传入线性模块的工作Gaussian消息为CN(Z_k,γ_k I)，γ_k>0。

1. 精确的Gaussian条件更新使用
   C_y=σ²I+Σ_j γ_j A_j A_jᴴ，d_k=tr(A_kᴴ C_y⁻¹ A_k)/P。
   后验均值为Z_k+γ_k A_kᴴ C_y⁻¹(Y−Σ_j A_jZ_j)，
   后验协方差的用户内平均迹为t_L,k=γ_k(1−γ_k d_k)。
2. 将该后验投影为每用户一个标量并除去传入消息，得到
   v_k=(t_L,k⁻¹−γ_k⁻¹)⁻¹=d_k⁻¹−γ_k，
   R_k=Z_k+d_k⁻¹ A_kᴴ C_y⁻¹(Y−Σ_j A_jZ_j)。
   这是Gaussian工作模型和指定投影下的恒等式，不推出实际误差独立AWGN。
3. 现有网络逐样本接受标量v_k；每用户沿用原site接受/复用及活动分类规则。
   设该规则实际使用的活跃条件均值、条件方差为μ_k、t_k，活动概率为p_k，
   则混合均值为Xhat_k=p_k μ_k，平均方差为
   u_k=p_k t_k+p_k(1−p_k)||μ_k||_F²/D。
   不把有限second输出自动等同于精确后验方差；发生site复用时使用实际保留矩。
4. 沿用原方差比裁剪：b_k=clip(u_k/v_k,10⁻⁶,1−10⁻⁶)，
   Z'_k=(Xhat_k−b_k R_k)/(1−b_k)，γ'_k=b_k v_k/(1−b_k)。
   查询与反馈均采用原0.2算术阻尼。不同用户保留不同γ'_k，进入下一轮C_y。

保留用户内标量投影、Gaussian消息、独立用户先验、伪AWGN网络、有限网络、
原接受/复用/裁剪及停止规则。原框架和本项均未获得有限AFDM下的收敛或性能保证。
本项相对原版同时保留逐用户条件二阶读数，这是第一项的延续。

## 冻结对照与判定

- 条件：历史scene003与scene007，均−4 dB、观测估计相位。
  选择依据是原版已有漏检，候选结果尚未生成。原版预期MD分别2、1，FA均0。

  的`estimated_operator_input.npz`；核对其由公开input.npz及已保存phase.npz构造。
  不使用真实相位，不重跑相位估计。
- 每条件按native、user_feedback的固定顺序；共4次，失败也计入尝试数并保留。

  信道相对误差均≤10⁻⁶、活动判决完全一致。此检查在本轮两次native运行内完成。
- 所有版本原权重、初始化、0.5门限、0.2阻尼、600轮上限及停止条件相同。
  不重训，不选门限，不因候选结果删选用户/条件，不增加完整循环重放。
- 推断只接收公开四字段；真值只在完成推断后用于评分。记录来源、权重、代码哈希、
  每轮概率/方差/裁剪/支持状态、末态查询、全部输出及警告。
- 运行前复核已有8项确定性测试（Gaussian代数、外信息、原site规则及适配器）。
- 主结果：MD、FA、AER=(MD+FA)/80；逐条件结果、停止原因和调用数完整报告。
  原版总错误3个；候选若未减少错误，停止扩大本项，不以NMSE收益替代检测收益。
  若减少错误，只记为预选困难条件上的开发证据，尚需另定新场景确认。
