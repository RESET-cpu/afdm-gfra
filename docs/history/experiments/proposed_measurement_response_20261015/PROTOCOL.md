只使用此前的四个开发条件：(scene000,−4 dB)、(scene008,0 dB)、
(scene016,4 dB)、(scene024,−4 dB)。不是新的独立性能样本。

每个重放把运行上限和最少轮数同时设成 T；所有迭代更新、网络、双向0.2阻尼、
支持范围与内部补噪种子保持原样。先做四条未扰动重放并逐数组核对旧预测与已保存残差。

每个条件使用两个独立 CN(0,I) 观测探针，种子为 202610158100000+100×scene+probe，
probe=0,1。对每个方向分别使用 epsilon/sqrt(sigma²)=0.01,0.02，中心差分的正负两侧。
sigma² 为归一化观测噪声方差，保持接收机中的已知噪声参数不变。
共4条未扰动重放+32条扰动重放，不按结果追加探针或选择步长。
两侧内部补噪随机数相同；每次均从初始状态重放，保留完整历史依赖。
保存与前阶段相同的观测轮次；其余轮次保存分支信息和补噪特征向量，用于检查局部变化。

## 估计量与目标

Y=AH+N，m=4096个复观测坐标，M_t(Y)=A F_t(Y)，F_t为阻尼后的反馈。
每个方向 xi~CN(0,I)，

    a_hat_t = Re <xi, [M_t(Y+epsilon xi)-M_t(Y-epsilon xi)]/(2 epsilon)> / m。

其方向期望对应 tr(J_real M_t)/(2m)，不是 tr(J_real)/m。
由一般Gaussian均值风险公式得到观测域风险估计

    Khat_ij = [Re<Z_i,Z_j> - m sigma² + m sigma²(a_hat_i+a_hat_j)] / c，
    Z_i=Y-M_i，c=256||A||F²。

依据 Nobel、Candès、Boyd，IEEE TSP 2023，§I-A式(1)、§I-B，p.4330：
https://web.stanford.edu/~boyd/papers/pdf/sure_tractable_eval.pdf 。
复坐标因子、历史链式依赖和观测风险/完整信道风险的区别已在前阶段解析核对。
本阶段的 check.py 额外核对实际差分函数在已知复线性/共轭线性映射上的因子。

## 预定分析

1. 四条未扰动预测及所选轮次残差必须精确复现；所有源文件与原 Proposed 备份哈希一致。
2. 保存两方向、两步长的全部结果，报告探针间差异、步长间差异；两个方向不构成可靠置信区间。
3. 保存 site接受、方差下限、支持范围、残差信号秩、补噪模式等各轮分支，比较正负扰动及未扰动。
   特征向量的复相位或旋转会影响使用相同随机数的补噪路径，也单独报告；不事后对齐特征向量。
4. 所有推断结果保存后，分析脚本才读取真值，核对实际噪声交叉项
   2Re< A(F_t-H),N >/c，与散度预计的2m sigma² a_hat_t/c比较。
   进一步报告改正前后观测域误差Gram及其对真实Gram的误差；同时明确完整信道误差仍另有投影项。
5. 负风险、非有限值、分支变化、差分不稳定和运行失败全部记录，不裁剪、不调参掩盖。
6. 统计全部额外网络/分类器调用及实测时间；本诊断没有算法提速结论。

相同局部分支与两步长近似一致都不能证明全局弱可微；硬分支可能有Stein公式未包括的边界项。
四个条件也不足以验证期望无偏。这里判断完整响应是否具有解释力、数值上是否值得继续，
不宣称此核对已使查询或反馈成为AWGN，不优化历史权重，不替换主线。
