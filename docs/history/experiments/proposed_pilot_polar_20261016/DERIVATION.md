# 方形用户导频块的单位响应与白热噪声

2026-10-16。以下为项目代数推导；性能由独立保存的接收机结果评价。

## 原导频上仅改线性滤波的限制

固定某用户方阵A_k，要求W_k A_k=I意味着A_k可逆且W_k=A_k^{-1}。
因此W_kW_k^H=(A_k^HA_k)^{-1}。若还要求W_kW_k^H=cI，必有
A_k^HA_k=c^{-1}I。当前每用户总导频能量为N，故c=1。
这说明任意非酉方阵块不能只靠另一套线性滤波器同时得到两项严格性质。
Q<N时rank(W_kA_k)≤Q<N，更不可能在完整N维信道坐标上获得单位响应。

## 保持帧数和每帧总能量的候选

对原块P_k=L_kΣ_kR_k^H，取B_k=L_kR_k^H。
这是Frobenius范数下最近酉矩阵，满秩时唯一；
‖B_k−P_k‖F²=Σ_i(σ_i−1)²。在原块‖P_k‖F²=N时等于2N−2Σ_iσ_i。
来源：Higham, Computing the Polar Decomposition—with Applications,
SIAM J. Sci. Stat. Comput. 7(4), 1986，§2.1式(2.2)、§2.2 Corollary 2.3，
印刷pp.1161–1162，https://eprints.maths.manchester.ac.uk/694/1/high86p.pdf。

任意单位模对角D_k满足polar(D_kP_k)=D_kpolar(P_k)，且右乘酉矩阵也等变。
所以A_k=D_kB_k为酉矩阵，A=[A_1,...,A_K]满足AA^H=KI。
在反馈共同标量方差γ、热噪声σ²的模型中，迹归一化LMMSE为

    W0=γA^H(γAA^H+σ²I)^{-1},
    W=W0 / [tr(W0 A)/(KN)] = A^H.

这给出W_kA_k=I、W_kW_k^H=I，且W不依赖γ。
当前接收机的共同空间协方差若在各天线特征方向分别归一化，也得到同一W。

给定准确固定相位时，查询写成

    r_k=x_k+Σ_{j≠k}A_k^HA_j(x_j−z_j)+A_k^Hn.

只在额外假设其他用户误差独立CN(0,γI)、并独立于目标与热噪声时，
残余为CN(0,[(K−1)γ+σ²]I)。真实学习闭环不自动满足这些假设。
从观测估计相位后，矩阵恒等式仍成立，但A_hat依赖噪声，还需加入
W(A_true−A_hat)x，不能凭WW^H=I断言实际条件误差独立白Gaussian。

## 用户之间的限制

Q=N且每用户块酉时，A_k^HA_j仍酉，全部奇异值为1，Frobenius范数平方为N。
所以改变酉码不能减少任意用户对的总耦合能量，也不能靠用户线性子空间分离。
若活跃完整信道是同方差各向同性Gaussian，则给定活动集合S的观测协方差为
(σ²+γ|S|)I，用户标签无法区分。原非酉块的不同奇异值/方向可能携带额外协方差信息。
这是说明可辨识性代价的合成先验反例，不是当前完整AFDM物理先验不可辨识的证明。
一般右酉变换不保持AFDM路径结构，实际用户区分仍可依赖该结构。

## 首末查询的可核查分解

每轮未阻尼查询为z_t+W_t(y−A_hat z_t)，新值阻尼权重β。
观察器仅由公开输入与状态累计

    L_t=(1−β)L_{t−1}+βW_t,
    b_t=(1−β)b_{t−1}+β(I−W_t A_hat)z_t,

首轮直接采用W_1、(I−W_1A_hat)z_1。于是r_t=L_t y+b_t，逐轮验证。
另外单独累计b_self,k,t对应(I−W_k,t A_hat,k)z_k,t；其余反馈为b−b_self。
接收机结束后才加载x和真实相位，严格展开

    r_k−x_k = (L_k A_hat,k−I)x_k
              +Σ_{j≠k}L_k A_hat,j x_j + L_k n
              +L_k(A_true−A_hat)x + b_self,k + b_other,k.

所有项都是当前数值轨迹的代数贡献；真值方向投影不是独立抽样估计或干预因果证明。
记录全部用户，不只保留漏检者。矩阵恒等式、近似统计、接收机性能分别报告。

## 与Cai的测量维度仍有区别

Cai v2 §II-A式(3)–(4)定义Q_k为NT×N，将T个对角导频块堆叠；§V-C式(66)
允许从K×K酉矩阵选行。在其DFT恒模设置中，Q_kᴴQ_k=TP I、QQᴴ=KP I。
因此W_k=Q_kᴴ/(TP)，C_kj=W_kQ_j，并由这两个等式直接推出

    Σ_{j≠k} C_kj C_kjᴴ = (K/T−1) I。

该式是基于原文设定的项目推导，不是原文另行给出的性能定理。
来源定位：[Cai et al. v2](https://arxiv.org/html/2506.00581v2#S2.SS1)，
§II-A式(3)–(4)及[§V-C式(66)](https://arxiv.org/html/2506.00581v2#S5.SS3)。
这里的用户内恒模/等能量条件不能无条件推广到任意酉矩阵选行的全部设计。

当前AFDM每个接收天线/输出坐标对应的未知量还有完整N维输入坐标；Q=N时，
极分解导频块是方阵，已有Σ_{j≠k}A_kᴴA_j A_jᴴA_k=(K−1)I。
在给定相位的线性模型中，两者的标量观测数/完整展开信道坐标数分别为T/K与Q/(KN)；当前后者为1/K。
不能把我们的16帧与Cai的T=16直接等同为相同矩阵压缩比例。

若其他用户反馈误差真是独立各向同性、共同方差γ，以上恒等式分别对应
γ(K/T−1)与γ(K−1)的干扰工作方差。真实闭环不满足这些条件时，不能由矩阵恒等式
保证该工作方差等于实际残余方差。Cai在固定算子下的热噪声方差为σ²/(TP)，
本候选为σ²；二者资源/未知维度不同，不能由这些量直接作公平性能优劣判断。
结构先验可以降低实际估计难度；上述维度比较不是当前物理信道不可恢复的证明。
