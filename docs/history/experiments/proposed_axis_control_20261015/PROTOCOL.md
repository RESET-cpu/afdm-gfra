# 首轮误差相关性的逐维Gaussian对照

2026-10-15。真值辅助的离线机制诊断；不属于可实现接收机，不训练、不替换原Proposed。

## 固定问题与设计

此前同功率理想AWGN消除了四例实际首轮查询的明显负散度。本轮区分天线、AFDM输出、
AFDM输入三个维度的误差相关性，检查哪些相关性足以在冻结联合映射D=pF中触发异常。
这是对所构造分布的敏感性检查，不把相关性分解写成真实闭环的因果分解。

固定四个已有开发条件：场景0/−4 dB、8/0 dB、16/4 dB、24/−4 dB。
查询复用D-OAMP首轮，其误差功率与标签v近似一致。固定原三个网络、归一化尺度、活动先验、
0.5判决门限。使用无site回退的瞬时pF映射；原带历史记忆的完整接收机保持不变。

每用户误差E_k=R_k−H_k形状为16×16×16。对各维展开为16×256，按行去均值，
计算样本协方差并归一化到trace=16，记为C_ka、C_ko、C_ki。只裁掉浮点舍入负特征值。
每用户功率q_k=mean|E_k|²另行保存。上述量均使用真值，是oracle诊断参数，
不是接收机可获得的噪声协方差，也不假定它们能一致估计真实总体协方差。

使用两个固定独立Gaussian重复；同一重复的全部条件共用基础Z~CN(0,I)：

- uniform：H+sqrt(v)Z，与旧网络的标量AWGN训练接口一致。
- 000至111：三个比特依次选择天线、AFDM输出、AFDM输入协方差，0表示单位阵。
  令L_j L_jᴴ=C_j，生成E=sqrt(q_k)(Z×₁L_a×₂L_o×₃L_i)，再查询H+E，标签仍为原v。

因此八个条件的每用户期望功率相同；000单独保留实际用户间功率差异。
只改变选择维度的协方差形状，Gaussian样本不按实现功率重新归一化，保留随机波动。
完整三维协方差采用Kronecker乘积；仅保持各维边缘形状，未保持真实误差的跨维依赖、
非Gaussian性、均值偏差或跨用户相关。条件于已估计矩阵时，模拟误差为零均值proper complex
Gaussian；由于矩阵来自同一真实查询，不能声称其总体分布与真实信道独立。

每场景原始查询1个、uniform 2个、八种协方差×2个，共19个查询；总计76个。
每查询固定3个复Gaussian探针、0.005/0.01/0.02乘sqrt(v)的中心差分，共9个迹估计。
保存全部结果，包括NMSE、MD/FA、实际MSE/v、三维协方差偏离、二阶代理、site可接受性。
有限差分重复不当成独立物理样本；不依据结果追加协方差、种子或调参。

## 验证与解释

本次诊断总墙钟预算15分钟；超时保留已有结果并明确报告未完成，不改变预定条件。
先对2×3×4小型复数张量核对逐维生成与显式Kronecker变换、协方差和trace恒等式。
生成协方差的因子重建误差应在双精度范围。冻结主线28项源文件与备份在运行前后核对。
全部程序仅写入独立experiments/proposed_axis_control_20261015与对应results目录。

报告同时列逐条件和全部四场景结果；两个随机重复先在场景内汇总，不虚增物理样本数。
若一个有色Gaussian条件重现异常，只能说明所设相关结构足以在该对照中诱发异常；
若未重现，也不能排除真实误差的其他依赖或非Gaussian性。正平均迹不是完整Jacobian半正定证明。
单次去噪NMSE不能当成完整接收机NMSE，oracle白噪声不是可实现性能上界。
