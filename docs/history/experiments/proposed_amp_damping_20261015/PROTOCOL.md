## 研究问题与变量

检验冻结score与活动分类器在保持同一初始化、标签、导数和阈值时，
阻尼能否使新循环留在训练支持范围并改善其后续估计。
主要阻尼新值权重预设为0.2，与原Proposed的数值相同，但不声称两者的实际更新等价。
另固定0.1、0.5作敏感性检查；原权重1作为无阻尼基线。
增加权重0.2且关闭Onsager的对照，以区分平滑本身和校正的共同作用。
全部设置保留，不根据真实NMSE挑选阈值、输出轮数或删去失败条件。

## 递推

固定beta时，用原联合去噪D和完整复数Jacobian部分迹B：

    r_t = x_t + A^H z_t
    d_t = D(r_t; ||z_t||_F^2/(Q C))
    x_{t+1} = (1-beta) x_t + beta d_t
    c_{t+1} = (1-beta) c_t + beta z_t B_t
    z_{t+1} = y - A x_{t+1} + c_{t+1}

以x_0=0,z_0=y,c_0=0初始化。代码采用精确等价的
z_{t+1}=(1-beta)z_t+beta[y-A d_t+z_t B_t]。
当前B保持对完整D求偏导；beta只在历史权重中使用，不重复乘到B。
每轮直接由实际阻尼后的残差计算方差，包含跨轮交叉项。
保留完整推导及对有限结构化AFDM适用性的限制，不把代数一致性称为统计保证。

## 冻结实验设置

- 四条件：原开发集scene000/snr-4、scene008/snr0、scene016/snr4、scene024/snr-4。
- 同一公开四字段输入；同一冻结网络、总体尺度、活动先验与0.5阈值。
- 原8探针、相对差分步长0.01、种子202610157301；每轮33次联合映射。
- 新设置共16条：beta=0.2、0.1、0.5各4条，beta=0.2无Onsager再4条。
- 每条最多100轮；完成预算不称为收敛。越出[0.001,100]或非有限更新记FAILED并保存最后有效状态。
- 不做标签裁剪、score重训、白化、额外初始化或按真值选择算法参数。
- 输出信道为阻尼状态x；活动概率为最新原始D的分类器输出，不平滑活动概率。
  同时保存原始d供诊断，不能在x与d中按真值挑选最终输出。
- 预算检查点1、2、3、5、10、20、50、100，以及每条最后有效轮保存完整诊断快照。
- 每条独立进程，900秒硬超时；运行期间监测输出增长与进程状态，超时完整记录。
- 先保存所有预测，再独立读取truth评分。报告全用户NMSE、漏检/虚警、查询误差/标签比、天线相关性和全部网络调用成本。
- 原Proposed沿用此前已核验的配对结果；原无阻尼AMP通过beta=1真实输入重放核对，不覆盖旧结果。

## 核验与解释

代数测试需覆盖beta=1与原实现逐轮完全一致、独立展开完整历史与紧凑递推一致、
复数残差方差含交叉项、关闭Onsager时等于普通残差、失败保留最后有效状态。
真实beta=1重放的数组采用与网络数值精度相称的容差，同时报告实际差异。
小阻尼带来的小步长不能冒充收敛；额外报告未阻尼映射的固定点残差。
主要比较固定100轮的完成状态，并明确失败最后有效输出和有限预算输出的差别。
所有方法同时报告成本；不声称100轮AMP和原Proposed的完成轮数具有相等网络成本。
四个已有失败开发条件不构成独立确认集；不建立总体优越性、白噪声保证或AFDM收敛定理。
