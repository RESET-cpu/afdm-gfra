1. 把日常使用的实现提取为独立包，按 `scenario`、`waveform`、`channel`、`receiver`、`experiment`、`plotting`、`networks`、`training` 分区，并改为包内绝对导入。
2. 场景表与 NTN-TDL 条件生成从实验模块归入 `scenario`。公共输入、噪声约定与物理路径算子归入 `channel`；相位和噪声估计保留在接收机前端。
3. GP-MP、STMP、DU、基准、消融和去噪对照集中在 `receiver`。新登记只改变工厂和直接源码位置，保持权重、数值配置和方法集合。
4. 实验执行、存储、评分、汇总分开；报告中的诊断绘图移到 `plotting/summary.py`。论文绘图使用包导入，统一通过 `plot` 子命令访问。
5. 新通用计划默认输出到 `result/organized_default_20261107/`。冻结的 `white_followup` 与 `convergence` 继续转交原模块，原计划不改写。
6. 新 GNN 训练副本的内存统计改为平台对应实现，使 Windows 可以导入训练模块；同时将 Linux 的峰值内存换算为字节。此项只影响资源记录，不改变训练计算。
7. 增加目录说明、路径对应和对照检查。项目声明加入新包、绘图/测试可选依赖，以及已有运行队列使用的 `psutil`。

原代码逐文件 SHA-256 与新路径见 `MAPPING.json`。原根入口、元数据和导航文件的修改前副本在 `before/`。`organize.py` 是初始提取过程记录，后续分层调整以最终映射和源码为准，不要对现有工作包重跑。
