# 高 SNR 去噪 baseline 诊断

结论：输入轴排列、物理尺度、噪声方差、Doppler 单位、折叠时延与原子导数的检查通过。前三个方法的主平台是原有整数粗字典的表示误差；Off-grid SBL 的主要额外误差来自固定中心的一阶近似与最终精确原子重建不一致。当前实验忠实复用了旧实现，但不足以说明这些方法在充分适配的独立去噪任务中的性能。上轮“适配器与原入口一致”的验证只证明了调用一致，未验证这两项模型误差。

## 范围与可复现性

- 原结果：`results/denoising_four_baselines_20261018`，500 场景、每场景 4 个信道、6 个噪声点。
- 字典投影检查使用全部 500 场景 / 2,000 个无噪声真值；原 Off-grid 停止与线性化统计覆盖全部 12,000 次推断。
- 详细 Off-grid 分解固定使用 scene000–009、全部 4 个信道，30 dB，共 40 个；1000 轮与精确非线性拟合固定使用 scene000–001，共 8 个。按索引取样，没有按表现筛选。
- 诊断实现：`runs/denoising_diagnosis_20261019/{check.py,controls.py,report.py}`。使用原实验冻结 runtime、配置和权重；未改动原求解器及正式结果。
- 真值只用于评价、字典表示下界和明确标记的 oracle。精确原子系数重拟合、非线性拟合均只读取观测及原求解器估计坐标。
- 检查了 191 个冻结文件和原适配器/runner 哈希，均未变；MAINLINE 身份与原实验一致。

## 输入、尺度与字典的代数检查

原输入为 H[天线,输出,输入]，通过单位输入算子形成 Y[输入,天线,输出]，然后堆叠为 [输入×输出,天线]。归一化查询乘 s=0.2647966452702405；噪声方差乘 s²；输出除 s。30 dB 时物理噪声方差为 7.01172633464e-05。

| 检查 | 最大或整体相对误差 |
|---|---:|
| 随机系数经字典重建、堆叠与直接矩阵乘法一致 | 4.36e-17 |
| 独立显式索引与堆叠一致 | 3.37e-17 |
| 40 个信道从原 seed 重生成与保存真值一致 | 0 |
| 真实长时延原子与折叠原子差异（允许自由复增益吸收标量相位） | 1.64e-11 |
| 时延/Doppler 解析导数与中心差分 | 8.82e-09 |

这些检查排除了已检查路径上的轴转置、噪声方差忘记平方缩放、Doppler Hz/子载波单位混用、折叠原子相位不能吸收等错误。它们不证明 GNN 训练分布与独立去噪分布一致。

## SOMP、GAMP-SBL、GNN-ASPL 的共同平台

原配置是时延步长 1 采样点，多普勒步长 30 kHz；16×5=80 个原子。单位输入算子下字典尺寸 256×80，秩 80。三者输出都限制在此字典列空间中。

对每个无噪声真值 T 计算 P_D T，其中 P_D 是该列空间的正交投影。全 2,000 个信道汇总后的最佳可达 NMSE 为 **-10.92315 dB**。这是该字典输出结构的表示下界，使用真值、全部 80 原子、无稀疏惩罚，不能作为实际可用 baseline。

| 方法 | 30 dB 正式 NMSE | 表示误差占总误差能量 |
|---|---:|---:|
| SOMP | -10.87427 dB | 98.88% |
| GAMP-SBL | -10.76802 dB | 96.49% |
| GNN-ASPL | -10.82375 dB | 97.74% |

因为输出仍在同一列空间，误差可正交分解为表示误差和列空间内的估计误差。平台几乎由表示误差解释，增加迭代不能跨越该下界。LS 直接保留完整观测，不受此 80 维限制，其全样本 30 dB NMSE 为 −29.92879 dB。

单路径控制也支持这个判断：恰在整数网格上的样例，噪声方差从 1e−3 降到 1e−8，SOMP 从 −53.88 降到 −103.88 dB、GAMP 从 −42.54 降到 −74.04 dB；连续离网样例中前三者仍在约 −10.2 dB。GNN 在整数单路径样例还有约 −34 dB 的剩余误差，固定层数和权重的适用范围需另行检查；本次不能把该剩余误差全部归因于训练分布。

## Off-grid SBL 的误差分解

代码固定原始中心及导数，使用 A(δ)=A0+Dd·diag(δd)+Df·diag(δf) 求后验均值 μ，最终却以中心+δ 的精确原子和原 μ 重建。偏移不够小时，两者不是同一个前向模型；直接搬用系数并不保证精确重建仍拟合观测。

30 dB 的全部 2,000 次推断中，一阶预测与精确重建的相对距离中位数为 **20.59%**，95 分位为 **72.00%**；它与 NMSE 的对数相关系数为 **0.9935**。这是相关性证据；下列配对重拟合实验进一步验证该误差来源。

在完全相同的 40 个信道上，汇总 NMSE：

| 输出 | NMSE |
|---|---:|
| LS | -29.45359 dB |
| 原 Off-grid SBL 精确重建 | -11.57697 dB |
| 原求解器的一阶预测直接还原矩阵（诊断） | -27.22476 dB |
| 固定原估计坐标，在精确原子上重做最小二乘系数拟合（诊断） | -23.34242 dB |
| 原估计坐标精确原子对无噪声真值的最佳投影（oracle） | -23.39139 dB |
| 已知真实路径坐标，对带噪观测做最小二乘（oracle） | -48.82218 dB |

只重新拟合系数便改善约 11.77 dB，说明原输出系数与精确模型不一致是主要可修正因素。但 −23.34 dB 仍逊于同子集 LS 的 −29.45 dB；精确原子对真值的最佳投影也只有 −23.39 dB，说明位置估计仍有误差，不能只修最后一步就宣称解决。

同一 40 个信道中，只看时延分支时全部覆盖；同时检查时延与 Doppler 的联合盒约束后，有 **8/40 个信道**至少一条真实路径不在任何保留候选的搜索盒内。代码仅按原始相关性保留 12 列，未做残差逐次筛选，候选筛选因此也是已经观测到的限制。完整覆盖的 32 个信道，精确原子系数重拟合后为 −24.05 dB；存在遗漏的 8 个信道为 −20.59 dB。两组信道不同，这个组间差异不能单独当作遗漏的因果效应。即使搜索盒覆盖真值，也不保证局部更新能找到正确坐标。

原模型在 30 dB 的 2,000 次推断中有 1,992 次到达 120 轮上限。不能把达到上限写成收敛；也不能直接断言平台只是轮数不够。配对的 8 个信道上：

| 处理 | NMSE |
|---|---:|
| LS | -30.05109 dB |
| 原 120 轮 | -10.09436 dB |
| 只提高到 1,000 轮 | -6.83011 dB |
| 在原筛选与原盒约束内，用精确原子联合重新拟合坐标和系数（诊断） | -31.42510 dB |

精确非线性拟合只使用观测，最多 100 次函数评估；8 例中 5 例达到预算，仍有局部最优问题，一例误差仍高于 LS。它证明改用一致的精确前向模型能够大幅改善这批样例，**不是已验证的新 SBL 算法，也不是 500 场景修复完成的结论**。Jacobian 与有限差分的最大相对误差为 6.95e-08。

单路径控制中，正好位于 Off-grid 初始中心的信道，噪声方差由 1e−3 降到 1e−8 时 NMSE 从 −51.82 降到 −101.81 dB；同样是单路径、移至区间内部的离网位置后，却停留在约 −13 dB。结合真实路径坐标 oracle 的极小无噪声投影误差，这排除了“这个连续 AFDM 原子本身只能到 −11 dB”的解释。

## 对后续正式比较的影响

1. 旧曲线作为“原配置直接复用”的结果保留；不应把它当作充分适配后四种方法的性能，或据此直接论证 proposed 的优势。
2. SOMP/GAMP 应在独立校准场景确定更合适的时延/Doppler 字典及运算预算。GNN 的现有权重绑定原整数网格，不能仅替换字典就假定训练适用；需要对应适配或明确保留它的原网格限制。
3. Off-grid 必须先统一求系数和重建时的前向模型；精确原子下系数更新是最低限度，进一步需要检查坐标更新、局部重新线性化和分支边界。任何变化单独保存实现与配置，并在独立校准集选择设置。
4. 再使用原 500 场景和同一噪声实现验证所有 SNR。此报告的 40/8 个样例已经用于诊断，不能同时宣称是未接触的验证集；若据其调参，应补充新种子验证。

没有改动冻结主线、云端 5k/50k 权重、旧 baseline 结果或旧合并图。原运行的数值 warning 仍保留在原记录中；这里的有限输出、独立代数检查及配对实验支持上述结论，但不等于对所有底层数值警告完成了专项审查。

主要源码证据：原适配器 `runs/denoising_baselines_20261018/adapter.py`；冻结 runtime 下 `system/dictionary.py` 的 `from_operator/stack/reconstruct`、`algorithm/baselines/offgrid/sbl.py` 的 `solve`、`offgrid/atoms.py` 的 `path_atom`。项目推导和原文定位见 `docs/OFFGRID_BASELINES.md` 与 `docs/TERMINOLOGY.md`；本报告结论来自本地代码与实验，未把项目适配解释为论文原算法的必然性质。
