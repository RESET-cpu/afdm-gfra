# 数学与数据审查

日期：2026-10-19。审查方式：同一任务共享上下文下的子代理复核，由主代理结合数值结果核对；不称为盲审或独立外部审计。未运行正式训练。

结论：未发现阻止本候选移交训练的具体数学或数据实现错误。当前实现成立为受监督的AFDM展开估计器，不是Cai或Wei原算法逐式复现。

核对范围：source_experiment/receiver.py、data.py、backbone.py、train.py，vendored NCSN++，Wei原文，以及快照中物理生成流程。

- 实数块矩阵、pack/unpack与物理信道h[k,m,r,n]及观测收缩方向一致。
- 复噪声方差v对应实坐标v/2；DSM、NCSN++输入标准差和Tweedie修正系数一致。
- 活动sigmoid门控与NMSE+BCE联合训练相容；活动分支作为直接监督估计器，不宣称精确AWGN似然比。
- RMS仅来自训练先验库，没有逐样本真值归一化；五个场景种子区间分离。
- forward只接收观测、算子、已知噪声和总体活动先验；标签仅用于损失和评估。
- 新层独立初始化，score加载新预训练权重，已有层保留并共同训练。

低严重度事实：最后一层beta只影响未被后续层使用的反馈，因此没有损失梯度。它不影响该层恢复输出。文档已明确该参数和反馈诊断不能作为已经校准的后验误差证据；不为制造梯度而改变目标函数。

解释边界：标量方差、logit校准、softplus正值处理、反馈上界属于项目适配；不证明外信息白化、精确贝叶斯推断或任意算子收敛。准确相位、准确噪声为oracle诊断。固定5层为最终方案，1至4层仅报告消融，不按测试结果选择深度。残差方差不能识别A零空间中的恢复误差。
