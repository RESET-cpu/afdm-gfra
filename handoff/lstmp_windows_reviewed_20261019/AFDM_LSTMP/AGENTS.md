# Windows训练候选执行约定

先阅读README.md与AUDIT.md。默认任务是通过本机检查后继续第366步的新网络训练。

- 只通过run_windows.py的check、resume、pause、status入口操作；不直接运行快照launch.py。
- 保留数据划分、训练集尺度、训练参数与预先指定的5层深度；不按测试结果调参。
- 本候选使用已知相位、已知噪声，报告中明确oracle范围。
- 旧三个权重仅供冻结对照，不用于初始化新网络。
- 修复环境问题不改变模型公式；需要修改实现或配置时另存候选并记录差异，保留既有断点与结果。
- 不自动初始化Git或恢复自动快照；不覆盖项目冻结主线。
- 如实报告失败、非有限值和不利场景，不删除样本或放宽阈值来宣称通过。
