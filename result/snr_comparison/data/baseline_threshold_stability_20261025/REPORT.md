# 独立校准场景门限稳定性验证

结论：四种 baseline 在六档 SNR 汇总后的 AER 均未触发追加条件；Off-grid SBL 在 −4 dB 的局部波动触发了预先冻结的追加规则。因此已经追加独立的 1000 场景，且没有使用正式比较场景 0–999 的预测或真值。

## 数据与方法

- 仅使用旧校准场景 **1000–1999**，首先精确复现四种算法原八档 SNR 的最优门限、漏检数、虚警数。
- 当前目标域为 −4、−2、0、2、4、6 dB，重新拟合门限仅用于本次诊断。原有八档门限和官方运行策略未变。
- 全部 1000 个物理场景做 400 次成组 bootstrap，记录门限的经验分布。
- 另做 200 次划分：每次留出 200 个物理场景，其余 800 个场景产生两个独立的、大小为 800 的 bootstrap 拟合样本。两组门限都评估在该次相同的 200 个留出场景上。
- 同一物理场景的用户和所有 SNR 始终在同组；拟合与留出场景严格分离。四种算法使用相同的划分和重采样。
- 每个算法始终只有一个固定门限。目标为最小化漏检与虚警总数；平局优先更少虚警，再选较小门限。

成组重采样依据 Cameron–Miller (2015), §II.F, pp.327–328 的 pairs cluster bootstrap；这里借用其保留组内依赖的重采样方式，不把回归渐近理论当作本项目非光滑最优门限的覆盖率证明。[原文](https://cameron.econ.ucdavis.edu/research/Cameron_Miller_JHR_2015.pdf)。门限拟合与验证分离也见 [scikit-learn §3.3.1](https://scikit-learn.org/stable/modules/classification_threshold.html)。

## 运行前冻结的判断标准

比较同一留出集合上的两个门限所产生的 AER 差异绝对值。

- 汇总 AER 的实质差异容差：`max(0.0005, 20% × 平均留出 AER)`。
- 单档 SNR 的容差：`max(0.001, 25% × 该档平均留出 AER)`。
- 200 次划分中，超过上述容差的比例达到 20%，则触发追加；所有方法使用相同规则。

这些是本次资源投入的实用容差，不是文献规定的显著性检验。方案在重采样前冻结，SHA256 为 `53305c6487d6f2ef401ccd9005f52a8b93f80585b1142e0bfa0e49ad7c53d206`。

## 结果

| 方法 | 六档全校准集最优门限 | bootstrap 5%–95% 分位范围 | 汇总 AER 超容差比例 | 单档最高超容差比例 | 是否触发追加 |
|---|---:|---:|---:|---:|---|
| Off-grid SBL | 0.070785 | 0.063244–0.073156 | 0% | **29%，−4 dB** | 是 |
| GNN-ASPL | 0.033905 | 0.022626–0.038062 | 0% | 0% | 否 |
| GAMP-SBL | 0.074113 | 0.070914–0.077306 | 0% | 1.5%，−4 dB | 否 |
| SOMP | 0.131400 | 0.129707–0.142031 | 0% | 0% | 否 |

Off-grid SBL 的 −4 dB 平均留出 AER 为 0.004725，对应容差 0.001181；58/200 次划分超过容差。该档两个拟合门限的 AER 差异绝对值，90% 分位数为 0.002。较低门限相对于较高门限，在每次同一 200 场景、8000 用户判决上，平均增加 7.32 次虚警、减少 0.805 次漏检。其他 SNR 下较低门限主要减少漏检，因此总体 AER 的稳定性可能掩盖最低 SNR 的敏感性。

GNN-ASPL 门限数值的分布更宽，但留出 AER 并未出现相应的大幅波动，不能仅凭门限范围就认定其需要追加数据。

250/500/800 校准场景的留出学习曲线没有显示所有算法都会随样本数增加而明显改善；追加数据的目的，是核验并减小最低 SNR 的门限抽样敏感性，**不保证 AER 必然改善**。

## 已启动的追加实验

路径：`../baseline_calibration_extension_1000_20261025/`。

- 新物理场景 IDs **2000–2999**，与原校准集和正式比较集均不重叠。
- 预先随机划分 **700 个补充校准场景 + 300 个独立验证场景**。
- 先用原 1000 + 新 700，共 1700 场景拟合四种固定门限并冻结；随后才运行、读取 300 个验证场景的结果。
- 四种 baseline 都使用同一组新场景和六档 SNR，共 6000 个输入、24000 份接收机结果。
- 比较旧八档门限、旧六档校准门限和追加后的六档门限；旧六档与新六档的对比才隔离了追加数据的影响。
- CPU 单进程、两线程，不使用 CUDA；不改变正在运行的 C-STMP 或任何官方门限，不因验证结果不利而挑选或排除场景。
