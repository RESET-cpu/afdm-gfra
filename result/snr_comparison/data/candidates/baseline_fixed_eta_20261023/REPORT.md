# 四种 baseline 的跨 SNR 固定门限诊断

结论：固定门限并不必然使 AER 变差。将各方法现行 0 dB 校准门限固定到六档 SNR 后，SOMP、GAMP 的总错误减少；GNN 略减、off-grid SBL 略增，后二者的配对区间均包含零。历史门限迁移则使 SOMP、GAMP、GNN 全部变差，不能把这种迁移影响归因于固定门限本身。

## 数据与比较规则

- 固定 scene0000–scene0799，800 个物理场景，每个场景在 −4、−2、0、2、4、6 dB 上配对。
- 40 用户；已知相位、估计噪声。每档 32000 次用户判决，六档合计 192000 次；独立抽样单位仍为 800 个物理场景。
- 直接复用审核后的恢复输出、能量和活动分数。只改变最终门限，不重新推断或训练，NMSE 不变。
- 主比较：每个方法使用各自现行 0 dB 校准门限，跨 SNR 固定；不是四种方法共用一个数字。
- 原分档策略依据估计 SNR 选门限，因此真实 0 dB 的原判决也可能与固定 0 dB 门限不同。
- 次比较：历史 SNR8 项目校准门限（场景、模型有差异）；补充保留此前固定 0.1 数值对照。无匹配的 off-grid 历史门限，不补造。
- 本次规则在新计算前写入 PLAN.json；之前已看过部分诊断，因此不称为独立确认实验。没有使用这 800 场景搜索或拟合门限。

## 解释边界与后续方法

门限降低会增加活动判决，通常在漏检与虚警之间交换错误。固定门限是否合适取决于当前恢复输出的分数分布、校准条件及目标 SNR 范围；分档增加自由度也不保证在另一批场景中更好。本次可以排除“所有 baseline 固定门限都会退化”的判断，尚不能证明任一固定值对后续工况最优。

若采用跨 SNR 固定门限，应在独立校准集上覆盖六档 SNR，为每个方法单独选取并冻结一个值，再用未参与校准的测试集验证。当前 800 场景用于诊断，不据此挑选最终门限；正在运行的冻结主实验保持原样。
