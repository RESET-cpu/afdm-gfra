# 新分类器 C-STMP：增大阻尼的配对诊断

按用户要求，仅将新消息权重 β 从 0.4 降到 0.2。更新规则仍为 (1−β)×旧消息 + β×新消息，因此降低 β 表示增大阻尼。此配置同时作用于原接收机的线性查询和反馈两处消息更新；未修改活动概率公式。

一阶 epoch 200、导数方差、新分类器 epoch 90 EMA、噪声估计、已知相位输入、0.5 门限及 60–600 轮停止条件完全相同。未训练任何网络，原始配置和完整 SNR 实验仍保持暂停。

固定此前出现错误的 8 个物理场景、10 个场景–SNR 组合，每个组合统计全部 40 用户。此为按错误选取的回顾性诊断，不能据此估计总体 AER 或宣称该阻尼已在独立集合上选优。
