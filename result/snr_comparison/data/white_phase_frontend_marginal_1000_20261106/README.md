## 执行入口

在仓库根目录设置 `PYTHONPATH=D:/afdm-gfra/src` 后使用项目 Python：

```powershell
.\.venv\Scripts\python.exe -X utf8 -B -m evaluation.white_phase_frontend_20261106.run inspect
.\.venv\Scripts\python.exe -X utf8 -B -m evaluation.white_phase_frontend_20261106.run coordinate
```

`coordinate` 和 `worker` 均在导入 torch/加载网络前检查两项前置完成证据与进程退出。协调器先做一次独立输入预检，核对相位前端复现、输出重新评分和资源预算，再启动最多 2 个工作进程。预检不计入正式 6000 份结果。`STOP.json` 停止派发并排空在运行任务；失败保留现场，不自动重试。明确检查过已有进程、锁及部分输出后，`coordinate --resume` 可复用完成结果；不完整目录会拒绝覆盖。

CPU 检查入口为 `src/tests/test_white_phase_frontend_20261106.py`。测试中的合成输入只检验接口、调用和门控，不是实验数据，也不代替后续 GPU 预检或正式结果验证。
