# 白噪声主 SNR：完成结果与配对比较

白/有色网络估计相位的最大绝对 NMSE 差为 0.104245 dB，最大 AER 差为 0.03 个百分点；低 SNR 白噪声结果略差，高 SNR NMSE 略好。该观察描述本批配对场景中的差异，不构成统计等价或未见测试集泛化声明。

相对同一白噪声网络的已知相位结果，估计相位 NMSE 损失为 0.279507–0.604199 dB。两者均使用现有权重，未训练或调参。

原读取故障、写入故障及其修复和旧结果均保留。收尾核验没有重新执行推断。主 SNR 之外的图源替换和额外扫描仍属于后续工作，当前稿为工作稿。
