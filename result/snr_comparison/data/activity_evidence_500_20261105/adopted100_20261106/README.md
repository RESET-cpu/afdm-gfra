# 100 场景活动证据对照完成

作者将原 500 场景预算改为每档 100 个配对场景（0–99），六档 SNR。两组 Gaussian 各采用 600 份新推断，两组密度比各复用 600 份，共 2400 份。停止时多派发的 1 份场景 100 输出保留在原目录，单独登记，不计入采用范围。原 PLAN 与停止状态保持，不将原 6000 次新增计划标为完成。

`summarize.py` 是独立只读评分入口，不运行推断，也不调用原 500 场景汇总。它核对停止授权、进程退出、配对输入、配置、权重、精度证据和逐份结果哈希，再重算活动指标及信道误差。`SUMMARY.json` 为 VERIFIED，`COMPLETION.json` 为 PASS；逐场景指标、来源哈希、汇总和完成收据相互绑定。已完成结果由完成收据保护，避免重复覆盖。

四组全部活动预测重新评分。STMP 密度比的 6 份完整信道预测可重评分，其余 594 份 NMSE 由已核对哈希的逐用户误差与真值能量重新汇总；另外三组均由完整信道预测评分。历史 `truth_used_in_inference` 聚合标志包括本实验允许的已知相位；核验分别确认通道/活动真值未加载、噪声真值未使用及已知相位接口。初次核验脚本将此聚合标志误作通道真值标志，按旧入口真实语义修正后重新完整核验，未修改推断和结果。

STMP Gaussian 的 9 次、GP-MP Gaussian 的 225 次有限迭代上限输出全部纳入。两组密度比均无上限输出。详细 AER、漏检/虚警及计数、NMSE、平均轮数和停止统计见汇总；论文只显示每档 AER (%) 与执行 600 轮的比例 (%)。

复现（在项目根目录）：`.venv/Scripts/python.exe -X utf8 -B result/snr_comparison/data/activity_evidence_500_20261105/adopted100_20261106/summarize.py`。入口拒绝覆盖已存在的完成收据；独立复查可直接按收据验证全部文件。
