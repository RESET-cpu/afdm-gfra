## 解释与尚未验证的部分

真实相位作为输入并不使当前神经网络与迭代接收机成为最优判决器。
源码明确使用近似神经网络输出与标量方差处理。不同相位算子下，保存的概率轨迹落在阈值两侧，
足以解释这一份有限样本的判决差异。更准确的相位与逐样本分类错误数之间没有在本实现中建立单调保证。
第 197 轮已有判决差异，因此不能简单以最终迭代次数差异解释此结果。
尚未强制延长已知相位到 311/600 轮，不能排除停止位置对最终数值的影响；
也未通过干预实验区分分类器、方差更新和其它近似各自的作用。

主批次和冻结参数均未修改。本核查未重新推断，未训练，未选择新阈值。
