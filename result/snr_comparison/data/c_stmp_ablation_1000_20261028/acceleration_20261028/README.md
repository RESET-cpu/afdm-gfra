# RTX 5080 并行接续

**2026-10-29 用户调整消融范围：高斯活动证据停止，两项高斯消融不单独出图。** 已安全保存2128份活动证据结果；纯高斯先验6000份保留。估计相位从3783份结果核验接续，仅补剩余2217份。旧三项完成后统一出图的安排由本次范围更新替代，见[仅相位接续](../phase_only_20261029/README.md)。

用户要求“让我的5080火力全开”。原串行阶段队列已排空，73份结果逐份核验哈希、
实际配置和重新评分通过；只继续剩余17927次推断。旧进程身份、状态和停止请求保留于 before/。

当前同时运行三项：纯高斯先验两个CPU进程；高斯活动证据和估计相位共用逐步扩大的GPU并发。
GPU起步两个进程，每45秒至多增加一个，最多六个；增加前检查最近采样平均利用率低于94%、
可用显存至少3500 MiB、可用内存至少2.5 GiB。满足条件才增加，达到利用率目标或内存限制时保持。
每个进程仍使用两条计算线程；不修改网络、数值精度、批内用户数、阻尼、门限或停止判据。
每个GPU进程只加载其负责版本，避免同时保留两套网络。一个版本完成后，释放进程或转给另一版本。

入口为 resume.py，当前已启动。最新状态同时写本目录与父目录 STATUS.json，
进程身份在 START.json，逐5秒显卡采样在 resources.jsonl，详细日志在 stdout.log/stderr.log。
父目录或本目录新建 STOP.json 可停止派发并保存全部在途结果。
原算法冻结计划保持原文；本目录 PLAN.json 是仅涉及资源的覆盖记录。
有限未收敛结果继续保留，数值异常停止派发并保留原因，不自动重试。
所有方法完成后复用原报告程序进行完整核验、汇总和出图。
