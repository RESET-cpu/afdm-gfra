## 结论

本快照295/852（34.62%）达到600轮上限。主要直接现象是活动概率持续变化、
不活跃用户反复跨越0.5判决门限，并经联合信道矩和方差反馈传播到后续迭代。
绝大多数不是仅略高于停止容差；也未发现支持范围回退、消息拒绝或方差裁剪在末段阻塞停止。
更重要的是，已收敛的557份高斯活动证据结果仍有34.34%的AER，说明当前替代证据还存在严重虚警，
不能只将问题解释成迭代预算不足。

这是对当前“从学习条件矩构造归一化高斯消息，再计算活动证据”近似的诊断，
不代表所有高斯活动证据方法都会失败，也不证明每个未收敛样本都属于同一种原因。

## 已排查的解释

1. **停止计数错误**：依据保存的每轮量重建全部852份消融及852份完整C-STMP的三个停止计数、首次停止时刻，共1704条轨迹，全部一致。实际采用当前配置中的0.0005/0.001等门限，不混用旧THEORY文档的历史参数。
2. **错误接入了旧信道模型或查询尺度**：当前配置与冻结配置一致；852对输入的第一轮查询方差及学习条件方差分别逐例完全相同。单元检查已验证同查询条件矩保持一致；替换活动概率后，后续查询和信道估计自然分离。
3. **查询超出训练支持范围、拒绝新消息、方差下限或外信息投影卡住**：295份未收敛轨迹最后100轮，这四类事件均为零；条件方差/查询方差的每例中位数范围约0.0071–0.0296，远小于拒绝阈值1。
4. **单用户导数方差出现负值**：该现象也出现在全部852份完整C-STMP的末段，不能单独解释消融差异。实际反馈使用跨用户平均后的条件方差；本批未收敛末段未触发其下限。导数方差近似可能参与敏感性，但未通过干预单独识别其贡献。

## 机制解释及证据边界

代码对高斯消息`CN(e,cI)`计算

`ell = ||r||²/v − ||r−e||²/(v+c) − D log(1+c/v)`，
`p = sigmoid(logit(rho)+ell)`。

本实验D=16×16×16=4096，包含完整维度的归一化项，活动先验只加一次。
这是对选定高斯消息的正确解析计算；但这里的e、c来自学习条件均值与导数方差，随当前查询变化，
并不因此成为真实结构化信道先验的精确边际密度比。
条件均值/方差合适，不能保证由它们构造的高斯活动证据准确。
既有推导 [THEORY.md §9–10](../../../../../../paper/C-STMP/docs/THEORY.md) 已给出这一区别和单点条件矩不能唯一决定活动证据的反例；该文中的旧停止参数不用于本次核验。

当前程序采用联合均值`p*mu`及联合协方差`p*tau*I+p*(1-p)*G`，
再将它们送入外信息和查询方差更新。因此活动概率误判和跳动会改变下一轮查询，
继而改变高斯活动证据。保存轨迹支持这一相互反馈解释，且不活跃用户贡献了绝大多数翻转。
这不是各环节因果贡献的独立证明，也不是整个迭代目标单调性的证明。

只看高斯活动证据已收敛的557份，仍有7626次虚警、25次漏检，AER为34.34%；

因此“数值收敛”与“检测正确”应分别报告，增加迭代上限并不能保证修复证据失配。
按是否收敛划分的子集是回顾性描述，不作独立显著性或因果比较。
