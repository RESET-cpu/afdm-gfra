# 前 30 个配对场景的收敛图

固定使用场景 0–29、SNR = 0 dB、已知相位、观测估计噪声。每种算法每个场景均实际执行 300 次迭代，共核验 150 份完整结果。NMSE 按总误差能量除以总活动信号能量后转为 dB；AER 按总错判人数除以总用户数。图中保留全部逐轮数据，不平滑，不补齐，不按结果筛选场景。

这是用户指定的 30 场景预览，完整实验仍为 50 场景。本次仅读取已保存结果，不运行推断，也不替换论文图片。

复现：在仓库根目录运行 `.venv/Scripts/python.exe -X utf8 -B src/evaluation/plots/convergence_first30_20261105.py`。
