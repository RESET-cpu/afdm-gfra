## 本批次观察

合成有色噪声下，新网络输入准确 C 在 −20、−10 dB 优于同网络输入 vI；在 0–30 dB 则退化，相关强度 0.5 时最大退化约 7.19 dB。没有省略这些不利点。
均匀接收机诊断组的六个 SNR×阶段条件中，新网络使用 vI 均优于旧网络；使用估计 C 均比同网络使用 vI 差约 0.32–1.94 dB。
这些观察支持继续检查新网络的协方差条件响应与训练目标适配；现有结果不能证明显式 C 普遍有益，也不能据此断言有色噪声模型本身不合理。

全批次约 46 分钟；1000 个合成场景、48 组接收机条件全部完成，未排除样本。逐文件哈希与汇总重算通过，PNG 图已视觉检查。
两种方法在同一输入上的差值为描述性配对结果；没有进行显著性检验，不声称实际误差 Gaussian、硬件实测或闭环改善。
