用户要求用训练中的最新候选再次对比已有网络。本次固定第 **92 轮 EMA**，与原白噪声网络第 **200 轮**及此前候选第 **10 轮**比较。训练继续运行，所有新输出不反馈到接收机。

复用 24 个仿真场景、每场景 −4/0 dB 两档接收 SNR，共 48 组条件。每组使用首轮、第 20 轮、最终轮三个保存输入，合计 144 份查询、5760 个用户查询。均匀抽取 12 场景与按旧漏检选择的 12 场景分开统计。

主指标为活跃用户 pooled NMSE：10 log10(活跃用户总误差能量/总真值能量)，单位 dB，越低越好。全部用户均执行推断，真值仅用于后续评分；非活跃用户的输出功率另存于 RESULT.json。

## 本次观察

第 92 轮候选在均匀组首轮查询上的 NMSE 比原 AWGN 网络改善 4.97/5.41 dB，两档 SNR 均为 12/12 场景改善。相较第 10 轮候选，同样输入上的首轮误差又降低约 53.5%/55.0%。

中后期进步同样明显，但当前 C 的作用随阶段变化：第 20 轮两档 SNR 中，相关 C 比同一新网络使用 vI 分别差 0.90/0.92 dB，全部场景均退化；最终轮 0 dB 中差 1.37 dB，也为全部场景退化。最终轮 −4 dB 的新 C 与原网络 pooled NMSE 接近（落后 0.03 dB），0 dB 仍落后 1.96 dB。

均匀组首轮的相关 C 相对 vI 额外收益仅 0.24/0.11 dB，描述性区间均跨 0；约 5 dB 的整体优势不能全部归因于显式 C。第 20 轮及 0 dB 最终轮出现明确的不利变化；−4 dB 最终轮差异较小且区间跨 0。不能单独区分工作协方差近似、噪声模型失配与有限网络条件响应等原因。

失败富集组的首轮也改善 5.14/5.52 dB；最终轮 −4 dB 改善 0.60 dB，0 dB 落后 0.32 dB。该组按旧漏检选择，只作困难条件诊断。

## C、核验及解释范围

- C 与前次完全相同：公开导频和接收噪声估计、原轨迹后验方差重建的线性工作协方差，按原参数阻尼递推，并投影到训练的 rank-4 加单位阵范围。Ra=I；没有用真值拟合 C。
- vI 使用原全局标量，相关 C 使用每用户功率和列相关方向；该对照同时改变功率和方向。
- 全部查询、公用输入及轨迹哈希、输入方差、真值能量和原 AWGN 误差与前次逐项一致。
- 协方差重建最大标量相对误差 1.088e-15；首组全部三个阶段重新执行 AWGN 网络，最大相对误差 0.000e+00。
- 无样本排除、无超范围输入方差；冻结绑定和原模型保护哈希通过。
- 首轮查询未受去噪器反馈影响；后续查询来自原网络轨迹。本次不检验新网络自身闭环轨迹、活动检测或运行时间。
- 不同训练预算，且样本是已多次查看的诊断集；不构成独立确认或等预算结构优劣结论。
- C 是近似工作模型，无法由此保证实际误差独立、高斯或跨轮不相关。
- 统计解释检查 11/11 完成，逐项范围保存在 COMPARISON.json；不作多重比较校正后的显著性声明。
