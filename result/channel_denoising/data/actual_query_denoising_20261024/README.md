使用已有低 SNR 诊断中保存的 24 个场景，每个场景 −4/0 dB 两个接收 SNR，共 48 组条件。每组包含第 1 轮、第 20 轮和最终一轮，共 144 份查询、5760 个用户查询。复用旧接收机轨迹，候选输出不反馈、不改变分类器或检测结果。

## 协方差与公平性

所有方法接收完全相同的实际查询 r。原网络使用原标量 v；新网络分别使用原 vI，以及从线性模块构造并投影到训练范围内的 C。后者使用每用户功率和输入列相关矩阵，天线因子为 I。因此两种 C 的比较包含功率与方向变化，不是单独隔离方向的实验。

C 只使用公开导频、按原接收机算法估计的噪声及原轨迹的输入/后验方差。用后验与输入方差之比恢复外信息方差，再恢复下一轮输入；未投影的完整列协方差按原 0.2 参数阻尼递推，在读取给网络时才进行 rank-4 加单位阵的投影。真值只用于所有预测完成后的评分。

上述 C 是原线性模块工作模型的近似；跨轮误差交叉项未知，参数阻尼不能解释为真实误差协方差。信号与误差相关以及非高斯误差也没有因此消失。公式及原有术语依据见 [线性接口说明](../../../../paper/docs/STMP_LINEAR_COVARIANCE_INTERFACE_20261024.md)。

## 活跃用户去噪结果

均匀组中，新候选在首轮输入上优于原网络，但在第 20 轮和最终轮明显落后。最终轮加入当前 C 相比同一候选使用 vI 改善约 0.42–0.77 dB，仍未达到已训练完成的原网络。因此合成噪声验证不能代替实际查询验证；同时，第 10 轮对第 200 轮不足以否定新结构或有色训练。

NMSE = 10 log10(所有活跃用户误差能量之和 / 对应真值能量之和)，单位 dB，越低越好。非活跃用户不参与此 NMSE；其输出功率保存在 RESULT.json 中。

## 核验与限制

- 所有 48 组协方差重建核验通过，标量方差最大相对差 1.088e-15。
- 保存的原网络输出已通过原诊断全组重算检查；本次另对首组全部三个阶段重算，最大相对差 0.000e+00。
- 5760 个用户查询均保留，所有输入方差在训练的 [0.001,100] 区间内，无删样本或裁剪输入方差。
- 正式绑定、原权重及保护文件哈希检查通过；本次没有重启、暂停或改变训练。
- 此结果检验候选在实际输入上的单次去噪能力，不能推出候选闭环活动检测、整体接收机 NMSE 或收敛性能。
- 样本为此前已经检查过的诊断集，包含按旧结果选择的场景；不属于新的独立验证集。
- 训练预算不同，而且新网络尚处早期；不能据此判定有色训练或网络结构最终优劣。
- 统计解释检查 11/11 完成：分层后报告阶段间排序差异；不从组均值推断每个用户；失败富集带有选择偏差及条件选择风险；不把活跃条件 NMSE 当作检测率；不从困难组变化推出回归均值以外的因果结论；无丢失样本；全阶段及全方法披露，区间不作多重比较后的显著性声明；方案在本次输出前固定，但使用既有诊断集，仍属探索；不把不同训练预算的比较解释为结构因果效应；真值未参与候选输入构造，不存在用目标误差反推 C 后再宣称预测收益的路径。
