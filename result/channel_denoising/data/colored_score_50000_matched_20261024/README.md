## 噪声变化及必要配套

采用已选定的单一条件复高斯族：C = v Ra ⊗ I_output ⊗ Rc。Ra/Rc 为独立的 16 维单位阵加归一化秩 4 矩阵，相关强度分别连续均匀取自 [0,0.5]。v 的 SNR 范围仍为 [-20,30] dB；不再拆分四类混合。

协方差形状使用独立随机数，不改变原数据排列、v 和基础标准高斯噪声的随机数流。网络条件输入增加 Ra、Rc，其新增权重置零，初始主干和原标量条件参数复用。损失与后验均值使用相应矩阵公式；原目标中的基础噪声直接保留为 epsilon，避免由 noisy-clean 反算的舍入误差。因条件维数和浮点计算路径改变，不声称优化轨迹逐位等同。

## 启动与记录

配置：`src/configs/training/colored_score_matched_20261024.json`。
入口：`python -B -u -m training.colored_score_20261024.formal train`（项目 .venv，PYTHONPATH=src）。

- `specification.json`、`recipe.json` 和 `source/` 保存配置、数据/源码哈希与精确源码快照。
- `PREFLIGHT.json` 保存完整 batch 64 GPU 检查；其一次优化步骤属于临时检查，不进入正式训练权重和随机数流。
- `status.json` / `training.stdout.log` / `training.stderr.log` 是实时状态和日志。
- `history.json` 保存每轮训练与验证；`first_best.pt` 是最低验证损失对应 EMA；`first_final.pt` 在正式完成时写出。
- `last.pt` 每 120 秒及每轮结束保存模型、EMA、Adam、数据游标和随机数状态；同命令可显式恢复。
- `complete.json` 出现且哈希核验通过才表示 200 轮完成。这里只完成训练，尚不能据此宣称低 SNR 活跃检测改善。
