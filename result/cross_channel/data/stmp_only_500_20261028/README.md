# STMP 跨信道单独图

用户于 2026-10-28 要求“用户数的图重新画一下，跨信道的 STMP 也画一下”。本目录只核验、重新评分并汇总已保存的 STMP 输出，不运行推断，不修改正在运行的六方法跨信道批次。

来源：`result/cross_channel/data/stmp_c_stmp_500_20261026`，24 个信道/SNR 条件，每条件场景 0–499，共 12000 份 STMP 输出。新消息权重保持 0.2，停止规则保持原样。NMSE 由总误差能量与总信号能量计算，AER 由总错误判决数计算，所有有限输出均保留。

`audit.py` 复用冻结报告中的输入、实际配置、预测及收敛记录核验与评分函数。`SUMMARY.json` 的完成状态只表示 STMP 子集完整，不能视为 C-STMP 或六方法跨信道比较已完成。历史紧凑结果按原流程核验保存的逐用户误差与活动概率，不能从已退役的完整信道预测重新计算。

`render.py` 将 D/A/B/C 四种信道各作为一条 STMP 曲线，合并 NMSE/AER 两个子图，采用既定 88.9 mm 单栏尺寸。数值统计中的算法身份始终为 STMP，图例区分信道。

论文中仅作为 STMP 阶段结果展示。完整跨信道比较完成后，须替换临时 STMP 单独图及“C-STMP 尚在运行”的说明，完成核验后按用户要求仅保留实际引用的独立 PDF。不得因单独图已完成而跳过原完整批次审计。
