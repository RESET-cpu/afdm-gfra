# 十层与十九个正式条件

本候选沿用第二版的score/活动头、消息公式、损失及梯度规则，只调整最大深度、
接收机样本分布及必要的执行内存选项。完整定义见
[第三版协议](../../docs/LSTMP_TRAINING_PROTOCOL_20261020_V3.md)。

`plan.py`构造四条正式单变量扫描的去重并集，共19个条件，SNR为
−4、−2、0、2、4、6 dB；不是14配置乘六SNR。4,750训练场景、1,900独立
开发验证场景。深度1–10各一轮适配、两轮联合，共142,500次更新。

准备、生成、冻结数据后，执行独立预检查，再启动运行目录中的
`start_training.ps1`。训练状态见`STATUS.json`；每个深度保留epoch0–3完整
验证和权重。创建`pause.request`可保存断点并暂停，移除请求后显式使用
`start_training.ps1 -Resume`恢复。旧运行保持暂停。
