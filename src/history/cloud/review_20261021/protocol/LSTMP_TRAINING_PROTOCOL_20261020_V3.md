# 十层接收机与正式实验条件对应的第三版训练协议

本版依据用户于2026-10-20提出的修改：停止正在运行的第二版；逐层扩展至十层；
调整训练数据分布；SNR采用−4、−2、0、2、4、6 dB；主训练范围严格采用正式
单变量扫描的19个去重条件，而不是14种配置与六档SNR的84种交叉组合。

## 范围与数据

默认条件为40用户、16导频帧、活动抽样概率0.1、SNR 0 dB。四条扫描如下：

| 扫描 | 取值 | 其他参数 |
|---|---|---|
| SNR / dB | −4、−2、0、2、4、6 | 默认值 |
| 用户数 | 20、40、60、80、100 | 默认值 |
| 导频帧数 | 8、16、24、32、40、48 | 默认值 |
| 活动抽样概率 | 0.05、0.10、0.15、0.20、0.25 | 默认值 |

来源：`experiment/_support/settings.py`、`snr_comparison.py`、`user_count.py`、
`pilot_frames.py`、`activity_probability.py`。默认条件只计一次，合计19个。
非默认用户数、导频帧数、活动概率均只与0 dB组合。具体条件由
`experiments/lstmp_training_v3_20261020/plan.py`确定并写入冻结清单。

每条件250个训练场景、100个开发验证场景，共4,750/1,900场景；保持原训练
场景总数的量级，并增加每个目标条件的验证覆盖。条件均衡分配场景数，默认
条件不因出现在四条扫描中而重复加权。这是预先固定的数据设计，不是按已有
性能重加权。原六组训练/验证和不利结果完整保留。

训练种子从202610206100001起，验证从202610206200001起；每个样本使用不同
物理场景种子，不将同一物理场景的不同噪声实现分到不同集合。生成前核查与
已保存接收机训练/验证数据的种子不重叠。独立测试种子另行保留，本入口不
生成或查看正式测试数据。

活动采样保持Bernoulli并拒绝全零活动，接收机使用对应的条件边缘先验。
连续时延/Doppler、原导频和信道模型沿用第二版冻结实现。原训练生成器最多
支持32帧；40/48帧使用正式实验`experiment/_common.py:observation`已有的
扩展方法：导频行取相同排列的前缀，前32帧标准噪声保留，后16帧来自固定的
独立随机流`[seed,2097]`，按完整接收功率设置噪声方差。适配入口与正式生成
结果进行配对核对，不把缺失的40/48帧条件删除。跨信道
模型实验仍保留为泛化评价，不将其测试信道混入本次训练。

本次继续使用已知相位、已知噪声的受控条件，单独研究条件接收机；这些结果
不等于正式未知相位/噪声接收机性能。后者需要独立评价，不在本次同时改变
前端和训练目标。

## 初始化、目标和梯度

完整数学依据与术语来源沿用
[第二版协议](LSTMP_TRAINING_PROTOCOL_20261020_V2.md)的T1–T11及其Cai、Wei原文定位。
十层是本项目计算预算选择，不声称来自Wei论文或已证明是最优深度。

复用同一个50,000信道AWGN预训练一阶score；每层权重独立。新训练从第一层
重新开始，不继承第二版已经微调的层或Adam状态。新层从原AWGN权重初始化；
前层继承本次运行上一深度选中的权重。活动头初值为公开先验，校准对数初值
为零。网络仍为DirectCai RefineNet；不增加二阶或方差网络。

固定RMS坐标尺度保持0.2647966452702405，AWGN先验二阶矩保持原绑定值。
仅从新训练集一次性计算总真值能量与总用户数，得到固定平均场景能量
`mean_scene_energy`和平均用户数`mean_users_per_scene`。验证标签不参与这些常数。

每层训练项为真实活跃用户的条件信道平方误差除以固定平均场景能量，加上
全部用户的自然比例BCE之和除以固定平均用户数。系数均为1，前层权重各0.2、
末层权重1，再除以层权重之和。有效信道仍由软活动概率乘条件均值计算。
真实活动只用于损失/评分，不用于推断或掩码预测输出。

两项损失均通过现有计算图更新允许训练的score、活动头和校准参数。保留
跨层路径；末层反馈beta不影响当前输出，因此不训练，增加下一层后再激活。
一般AFDM线性更新、残差反馈方差、正值处理与自然参数阻尼保持第二版公式。

## 阶段与选模

深度1至10均采用相同预算：

1. 新增层适配一轮：训练新层score、活动头、gamma/alpha，以及上一末层beta。
2. 全层联合微调两轮：训练全部有作用的参数，末层beta仍冻结。

适配学习率为score 2e-5、活动头1e-4、校准量1e-3；联合阶段统一乘0.1。
Adam betas=(0.9,0.999)、eps=1e-8、weight decay=0，全局梯度范数上限1。
每增加深度重建Adam；同一深度从适配转联合时保留已有优化器状态。
每轮完整遍历4,750场景，合计30轮、142,500次更新，不包含AWGN预训练。

每个深度完整评价epoch0及三个训练轮次。统一选择全体1,900开发场景上
末层条件信道损失+BCE最小的检查点，同值取较早者；它作为下一深度的初值。
保留所有深度和各轮结果，主十层模型仍按这一规则选出。所有条件活动门限
固定0.5，不按条件选择层数、检查点或门限。分条件和四条扫描曲线均报告，
汇总指标明确说明其19条件采样分布。

## 实现和核验

新入口位于`experiments/lstmp_training_v3_20261020`。沿用第二版的接收机、
目标、优化与验证代码，并在新运行目录复制冻结。第三版数据入口显式循环19
个完整条件，避免旧数据接口再次把配置与SNR做笛卡尔积。

运行目录：`D:/afdm-gfra-cpu/runs/lstmp_conditional_bce_v3_depth10_20261020`。
源代码、初始化、数据逐文件哈希、统计量及本协议在训练前绑定。开发检查
的优化结果全部丢弃。正式训练须通过数据覆盖/分离、继承公式一致性、梯度、
断点恢复，以及最大十层在全部19条件上的训练和验证容量检查。

为控制显存，使用既有activation checkpointing功能，在深度至少6时对全部
score层执行重计算，对所有条件统一应用；用户微批仍为100，Adam仍为fused实现。
这是执行方式，不改变消息公式、损失、参数独立性或更新预算。实际显存与
耗时通过完整十层反向传播测量，不按层数凭空承诺。

每层训练前分损失梯度诊断会额外执行反向传播，其容量也单独检查。若容量
检查需要调整执行方式，必须在正式启动前重做对应检查和清单绑定，记录原因。
训练过程中不静默更改样本、预算或目标。

启动前第一次容量检查中，原“深度至少6且用户至少60时重计算前7层”的配置
完成了全部19条件的十层更新，但最终可用显存未达到预设的0.5 GiB余量。
因此在正式训练前扩大重计算范围，并重新检查；没有修改检查门槛。

第二版已依用户指令在第五层第1轮第4,294步安全停止，累计61,894次更新。
前四层全部检查点、第五层可恢复断点及其原配置保留；没有把未完成训练标记
为完成。新方案在多个方面与历史运行不同，不作为单一因素或等预算消融结论。
