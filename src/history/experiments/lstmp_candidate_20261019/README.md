## 修改

- 正校准系数放到 softplus 正值化之后；反馈比率的下限采用平滑函数，避免硬截断将 beta 的梯度置零。
- 线性外信息直接计算信息比例，代数上保持原校准公式；不再通过两个接近 1 的数相减求外信息方差，也不依靠固定截断替代真实比例。
- 打包、线性迹平均、噪声能量与初始化尺寸从实际输入计算；支持配置不同用户数、导频帧数和活动概率。单用户网络块仍固定为 16×16×16。
- 训练/验证/测试配置可混合多个条件，场景收据绑定条件和生成器。已有先验库的重复导入 `json` 错误已修复。
- 可显式选择已知或估计相位、噪声。估计模式从公开观测和原始导频建立算子；标签与真实算子不进入该前端。
- 新算法与冻结对照共享前端生成的原始精度公开输入。历史权重＋0.2 阻尼，以及本机 50,000 样本权重＋0.1 阻尼分别记录。
- 保存每场景误差能量、真值能量、活跃/非活跃误差及检测计数；同时报告累计能量比和逐场景平均 NMSE，并按条件汇总。
- 收敛曲线使用最终五层模型的五个中间输出；分别训练的 1～5 层模型标为深度消融。

方差反馈仍是待学习校准的迭代参数，不宣称等于准确后验 MSE；没有向残差直接叠加 Cai 的活动混合方差项。
最后一层 beta 不影响最终输出，梯度为零属于预期；前四层 beta 的梯度连通性已检查。

## 入口与复现

从仓库根目录执行非训练检查：

```powershell
.venv/Scripts/python.exe -m pytest tests/test_lstmp_candidate_interfaces.py -q
.venv/Scripts/python.exe scripts/validate_lstmp_interfaces.py --output results/new_interface_check.json
```

第二个入口只做一次合成前向、反向及参数未变核对，不调用优化器。
实际执行记录位于 `results/lstmp_interface_repair_20261019/INTERFACE_CHECKS.json`。

训练入口为模块 `experiments.lstmp_candidate_20261019.train`，只有显式提供 `--train` 才会开始优化；
`--resume` 不能单独触发训练。此轮没有调用该训练入口。
配置默认读取本目录 `config.json`；可在进程启动前通过 `AFDM_LSTMP_CONFIG` 指定另一配置，
并指定全新的 `run_directory`。已有运行的配置、源码身份改变时会拒绝续跑。

本目录的混合条件是待训练的配置草案，继承的 16,384 样本预算不是原正式 5,000/50,000 配对协议。
默认仍为已知相位、已知噪声的诊断设置；估计模式必须显式选择并在结果中记录。
不要把已有预训练断点当成完成联合训练的五层接收机。
