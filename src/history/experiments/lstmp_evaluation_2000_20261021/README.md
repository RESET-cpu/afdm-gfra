# 十层评价执行包

本包已接入当前 [experiment/](../../experiment/README.md) 的八项公开入口：七项启用，旧三网络密度比消融暂缓。七项入口的 184 条小规模检查记录已通过；正式 2000 场景评价尚未启动。

## 文件分工

| 文件 | 职责 |
|---|---|
| [suite.py](suite.py) | 计划和命令分派、共享观测、相位估计、锁、接收机运行、计时与失败记录 |
| [receivers.py](receivers.py) | 十层冻结实现加载、旧三网络接入、四个原有基线接入、设备和参数量信息 |

实际流程是 `experiment/<实验>.py` → `experiment/_suite_entry.py` → 本包 `suite.main()`。公共观测/相位辅助函数仍复用 `experiment/_common.py`，跨信道与去噪辅助函数仍来自相应入口文件。

## 当前规则

- 十层固定 10 轮、选中 epoch 1、活动门限 0.5；接收机估计相位与噪声。
- 常规比较默认十层、Off-grid SBL、GNN-ASPL、GAMP-SBL、SOMP；旧三网络不执行。
- 去噪只评估预训练一阶网络，辅以噪声输入、Gaussian 和显式使用真值信息的 genie 参考。
- 收敛曲线已改为运行时间与精度比较；固定共享清单前 20 场景，−4/0/4 dB，每输入计时 3 次。
- 其余原每点 500 场景的实验使用 2000 个共享物理场景。密度比消融计划保留，但状态为 `DEFERRED_BY_USER`。

## 配对含义

四条主要扫描合计 19 种去重工况；跨信道 D 的六档 SNR 也复用对应输入。
共享场景不表示所有扫描点的接收矩阵相同：SNR 改噪声幅度，导频和用户数改变相应维度，活动概率改变掩码，信道模型改变抽头/衰落。几何和随机流按原物理生成规则配对；活动拒绝全零的抽样规则可能使活动集合不严格嵌套。

相位和噪声估计绑定当前观测，不能跨 SNR 直接移用。接收机指标按物理场景进行 10000 次配对重抽样；共享场景及每场景四条去噪信道不是额外独立样本。单场景检查不提供置信区间，独立去噪当前输出汇总误差能量与信号能量。

## 使用与修改

日常从 `experiment/` 的公开入口执行 `plan / inspect / run / summarize`，完整用法见[实验说明](../../experiment/README.md)。`shared_scenes.py --prepare` 是已完成的建表动作，不应对既有清单重复执行。

十层实际源码和权重来自 `models.json` 指定的 D 盘最终运行；本包负责接入，不复制或改写算法。冻结计划校验 Python 源码、配置 JSON 和模型文件。修改这些内容后要生成新计划，不能覆盖已有结果身份。README 的导航更新不改变推断或冻结资产。
